坐忘论第六篇精读：定极生慧，慧而不用，恬智相养而归真常；由有意守定进入无心于定而无所不定。

导读坐忘论司马承祯

坐忘论·泰定 ​

入读提示

无心于定，而无所不定

本篇由具体调心进入成熟定境，也是全书理论最精微的部分。它最重要的不是「定能生慧」，而是慧生以后怎样不破坏定——司马承祯直言：非生慧难，慧而不用难。

说定 形如槁木，心若死灰；虚静至极，则道居而慧生。说慧 慧出本性，非适今有；宝而怀之，勿以多知而伤于定。说养 以恬养智、以智养恬，智与恬交相养，和理出于性。

可与《天隐子·神解》对读：那里的「信定闲慧」四解，正是这里「定慧交养」的更简说法。

【原典层】原文 ​

一、泰定的定义及定极生慧

夫定者出俗之极地致道之初基习静之成功持安之毕事

形如槁木心若死灰无感无求寂泊之至

无心于定而无所不定故曰泰定

庄云宇泰定者发乎天光

宇则心也天光则发慧也

心为道之器宇虚静至极则道居而慧生

慧出本性非适今有故曰天光

但以贪爱浊乱遂至昏迷

澡雪柔挺复归纯静本真神识稍稍自明

非谓今时别生他慧

二、慧生以后，最难的是不用

慧既生已宝而怀之勿以多知而伤于定

非生慧难慧而不用难

自古忘形者众忘名者寡

慧而不用是忘名也天下希及之故为难

贵能不骄富能不奢为无俗过故得长守富贵

定而不动慧而不用为无道过故得深证真常

三、知道、言说与得道的区别

庄云知道易而弗言难

知而不言所以之天

知而言之所以之人

古之人天而不人慧能知道非得道也

人知得慧之利未知得道之益

因慧以明至理纵辩以感物情兴心徇事

触类而长自云处动而常寂

焉知寂者寂以待物乎

此语俱非泰定也

智虽出众弥不近道

本期逐鹿获兔而归

所得太微良由局小

四、以恬养智，以智养恬

庄云古之治道者以恬养智

智生而无以智为也谓之以智养恬

智与恬交相养而和理出其性

恬智则定慧也和理则道德也

有智不用而安其恬积而久之自成道德

五、泰定的形成与征验

然论此定因为而得成或因观利而见害

惧祸而息心捐舍涤除积习心熟同归于定咸若自然

疾雷破山而不惊白刃交前而不惧

视名利如过隙知生死如溃痈故知用志不分乃凝于神

心之虚妙不可思也

夫心之为物也即体非有随用非无不驰而速

不召而至怒则玄石饮羽怨则朱夏殒霜

纵恶则九幽匪遥积善则三清何远忽来忽往

动寂不能名时可时否蓍龟莫能测其为调御岂鹿马比其难乎

六、总摄修法：渐修与顿证

太上老君运常善以度人升灵台而演妙

略三乘之因果广万有之自然渐之以日损有为

顿之以证归无学喻则张弓凿矢法则挫锐解纷

修之有常习以成性黜聪隳体嗒然坐忘

不动于寂几微入照

履殊方者了义无日游斯道者观妙可期

力少功多要矣妙矣

【原典层】字词释义 ​

chū出sú俗zhī之jí极dì地

定是摆脱世俗爱恶、得失与躁竞所能达到的极深境地。非仅离开社会生活，而是心不再遵循世俗心的运行方式。

zhì致dào道zhī之chū初jī基

定又是达到大道的初步基础。与「出俗之极地」并观：从修心看定已极深，从证道看定仍只是基础。

yǔ宇tài泰dìng定

语本《庄子·庚桑楚》「宇泰定者，发乎天光」。本篇以「宇」为心之器宇：心虚而不受，便成为道所居之宇。

tiān天guāng光

本性智慧自然显发。天，自然本有；光，照明辨别。非外在光象，也非静坐中所见亮光。

bǎo宝ér而huái怀zhī之

慧生以后如珍藏宝物般含藏于心。怀，非拒绝一切必要运用，而是不急于宣说、炫耀、以慧换名。

wàng忘xíng形

静坐中不觉身体、对身形得失较为淡泊、能忍受简朴。司马承祯说自古能一定程度忘形者并不少见。

wàng忘míng名

不把修行所得变成新的自我资本（我是得定者、我是有慧者）。名相细微，常隐藏在修行成就之中，故比忘形更难。

dào道guò过

修道过程中特有的过失：因定自高、因慧好辩、以境界分高下。俗过易识别，道过常披着修道外衣，故更难察觉。

zhú逐lù鹿huò获tù兔

本欲逐鹿（得道、真常），却只捉到兔子（智慧、辩才、名声）。喻得少许慧解便满足，志向与心量太局促。

tián恬zhì智

恬，恬静，本篇释为「定」；智，智慧，本篇释为「慧」。恬智交养即定慧交养，语本《庄子·缮性》。

hé和lǐ理

心不偏于两端以后自然呈现的秩序。恬智达到和谐，合道之理便从本性中自然显现，本篇以之对应「道德」。

jí即tǐ体fēi非yǒu有suí，yòng随fēi用wú非　无

就体而言找不到固定可执的实体；就用而言却确实能感知、造业、生慧。故既不可执心为恒常实物，也不可落入断灭空无。

xuán玄shí石yǐn饮yǔ羽

「饮羽」谓箭入极深至箭羽没入。用李广射石传说，说明心志能强烈影响身体力量与行为结果。

zhū朱xià夏yǔn殒shuāng霜

朱夏，盛夏；殒霜，降霜。古代冤气感天之传说，属传统天人感应观，非现代气象因果。用以强调心念怨气力量巨大。

jiǔ九yōu幽

道教幽冥、苦难境界的表达。既可指死后果报，也可从现世心性理解为恶念长期放纵所形成的幽暗心境。

sān三qīng清

道教最高神圣境界（玉清、上清、太清）。「纵恶则九幽匪遥，积善则三清何远」两两相对。

shī蓍guī龟

蓍草与龟甲，古代占卜之法。此处夸张说明心念幽微迅疾，难以把握预测。

sān三chéng乘

佛教术语，通常指声闻、缘觉、菩萨三乘。唐代道教文献吸收并改造此类分类语言，「略三乘之因果」反映道佛交涉背景。

wú无xué学

佛教术语，指修学完成、已无更高内容需学的果位。此处借以表达能所双忘、不再刻意守定、由有为之学归入自然无为。

cuò挫ruì锐jiě解fēn纷

语本《道德经》「挫其锐，解其纷」。挫锐，不逞才不争胜不以慧炫耀；解纷，解除杂念、人事和名相纠缠。

chù黜cōng聪huī隳tǐ体

黜聪，退去自作聪明与向外炫用的智巧；隳体，松开对形体与自我身份的固执。非消灭智慧，也非损伤身体。

tà嗒rán然zuò坐wàng忘

嗒然，语本《庄子》，形容自我意识淡化、若有所丧的状态。所忘是身执、智执、名执与「我正在得定」的意识，而觉照未断。

jī几wēi微rù入zhào照

几微，极细微的念头与变化征兆；照，清醒觉察。谓寂静更深而觉照更细，念头尚在萌芽已被察觉——「息乱而不灭照」的完成形态。

xiū修zhī之yǒu有cháng常

修习必须持久而有常。不能依赖一时兴奋、一次深度体验或外界赞誉带来的动力，须落实为长期稳定不过度的训练。

xí习yǐ以chéng成xìng性

长期练习使安定成为自然性情。凡夫的逐境亦由积习而成，故此「自然」并不等于顺从当前习惯。

【解读层】精读 ​

全篇结构与六层读法 ​

前五篇的次第是：敬信确认大道可学、断缘减少俗缘、收心息乱而不灭照、简事舍去非要非重、真观以无欲之心照见爱恶生死。本篇则进入成熟定境。

「泰定」不是普通的平静，也不是静坐时偶然无念，而是：

心已经不再刻意求定，却在动静之中无不安定；智慧虽然自然显发，却不以智慧炫耀、逐物和生事。

text
由收心、简事、真观而入定 → 有意安心得以调熟 → 无心于定而无所不定
        ↓ 心虚静至极，道居慧生
慧本由定发，不是新添之物 → 慧生以后不炫、不逐、不多用
        ↓ 以恬养智，以智养恬
定慧交相涵养，道德自然显现 → 长期积习，渐若自然
        ↓ 黜聪隳体，坐忘入照
层核心问题
一 · 定义与定极生慧定在七阶中处于什么位置？槁木死灰是否昏沉？何谓「无心于定」？智慧是新生还是本有？
二 · 慧生以后最难的是不用怎样「宝而怀之」？多知为何伤定？「忘形者众，忘名者寡」何意？
三 · 知道、言说与得道为何知道易而不言难？「天」与「人」之别？「逐鹿获兔」批评什么？
四 · 以恬养智定慧怎样相互涵养？何谓「有智不用而安其恬」？
五 · 形成、征验与调心之难自然之定是否不需要有为训练？心为何「即体非有，随用非无」？
六 · 渐修与顿证「三乘」「无学」为何出现于道教论著？「黜聪隳体，嗒然坐忘」如何收束全篇？

一、定是「出俗之极地，致道之初基」 ​

「出俗」不只是离开社会生活，而是心不再遵循世俗心的运行方式：

text
俗心：见利便逐，见名便求，得则喜，失则忧，毁则怒，誉则悦
定心：见境而不黏，应事而不留，得失不足以夺其安，毁誉不足以改其志

所以身体离群独处未必出俗；心不再被俗欲支配，才真正开始出俗。

「致道之初基」与「出俗之极地」形成看似矛盾、实际重要的结构：

从俗世修心看从证道进程看
定是出俗的极深境界定只是证道的基础
text
无定 → 心随境转，无法见道
有定 → 心虚静清明，才具备发慧合道的基础

因此，不应把某次深度静坐体验当作全部修道已经完成。

「习静之成功，持安之毕事」承接【收心】「常须作意安之」「随起随制，久久调熟」：初学需要作意安定、念起即觉、避免非必要扰动；到了泰定，原先有意的「习静」「持安」已经纯熟，不再时时感到自己正在控制心。

text
初学之定：我在努力使心安静
泰定：没有一个突出之我在守定，心却自然不失其定

二、「形如槁木，心若死灰」是不是昏沉 ​

「形如槁木，心若死灰」承接《庄子》（《齐物论》有「形固可使如槁木，而心固可使如死灰乎」）。

  • 「形如槁木」：形体安静稳定，不再因欲望向外躁动，如同枯木不随境迁。不是说身体僵硬——若静坐时强行僵住身体，反而使心气不和。
  • 「心若死灰」：心中的贪爱、怨恨和躁动如火熄灭，不再随境燃烧。「死」的不是觉照，而是爱恶妄动：
text
贪火熄灭、怒火熄灭、名利之火熄灭、是非争竞之火熄灭
但觉照并未熄灭，智慧反而由此显发

死灰不是意识断灭，而是欲火不起；槁木不是生命僵死，而是形体不逐。

「无感无求」也不能机械理解成完全丧失感知：「无感」是不因境界产生黏著性的感动、不被外物牵引；「无求」是不追逐额外所得、不求名位、不求炫耀慧解，甚至不刻意追求「定境」。感知仍可存在，必要事务仍可处理，只是不再形成攀缘求取。

「寂泊之至」——「寂」防止散乱，「泊」防止占有；仅仅无声无念还未必淡泊，若仍执著「我的定境」，便不是真正寂泊。

三、「无心于定，而无所不定」 ​

初学的定带有对象性（我要守住清静、我要排除念头、我要保持这种状态），泰定则已不再需要这种自我监督：

text
不特意求静，却不随境乱
不害怕念头，却不为念头所带
不刻意维持定相，却在动静中皆不失其根

「无心」不是无意识：所消失的是守定的造作痕迹（造作心、求取心、「我正在入定」的自我标榜），而不是清明。

「无所不定」意味着安定不再只依赖固定环境：静坐时定，行动时也不散；无事时定，应事时也不被夺。但这不意味着证得少许定分后便应主动增加事务——处事不乱属功夫成熟后的自然结果，不是初学阶段的自我宣称。

为什么称「泰定」？「泰」有广大、安宁、通达之意：

text
守一处空境 → 定仍狭小
动静皆不失安 → 定乃广大
不以定为所得 → 故称泰定

四、「宇泰定者，发乎天光」 ​

《庄子·庚桑楚》有「宇泰定者，发乎天光」，《坐忘论》明确将其解释为定极发慧。

「宇则心也」——心如同容纳事物的空间：心被爱恶塞满便狭隘闭塞；心虚而不受便能容物。这与【收心】「心满则道无所居」「心安而虚，道自来居」相接。

「天光则发慧也」——「天」表示自然本有、非人为造作，「光」表示照明清楚。「天光」不是外在神秘光象，也不是静坐中看见特殊亮光，而是：对爱恶看得更清楚、对因果能由本知末、不再被自己的欲望欺骗、觉照明而不昏。若静坐时出现视觉光感，那只是身心现象，不能直接等同于此处的「天光」。

「心为道之器宇」——对人而言，道通过清静心体得到显明：心浊乱则道虽不失却不能显；心虚静则遮蔽减少而道用显明。「虚静至极，则道居而慧生」的次序是：

text
心虚：不被名相爱恶填满 → 心静：不再随境迁流
虚静至极：能安而无所著 → 道居：心与道相应 → 慧生：本有觉照自然显发

慧不是靠思虑堆积出来的，而是心不再被思虑遮蔽后自然显露。

五、「慧出本性，非适今有」 ​

这一句明确规定《坐忘论》的智慧观：修道不是把原来没有的智慧安装进心里，而是清除遮蔽，使本有灵明显露。

平常为何看不见本慧？「但以贪爱浊乱，遂至昏迷」：

text
心本有明 → 贪爱某境 → 爱则欲取，恶则欲避
→ 思虑不断增长 → 心逐渐浊乱 → 本有智慧被遮蔽

问题不在智慧消失，而在判断被爱恶预先扭曲。

「澡雪柔挺，复归纯静」——「澡雪」令人想到《庄子·知北游》「澡雪而精神」，即洗涤精神中的尘垢（「柔挺」底本文字较难，宜保留存疑）。修行不是增加本体，而是净除障蔽。「本真神识，稍稍自明」的「稍稍」说明这个过程通常是渐进的：最初只是偶尔发现念头，后来较能不随，再后来能看清爱恶的形成——不主张一次体验后便宣称彻底悟道。

慧本来有，不是修出来的新增物；遮蔽需要修，因此仍须长期用功。修的是障蔽，显的是本慧。

这与【敬信】「怀宝求宝」、【收心】「开识神本」前后贯通。

六、慧生以后为什么必须「宝而怀之」 ​

「慧既生已，宝而怀之」——「怀」不是拒绝一切必要运用，而是不急于宣说所得、炫耀见解、显示辩才、以慧换取名声。智慧原本由静定而生，如果立刻向外驰用，心又会重回事务和毁誉之中。

「勿以多知而伤于定」——定生慧以后，修行者可能发现思路更敏捷、对人更容易洞察、语言更有条理；这时最容易出现新的欲望：

text
想让别人知道自己有慧，想用慧解决所有问题
想参与更多争论，想以修道知识建立身份

「多知」若使心重新外驰，智慧便成了定的敌人。

「非生慧难，慧而不用难」——这里的「不用」不能理解为拒绝必要判断（【收心】已允许「有事或法要有疑者，且任思量……悟已则止」）：

text
必要时可以使用，但不用来逞能
事情解决便停止，不让智慧自行繁衍事务
有能力而不抢先表现，有见解而不求别人赞叹

「不用」主要反对的是多余、功利和自我表现式的使用。

七、「忘形者众，忘名者寡」 ​

「忘形」可表现为静坐时不觉身体、对身形得失较为淡泊、能忍受简朴生活——自古能一定程度忘形者并不少见。

「忘名」的「名」不只指社会名声，也包括「我是得定者」「我是有智慧的人」「我的见解高于他人」。形体粗重，较容易在定中暂忘；名相细微，常隐藏在修行成就之中：

text
舍弃财物，可能带来「清高」之名
远离世俗，可能形成「隐士」之名
智慧显发，可能形成「导师」之名
越想忘世，越可能建立新的修行身份

「慧而不用，是忘名也」——如果不求名，就不需要通过慧证明自己；因此「慧而不用」检验的不是智力，而是自我是否真正淡化。

「天下希及之，故为难」——人常愿意忍受清苦，却很难忍受：自己知道却不被人知道、自己能做却让别人去做、自己看得清楚却不争取最后发言、自己有所成就却没有相应名声。

八、世俗过失与修道过失 ​

贵能不骄，富能不奢，为无俗过，故得长守富贵。定而不动，慧而不用，为无道过，故得深证真常。

与富贵相对应，修道者也有自己的「财富」：定是内在安稳，慧是内在明见。但得定可能产生定执，得慧可能产生智骄——修道人也有特殊过失：

text
因定而自高、因慧而好辩、以境界区别高下、以见解控制他人

「俗过」容易识别，「道过」更难察觉，因为它往往披着修道外衣：以清静为傲、以无欲轻视他人、以智慧炫耀境界、以「无为」推卸责任、以「真观」随意评判他人。修道所得一旦成为自我资本，道便重新变成名利。 因此：慧生并不是终点；能否在慧生之后仍然清静无名，决定修行能否继续深入。

九、「知道易，而弗言难」 ​

这组文字见于《庄子》相关思想传统（通行本《列御寇》有接近表述）。

人一旦有所悟，往往产生立刻表达的冲动：希望被承认、希望纠正别人、希望确立权威、希望把瞬间体会固定成理论。言说本身并非错误，问题在于「为什么说」「何时说」「说后是否系心」。

text
知而不言，所以之天：有所知而不刻意炫说，使智慧保持自然无为
知而言之，所以之人：有知便急于表达经营表现，容易落入人为造作

必要教导当然可以言说；但若言说由争胜和名心推动，便从「天」落入「人」。

「能知道，非得道也」：

知道得道
能解释无为行动不再强作
能说明无著遇境确实不黏
能谈生死齐面对变化不乱
能讲忘名有慧而不求名

语言正确只是起点，不是证成。

十、为什么人重慧利，而轻得道之益 ​

智慧带来的好处很容易被看见（更会分析、更有辩才、更容易获得尊敬），这些都是即时、可见、可利用的「利」。得道之益却较难被俗心理解，因为它表现为不争、不显、不积、不被毁誉牵动，甚至不再强调「我得到了什么」。俗心以增加为利益，道却以减损为进益。

「因慧以明至理」本身没有问题——慧的正当作用正是辨明真妄、观察爱恶、了解修法。问题发生在下一步：「纵辩以感物情」——「纵」表示失去限度，智慧不再只是照理，而开始用于吸引听众、建立声誉、争取认同。慧于是从明道工具变成经营名声的工具。

「兴心徇事，触类而长」的完整链条：

text
由定生慧 → 因慧好辩 → 因辩得名 → 因名引来人事
→ 为应人事而动心 → 事务触类增长 → 心重新散乱

这正是「以智害恬，为子伤本」。

此时修行者还可能自称「我虽然身处纷繁活动，内心始终寂静」——这与【收心】【简事】反复批评的自欺相同。判断标准不能听口号，而要看：是否主动生事？是否受毁誉影响？是否因言说而期待回报？是否事后仍留心？是否定力因此减弱？

「焉知寂者寂以待物乎」——真正的寂不是「内守一个空境 + 外面继续无限生事」，也不是一边主动逐物、一边声称内心有个不动的核心；真正的寂是不主动兴心徇事，物来则应，物去则止。

十一、「本期逐鹿，获兔而归」 ​

譬喻所指
鹿得道、真常
兔智慧、辩才、名声
逐鹿修道
得兔而归得少许慧解便满足

智慧并非毫无价值，但与得道相比，它只是途中较小的成果。「所得太微，良由局小」——修道者若一获得特殊体验、经义理解、辩才或他人尊敬便认为已经完成，就把原本趋道的大志缩小成个人成就：

text
大道本来要求忘我，却拿智慧装饰自我
大道本来要求忘名，却拿修行换取名声
所以不是道太远，而是所求变小了

十二、「以恬养智，以智养恬」 ​

这段化用《庄子·缮性》，本篇将「知」释为「慧」、「恬」释为「定」，从而建立明确的定慧相养论。

  • 以恬养智：心越躁动，判断越容易被欲望和成见扭曲；心越恬静，智慧越容易保持清明。定不是压制智慧，而是智慧的养分。
  • 智生而无以智为也：不靠智慧谋名、不以智慧争胜、不因能做而事事都做、不因能说而事事都说。智慧只在确有必要时应物，用后即止。
  • 以智养恬：智慧生起以后，不任其向外驰散，反而用智慧看清造作之害，使心更加恬静。
text
恬静生智 → 智慧看清爱欲和多事之害 → 不再追逐 → 恬静更加稳固

若智慧只向外使用，则是「智害恬」；若智慧返照自身使心更安，则是「智养恬」。

「智与恬交相养」的正確关系是：

text
定生慧，慧护定；定使慧不乱，慧使定不盲；定而有照，慧而不驰

这正是【收心】「息乱而不灭照，守静而不著空」的成熟形态。

「和理出其性」——「和理」不是外加规则，而是心不偏于两端以后自然呈现的秩序（不偏于无知昏沉，不偏于多知躁动，不偏于执空，不偏于逐有）。本篇明确作出对应：恬＝定、智＝慧、恬智相养＝定慧相养、和理＝道德自然显现。这里体现了《坐忘论》的「道佛会通」：用佛教常见的「定慧」语言重新解释《庄子》的恬智结构，却将终点规定为道教的「道德」。

「有智不用而安其恬」不是反智，而是让智慧回到正确位置：智慧服务于道，而不是道服务于智慧；智慧保护清静，而不是清静成为炫慧资本。「积而久之，自成道德」——「自成」说明道德不是外表模仿（不是故意表现谦虚、不是压住骄慢而装作无我）。

十三、自然之定仍由有为修成 ​

「因为而得成」——这种看似自然无为的泰定，最初仍要通过有意识的修习才能成就：

text
起点：有意收心、有意简事、有意真观
中段：习惯逐渐改变
成熟：不再需要明显控制，咸若自然

不能因为终点无为，就否定起点的有为训练。

「因观利而见害」——原先只看见外物之利，经过真观又看见它附带的损害（名位有利却增加事务与毁誉、财物有利却增加忧失、美色有乐却引起系著、多知有用却可能伤定）。看见「利中之害」，欲望才不再只受眼前利益推动。

「惧祸而息心」是初步动机，仍带趋利避害性质，并非最高境界，却可以成为入门方便：最初因惧怕后果而止 → 后来因看清虚妄而舍 → 最终无所贪取，自然不动。

「捐舍涤除」——「捐舍」偏向外在断缘、简事，「涤除」偏向内在收心、真观；内外同时调整，定才容易稳定。

「积习心熟，同归于定，咸若自然」——「若自然」不等于从未训练，而是训练痕迹已经淡化：

text
初学书写：每一笔都须用意 → 长期纯熟：运笔自然
初学收心：每一念都需提醒 → 长期调熟：念来不随，事去不留

圣人的自然，不是未经训练的放任，而是修习成熟后的无痕。

十四、泰定的四种征验 ​

text
疾雷破山而不惊，白刃交前而不惧
视名利如过隙，知生死如溃痈
  • 「疾雷破山而不惊」——不是说身体完全没有自然惊跳反应；生理反射可以出现，关键是心不继续灾难化想象、长久恐惧、丧失判断。「不惊」主要指神不散乱。
  • 「白刃交前而不惧」——不是不避危险，也不等于鲁莽求死；真正的定会使人更清楚地采取合宜行动，而不是否认危险。
  • 「视名利如过隙」——如缝隙前一闪而过的光影：来得快、去得快、短暂不住，不再构成固定自我。
  • 「知生死如溃痈」——「痈」是积聚肿毒，溃破虽在感受上不愉快，却是聚结解除的过程。这个譬喻不应被理解为否定生命价值，更不能用来鼓励放弃治疗，它只处理自然死亡到来时的执著问题。

「用志不分，乃凝于神」（与《庄子·达生》专志凝神之说相通）——前面四种「不动」之所以可能，并非靠麻木，而是因为志不分于名利、心不散于爱恶、神不耗于多事，于是精神凝定。「凝神」是专一清明，不是意识封闭。

十五、心为什么比鹿马更难调御 ​

「心之虚妙，不可思也」——心没有固定形状，却能瞬间忆及远方、因一句话改变情绪、由一个念头引出无数联想、由定发慧也能由慧伤定。

**「即体非有，随用非无」**是本段最重要的心体论命题：

text
即体非有：就本体而言，找不到一个固定、可见、可执取的实体
随用非无：但随其作用看，心又能感知、思考、爱恶、发愿、调身、造业、生慧

故：心体非有，不可执作固定实体；心用非无，不可落入断灭空无

这与「守静而不著空」完全一致。「不驰而速，不召而至」——心不需要身体奔驰，瞬间便能到达远方；不必从外面召唤，一个念头随缘便突然出现。正因心念迅疾，收摄它比控制身体更难。

十六、「玄石饮羽」与「朱夏殒霜」 ​

「怒则玄石饮羽」用李广射石传说（类似故事见于《史记·李将军列传》），说明心志能够强烈影响人的身体力量和行为结果。「怨则朱夏殒霜」属传统天人感应观（古代有冤气感天、盛夏降霜的传说），不是现代气象学意义上的因果结论；司马承祯引用它，是为了强调心念和怨气力量巨大。

text
怒可发极强之力，怨可感非常之变
说明：心念虽无形，其作用却不可轻视

因此，调心不是处理无关紧要的「内在感受」，而是在调整可能影响行为、形神和业果的根本力量。

十七、「纵恶九幽，积善三清」 ​

text
纵恶则九幽匪遥：若放纵恶念恶行，九幽恶趣便离自己不远
积善则三清何远：若长期积累善行，与三清圣境相应又怎么会遥远

「九幽」既有死后果报意义，也可以从现世心性理解：恶念长期放纵，行为愈发偏曲，人际与生命环境恶化，心中长期处于怨恨恐惧——人在现世也可能先形成一种「幽暗心境」。

需要留意：前文曾说不可因见善而爱著，也说定者无感无求，这并不取消善恶：

text
不执著善名 ≠ 不行善
不以善自高 ≠ 善恶无别
慧而不用 ≠ 见恶不制、见善不为

真正要求是：行善而不居善名，去恶而不以憎恨污染自身。

「忽来忽往，动寂不能名，时可时否，蓍龟莫能测」——心既不是永远动也不是永远静，同一个对象今日喜爱、明日厌恶。这正证明爱恶不可作为真实根本。 因此「岂鹿马比其难乎」：鹿马有形可见、可以用缰绳约束；心却无形、迅疾、善于自我掩饰，甚至会利用修道理论保护欲望。真正修道不是控制外物，而是长期调御此心。

十八、渐修与顿证 ​

「太上老君运常善以度人，升灵台而演妙」——「常善」意味着随人根器、不拘一法、既有渐修也有顿悟。「略三乘之因果」使用佛教术语（声闻、缘觉、菩萨），反映本篇明显的道佛交涉背景：司马承祯并不避讳使用佛教修行术语，却把它们纳入太上老君的教化体系。

text
三乘因果：偏重修行次第与行为后果
万有自然：偏重道家本体论，万物依道自生自化
二者结合：既不否认修习次第，也不把道理解成人为制造

「渐之以日损有为」落实在七篇中就是：

text
断缘：损功利关系    收心：损杂乱思虑    简事：损非要事务
真观：损爱恶妄执    泰定：损对定慧的占有

「顿之以证归无学」借佛教「无学」表达：能所双忘、不再刻意守定、不再以修行求得某物。但「顿证」并不是没有此前的渐修——本篇已明确说「此定，因为而得成……积习心熟，咸若自然」。更准确的关系是：长期渐修 → 条件逐渐成熟 → 在关键处顿然契入 → 所证不再有修习造作之迹。渐与顿不是绝对对立。

「法则挫锐解纷」（语本《道德经》「挫其锐，解其纷」）——挫锐是不逞才、不争胜、不以慧炫耀；解纷是解除杂念、人事和名相纠缠：

text
有慧而不露其锋，有知而不增加纷争

十九、「修之有常，习以成性」 ​

修道不能依赖一时兴奋、一次深度体验、偶尔读经后的感动或外界赞誉带来的动力；必须落实为长期、稳定、不过度的训练。

text
凡夫的逐境也是习以成性：反复受毁誉→敏感；反复逐欲→贪著；反复多事→躁动
修道则逆转这种积习：反复觉察→不再随念；反复简事→心有余闲
                    反复真观→爱恶渐薄；反复安养→定慧相资 → 清静若自然

所谓「自然」并不等同于原封不动地顺从当前习惯——当前习惯本身可能正是长期染习的结果。

二十、「黜聪隳体，嗒然坐忘」与「不动于寂，几微入照」 ​

  • 「黜聪」：退去自作聪明和向外炫用的智巧。不是消灭智慧（前文说慧出本性、定极发慧、以智养恬），所黜的是多知自负、辩才争胜、以慧求名、以机心控制事物。
  • 「隳体」：松开对形体与自我身份的固执（承接《庄子·大宗师》颜回坐忘「堕肢体，黜聪明，离形去知，同于大通」）。不是损伤身体，而是不以身体为固定自我、不以感官满足为中心。
  • 「嗒然坐忘」：安坐之中，形体、智巧与自我占有逐渐淡化，进入坐忘。所忘是对身体的执著、对聪明的占有、对名声的追求、「我正在得定」的意识——但觉照并没有断灭。

「不动于寂，几微入照」是篇末极为关键的一句：

text
不动于寂：安住寂静而不再随境迁动；同时不把「寂」执为固定对象，寂而不滞、静而能照
几微入照：心安于寂静以后，极细微的心念和变化也在清明觉照之中

寂静更深 → 觉照更细
念头尚在几微 → 已经清楚察觉（不必等到形成强烈欲望才发现心已随境）

这正是「息乱而不灭照」的完成形态：

text
初学：乱念形成后才察觉
进步：念头初起便察觉
泰定：几微未著，已在觉照

因此，「不动于寂」是定，「几微入照」是慧；两者同时出现，才是泰定。

二十一、「力少功多，要矣妙矣」 ​

「游斯道者，观妙可期」——「可期」不是承诺固定时间，而是说方法与结果之间具有清楚次第。「力少功多」不是完全不修，而是不用强力压心（不与念头激烈搏斗、不追求复杂技术、不依奇异玄谈、不强造特殊境界）：

text
减少而不是增加，放下而不是攫取，长期调熟而不是一时猛进

所以看似用力少，实则切中根本，功效深远。「要」在于抓住心这个根本；「妙」在于最终不依强制，而由积习归于自然。

（「履殊方者，了义无日」文字较难解，可能涉及版本或断句问题；依上下文可谨慎理解为：若不断驰逐各种旁杂方法，想要究竟通达真实义理，恐怕遥遥无期。）

本篇最重要的七组辨析 ​

不是而是
昏沉无知寂静而发天光
刻意守住定境无心于定而无所不定
后来增添新智慧净除遮蔽，本慧自明

容易误解的地方 ​

  1. 「槁木死灰」不是抑郁和情感麻木——它指贪爱躁动止息，并非失去生命意愿或全部情感。如果现实中持续出现情绪低落、兴趣丧失或功能受损，应寻求专业帮助，不能将其美化为定境。
  2. 「无感无求」不是失去正常反应——自然生理反应与必要需求仍在，只是不因它们形成强烈系著。
  3. 「慧而不用」不是反对知识与理性——正当事务仍可使用智慧；所反对的是逞能、求名和由慧生事。
  4. 「不言」不是永远沉默——经典本身就是言说。该说时可以说，但不以言说证明自己，不让言说引出无穷事务。
  5. 「白刃当前不惧」不是鼓励冒险——面对危险仍应避让、自救和求助；泰定所说的是心不因恐惧完全失去判断。
  6. 「知生死如溃痈」不是轻生——它针对自然死亡的执著，不是鼓励主动毁弃生命。
  7. 「纵恶九幽、积善三清」属道教业报体系——可以理解其宗教意义，但不能借此简单判断现实受苦者的前世善恶。
  8. 「天光」不是视觉光象——它是本性智慧显发；静坐中的明暗、光点等感觉不应被轻率解释为证道。

实践检验 ​

一、是否越来越依赖特定环境？ 若只有在绝对安静、无人打扰时才能保持安定，一遇事务便烦躁，说明已有少许静境，但尚未达到泰定。

二、智慧增长以后，事务是否反而增加？ 观察：是否更喜欢参与争论？是否总想纠正别人？是否因见解得到认可而兴奋？是否用「弘道」之名扩大人事？——如果「慧」使人越来越忙、越来越好辩，就可能已出现「以智伤定」。

三、能否「悟已则止」？ 问题未明可以思考，问题已明应当停止；事情未济可以用智，事情已济不再反复经营。若事情结束仍不断复盘、辩护和炫示，就尚未做到「慧而不用」。

四、是否建立了新的修行身份？「我是比别人清静的人」「我是已经看破名利的人」「普通人无法理解我的境界」——这些念头说明粗重名利虽减，微细的「道名」却可能生起。忘名不是没有社会姓名，而是不把修行所得变成新的自我资本。

五、定是否伴随清明？ 若静中长时间昏沉、意识模糊、身心僵硬紧张，便不符合「发乎天光」和「几微入照」。真正的泰定应趋向：身心安稳、觉知清楚、反应不过度、寂静而非麻木。

六、慧是否反过来保护恬静？ 真正的智慧应使人更清楚地看见哪些事务不必参与、哪些话不必说、哪些名声不值得追求——如果智慧使生活越来越简静，便接近「以智养恬」；如果使欲望、事务和自我评价越来越多，则是「以智害恬」。

完整路线图 ​

text
长期习静、持安 → 形不逐境，心不燃欲 → 寂泊至极 → 无心于定，而无所不定
        ↓ 心宇泰定 → 道居慧生，发乎天光
慧非新生，只是本有神识除蔽自明
        ↓ 慧既生已，宝而怀之
不以多知伤定，不以辩才求名，不因智慧重新生事
        ↓ 由忘形进一步达到忘名

        ↓ 能知道，不等于已经得道
若因慧纵辩，便会兴心徇事、触类而长
原本志在得道，最终却只得到辩才与名声——本欲逐鹿，却获兔而归
        ↓ 因此须以恬养智，又须以智养恬

        ↓ 长期积习，心渐调熟，有意守定的痕迹逐渐消失，咸若自然
疾雷不能惊其神，白刃不能乱其心，名利如过隙，生死如溃痈

这条路线最值得注意的是：它不是由「无知」走向「有知」以后便结束，而是经历了更完整的回环：

text
散乱无明 → 收心入定 → 定极生慧 → 慧照至理 → 不以慧外驰
→ 慧反过来保护定 → 定慧相养 → 道德自成 → 最终连定慧之名也不再执著

换句话说，【泰定】不是单纯的「越来越静」，而是经历三个阶段：

阶段状态主要危险
由乱入定作意收心，止息外驰昏沉、执空
由定生慧本有智慧逐渐显发多知、好辩、自骄
定慧相养慧不外驰，反养恬静执著定慧为个人所得

真正的泰定必须同时具备：定（心不随境迁流）· 慧（几微变化皆能觉照）· 无为（不以定慧建立自我）· 自然（不再刻意守定而无所不定）。

小结 ​

本篇集中回答了一个贯穿全书的问题：心怎样从有意控制，进入真正自然的安定？ 答案不是突然取消一切修习，而是：

text
先以有为收心 → 再以真观看清爱恶 → 长期积习使心调熟
→ 定极而本慧自明 → 慧生后不向外炫用 → 反以智慧保护恬静
→ 定慧交相涵养 → 最终无心于定而无所不定

最核心的四句话是：

无心于定，而无所不定，故曰泰定。慧出本性，非适今有。非生慧难，慧而不用难。智与恬交相养，而和理出其性。

因此，【泰定】不是把心训练成一块没有反应的木石，而是使它成为一种寂而常照、慧而不驰、应而不乱、用而不有的存在：寂静，却不昏沉；明慧，却不炫耀；能应物，却不主动生事；有所知，却不以知建立自我。

到了这里，修行已经由「我在用功」逐渐转向「自然如此」，由「守定」转向「忘定」。但泰定仍主要说明心如何定、慧如何发。下一篇《得道》将进入全书最后阶段：当形神与大道真正契合以后，人的身心会发生怎样的转化？所谓「得道」究竟是获得某种神异能力，还是彻底消除人与道之间的隔碍？

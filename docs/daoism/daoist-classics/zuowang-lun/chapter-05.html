坐忘论第五篇精读（上/下合并）：由无欲观妙，于衣食而不贪、于色境而不著；观贫病生死，从「被境所困」转为「以境炼心」。

导读坐忘论司马承祯

坐忘论·真观 ​

入读提示

观本知末，又非躁竞之情

收心使心不随念头散乱，简事使形神不为万事耗损；真观进一步追问：我们为什么会被某种境界吸引、排斥或困扰？这层爱恶所依赖的判断，究竟真实可靠吗？它不是观看异象，也不是预测吉凶。

先立观 收心简事，日损有为，体静心闲，方可观妙。次观境 衣食如船、色由想起、善恶不引为己病、贫病生死皆可观。后辨心 「合境之心观境」终身不觉有恶；须以「离境之心」才见是非。

本篇较长，按所观对象分为六节。可与《天隐子·存想》对读：一篇收心，一篇观理。

【原典层】原文 ​

一、何谓真观

夫真观者智士之先鉴能人之善察

究傥来之祸福详动静之吉凶得见机前

因之造适深祈卫足窃务全生自始至末

行无遗累理不违此者谓之真观

然一餐一寝俱为损益之源一行一言堪成祸福之本

虽作巧持其末不如拙诫其本

观本知末又非躁竞之情

是故收心简事日损有为体静心闲方可观妙

经云常无欲以观其妙

然修道之身必资衣食事有不可废

物有不可弃者当须虚襟而受之明目而当之

勿以为妨心生烦躁

若因事烦躁者心病已动何名安心

二、衣食如船舫

夫人事衣食者我之船舫也

欲渡于海事资船舫渡海若讫理自不留

因何未渡先欲废舍

衣食虚幻实不足营为出离虚幻故求衣食

虽有营求之事莫生得失之心即有事无事心常安泰

与物同求而不同贪与物同得而不同积

不贪故无忧不积故无失迹每同人心常异俗

此实行之宗要可力为之

三、观色欲

前虽断简病有难除者但依法观之

若色病重者当观染色都由想尔想若不生终无色事

当知色想外空色心内妄妄想心空谁为色主

经云色者想尔想悉是空何有色也

又思妖妍美色甚于狐魅狐魅媚人令人厌患

虽身致死不入恶道为厌患故永离邪淫

妖艳惑人令人爱著乃致身死留恋弥深

为邪念故死堕诸趣生地狱中

故经云今代发心为夫妻死后不得俱生人道

所以者何

为邪念故

又观色若定是美何故鱼见深入鸟见高飞

仙人观之为秽浊贤人喻之为刀斧

一生之命七日不食便至于死百年无色翻免夭伤

故知色者非身心之要适为性命之仇贼

何须系著自取消毁

四、观他人善恶

若见他人为恶心生嫌恶者犹如见人自杀

己身引颈乘取他刀以自害命

他自为恶不遣我当何故引取他恶以为己病

又见为恶者若可嫌见为善者亦须恶

何以然耶

同障道故

五、观贫病

若贫者亦审观之谁与我贫

天地平等覆载无私我今贫苦非天地也

父母生子欲令富贵我今贫贱非父母也

人及鬼神自救无暇何能有力将贫与我

进退寻察无所从来乃知我业也乃知天命也

业由我造命由天赋业之与命犹影响之逐形声

既不可逃又不可怨唯有智者善而达之

乐天知命故不忧何贫之可苦也

庄云业入而不可舍

为自业故贫病来入不可舍止

经云天地不能改其操阴阳不能回其业

由此言之故真命也非假物耳有何怨焉

又如勇士逢贼无所畏惧挥剑当前群寇皆溃

功勋一立荣禄终身

今有贫病恼乱我身则寇贼也我有正心

则勇士也用智观察则挥剑也恼累消除

则战胜也湛然常乐则荣禄也

凡有苦事来迫我心不以此观而生忧累

则如人逢贼不立功勋弃甲背军逃亡获罪

去乐就苦何可悯焉

若病苦者当观此病由有我身若无我身患无所托

经云及吾无身吾有何患

次观于心亦无真宰内外求觅无能受者

所有计念从妄心生

然枯形灰心则万病俱泯

六、观生死与总归

若恶死者应思我身是神之舍身今老病

气力衰微如屋朽坏不堪居止自须舍离别处求安

身死神逝亦复如是

若恋生恶死拒违变化则神识错乱失其正业

以此托生受气之际不感清秀多逢浊辱

盖下愚贪鄙实此之由

若当生不悦顺死不恶者一为生死理齐二为后身成业

若贪爱万境一爱一病

一肢有病犹令举体不安

况一心万病身欲长生岂可得乎

凡有爱恶皆是妄生积妄不除以妨见道

是故须舍诸欲住无所有徐清有本

然后返观旧所爱处自生厌薄

若以合境之心观境终身不觉有恶

如将离境之心观境方能了见是非

譬如醒人能观醉者为恶如其自醉不觉其非

经云吾本弃俗厌离世间

又云耳目声色为子留愆鼻口所喜香味是怨

老君厌世弃俗独见香味是怨嗜欲之流焉知鲍肆为臭哉

【原典层】字词释义 ​

xiān先jiàn鉴

在结果完全出现以前便有所鉴察。非无根据地预知未来，而是从已存在的细微征兆看见可能的后果。

shàn善chá察

善于辨别细微的原因、倾向与后果。

tǎng傥lái来

偶然而来、忽然而至。近《庄子》「物之傥来，寄者也」之义：得失常因条件暂时聚合，非可永久占有。

jiàn见jī机qián前

机，事物变化的细微开端。谓在结果充分形成以前看见其趋势，并据此调整。

zào造shì适

采取适当行动，使之趋向合宜。

wèi卫zú足

保全自身，不使自己陷入危险；亦有谨慎自守、不使性命受损之意。

yí遗lěi累

遗留的牵累。行无遗累，谓从开始到结束都不留下后续负担——这是判断真观的重要标准。

qiǎo巧chí持qí其mò末

用高明技巧挽救事情的末端后果。与其如此，不如「拙诫其本」——在起点上谨慎防范。本篇明确贵拙而抑巧。

xū虚jīn襟

心胸虚静，不以贪爱占有。对必要之衣食，「虚襟而受之，明目而当之」。

chuán船fǎng舫

船。人事衣食如渡海之船：是工具而非终点；未渡不可先舍，渡讫则理自不留。

xiǎng想ěr尔

想，心的构画标记。染色都由想尔，谓对美色的染著主要由心的想象、命名与反复加工形成。

hú狐mèi魅

古代关于精怪魅惑人的文化想象。本篇以美色甚于狐魅为喻：狐魅令人厌患，美色却令人主动爱著。

zhū诸qù趣

佛教语，指六道众生所趣之处。原文以「死堕诸趣」为业报警示。

zhēn真zǎi宰

语本《庄子·齐物论》「必有真宰，而特不得其朕」。此处谓内外求觅，找不到一个独立不变、专门承受苦患的主宰。

kū枯xíng形huī灰xīn心

对形体的执著如枯木般不再繁兴，妄动之心如死灰般寂静。与《泰定》「形如槁木，心若死灰」相近。

hé合jìng境zhī之xīn心

已与境界黏合、认同、沉迷的心。以此观境，终身不觉有恶。

lí离jìng境zhī之xīn心

已开始离开、不再完全认同那个境界的心。以此观境，方能了见是非。本篇真观之要害。

bào鲍sì肆

卖腌鱼、咸鱼的店铺，气味浓重。古以「久入鲍鱼之肆，不闻其臭」喻久处不良环境而渐不自觉。

【解读层】精读 ​

全篇结构与上下篇划分 ​

【真观】是七阶中由「定」转向「慧」的关键一篇。前四篇大致完成了准备：

text
敬信：确立方向    断缘：减少功利关系
收心：停止随境迁流   简事：减去非要、非重、非当之事
真观：运用清明观照，从根本上识破旧有执著

【收心】主要是使念头不再继续扩展；【真观】则进一步追问：我们为什么会被某种境界吸引、排斥或困扰？这种爱恶所依赖的判断，究竟真实可靠吗？ 因此真观不是观看异象，也不是预测吉凶的神秘能力，而是对原因、后果、需要、欲望与执著机制的深入观察。

部分范围所观
上篇「夫真观者」→「同障道故」真观的定义（由本知末、见机于先）；衣食舟航；色欲；善恶
下篇「若贫者亦审观之」→ 篇末贫穷；苦难（业与命）；疾病、生死；万境爱恶；离境而观

阅读提醒 下篇包含鲜明的唐代道教业报观与神识观。需要同时保留两个视角：原典宗教视角（业、命、神识、托生与后身）与心性修养视角（停止归怨、正视现实、减少由抗拒和执著增加的心理负担）。原文将贫病解释为「自业」与「天命」，属古代宗教思想，不能直接用来责备现实中的贫困者、病人或受害者，也不能替代医疗、社会救助与现实责任分析。

一、真观不是预测术，而是「见机于先」 ​

「智士之先鉴，能人之善察」——「先鉴」不是无根据地预知未来，而是从已经存在的细微征兆看见可能的后果：

text
一次纵欲看似只是短暂享受，真观却能看见它如何强化习惯
一件事务看似只有眼前利益，真观却能看见它将引出多少牵累
一句话看似无关紧要，真观却能看见它可能造成怎样的关系与业果

「真」就在于不只看眼前感受，还看完整因果。

「究傥来之祸福，详动静之吉凶」——「动静」不只是身体动或不动，还包括：此时应当行动还是停止？这件事应当承担还是舍弃？这句话应当说还是保持沉默？真观不是一味以「静」为好、以「动」为坏，而是观察：这一动是否合时合宜，这一静是否只是逃避或昏沉。

「得见机前，因之造适」可用「念头—习惯—行为—后果」的链条理解：普通人只在严重后果出现后感到痛苦，真观则在念头初起时已经看见它将走向何处。因此「见机前」与【收心】「随起随制」互相配合：

text
收心：念起时及时觉察，不继续跟随
真观：明白为什么不应跟随，看见后续因果

没有真观，收心容易变成勉强压制；有了真观，放下才逐渐成为主动选择。

「深祈卫足，窃务全生」——真观的目的不是增长谈论玄理的能力，而是避免以轻害重、以欲伤生、因言行不慎制造后患。

「自始至末，行无遗累」是判断真观的重要标准。一件事不仅要看当下能否完成，还要看：会不会留下人情债务？会不会加强欲望？会不会造成长期心理负担？会不会为了短期利益损害长远性命？普通的「巧」常只解决眼前问题，真观则连后续遗累一起观察。

因此真观包括四个基本能力：

text
观因：看见结果从何而来       观机：看见事情尚未成熟时的征兆
观末：看见行动可能造成的后果   观累：看见事情结束后是否还会留下牵缠

真观不是追求异象，而是对因果和心行的如实辨别。

二、「一餐一寝，一行一言」皆是损益祸福之本 ​

修道的祸福，不一定始于重大选择，也可能始于饮食是否适度、作息是否合宜、是否为了欲望忽略基本休息——这与《天隐子》【斋戒】【安处】相应：真正的观照不离生活细节。

一句话说出以后，可能引起争执、伤害关系、建立虚假承诺、强化自我形象；也可能化解冲突、澄清责任。因此真观不是等后果出现再补救，而是在言行开始以前便观察其必要性——是否当说？是否当做？是否当由我承担？是否当在此时进行？

「虽作巧持其末，不如拙诫其本」——与其等事情发展出后果再用巧妙手段挽救，不如在根本处以朴拙谨慎的方法预先防止：

text
先放纵言语，再巧妙解释 → 不如起初少说一句
先承担过多事务，再研究时间管理 → 不如起初慎重取舍
先任欲望增长，再用强力压制 → 不如念初即觉，不再续接

司马承祯在这里明确地贵拙而抑巧——因为许多所谓聪明，只是在不断解决自己先前制造的问题。

「观本知末，又非躁竞之情」——心若急躁，就只想立即获得结果；心若好胜，就倾向于相信自己想相信的东西。真观必须建立在相对清静中。

三、真观必须以收心、简事为前提 ​

「收心简事，日损有为」化用《道德经》第四十八章「为学日益，为道日损」。「日损」不是损害生命，而是减去多余事务、欲望追加、功利关系、反复思虑、自我表现、对结果的强行控制——【真观】不是在旧有生活上增加更多分析，而是在减损以后，以清明的心看见事物。

「体静心闲，方可观妙」：「体静」对应外在事务有所减少、身体不再过劳；「心闲」对应不被毁誉塞满、不被得失驱迫、内心留有观察空间。如果心正被强烈欲望占据，它的所谓观察往往只是替欲望寻找理由。

text
先静 → 后观；先减欲 → 后见妙；先不随境 → 后能如实看境

「常无欲，以观其妙」（《道德经》第一章，原章还有「常有欲，以观其徼」相对）：

text
有欲之观：看见对象如何为我所用（它能给我什么？我能否占有它？）
无欲之观：看见对象本身如何成立、变化和消散

真观并非没有观察能力，而是让观察不再由贪爱预先决定答案。

四、修道仍然需要衣食，衣食如船 ​

「修道之身，必资衣食」这一句防止把「简事」「无欲」理解为厌弃一切生存条件。司马承祯不赞成为了追求「无事」而先毁坏修道所依之身。这与【断缘】篇末「若事有不可废者，不得已而行之」、与【简事】「辨别非要非重者」完全相接。

「当须虚襟而受之，明目而当之」给出两个尺度：

text
虚襟：虽接受，却不据为固定所有
明目：虽参与，却清楚它只是必要手段

既不贪恋，也不厌恶；既不无限经营，也不因害怕「有为」而拒绝基本需要。「勿以为妨，心生烦躁」——修行者有时会对事务产生另一种执著（认为只有绝对安静才能修，一有人打扰便愤怒）。这种烦躁说明心仍然依赖外在条件才安定。故反问：「若因事烦躁者，心病已动，何名安心？」 真正的安心不是完全没有事务，而是非必要之事不造、必要之事能够承担、承担时不贪不怨、事情完成后不再留滞。

「人事衣食者，我之船舫也」：

譬喻所指
大海生死、烦恼与修道过程
渡海者修道之人
船舫身体所需的衣食条件
到岸完成修道目标

船不是最终目的，却是渡海工具。修道须避免两个极端：把衣食财物当作终极目的；把基本衣食视为绝对障碍。「渡海若讫，理自不留」强调「自然不留」，而不是在尚未完成需要时强行舍弃——若因错误理解「无欲」而故意拒绝必要营养、不顾疾病、使形神因匮乏无法修习，就是「未渡先舍船」。 真正的简素，应以能否支持性命与修道为尺度，而不是以受苦程度衡量境界。

「衣食虚幻，实不足营，为出离虚幻，故求衣食」是一种「以幻渡幻」的工具观：衣食不是终点，但能维持修道之身；身体不是恒常，但正可借身体实行修道。衣食之求是否妨道，取决于它在整个价值结构中的位置——若衣食服务修道，便是船舫；若修道服务享受，便是本末倒置。

五、「有营求之事，无得失之心」 ​

「虽有营求之事，莫生得失之心」——「营求」是外在行动，「得失」是内在系缚。这正是【断缘】「不得已而行之，勿遂生爱」的深化。

text
可以求衣食，但不把求取变成贪欲
可以处理事务，但不把结果等同于自我价值

「即有事无事，心常安泰」——真正的安心不能只在「无事」时存在：

text
无事时安静，有事时全然失守 → 定力尚依赖环境
有事能应，无事能静，两者皆不留滞 → 心逐渐具有自主性

（这不意味着初学可以重新无限增加事务；此处说的是不可废的必要之事。）

「与物同求而不同贪」——修道者不必为显示清高而故意做出完全异于常人的外表：

世俗之求修道之求
以占有为满足以足用为限
得一求二得其所需即止
用所得确认自我把所得视为暂时工具
害怕失去知其无常，不深系著

「与物同得而不同积」——「不积」既包括物质层面，也包括心理层面：不积聚超出需要的财物、不积累人情债务、不收藏赞誉、不把一次所得变成继续追求更多的起点。

「不贪故无忧，不积故无失」——不是说修道者现实中永不遭遇损失，而是说：

text
外在变化仍会发生，但心没有建立庞大占有
因此可失之物减少，因失而生的忧惧也随之减少

所有权越成为自我中心，失去时受到的冲击越大。「不积」是在根源上减少「我的东西必须永远存在」的要求。

「迹每同人，心常异俗」是本段最精彩的一句：正常衣食、正常做事、正常承担责任，却不以占有为成功、不以积累为安全、不以得失定自身价值、不把工具变成归宿。这说明《坐忘论》并不以奇装异行作为修道证明——真正的差别首先在心如何与事物相处。

六、「染色都由想尔」：欲望如何由想象形成 ​

「前虽断简，病有难除者，但依法观之」——这句话说明【真观】为什么位于【收心】【简事】之后：

text
断缘：减少外在诱因    收心：不继续跟随念头
简事：减少生活负担
但旧有习气仍可能存在 → 必须真观其本

某些执著不是单靠隔离环境就能消失；若只是压住，它会在因缘适合时重新生起。

此处「色」主要指男女情欲、对容貌身体的迷恋。当作如下理解：「病」不是把身体或正常情感本身宣布为罪恶，而是指反复幻想、强烈占有、明知有害仍不能停止、把对方当作满足欲望的对象。原文属出家道士的戒欲语境，措辞十分严厉；现代阅读应把握其调心目标，不宜扩张为对身体、伴侣关系或所有情感的污名化。

「当观染色都由想尔」——外在身体只是身体；心进一步进行选择某些特征、命名为美、反复想象、加入满足期待、把对方变成欲望对象，于是形成「色染」：

text
外在形色 → 心作美想 → 反复想象 → 欲望强化 → 执著与追求

真观不是说对象完全不存在，而是看见「欲望对象」并不只是外界直接给予的，它也由心的想象建构。

「想若不生，终无色事」——不是要求第一眼的感知完全消失，而是不继续进行心理加工：

text
见到形色 → 只作如实觉察 → 不反复想象 → 不附加占有 → 色欲之事无从扩大

这与【收心】「随觉则除」完全相应。「想不生」更准确地说，是染想不被续接。

七、「色想外空，色心内妄」 ​

  • 「色想外空」：向外观察，所谓值得贪著的「美色」，并没有一种独立、固定、永恒不变的美性（受年龄、健康、光线、文化标准、观察者偏好、关系记忆等条件影响）。「外空」不是否认身体存在，而是否认「固定美性」可以由对象自身永久保持。
  • 「色心内妄」：向内观察，贪著美色的心又由妄想、投射和分别形成——同一对象，一个人觉得美，另一个人可能无感；欲望强时觉得极美，心境改变后又可能不同。
  • 「妄想心空，谁为色主？」：一层层松开——
text
向外观：美色没有固定不变的本性
向内观：色欲由想象和分别形成
再观想心：念头来去生灭，也没有固定主宰
由此可见：对象、欲望和占有者都非恒常

「谁为色主」不是否定责任，而是瓦解「有一个固定的我必须占有这一对象」的执著结构。

「色者，想尔；想悉是空，何有色也」只称「经云」，具体出处暂不宜强定，其思想明显带有佛教色空、想蕴与观心传统的影响。它的修行意义是：所谓可贪之色，很大程度上依赖内心想象；若看见想念本身无常、空而不实，色欲便失去原有的绝对力量。 但不能由此推导为「他人的身体只是我的想象」，更不能否定他人的主体性和现实边界——它处理的是欲望如何在自己的心中成立。

八、「狐魅」譬喻与「美是否有固定标准」 ​

「妖妍美色，甚于狐魅」——狐魅使人恐惧厌患，美色却使人主动爱著：真正危险的不只是外境，而是心把危险视为可爱。 原文由此引向邪念、诸趣、地狱等宗教警示。现代阅读可保留两层：

  • 原典宗教层面：邪淫形成业力，可能招致死后恶趣果报；
  • 心性修养层面：欲望若长期受到反复想象和行为强化，即使外境消失，心理惯性仍会延续，并继续制造痛苦。

（应尊重原文宗教语境，同时不把其业报描述冒充为现代经验科学结论。）

关于「今代发心为夫妻，死后不得俱生人道」的「经云」，其出处尚应存疑。从上下文看，它并不是断言所有现实夫妻关系本身皆属邪恶，所批评的重点应是由强烈情欲、占有和邪念结成的执著。需警惕两种过度解释：不能把所有婚姻与亲密关系一概视为邪淫（「邪淫」通常具有不正当、破坏伦理边界、伤害他人的含义）；也不能完全抹去原文的出家戒欲立场。稳妥的理解是：本段从出家修道立场严厉批评以情欲和占有为核心的男女执著，并以业报思想加强警戒。

「又观色若定是美，何故鱼见深入，鸟见高飞？」化用《庄子·齐物论》——毛嫱、丽姬为人所美，鱼见之深入、鸟见之高飞、麋鹿见之决骤。若某种容貌具有绝对、普遍、固定的美，为何其他动物并不趋近？为何不同的人审美并不完全相同？因此美色并非脱离观察者、恒常自立的绝对属性。

「仙人观之为秽浊，贤人喻之为刀斧」运用的是「对治观」：当爱欲过强时，暂时改变观察角度，打破心中过度美化的单一图像。平常欲望只选择性地看见容貌、快感、占有后的满足；对治观则有意看见被忽略的一面（身体无常、欲望可能造成的失控、得失忧惧、对心神的耗损）。目的不是仇恨身体，而是纠正被欲望美化得过度失真的认识。

「七日不食便至于死，百年无色翻免夭伤」通过对比区分必要与欲望：

饮食色欲
个体生命直接需要并非身体存续的直接必要条件
完全缺乏会危及生命不满足不等于不能生存
应取其适度对出家修道者则主张断除爱著

「色者非身心之要，适为性命之仇贼」——需注意「色者」主要指使心染著的色欲，不宜把所有美感、身体或人与人之间的关怀都视为「仇贼」。真正成为「仇贼」的是反复幻想、强烈占有、不顾边界、以欲望支配判断。伤害并不完全来自外境，而来自「系著」：

text
外境存在，未必直接成为病
心反复想象并系著，才使它持续占据生命

这就是【真观】的作用：不是只说「不可欲」，而是看清为什么不值得系著。

九、见他人为恶，为什么反而伤害自己 ​

此处必须区分：辨别恶行与让厌恶长期占据内心。真观并不取消善恶判断——面对伤害行为，仍可以制止、远离、追究责任、保护受害者。问题在于：事情处理之外，是否把他人的恶行不断带回心中，转化为自己的愤恨与散乱。

犹如见人自杀，己身引颈，乘取他刀以自害命。

譬喻心理含义
他人拿刀他人造恶
自己引颈自己生起长期憎恨
借刀害己把他人的恶变成自己的心病

他人作恶已经是一重损害；若自己因此长期愤怒、失眠、反复想象，便又增加了第二重损害。这正是【收心】所说「莫将心受。受之则心满，心满则道无所居」。

text
恶行需要辨明，责任需要处理，边界需要建立
但处理完以后，不再以憎恨反复伤害自己

十、「见恶若嫌，见善亦须恶」究竟是什么意思 ​

这是本部分最容易误解的一句。若按字面孤立理解，似乎是在说善恶相同、见善也要厌恶——这显然与全书重道德、去贪残的立场不合。关键在最后四字：「同障道故」。

它不是说道德上的善恶相同：从行为后果看，善行与恶行不同，应当作出合宜辨别（【收心】本身已经批评「不简是非」）。真正「同障道」的是对善恶之人的爱憎执著：

text
见恶生憎 → 心被排斥所系
见善生爱 → 心被贪著所系
对象虽一恶一善，系心结构却相同

因此「见善者亦须恶」更稳妥的理解是反诘：如果只因见到恶而允许自己陷入嫌恶，那么依同样的逐境逻辑，见到善也会陷入爱著；爱憎二者都可能妨碍心的虚静。其核心不在厌恶善人，而在破除对「善恶名相」的黏著——知善恶而不使爱恶成为心的主人。

如实辨别爱憎系心
知道恶行有害因恶行长期仇恨
知道善行可取因善名盲目崇拜
根据事实处理根据好恶扭曲事实
事毕能放反复收藏毁誉
text
不执善 ≠ 不行善；不憎恶 ≠ 纵容恶
不受善恶名相 = 不让爱憎遮蔽如实判断

这正是「真观」之真。

十一、观贫：停止向外归怨 ​

「若贫者亦审观之，谁与我贫？」——这不是要求贫者否认现实困难（贫穷可能真实影响饮食、居所、医疗、安全、教育与社会机会）。司马承祯所要处理的是贫困发生以后，心不断追问并怨恨某个绝对施加者的倾向：

text
我现在贫困 → 必定有某个对象故意使我如此 → 我要不断怨恨这个对象
→ 心因此长期受贫困与怨恨双重压迫

他试图通过逐层排查（天地平等覆载无私 / 父母生子欲令富贵 / 人及鬼神自救无暇）使心停止无休止的归怨。但从现代社会视角看，贫困当然可能与制度、灾害、剥削、家庭条件和偶然事件有关；因此本段不能被用来否认现实原因——它关注的是修道者面对已经形成的处境时，怎样避免心完全陷入怨尤。

「进退寻察，无所从来」——不是先说贫穷没有任何现实原因，而是说它通常不是一个单独主体把某个叫作「贫」的实体送给我；贫穷是多种条件共同形成的状态。

十二、「业」与「命」：既不可逃，又不可怨 ​

概念本篇中的侧重
业自己过去行为积累而来的后果
命超出当前主观控制的既定条件
text
只讲命：容易完全消极，否认人的责任
只讲业：容易认为一切都能由当前意志控制
业与命并说：承认行为会形成后果，也承认既成条件并非立刻可改

必须再次强调：把贫病一概归为个人过去造业，属于古代宗教解释，不能成为责备弱者的依据；现实中的贫病需要现实分析和救助。

从心性训练角度可以作较稳妥的理解：

text
已形成的处境 → 暂时不能否认，属于当前必须面对的条件
当下如何回应 → 仍有一定选择余地，会形成新的行为后果

也就是说：过去和环境形成了我现在面对的局面；但我此刻怎样面对，又参与塑造未来。 这避免了单纯宿命论。「业之与命，犹影响之逐形声」是道德因果比喻，但现实因果往往极为复杂，不宜机械理解为「某人遭遇某种苦难，就一定是他做了与之完全对应的坏事」。

「既不可逃，又不可怨」不是说不可采取行动改善贫病，也不是禁止指出不公：

text
不能靠否认现实代替处理现实
不能靠不断怨恨代替可以实行的改变

若有改善贫困、治疗疾病、寻求援助的现实途径，当然应当采取。真观反对的是：一边拒绝面对事实、一边让怨尤不断消耗心神，却不处理当前可处理之事。

「唯智者善而达之」的「达」不是把贫穷说成好事，而是：看清处境、接受已经发生的事实、分辨可改与不可改、对可改者采取行动、不让贫穷成为全部自我身份。「乐天知命，故不忧」则承认：

text
可为者 → 尽力而为         不可强为者 → 不以焦虑继续强求
结果已至 → 如实承担        下一步可行 → 清醒选择

「何贫之可苦也」——物质匮乏的现实困难是一层苦；因比较、羞耻、怨恨和自我否定又增加一层苦。 真观未必立刻取消第一层，却尝试不再制造第二层。

十三、勇士与寇贼：逆境如何转化为修道之机 ​

譬喻所指
贫病恼乱寇贼
正心勇士
用智观察挥剑
恼累消除战胜
湛然常乐荣禄

这个比喻防止把「知命」理解成软弱消极——面对贫病，不是躺下任其摆布，而是以正心立定方向、以智慧分辨苦因、采取现实可行之法、不让忧惧继续扩张。

「我有正心，则勇士也」——不是强行保持乐观，而是不否认困难、不被恐惧完全控制、不因逆境放弃道德、保留采取行动的能力。

「用智观察，则挥剑也」——真观必须转化为实际辨别：哪些痛苦来自客观处境？哪些来自自己的想象和灾难化判断？哪些可以通过求医、求助、调整生活改善？哪些暂时不能改变？「观察」不是坐着解释一切，而是帮助作出合宜行动。

「恼累消除，则战胜也」——真正要战胜的，不一定是令贫病当场消失，而是「不再被恼累完全占据」。即使疾病仍需治疗、贫困仍需改善，心若能恢复清楚、稳定、不怨、不乱，便已经取得一部分胜利。

「湛然常乐，则荣禄也」——这里的「乐」不是感官兴奋，而是不再与事实无休止搏斗、心仍有一处不被外境完全夺走的安定。

关于「弃甲背军」譬喻的限度：原文语气很强，需要谨慎理解。现实中，面对重大贫病、创伤和丧失，人出现悲伤、恐惧、无助、情绪崩溃，并不等于道德失败，更不能因此受到责备。真观是一项渐进训练，不是要求人在苦难中立刻表现得毫无情绪。较合理的理解是：情绪可以出现，但不要因一时无力便彻底放弃治疗、求助和重新安顿身心的可能。 真正的「挥剑」有时正包括向专业医者求助、接受社会支持、暂停过度事务、承认自己需要休息。

十四、观病：疾病依身体而成立 ​

「当观此病由有我身」——疾病是身体处于特定变化时的状态，它不是人格的全部：

text
我正在经历疾病 ≠ 我就是疾病本身

「若无我身，患无所托」不是要求伤害身体，更不是鼓励以死亡逃避疾病，而是在作哲学观察：疾病与忧患依身体条件成立，不是一个脱离身心、永恒存在的实体；既然依条件成立，它也处在变化中——可能加重、缓解、治愈，也可能需要长期共处。病不是固定不变的「我」。

引《道德经》第十三章「及吾无身，吾有何患」（原章讨论宠辱与身体执著）：

text
有身 → 身有老病变化
执身为固定的我 → 对变化增加巨大恐惧
松开身体执著 → 病苦仍在，但由执著追加的忧患可以减轻

（再次强调：「无身」主要是放下对身体的绝对执著，不是现实地毁弃身体。）

十五、「次观于心，亦无真宰」 ​

如果只说「病由有身」，仍可能认为「有一个固定的『我心』正在承受身体施加给我的痛苦」。所以进一步观察：这个承受痛苦的「我」，是否也有一个固定不变的主宰？

「内外求觅，无能受者」——身体中可以找到疼痛感觉、紧张、疲劳；心中可以找到「这很痛」的判断、对未来的恐惧、希望疼痛停止的愿望；但这些都是不断变化的过程，难以找到一个完全独立、恒常不变的「受者」。（此处带有明显的佛教无我、五蕴观照色彩，同时被纳入道教坐忘体系。）

「所有计念，从妄心生」——需区分：

  • 实际病痛：身体确实存在的不适，需要诊断和治疗；
  • 追加之苦：想象最坏结局、反复问「为什么是我」、把病情等同于自我价值、因恐惧而拒绝合理治疗。

真观并不否认前者，而是减少后者。

「枯形灰心，则万病俱泯」与《泰定》「形如槁木，心若死灰」相近，不是说身体真的枯死、心智完全断灭，而是身体不再成为自我执著中心、爱恶不再不断煽动心火。此处「万病俱泯」不宜理解为所有器质性疾病必然痊愈——它首先指由妄心、爱著和忧惧形成的「心病」止息；患病时仍应接受合理医疗。

十六、观死：身体是「神之舍」 ​

譬喻所指
房屋身体
居住者神、神识
房屋朽坏身体老病
离开旧屋身死神逝

原文借房舍自然损坏，缓解人对死亡的绝对恐惧，把死亡从「绝对毁灭」重新理解为「生命状态的变化」。这一观法建立在神识不随肉身完全断灭的宗教信念上，并非现代科学已经证实的结论。

「自须舍离，别处求安」不应理解为鼓励主动结束生命——原文讨论的是自然衰老死亡时的态度，而不是以人为方式提前「舍身」。《坐忘论》开篇以「贵生」为本，修道又以保全形神为目标，因此观死是为了减少对自然死亡的恐惧，不是为了轻视或放弃当下生命。

十七、「恋生恶死」为什么会扰乱神识 ​

这里批评的不是珍惜生命，而是「恋生」：

贵生恋生
保养身体把身体当作永恒自我
珍惜生命机会要求生命永不变化
合理治疗疾病因恐惧而拒绝面对衰老
顺应自然限度以强烈抗拒增加精神混乱

在道教业报框架中，临终心念会影响后续托生，因此要求修道者平日便练习：不把身体视为绝对自我、不因变化完全失去安定、不在临终时陷入强烈贪恋和恐惧。从一般心性层面看，它也指出：越拒绝一切变化，变化到来时越容易陷入混乱。

「以此托生，受气之际，不感清秀，多逢浊辱」属于传统道教的禀气、托生与业报论述。现代阅读不能用这类说法给现实中的认知障碍、贫困或社会弱势贴上「前业所致」的标签——这样既超出了可验证范围，也容易造成伤害。这里应把它限定在原文的宗教业报体系内。

十八、「当生不悦，顺死不恶」与「一爱一病」 ​

「当生不悦，顺死不恶」不是冷漠，而是对生死两端不作绝对取舍：生来，珍惜而不贪恋；死至，面对而不憎拒。「一为生死理齐」——生与死是同一变化过程的两端，只爱生而绝对恨死，是只接受变化的一半；「理齐」不是说生死在现实感受上完全一样，而是说它们都属于自然变化。「二为后身成业」再次把当下修心与「后身」相连；即使暂不接受后身理论，从现世修养看，不以恐惧和贪恋支配当下，也有助于更清醒地安排生命。

「若贪爱万境，一爱一病」——「爱」在此指占有性的系著（它必须属于我、必须保持不变、没有它我便不能安定）：

text
爱名 → 怕毁    爱利 → 怕失    爱色 → 怕离
爱位 → 怕退    爱己见 → 怕被否定

每建立一种这样的依附，心便多出一个可能被扰动的入口。「一肢有病，犹令举体不安；况一心万病，身欲长生，岂可得乎」——把心病与道教长生目标联系起来：

text
所爱越多 → 所忧越多 → 心神越乱 → 精气越耗 → 形神俱弊，与长生之道相反

「凡有爱恶，皆是妄生」——爱与恶方向相反，实质都让心围绕对象旋转（爱：我要得到它；恶：我要摆脱它；共同点：心的安定都由对象决定）。「妄」主要指把无常对象当作恒常、把一时感受当作固定自我、要求外境完全按自己意愿存在——并非否定正常情感：

text
关怀亲友 ≠ 要求亲友永远符合我的期待
欣赏美好 ≠ 必须据为己有

「积妄不除，以妨见道」——爱恶会预先规定观察结论：所爱者倾向于只见其好，所恶者倾向于只见其坏，符合己见者倾向于轻易相信。所以要有真观，必须逐渐松开爱恶。

十九、「舍诸欲，住无所有，徐清有本」 ​

text
是故须舍诸欲 → 住无所有 → 徐清有本 → 返观旧所爱处，自生厌薄
  • 「舍」不是压抑到完全不承认，而是通过真观看清：此物是否生命所需？欲望如何由想象构成？所得是否真能带来恒常安定？失去时心为何如此恐惧？——看清以后，欲望对心的支配力自然减弱。
  • 「住无所有」与【收心】完全相接：不让任何境界成为必须占有的固定依托。
  • 「徐清有本」的「徐」非常重要：爱恶由长期积习形成，不适合猛烈强压。
text
强迫自己立刻无欲 → 容易产生紧张与反弹
依法持续观照 → 欲望逐渐失去虚假美化 → 本心慢慢清明

「然后返观旧所爱处，自生厌薄」——真正的「厌薄」不是靠仇恨欲望形成，而是价值体验已经改变：过去只体验声色带来的刺激，所以认为它最可爱；后来体验到清静安定，并看清欲望的后果，所以旧爱自然失去吸引力。这与【收心】「平生所爱，已嫌蔽陋」相应。

二十、为什么必须先「离境」才能观境 ​

「若以合境之心观境，终身不觉有恶」：

text
正在贪名 → 会把追名解释成责任心
正在贪利 → 会把积累解释成安全需要
正在色著 → 会把占有解释成真情
正在愤怒 → 会把仇恨解释成正义

心已经与境相合，观察便失去距离。欲望最强时，心只看见眼前满足，不容易看见长期耗损、关系伤害、自主性丧失、失去时的痛苦。

「如将离境之心观境，方能了见是非」——这说明【真观】必须以【断缘】【收心】【简事】为前提：

text
先暂时离境 → 欲望强度减弱
心不再完全被对象占据 → 获得观察距离
再返观旧境 → 才看见此前忽略的后果

「醒人观醉」：清醒的人能够看见醉酒者言行失常，醒者因为没有处在同一种迷乱状态中才能辨别。这正是真观的认识论——

被一种欲望完全占据时，心无法只凭更多思考摆脱欲望，因为思考本身也可能替欲望服务。

所以必须先通过断缘、简事、收心、暂离诱因、安住清静，使自己从「醉」中稍微醒来，然后再观。而「暂离」不是最终回避：

text
初学：暂离强烈诱因，保护心神
中段：在距离中观察欲望机制
深入：看清其虚妄，爱著自然减弱
成熟：再次接触相应境界，也较少被染

正如【收心】所说，最终目标仍是「在物不染、处事不乱」，但不能跳过前面的离境训练。

「嗜欲之流，焉知鲍肆为臭哉」——「鲍肆」是卖腌鱼咸鱼的店铺，古以「久入鲍鱼之肆，不闻其臭」喻久处不良环境而渐不自觉。欲望有适应作用：

text
初次接触 → 感受强烈 → 长期重复 → 逐渐习惯
为获得原有刺激 → 追求更强对象 → 久而久之 → 把被欲望支配当作正常

这也解释了为什么需要经典、善友与暂时离境：经典提供不同尺度，善友帮助指出盲点，离境使习惯刺激减弱，收心使内在活动变得可见，真观使人重新辨认其中利害。

容易误解的地方 ​

  1. 真观不是算祸福——「究傥来之祸福」是从原因观察后果，不是预测不可知未来。
  2. 无欲不是没有正常需要——衣食仍须取得；无欲指不贪、不积、不以得失扰心。
  3. 衣食如船不等于身体毫无价值——身体正是修道所依，未完成修习以前不能任意损害。
  4. 「色空」不是否定他人真实存在——它观察欲望如何由想象与投射形成，不是否定他人的人格、意愿与边界。
  5. 戒色不能转化为身体羞耻——原文针对染著、邪念与纵欲，不应扩张成对身体或所有正常情感的仇恨。
  6. 不嫌恶他人不等于纵容恶行——可以依法依理阻止伤害，只是不把对方的恶继续变成自己的心病。
  7. 「善恶同障道」不是善恶行为没有区别——真正同样妨道的是对善恶对象的黏著性爱憎。
  8. 知命不等于宿命——知命是承认当前条件、分辨可为与不可强为；宿命则认为一切努力都无意义。
  9. 不怨不等于不求公正——面对不公，可以澄清事实、保护自己、寻求法律与社会支持。
  10. 观病不等于拒绝医疗——真观减少由恐惧执著增加的心理层面，医疗处理身体层面，二者不相互取代。
  11. 身体如舍是宗教譬喻——「身死神逝、别处求安」属道教神识与后身理论，宜在原典宗教框架中理解。
  12. 生死理齐不等于生死无别——「理齐」是说两者同属自然变化，不以绝对贪爱憎恶割裂它们。
  13. 「一爱一病」不否定关怀与责任——它反对占有性依附，而非慈爱、友善与责任。

现实中的「真观」如何实行 ​

第一步：分开事实与追加判断

事实追加判断
身体正在疼痛我的人生彻底毁了
需要接受检查一定会出现最坏结果
当前行动受限我从此毫无价值

先处理事实，不必把所有灾难性解释都当成事实。

第二步：寻找可为与不可强为——现在有什么可以实际改善？哪些需要专业帮助？哪些结果尚不确定？哪些已经发生、暂时只能承认？哪些思考只是在重复制造忧惧？

第三步：观察爱恶怎样追加痛苦——我是否要求此境永远不变？是否把一次失去看作全部自我崩塌？是否因憎恶某事，反而让它整日占据内心？是否把他人的恶不断引入自己心中？

第四步：必要时暂离其境——暂停刺激来源、减少相关信息、不继续争辩、给身心留出安静时间，在距离中重新观察。

第五步：事来则处理，事去不再积藏

text
病则治疗    贫则设法改善    不公则寻求救济    责任则合理承担
但不让一次境遇，成为心中永远反复播放的全部世界

小结 ​

【真观】由极其平常的衣食与言行开始，逐步进入欲望和爱恶的深层结构。其核心不在「什么都不要」，而在于：

取其所需而不贪，所得不积而不忧；看见境界如何出现，也看见爱著如何由自己的想象形成。

下篇则不是承诺修道以后贫病不来、生死不至，而是训练一种不被贫病生死完全夺走的心：

text
从归怨 → 转为审察        从逃避 → 转为承认
从恐惧 → 转为如实应对     从「为什么偏偏是我」 → 转为「此刻什么可以做」
从被爱恶牵引 → 转为观察爱恶如何成立
从身在醉中不知其醉 → 转为稍离其境、如醒而观

最关键的几句话是：

虽作巧持其末，不如拙诫其本。常无欲，以观其妙。与物同求而不同贪，与物同得而不同积。他自为恶不遣，我当何故引取他恶，以为己病。既不可逃，又不可怨，唯有智者善而达之。若以合境之心观境，终身不觉有恶；如将离境之心观境，方能了见是非。

因此，「真观」的核心不是把苦难说成不存在，也不是把一切责任推给业命，而是：

面对事实而不逃，处理事实而不乱；看见外境造成的现实困难，也看见自己的爱恶、恐惧和归怨怎样继续增加内在牵累。

至此，【真观】完成了由「定」向「慧」的转折：【收心】使心不随念头散乱，【简事】使形神不为万事耗损，【真观】使人看清欲望、贫病与生死的成立方式。下一篇《泰定》将讨论定慧进一步成熟后的状态：心如何从「有意守定」进入「无心于定而无所不定」？智慧生起以后，为什么最危险的反而是炫用智慧？

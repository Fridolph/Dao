坐忘论·断缘 ​

入读提示

断的是机心之缘，不是一切人情

【敬信】解决「是否真正认定修道」，【断缘】则要求把这份认定落实到现实生活。信道却仍不断经营名声、关系、利益与机会，心神便持续被外事牵引——所以先减少使心向外活动的条件，再谈心如何安住。

说所断 显德露能、遗问庆吊、假隐逸、酒食邀致——皆巧蕴机心，以干时利。说方法 不唱不和，旧缘渐断、新缘莫结，使利益之交自然日疏。说底线 事有不可废者，不得已而行之，勿遂生爱、系心为业。

此篇可与《天隐子·安处》对读：一在断外缘，一在调环境，都是为收心先清出一块地方。

【原典层】原文 ​

一、断缘的定义与作用

释义

断缘者断有为俗事之缘也

弃事则形不劳无为则心自安恬简日就

尘累日薄迹弥远俗心弥近道至圣至神孰不由此乎

经云塞其兑闭其门终身不勤

二、四类应当断除的俗缘

释义

或显德露能求人保己

或遗问庆吊以事往还

或假隐逸情希升进

或酒食邀致以望后恩

斯乃巧蕴机心以干时利既非顺道深妨正业

凡此类例皆应绝之

三、不唱不和，使缘渐疏

释义

经云开其兑济其事终身不救

我但不唱彼自不和

彼虽有唱我不和之

旧缘渐断新缘莫结醴交势合自致日疏

无事安闲方可修道

四、《庄子》的「不将不迎」

释义

庄云不将不迎无为交俗之情

又云无为谋府无为事任无为知主

五、不可废之事如何处理

释义

若事有不可废者不得已而行之勿遂生爱系心为业

【原典层】字词释义 ​

yuán缘

使人与某人、某事相连并持续牵引身心的关系与条件。不只是一次接触，更是「事情在心中继续延续、并引出新的欲望与行动」。

yǒu有wéi为

此处非泛指一切行动，而是由私心造作推动的活动——为显名而表现、为受保护而依附、为回报而宴请之类。

tián恬jiǎn简

恬，安静淡泊不躁竞；简，简少不繁杂。「日就」谓一天天形成，非一夕可得。

chén尘lěi累

尘，尘俗，亦喻遮蔽心性者；累，牵累系缚。日薄，谓一天天变淡——不只看事情多少，更看事情在心中占多少位置。

jì迹mí弥yuǎn远sú俗

迹，外在行为行迹；弥，越发。外在越远离世俗机巧追逐，内心越接近大道——所远者是「俗情」，不只是「俗地」。

sāi塞qí其duì兑bì，qí闭mén其　门

《道德经》第五十二章。兑指孔窍、感官与外相通的门户。非封闭感官，而是不让感知立刻发展为内心的追逐。

zhōng终shēn身bù不qín勤

勤，劳苦困乏。谓不因无穷事务而终身劳困，非提倡懒惰。

xiǎn显dé德lù露néng能

显露德行与才能以求人保护。批评的不在「有」德能，而在「显」「露」背后的目的。与《得道》「含光藏辉」相对。

wèi遗wèn问qìng庆diào吊

遗问，遣人问候馈赠（依底本保留此字）；庆吊，贺喜与吊丧。此处指借礼节往来维持利益关系。

jiǎ假yǐn隐yì逸qíng，xī情shēng希jìn升　进

表面隐居退让，内心期待升迁进用。四类俗缘中最具讽刺的一类：以退为进，外表无为而内心有为。

jī机xīn心

算计、谋利、操控结果之心。特征：外在理由与内在目的不同；把他人当作实现目标的工具；以礼、德、隐逸等高尚形式包装私利。

gān干shí时lì利

干，求取；时利，当时现实中的名位、机会与利益。时利不稳定，心若建立其上便须随时局不断忧惧经营。

zhèng正yè业

此处指修道本业。机心交往会妨此正业，所以说「深妨」。

kāi开qí其duì兑jì，qí济shì其　事

与「塞其兑」相反：向感官欲望敞开，并增加、扩张种种事务，则「终身不救」。

chàng唱hè、　和

唱，首先发起；和，响应配合。「我但不唱，彼自不和；彼虽有唱，我不和之」——断缘的方法不是决裂，而是停止提供动力。

lǐ醴jiāo交shì势hé合

醴，甜酒（依底本作「醴」）。醴交，以酒食款待相结；势合，因权势利益相合。皆非道义性情之交，利益条件消失便自然淡去。

bù不jiāng将bù不yíng迎

《庄子·应帝王》「至人之用心若镜，不将不迎，应而不藏」。将，迎送追随；迎，预先迎取。如镜：物未至不预想，物来如实映照，物去不留影。

móu谋fǔ府

计谋聚集的府库。无为谋府，谓不使心成为盘算的常态仓库，非谓不能正常思考。

shì事rèn任

把事务全部揽在自己身上。无为事任，非拒绝责任，而是不把所有事都揽成自己的任务——与《简事》「事物称万，不独委于一人」相通。

zhī知zhǔ主

知通「智」。无为知主，谓不让机巧聪明成为生命的主人；不消灭智慧，而让它回到辅助位置。

bù不dé得yǐ已ér而xíng行zhī之

行动来自事情本身的必要性，而非个人欲望的扩张——是一种有限、有界的行动。

jì系xīn心wéi为yè业

把心系缚在事务上，使其成为不断延续的业。业不只取决于外在做了什么，更取决于心如何依附。

【解读层】精读 ​

一、断的不是一切关系，而是「有为俗事之缘」 ​

「缘」不只是客观上遇到了某人某事，更重要的是一件事怎样在心中延续，并继续引出新的欲望与行动。一次普通交往本已结束，心中却继续盘算：他如何看我？是否应再联系？这段关系能带来什么？

text
接触一件事 → 生起利害判断 → 产生期待或排斥
        → 继续经营筹划 → 又引出新的关系与事务 → 心神长期被占据

断缘，就是切断这种不断自我增殖的过程。

「有为」在此不等于所有行动——否则篇末「事有不可废者，不得已而行之」便无从成立。所批评的是带有强烈私心造作的行为：为显名而表现、为受保护而依附、为升迁而假装隐逸、为回报而宴请。所以本篇区分的不是「行动＝错 / 不动＝对」，而是机心造作的行动与因事而应、不留爱著的行动。

同样，「断缘」也不等于断绝亲情与责任。本篇列举的对象都有明确特征（展示德能、求人保护、借礼仪经营关系、以隐逸换升迁、以酒食换回报），针对的是功利化、表演化、交换化的交往。若照顾父母、完成必要工作确实不可废除，属下文的「不得已而行之」；问题不在事情是否发生，而在心是否被事情长期占有。

二、断缘为什么是「收心」的前提 ​

「弃事则形不劳」——「弃事」不是丢弃一切事务，而是舍去由名利机心制造出来的非必要之事。外事首先消耗「形」：奔走往来、饮宴应酬、为求人而反复经营。

text
俗事增加 → 身体劳倦 → 呼吸与情绪不安 → 坐中昏沉或躁动 → 收心更加困难

这与《天隐子》先讲【斋戒】【安处】再讲【存想】同一逻辑：心的安定不是与身体和生活条件无关的。

「无为则心自安」——用的是「自安」，不是「强安」。心的不安往往不只来自已发生的事，更来自人为增加的期待（希望别人认可→害怕不被认可；希望关系带来利益→担心关系中断）。当这些造作减少，心不必时时防备计算，于是自然安定。断缘不是直接控制每一个念头，而是先减少不断生产念头的现实条件。

方法直接作用结果
弃去非必要之事使形体不再奔劳形不劳
停止机心造作使内心不再经营心自安
text
外在减事 + 内在去机 → 形不劳，心自安

只在外表上减少交往，却在心里反复思量，尚未真正断缘；外在仍有必要事务，而内心不攀附、不留滞，也可能已经开始进入无为。

三、恬简日就，尘累日薄 ​

「恬简」不是突然获得的，而是「日就」——每天少经营一点无谓事务，心中便多出一点空余：

text
少一次无谓唱和 → 少一次功利应酬 → 少承担一件非必要之事
        → 生活逐渐简化 → 心神逐渐安定

「尘累」不只指外面有多少事，更指事情在心中占多少位置。同一项事务有两种状态：事已结束心也放下（只有事务，没有牵累）／事已结束心仍盘旋（外事虽止，尘累未薄）。所以「日薄」的标志不一定是社会关系数量骤减，而是：对毁誉的反应减弱、不再期待所有付出都有回报、不主动追踪已结束的关系、不因机会减少而焦虑。

「迹弥远俗，心弥近道」建立了「外迹—内心」的关系，但「远俗」不必理解成空间上远离人群——住山中也可能每天想着名声供养；生活在人群中而不经营利害、不使事留滞于心，才算真远。真正要远离的是「俗情」，不只是「俗地」。 不过对初学者，外在环境并非无关紧要：断缘正是承认心尚未独立时，需要减少环境刺激。

「至圣至神，孰不由此乎」是一句反问，预先回应了「得道的人应当处闹市而不乱，为何还要断缘」的质疑：初学与证成不同，不能只模仿圣人最终的外在表现，却跳过圣人成就定力的过程。（这一点【收心】篇末还会展开。）

四、塞其兑，闭其门：关闭什么门户 ​

「塞其兑，闭其门」出自《道德经》第五十二章（通行本作「塞其兑，闭其门，终身不勤；开其兑，济其事，终身不救」）。兑指孔窍、出口，「门」是身心向外驰逐的通道。

若机械理解成永远闭眼、不听声音、不与任何人接触，便容易僵化。它主要是说：不让感官接触立刻发展为内心的追逐，不让每个外来刺激都成为新的事务入口。

text
看见、听见 → 正常感知 → 未必成缘
看见、听见 → 生起欲望和比较 → 继续追逐经营 → 成为俗缘

这与《天隐子·坐忘》「有见而不行其见」非常接近：可以有见闻，却不跟随见闻继续向外奔走。

「终身不勤」的「不勤」不是懒惰，而是不因无穷事务而终身劳困——认识一个人便经营一层利益，得到一个职位便追逐更高位置，如此事务没有终点，心也不可能真正休息。塞兑闭门，就是不再让所有可能性都变成自己的责任和追求。

五、四类应断的俗缘 ​

第一类：显德露能，求人保己——批评的不是实际具有德能，而是「显」「露」背后的目的（使有权势者注意自己，希望获得保护与提拔）。问题不在有才有德，而在把德能变成求取利益的手段。这与《得道》「含光藏辉」形成对照。

第二类：遗问庆吊，以事往还——庆吊本可以是正常礼节，但若借礼节之名维持利益关系、表示未曾疏远、期待日后回礼，礼就成了机心的工具：

text
我来庆贺你 → 你以后必须回访我
我赠礼给你 → 你应记得我的人情

这种往还会不断生成新的义务与期待。若庆吊属不可废的亲情责任，可归入「不得已而行之」，只是不要借此扩张关系或期待回报。

第三类：假隐逸，情希升进——四类中最具讽刺的一类：外表远俗、内心求名；外表无为、内心有为。修道本身也可能成为获取名声的策略，所以真正的断缘不能只看外在身份，而要看内心是否仍在等待世俗回报。

第四类：酒食邀致，以望后恩——把宴请当作投资：今日请客→建立人情债→日后要求帮助。若一开始就预设回报，表面的慷慨仍是交换。宴席早已结束，心理交易却长期没有结束，这就是俗缘之所以「累」的原因。

六、四类俗缘的共同本质：机心与时利 ​

「斯乃巧蕴机心，以干时利」——「机心」不等于正常计划，其特征是：外在理由与内在目的不同、把他人当作实现目标的工具、以高尚形式包装私利。

外在形式隐藏目的
显示德行求人保护
庆吊往来维持利益网络
隐逸退让等待升迁
酒食款待换取日后恩惠

「时利」具有不稳定性（今日得势明日可能失势），心若建立其上，就必须随时局不断调整忧惧，当然难以静定。故「既非顺道，深妨正业」：

text
机心交往 → 心中充满预测与计算 → 对得失毁誉极其敏感
        → 静坐时杂念不断 → 无法安住 → 真观与泰定无从生起

外缘不是修行之外的小问题，而是直接决定心能否收回。

「凡此类例，皆应绝之」的重点在「类例」：所举不是封闭清单，而是让读者辨认共同结构——行为表面正当 + 内心以名利回报为目的 + 事情结束后仍继续牵心。据此，现代情境中下列行为同属此类：为获得认可而持续展示自己、为未来机会维持大量无意义联系、以帮助别人换取隐性情感债务、因害怕错过机会而参加所有活动、把每段关系都视为潜在资源。断缘针对的，是人心把世界「关系资本化」的倾向。

七、开其兑，济其事，终身不救 ​

text
感官与欲望不断向外开放 → 每一欲望都形成新事务 → 事务又制造更多关系
        → 关系又带来新的利害 → 终身不得解脱

「不救」不是说多做几件事便受外在惩罚，而是：若不断制造造成忙乱的原因，就无法从忙乱的结果中解脱。 这正是总论「恶生死之苦，爱生死之业」在本篇的具体表现：

text
厌恶事务繁重，却不断结新缘
希望内心安静，却处处回应唱和
抱怨人情负担，却又依靠人情谋利

人若同时保留「缘所带来的利益」与「心不受缘牵累」，往往难以做到。

八、「我但不唱」：断缘的方法不是激烈冲突 ​

「唱」是首先发声发起，「和」是响应配合。「我但不唱，彼自不和；彼虽有唱，我不和之」提出的是一种温和的断缘方法：先停止自己主动制造关系和事务。 很多俗缘并不需要公开宣布断交，只要不再主动提供动力，它自然淡化。

「不和」也不一定意味着粗暴拒绝：不进入原来的利益交换模式，不因邀约便重新生起期待，不因别人议论是非便参与扩散。必须礼貌回应时可以回应，但不再顺着它延伸——必要的信息回应 ≠ 继续经营俗缘。真正的不和是内心不接续，而不必表现为外在无礼。

之所以不主动与所有人决裂，是因为激烈断交本身可能制造更多心事（对方怨恨、自己愧疚、反复解释、以「我已经断缘」建立清高身份），这又形成新的缘：

text
不主动唱 → 不随俗和 → 不再续接 → 让旧缘自然变淡

这与无为相应：不以强力切割制造新冲突，而是停止为旧有关系提供新动力。

九、旧缘渐断，新缘莫结 ​

「渐」字很重要。已形成的关系、责任与习惯不一定能立刻消失（有些关系仍需正常处理，有些承诺仍须履行）。所以旧缘不是粗暴「一刀切」，而是：不再主动强化、不再增加新内容、完成必要责任、停止额外经营，让其逐渐结束。

旧缘尚未清理时，最重要的是不再结新缘，否则「一边清理旧事，一边制造新事，事务永无减少」。「新缘莫结」要求在事情开始前多一道观察：这件事真有必要吗？是否只是为了名声或人情？一旦开始还会引出多少新事务？我是否只是害怕错过机会？——这已为下一篇【简事】预作铺垫。

判断断缘是否有效，不能只看外部数量：

text
交往减少很多，但心中天天思念、怨恨、期待 → 缘未断
仍需处理必要事务，但事来则应、事去不留 → 缘在渐薄
  • 外在指标：不主动增加无谓关系、不承担非必要事务、不以礼节包装利益交换。
  • 内在指标：不期待回报、不反复盘算、不以别人态度决定自身安定、事情过去后能够放下。

十、醴交势合，自致日疏 ​

底本作「醴交势合」（「醴」为甜酒），可参「君子之交淡若水，小人之交甘若醴」之义（《庄子·山木》有相近表述）——「甘若醴」的关系起初甜蜜，却容易因利益变化而断绝。

text
醴交：因享乐、款待而合
势合：因权势、利益而合

这些关系并非建立在道义与性情相知上，而依赖持续的利益供给。当自己不再维持酒食与势利之交，它们自然一天天疏远——不必带有怨恨。功利关系因利益而来，条件消失便自然淡去；修道者无需指责对方势利，也无需对关系变淡感到受伤，只需看清这种关系原本依何而立。

十一、无事安闲，方可修道 ​

心需要空间才能被看见。若一天被工作安排、人情往来、信息刺激、利害计算、毁誉反应占满，即使短暂坐下，也只是把白天未完成的思虑搬进静坐。

text
外事减少 → 心的活动变得可见 → 才能发现念头如何生起 → 才能开始真正收心

这正是【断缘】必须位于【收心】之前的原因。

「无事」不是绝对没有事情（否则大多数人永远无法开始），而是：没有主动制造的多余事务、没有未清理的利益关系、没有不断扩张的心理计划、当前没有必须立即处理之事——让身心拥有相对完整、不被持续打断的时间。

「安闲」也不是无所事事：普通的无所事事仍可能充满无聊、信息浏览、幻想、对刺激的寻找。「无事」是外在条件，「安闲」才是内在结果——外事暂息，内心也不急着寻找新的攀缘对象。

十二、《庄子》的「不将不迎」 ​

「不将不迎」见于《庄子·应帝王》「至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤」。镜子对物的方式是：

text
物未至 → 不预先想象
物来时 → 如实映照
物离去 → 不保留影像

这正是断缘的理想状态。但它不是冷漠——镜子并不拒绝映现事物，事物来时仍清楚反映。所强调的是不预先攀附、不主动招引、不曲意迎合、不在事过之后留藏。真正对应的是：应而不染，行而不系。

「无为交俗之情」中「情」主要指围绕世俗利害形成的交往心态。若「断缘」变成对所有人的厌恶，心中充满排斥与敌意，也不是「不将不迎」——厌恶同样使心被对象占据：

text
贪恋关系 → 被关系束缚
怨恨关系 → 仍被关系束缚
不将不迎 → 关系来去，不使心留滞

十三、无为谋府，无为事任，无为知主 ​

三句同出《庄子·应帝王》的思想语境（常见原文作「无为名尸，无为谋府，无为事任，无为知主」，底本节引后三项）。

  • 无为谋府——不使心成为各种计谋盘算的府库（怎样经营关系、怎样取得优势、怎样使人依从）。「谋府」不是正常思考，而是把计谋变成内心常态。
  • 无为事任——不把自己变成承担一切事务的人。人容易因想证明自己不可替代、不相信别人能完成、享受被需要、借责任获得权力而过任事；表面勤勉，内在仍可能是「显德露能」。它与【简事】「事物称万，不独委于一人」直接相通。
  • 无为知主——不让机巧聪明成为生命的主人。智巧本是工具，却反过来役使心神。这与【敬信】的「黜聪明」相接：黜聪明是不以智巧把握大道，无为知主是不让智巧主宰日常生命——不消灭智慧，而让它回到辅助位置。

十四、篇末的平衡：不可废之事仍然要做 ​

「若事有不可废者」这一句非常重要，它防止把断缘理解成绝对逃避。不可废之事可能包括：维持基本生计、照顾亲属、履行已承担的责任、处理疾病与安全问题、完成不能随意中止的工作。修道者仍处于现实世界，不能把一切必要条件都抛弃。

「不得已而行之」——行动来自事情本身的必要性，而非个人欲望的扩张：

text
必要之行：事情确实需要处理，处理到合适程度便停止
欲望之行：借事情显示自我，不断追加目标，使一事又生多事

**「勿遂生爱」**是在事情进行中保持觉察：

text
因责任而做 → 做得不错 → 获得认可 → 开始喜欢这种地位
        → 继续扩大事务 → 必要之事变成名利之缘

不因擅长而沉迷、不因称赞而扩张、不因掌握权力而不愿放手、不因已有投入便无限追加、不把角色当作固定自我。

「系心为业」——业不只看外在做了什么，还看心如何依附：

text
事情发生 → 心产生爱著 → 反复想起、继续追求 → 爱著推动新行动 → 新行动又加强爱著

必要之事来 → 如理完成 → 不借此求名求利 → 事毕即放 → 不再续结新缘

十五、断缘与简事的区别 ​

两篇内容看似相近，重点不同：

  • 断缘：处理牵心的关系机制——为什么与人交往？是否期待回报？是否谋求保护与升进？
  • 简事：处理事务的数量与必要性——什么属于生命必需、什么属于欲望余好、什么在自己分内？
text
断缘：先停止以机心制造事务
简事：再对尚存事务衡量轻重、去取

而位于两者之间的【收心】，直接处理事务在内心留下的攀缘与杂念。

与《天隐子》的对应 ​

《天隐子》本篇呼应
安处五（调节风气明暗，心目皆安）断缘（减少功利往来）都承认初学者的心易受环境影响，先减少外扰是合理次第
存想六（目终日视他人，故心亦逐外走；终日接他事，故目亦逐外瞻）断缘（减少「接他事」）断缘＝减少接他事，收心＝停止逐外走
坐忘七（有见而不行其见）不将不迎「忘」不是什么都不接触，而是接触而不续接
神解八（斋戒谓之信解，无信心则不能解）敬信之后紧接断缘信必须通过生活选择来证明：若真信道，便会减少妨道之缘

容易误解的地方 ​

  1. 断缘不是与所有人断交——所断的是功利、攀附、交换与机心之缘，不可废的人伦责任仍应履行。
  2. 断缘不是厌恶世人——厌恶也是一种强烈系心；真正的断缘不需要怨恨，只是不再以世俗利益维持关系。
  3. 不唱不和不是故意无礼——主要是不主动发起、不继续扩张；必要回应仍可有，只是不进入无穷唱和。
  4. 无为不是不负责任——篇末明确允许「不得已而行之」；无为反对的是人为增加、以私欲强作。
  5. 减少事务不是为了变得封闭——目的是使心恢复自主；若必须靠完全隔绝才能勉强不动，定力仍未成熟。
  6. 「无事安闲」不是躺平放逸——放逸仍在不断寻求娱乐刺激；真正的安闲是外事减少后，心也不急着寻找新的攀缘。
  7. 不应借「修道」逃避应尽责任——若把不可废的责任推给他人，反而制造新的过失、冲突与心累，不合「不得已而行之」的平衡。

现实中的「缘」如何辨认 ​

四个问题：

  1. 动机——我为什么开始或维持它？是真实责任与自然情谊，还是为了名声、机会、保护或回报？
  2. 增殖——它是否不断引出新的事务？一件完成后，是否又要求更多应酬、解释、维护？
  3. 留滞——事情过去后，我的心能否放下？若持续盘算对方评价、回报与得失，说明外事已转为内累。
  4. 边界——做到什么程度就足够？必要之事通常有合适边界；欲望之事则永远可以继续扩大。

由此把事务分成三类：

类型处理原则
明显由机心和利益制造应断
已形成但可逐渐退出不再强化，使其渐疏
确实不可废的责任如理完成，不生爱著

修行逻辑 ​

text
敬信以后，必须把信落实到生活
        ↓ 先断有为俗事之缘
弃去非必要事务 → 使形体不劳
停止机心造作 → 使内心自安
        ↓
恬简日就，尘累日薄；迹渐远俗，心渐近道
        ↓ 尤其应断：显德求助、庆吊经营、假隐求进、酒食求报
（皆以机心谋时利，严重妨碍修道本业）
        ↓ 方法不是激烈决裂，而是不唱、不和
旧缘渐断，新缘莫结，利益之交自然日疏
        ↓
获得无事安闲的收心条件
        ↓
但不可废之事仍须处理：不得已而行，事毕即放，勿生爱著、系心为业

小结 ​

本篇的核心不是简单减少人与人的接触，而是停止一套不断制造心事的机制：

以德能求保护，以礼节经营关系，以隐逸谋升进，以酒食换回报。

这些行为表面不同，内在都是：巧蕴机心 → 谋取时利 → 事务增殖 → 身劳心乱 → 妨碍修道。给出的办法也不是猛烈切断一切，而是：

我不主动唱，也不随俗和；旧缘让它渐渐淡去，新缘不再继续结成。

而全篇最重要的平衡在最后一句：若事有不可废者，不得已而行之，勿遂生爱，系心为业。 由此可知，断缘的真正尺度不是「有没有做事」，而是：是否人为增加不必要的事？是否借事情追逐名利？是否期待交换与回报？是否事已过去而心仍不放？

所以，本篇可以浓缩为一句话：

断缘不是逃离生活，而是停止用机心扩张生活；必要之事来则应，事情过去心不留。

完成这一步，修行者获得了相对安闲的外部条件。下一篇《收心》才正式进入全书的中心：外事虽然减少，但长期外驰的心不会因此立刻安定——它会怎样散乱，又应怎样「息乱而不灭照，守静而不著空」？

导读坐忘论司马承祯

坐忘论·得道 ​

入读提示

形随道通，与神合一

七篇终章。前六篇都在逐层消除人与道之间的阻隔，本篇进一步追问：道力能否由心及形，使整个生命——不只是意识，也包括形体——发生转化？司马承祯的回答是肯定的，并把得道分为「及心」与「被形」两个深浅层次。

说道体 灵而有性，虚而无象；不知所以然而然，通生无匮谓之道。说深浅 深则兼被于形，浅则唯及于心——差别在道力，不在言说。说归宿 含光藏辉，凝神宝气，学道无心，神与道合，谓之得道。

本篇含道教成仙论内容（长生、炼形、神人真身）。可作宗教层面理解，不必全部折算为现代心理学结论；其中蹈水火、六根洞达等描述也不可作为现实模仿或追求的目标。

【原典层】原文 ​

一、道的性质与得道的可能

释义

夫道者神异之物灵而有性虚而无象

随迎不测影响莫求不知所以然而然通生无匮谓之道

至圣得之于古妙法传之于今循名究理全然有实

上士纯信克己勤行虚心谷神唯道来集

二、道力改变形神，成就神人

释义

道有深力徐易形神形随道通与神合一谓之神人

神性虚融体无变灭形与道同故无生死

隐则形同于神显则神同于气

所以蹈水火而无害对日月而无影存亡在己

出入无间身为滓质犹至虚妙

况其灵智益深益远乎

生神经云身神并一则为真身

三、道力有深浅：及心与被形

释义

又西升经云形神合同故能长久

然虚无之道力有浅深深则兼被于形浅则唯及于心

被形者神人也

及心者但得慧觉而身不免谢

何耶

慧是心用用多则心劳

初得少慧悦而多辩神气漏泄无灵润身光

遂致早终道故难备

经云尸解此之谓也

四、含光藏辉，凝神宝气，才叫得道

释义

是故大人含光藏辉以期全备凝神宝气

学道无心神与道合谓之得道

经云同于道者道亦得之

又云古之所以贵此道者何

不日求以得有罪以免邪

山有玉草木以之不雕

人怀道形骸以之永固

资薰日久变质同神链形入微与道冥一

五、一身与万法互摄，真应无方

释义

散一身为万法混万法为一身智照无边

形超靡极总色空而为用含造化以成功

真应无方其惟道德

西升经云与天同心而无知与道同身而无体然后天道盛矣

谓证得其极者也

又云神不出身与道同久

六、六根皆与道同，以及对「唯舍形论」的批评

释义

且身与道同则无时而不存

心与道同则无法而不通

耳与道同则无声而不闻

眼与道同则无色而不见

六根洞达良由于此

近代常流识不及远唯闻舍形之道

未达即身之妙无惭己短有效人非

其犹夏虫不信冰霜醯鸡断无天地

其愚不可及何可诲焉

【原典层】字词释义 ​

shén神yì异zhī之wù物

此处「物」不宜按普通有形物质理解，因紧接便说「虚而无象」。近于「神妙不可测的真实」：不能由感官直接限定，却贯通生成万物。

líng灵ér而yǒu有xìng性

道灵妙而具有真实本性。强调「有性」，是防止把虚无之道误解成什么都没有——道虚不等于不存在，道无象不等于无作用。

xū虚ér而wú无xiàng象

道虚通而没有固定形象：不被一个形体限定，不为任何一物独占，不能当作特殊对象抓取。

suí随yíng迎bù不cè测

向前往迎、从后追随都无法用普通方式测定。近《道德经》「迎之不见其首，随之不见其后」：道不是可被前后追踪的空间对象。

yǐng影xiǎng响mò莫qiú求

影随形、响应声，道的作用虽如此，却不能作为独立对象强行求得。道不能用世俗占有外物的方式求取。

tōng通shēng生wú无kuì匮

贯通、生成和养育万物，其作用无穷无尽。道体虚而无象，道用则通生无匮。

xū虚xīn心gǔ谷shén神

虚心，心不被爱恶名利和多知填满；谷神语出《道德经》第六章「谷神不死」，谓心神如空谷——虚而能受，空而能应，不自满不固执。

xú徐yì易xíng形shén神

徐，渐渐；易，改变。道力经长期薰习而逐渐改变形体与精神。对应前篇的「日损有为」「久久调熟」「资薰日久」。

xíng形suí随dào道tōng通

形体随道力薰习而变得通达，不再保持普通滞碍之质。后文称之为「变质同神，炼形入微」——不是简单保养身体，而是存在方式的根本转变。

shén神rén人

《庄子·逍遥游》中的理想人格（「神人无功」），道教中又具形神超化、具足神通之意。本篇所说神人兼有两层：心性上无己无名无执，形神上与道合一。

xū虚róng融

虚，无固定实体可执；融，无碍贯通不与道隔。神之所以能与道相合，正因二者都具有虚通性质。

shī尸jiě解

道教仙学概念，指修道者死后遗下形骸衣冠等物、以某种方式脱离肉身。不同道教时期评价不一；本篇把它归入「道力及心、身仍不免谢」的未全层次。

hán含guāng光cáng藏huī辉

把内在智慧光明含藏起来，不急于向外炫耀。非故意装作无知，而是不用所得建立身份、不因有慧便到处辩论。近《道德经》「和其光，同其尘」。

níng凝shén神bǎo宝qì气

使精神凝聚，珍惜并保养生命之气。「宝」作动词，以之为宝而爱护。非把气想象成可任意操纵的物质，而是减少精神耗散、使形神相养。

xué学dào道wú无xīn心

修道而不带强烈的占有心、功利心和自我意识：不想靠修道获得名声，不想证明有境界，不想把大道当作自己的所有物。

zī资xūn薰rì日jiǔ久

依靠大道长期薰习浸润，如香气久熏衣物。一次静坐不足以改易形神，须长期定慧相养、神气不漏，才会发生深层变化。

biàn变zhì质tóng同shén神

身体原本粗重的形质逐渐变化，变得与神同样虚妙。这是「道力兼被于形」的结果，故形神才能不相分离。

liàn炼xíng形rù入wēi微

通过道力与神气的长期薰炼，使形体进入精微虚化的状态。粗形→气化→神化→与道冥一。本篇未详论吐纳外丹，而把炼形之本放在虚心、定慧、含光、凝神、宝气。

míng冥yī一

不是外在拼合，不是概念宣布，也不是「我与道合一」的自我感觉，而是界限与阻碍自然消失——心、神、形皆不再与道隔。

zǒng总sè色kōng空ér而wéi为yòng用

统摄有形（色）与无自性（空）而能自在运用，不滞于任何一端。带明显佛教色空语言影响，被纳入道教形神仙化：色不定色故形可炼化，空不滞空故神可显用。

zhēn真yìng应wú无fāng方

真实的感应与作用没有固定形式，能随缘而应：隐显无定、动静不滞、有无相通、应后不留。与【收心】「神用无方」首尾呼应。

wú无zhī知wú无tǐ体

《西升经》「与天同心而无知，与道同身而无体」。无知所破是人为智巧与自以为知（非无觉）；无体所破是固定粗重形体之执（非不存在）。

liù六gēn根dòng洞dá达

六根（眼耳鼻舌身意，佛教术语）完全通达，不再受普通障碍限制。本篇把它解释为整个形神与道相同的结果，而非单独训练感官异能所得。

jí即shēn身zhī之miào妙

不必先舍弃身体，此现有形身本身也可以经过道化而成真。非「离身之外另求真身」，而是此身由粗入微、由形合神，转为真身。

xī醯jī鸡

醋瓮中滋生的小虫，生活在狭小容器中而视野极为有限。喻因见闻狭隘便武断否定广大天地者。

【解读层】精读 ​

全篇结构与六层读法 ​

前六篇都在消除人与道之间的阻隔：敬信由疑道转为信道、断缘减少功利关系、收心使心不再逐境、简事减少非要非重之事、真观照见欲望贫病生死的虚实、泰定定极生慧而定慧相养。

如果说【泰定】主要讨论「心如何与道相应」，本篇进一步追问：道力能否由心及形，使整个生命——不仅是意识，也包括形体——发生转化？ 司马承祯的回答是肯定的，并把得道分为深浅两层：

text
道力浅：主要作用于心，得到慧觉，但形体仍会死亡
道力深：进一步作用于形，使形神合同，炼形入微，成就神人、真身

这一区分是理解本篇的关键。 司马承祯并不满足于「心中觉悟」，而坚持道教特有的形神双全、即身成真理想。

阅读提醒 本篇关于形体不死、蹈水火而无害、对日月而无影、存亡在己、六根洞达等，都属于道教神仙学的宗教性陈述，不能直接当作已经得到现代科学验证的身体事实。精读时既不应抹去原文的神仙信仰，也不应把象征性或宗教性语言轻率包装成可实证能力。

层核心问题
一 · 道的性质与得道的可能道为何「灵而有性，虚而无象」？「影响莫求」说明什么？为何强调「全然有实」？
二 · 道力改变形神「徐易形神」何意？「形随道通，与神合一」如何成为神人？
三 · 道力有深浅为何分「及心」与「被形」？得慧者为何仍会死亡？为何把「尸解」视为未全？
四 · 含光藏辉才叫得道为何得慧以后必须含藏？「学道无心」何意？道如何如山中玉般护养形骸？
五 · 一身与万法互摄「散一身为万法，混万法为一身」何意？「与天同心而无知」是否断灭？
六 · 六根与道同、批评舍形论「六根洞达」怎样形成？何谓「舍形之道」？为何坚持「即身之妙」？
text
道虚而无象，却灵妙真实、通生无穷
        ↓ 修道者克己勤行、虚心谷神
心虚而道集 → 道力由浅入深：先明心，后易形
        ↓ 形随道通，形神合一
得慧以后含光藏辉，不使神气因多知好辩而漏泄
        ↓ 凝神宝气，长期薰习
变质同神，炼形入微 → 形神与道冥一
        ↓
一身与万法相通，真应无方；身心六根皆与道同
        ↓
由普通生命转成道教意义上的神人、真身

一、道究竟是什么 ​

「神异之物」——「物」不宜按普通有形物质理解，因为紧接着便说「虚而无象」。「神异」不是只指奇迹，而是说道的作用超出普通分别思维的范围：它不是一般物体，不能由感官直接限定，却不是纯粹虚构，能够贯通生成万物。

「灵而有性」——强调「有性」是在防止把「虚无之道」误解成什么都没有：

text
道虚 ≠ 道不存在；道无象 ≠ 道无作用

道虽然不能像普通物体一样被看见，却能通生万物、薰习心神、改易形质、成为形神长久的根据。

「虚而无象」——「虚」表示不被一个形体限定、不为任何一物独占、能够贯通万有；「无象」则是不能用单一形象代表、不能当作一个特殊对象抓取、不等同于静坐中的某种光影或感受。这与【收心】「住无所有」、【泰定】「心体非有」彼此呼应。

二者必须合看，各自避免一种极端：

偏差本篇的纠正
把道当作有形实体道虚而无象
把道理解成绝对空无道灵而有性
text
无固定形象，却有真实作用；不可执取，却能通生万物；不属于一物，却无物不贯

二、「随迎不测，影响莫求」：道不可对象化 ​

「随迎不测」近《道德经》第十四章「迎之不见其首，随之不见其后」——大道不是一个处在空间中、可以被前后追踪的对象。若修道者把道当作某种外在东西去寻找，就仍然落在逐物之心中：以对象心求道，道便被想象成一个「物」，越想抓住越背离其虚无无象。所以得道不是占有道，而是使自身与道相应。

「影响莫求」——「影响」即影与响（形现则影随，声发则响随）。「莫求」并不是说完全不必修道，而是说：道不能用世俗占有外物的方式求取。【敬信】已批评「怀宝求宝」；本篇确认：不是向外获得一个叫作「道」的东西，而是净除阻隔，使本有形神与道相合。

「不知所以然而然」——强调大道的自发性：它自然而然，不由外力推动，不以人的理解为转移。这里的「不知所以然」不是赞美无知，而是说普通因果语言无法穷尽道作为万物根源的最终根据。

「通生无匮谓之道」——道的真实性由「通生」体现，与【收心】所引「至道之中，寂无所有，神用无方」完全一致：道体虚而无象，道用通生无匮。

三、大道是否真实可得 ​

「至圣得之于古，妙法传之于今」回应【敬信】的根本问题（道究竟只是经典中的传说，还是人可以实际修证的真实？），并从道教传统内部给出两项根据：古代圣人已经得道（说明道可证），修习妙法传到当今（说明后人有路可循）。

这是一种宗教传统中的传承论证，不等同于现代科学实验意义上的证明。

「循名究理，全然有实」——「名」包括道、虚心、谷神、神人、真身、形神合同、坐忘、得道。名称本身不是证悟，但可以作为进入义理的路径：

text
循名 → 不停留于名；究理 → 理解其修行结构；实行 → 亲自验证心行转化

若只执著名称，就落入玄谈；若完全拒绝经典名称，又可能失去修行指引。

四、「上士纯信，克己勤行，虚心谷神」 ​

「上士纯信」与《道德经》第四十一章「上士闻道，勤而行之」相应。「纯信」不是拒绝思考的盲信，而是经过辨理以后，不再因为暂时困难便反复怀疑修道方向。【敬信】建立的信，到此成为得道的起点。

「克己勤行」——「克己」主要克服贪爱、名心、自是、好辩、多事、得失计较；「勤行」则意味着不能只有信仰和理解而没有实际改变：

text
信而不行 → 只是观念；行而无常 → 难以调熟
克己勤行 → 积习渐深 → 形神才可能受道薰习

「虚心谷神」——「谷神」出自《道德经》第六章「谷神不死，是谓玄牝」：心神如空谷一般，虚而能受，空而能应，不自满，不固执。「唯道来集」——「道来集」并不是道原来在远处、现在移动过来，而是心中障蔽减少，与道相应的本性显露；这与【收心】「心安而虚，道自来居」前后相应。

五、道怎样「徐易形神」 ​

「道有深力」首先表现为心性改变（贪欲减弱、心神安定、智慧显发），进一步则按道教神仙学的理解作用于形体。「徐易形神」的「徐」说明形神变化不是突然完成，它对应前篇反复强调的「日损有为」「久久调熟」「积习心熟」「资薰日久」：

text
先改变心行 → 心不再耗散神气 → 神气凝聚 → 形体得到薰养
→ 长期道力薰习 → 形神关系逐渐改变

「形随道通」——普通形体被理解为粗重、有限、会衰败、受物质条件限制；「形随道通」则是形体逐渐道化、神化，后文称「变质同神，炼形入微」。

「与神合一」——普通人的形神关系是「心逐欲→神耗散→形体衰败→神离身而去」；神人的形神关系则是「神与道合→神气凝定→道力薰形→形随道通→形神合同」，不再有形坏神离的普通死亡。

「谓之神人」——《庄子·逍遥游》中「神人无功」，「神人」在道教中又进一步具有形神超化、具足神通的意义。本篇所说的神人兼有两层：心性上无己、无名、无执；形神上与道合一、超越普通生死。

六、「神性虚融，体无变灭」 ​

「神性虚融」（虚：无固定实体可执；融：无碍贯通）——神之所以可能与道相合，是因为二者都具有虚通性质。「体无变灭」是道教形神论的宗教立场：身体可能老病，神则具有虚融灵性；若形未道化，身坏时神离；若形随道通，便能与神合一而同于不灭。这里不能简单等同于现代哲学中的意识理论，也不能视为已经实证的灵魂不灭结论。

「形与道同，故无生死」揭示本篇的最终目标不是单纯灵魂不灭，而是形也与道同，形神共同超越生死：

层次结果
心得慧觉，形未道化身体仍会死亡
形神俱受道力形神合同，成就神人
形与道同道教意义上的无生死

七、「隐则形同于神，显则神同于气」 ​

「隐则形同于神」——神人隐没形迹时，形体能像神一样虚妙不可见；「显则神同于气」——显现时，神又能通过气化而呈现形体作用。「气」在道教形神论中是连接形与神的中介：

text
普通人：形粗而滞，气易耗散，神受形拘
修道人：收心凝神，养气润形，形质渐化
神人：  形可入神而隐，神可乘气而显，显隐存亡不再受普通限制

（这属于道教炼养与神仙学体系。）

八、「蹈水火而无害，对日月而无影」 ​

「蹈水火而无害」延续《庄子》神人「不溺不热」的传统，也与道教仙传中的神异能力相通——从原典内部看，是形体道化、不再受普通物质条件拘束的表现。

从现代阅读看，不应据此尝试任何危险行为。现实中的人体会受到溺水、烧伤等严重伤害，修习者仍须遵守安全常识。

「对日月而无影」表示形质已由粗重转为虚妙，不再完全属于可遮光的普通物质身体。它可以作为「炼形入微」的神仙学象征理解，但不能轻率当作现实修炼程度的检测方式。

「存亡在己，出入无间」——「存」是显现、存在于可见形态，「亡」是隐没（不一定指死亡），「出入无间」是来去自在。神人的「自由」不只是心理上想得开，而是原文所信仰的形神存在方式已经发生超常变化。

「身为滓质，犹至虚妙」是为下面的反问蓄势：连最粗重的身体都能道化，何况本来虚灵的神识与智慧（「况其灵智益深益远乎」）。

九、《生神经》「身神并一，则为真身」 ​

「身神并一」——形体与精神合并为统一整体，不再有神离形坏的分裂。这里的「一」不是把神降格为普通肉体，也不是把身体彻底抛弃，而是双方共同道化：

text
不是舍形存神，也不是只养形体，而是形神俱妙、合同为一

「真身」与普通血肉身体相对，是经过道力薰习与炼化、形神合同的身体：普通之身因缘聚合、会老病衰败、形神可能分离；真身形神并一、形随道通、按道教信仰能够长久不灭。

因此，得道不是「离开身体才得解脱」，而是使身体本身也参与成真。

十、道力为什么有深浅 ​

「形神合同，故能长久」是本篇长生理论的中心（形神分离则身坏神离、普通死亡；形神合同则形不成为神的障碍、神也不离弃形体，得以长久）。

「虚无之道，力有浅深」——并不是大道本身有所缺损，而是修道者信心不同、用功深浅不同、心垢厚薄不同、定慧是否外泄不同，所以结果出现差别。

「深则兼被于形」——「被」即覆盖、施及、薰染。道力及心则心明慧觉；道力被形则神气润身、形质渐化、形神合同。

「浅则唯及于心」——道力较浅时，只能使内心获得智慧觉照，不能完成形体转化。这说明在司马承祯看来，心性觉悟虽然重要，却仍不是道教修炼的最高完成。

「及心者，但得慧觉，而身不免谢」明确把「慧觉」与「神仙」区别开来：

得慧觉成神人
心明心明且形化
能见道理形神与道相通
身仍会谢灭形神合同而长久
道力及心道力兼被于形

这种强调形体成真的立场，是《坐忘论》作为道教修炼论的重要特征。

十一、为什么得慧以后反而可能早终 ​

「慧是心用，用多则心劳」直接承接【泰定】「勿以多知而伤于定」「非生慧难，慧而不用难」——智慧虽然出自本性，却需要神气支持；若不断思虑、言说、辩论、经营名声，心神就重新向外耗散。

「初得少慧，悦而多辩」——「悦」不是单纯喜悦，而是对自己的慧产生占有和陶醉：

text
我有所悟 → 我与别人不同；我看得更清楚 → 我应当告诉所有人
别人不接受 → 我要继续辩论；辩论得到赞誉 → 更想扩大影响

于是，慧成为新的名利。「神气漏泄」在道教生命观中指神应凝、气应宝，若神气漏泄，定无法深入，道力也难以「兼被于形」。

完整链条：

text
定生少慧 → 因慧自悦 → 多言好辩 → 神气漏泄 → 不能润养形体 → 形体无法完成道化

关于「遂致早终」：现代医学上，寿命和疾病由多种复杂因素决定，不能把早逝简单归因于「多辩漏气」。其修行意义仍然清楚：慧若转成名心与事务，会破坏原先产生慧的定，也使形神长期处于消耗状态。

十二、「尸解」为什么在这里属于未全之道 ​

「尸解」是道教仙学中的重要概念，不同时期和文献评价并不完全一致（有些传统视为仙化途径，有些认为低于肉身直接升仙）。依上下文，本篇把尸解归入：

text
道力只及于心 → 已有慧觉 → 但未能兼被形体 → 身体仍然衰谢 → 神识离形而解

所以尸解并非完全没有成就，却没有达到「形神合同、即身成真」的最高层次：

尸解神人
神有所成形神俱成
身体仍谢形随道通
舍形而解即身而妙
道力主要及心道力兼被于形
属于未全备的成就属于本篇最高理想

这也为篇末批评「唯闻舍形之道」埋下伏笔。

十三、含光藏辉，凝神宝气，学道无心 ​

「含光藏辉」——「光」「辉」指智慧、德行、修习所得、灵妙能力。「含藏」不是故意装作无知，而是不用所得建立身份、不因有慧便到处辩论、不以神异吸引他人。近《道德经》「和其光，同其尘」。

「以期全备」——若慧刚出现便外泄，只能停留在「及心」；若含光凝神，道力才可能继续「兼被于形」：

text
慧而外用 → 道力停于心 → 形未得化
慧而含藏 → 神气不泄 → 润养形体 → 形神俱备

「凝神宝气」——「宝」作动词，以之为宝而爱护。这不是把气想象成一种可以任意操纵的物质，而是在传统道教语境中要求减少精神耗散、节制欲望、使形神相养。

「学道无心」——不是不修，也不是无意识，而是不再带着强烈的占有心、功利心和自我意识：不想靠修道获得名声，不想证明自己有境界，不想把大道当作自己的所有物。从【敬信】的「克己勤行」到这里的「学道无心」，形成由有为入无为的过程。

「神与道合，谓之得道」——这里的「得」不是占有，不是「我获得了道」，而是「我对道的阻隔消失」。

十四、「同于道者，道亦得之」 ​

（《道德经》第二十三章，通行本作「同于道者，道亦乐得之」）——自身与道相同相应，大道也便在其身上显现；它不是单向占有，而是相互契合：

text
人以虚静同道 → 道力集于其身；人不再外求 → 道自然为其所得
得道 = 人同于道 + 道显于人

「古之所以贵此道者何？不日求以得，有罪以免邪？」（近《道德经》第六十二章）——古人为什么珍贵大道？不正是因为求之可得、有过者也能借此改过免咎吗？这里说明大道不是只属于无过失之人：修道本身就是净除心垢、改变旧业、由迷返明。若必须先天完美才能修道，就失去了道「常善救人」的意义。

十五、「山有玉，草木以之不雕」 ​

这是古代常见的「玉气润山」观念（现代自然科学并不支持美玉必然使山中草木不凋，此处主要是象征性、传统气化论式譬喻）：

山玉之喻修道之义
山人身
玉大道
玉气润草木道力润形神
草木不雕形骸长固

司马承祯借此说明：道不只改变内在认识，也能外及身体。 与【敬信】「怀宝求宝」相承：前者强调不要向外求道，后者强调内在道力可以进一步薰养形体。

十六、「资薰日久，变质同神」 ​

「资薰日久」——「薰」像香气长期熏染衣物，不是一次完成：

text
一次静坐不足以改易形神，一次悟理不足以炼形入微
长期定慧相养、神气不漏，才能逐渐发生深层变化

「变质同神」——身体原本粗重的形质逐渐变化，变得与神同样虚妙（普通关系是「神虚而形滞」，修炼完成后则是「形质入微，与神同妙」），所以形神才能不相分离。

「炼形入微」——「炼形」是道教神仙学的重要观念，它不是单纯锻炼体格，而是改变形体的存在层次（粗形→气化→神化→与道冥一）。本篇没有详细讨论吐纳、服气、存神或外丹等具体技术，而把炼形的根本放在虚心、定慧、含光、凝神、宝气。因此，《坐忘论》的炼形路线首先以心性修炼为核心。

「与道冥一」——形与神最终都在幽深无迹中与大道合而为一。「冥」表示不是外在拼合、不是概念宣布、不是「我与道合一」的自我感觉，而是界限和阻碍自然消失：心不再与道隔，神不再与道隔，形也不再与道隔。

十七、「散一身为万法，混万法为一身」 ​

text
散一身为万法 → 一中有多
混万法为一身 → 多不离一

因为真身与道冥一，所以个体与万有之间不再具有绝对隔离。

但这不能理解为普通自我无限膨胀——不是日常自我成为宇宙中心，也不是「我可以任意控制万物」。恰恰相反，只有经过忘形、忘名、无心、与道冥一，「小我」不再占据中心，才谈得上一身与万法相通。如果仍是「我要拥有万法、控制万物」，就只是把世俗占有欲扩大为宗教性的自我膨胀。

十八、「智照无边」与「总色空而为用」 ​

「智照无边」是【泰定】「发乎天光」的最终展开：「初步真观（照见自身欲望爱恶）→ 泰定（几微入照）→ 得道（智照无边）」。「形超靡极」仍属神人真身的神仙学描述，与蹈水火、对日月无影同属一个理论体系。

「总色空而为用」——「色」是有形有相的现象，「空」是无固定自性、不可执取（明显带佛教色空语言影响）：得道者统摄有形与无形而自在运用，不滞于任何一端。这与【收心】早已确立的原则一致（「若执心住空，还是有所」）：

text
不执有形 → 形可以入微；不滞于空 → 神可以随气显形；色空互通 → 隐显自在

佛教传统常以色空观破除自性执著；司马承祯将其纳入形神仙化，终点不是单纯证空，而是成就道教「真身」。

「含造化以成功」——得道者不是凭个人私意造作，而是与造化同流：不是「我能」，而是「道通过真身而用」。「真应无方」不是无原则，而是不拘一法——隐显无定、动静不滞、随物而应、应后不留，与【收心】「神用无方」首尾呼应。「其惟道德」——得道者之能有无方妙用，不是由于小我能力无限，而是由于小我不再阻碍道德之用。

十九、《西升经》「与天同心而无知，与道同身而无体」 ​

「与天同心而无知」——心与自然天道相同，不再以人为分别智和机心造作。「无知」不是愚昧，也不是丧失智慧，而是：没有自以为知、不用智巧控制万物、不把智慧据为个人所有。这正是【泰定】「慧而不用」的最终形态。

「与道同身而无体」——身体与大道相同，不再固执为一个固定、有限、粗重的实体。「无体」不是完全没有存在，而是无固定形体可限、不执一形为真实自我，对应前文「隐则形同于神，显则神同于气」。

说法所破除者并非
无知人为智巧和自我占有无觉、愚昧
无体固定粗重形体之执彻底不存在

「然后天道盛矣」——个人的机心和形执越少，道的自然作用越充分。「谓证得其极者也」——这不是普通初学者可以口头自称的境界：全书一再反对未成而称无累、处动而自称常寂、得少慧便多辩。因此这里的宏大神通描述必须放在七阶全部成熟之后理解。

二十、「神不出身，与道同久」与六根洞达 ​

「神不出身」——普通死亡的根本在形神分离；神人长久的根本则在神凝而不散、气充而润形、形炼而入微、形神合为真身：

text
尸解：神出其身，舍形而去
真身：神不出身，形神同化，共同长久

司马承祯显然把后者视为更完整的得道。

「身与道同，则无时而不存」是道教长生不死理想的直接表达。「心与道同，则无法而不通」不是掌握所有百科知识，而是心与万法共同根源相契——若仍用世俗心衡量，它并不等于永远不会犯事实错误、不经学习便懂一切。 耳、眼与道同则「无声而不闻」「无色而不见」，与上句相同，同时具有感官无碍、智慧无蔽的含义，也包含超常感官能力的宗教信仰。

「六根洞达」使用佛教术语（眼耳鼻舌身意），再次显示道佛会通：「良由于此」——六根之所以洞达，正是由于整个形神都已与道相同。所以六根洞达不是单独训练某种感官异能得来的，而是形神道化的结果：

text
不是追求耳聪目明 → 才能得道；而是形神与道同 → 六根自然洞达

这也说明不可把神通当作起点或主要目标。

二十一、「舍形之道」与「即身之妙」 ​

「近代常流，识不及远，唯闻舍形之道」——他们只听说过舍弃身体、使神识脱离形骸的成仙方法（这可能包括尸解、只重心性觉悟、把身体视为纯粹累赘）。司马承祯认为这种方法并非完全无效，但层次不够圆满。

「未达即身之妙」——他们没有理解，不必先舍弃身体，这一现有形身本身也可以经过道化而成真：

text
不是离身之外另求真身，而是此身经道力薰炼，由粗入微、由形合神，由凡质转为真身

（这里的「即身」与后来佛教密教「即身成佛」等术语不能简单等同；司马承祯表达的是道教的即身神仙化、形神俱妙。）

舍形即身
身体是需要离弃的障碍身体是可以炼化的基础
神成而形谢形神共同成真
道力及心道力兼被于形
尸解真身、神人
成就尚未全备得道之极

「无惭己短，有效人非」可理解为：他们不以自己的见识短浅为惭，反而仿效或附和他人的错误——把不了解当作不存在，甚至把舍形说成唯一道路。这正引出下面两个认识局限的譬喻。

二十二、「夏虫不信冰霜，醯鸡断无天地」 ​

「夏虫不信冰霜」近《庄子·秋水》「夏虫不可以语于冰者，笃于时也」：

譬喻所指
夏虫见识局限之人
夏季经验只知普通形体或舍形之法
冰霜形神合同、即身成真的境界
不信冰霜因未经历而否定其可能

「醯鸡」是醋瓮中滋生的小虫，生活在狭小容器中而视野极为有限。它比夏虫譬喻更进一步：

text
不知道，本来只是经验有限
却从「不知道」跳到「不存在」，便成为武断

「其愚不可及，何可诲焉」——本篇以严厉批评结尾，说明司马承祯对「即身成真」的坚持：形神俱妙不是可有可无的附加理论，而是他所理解的道教得道之极。

（从现代认识论看，「没有见过不能直接证明不存在」是合理提醒；但反过来，「有人宣称存在」也不能自动构成实证。原文是在宗教传统内部立论，应依其经典体系理解。）

本篇最重要的六组辨析 ​

不是而是
向外抓取大道虚心谷神，使自身与道相应
只有心中觉悟道力进一步兼被于形
得少慧便多言多事含光藏辉，凝神宝气
舍弃身体才是最高成就炼形入微，形神合同

执有形或滞空无总摄色空，隐显无碍

容易误解的地方 ​

  1. 「神异之物」不是普通物质对象——道无固定形象，不能像外物一样被定位和占有；「物」在此是对真实存在或真实作用的强调。
  2. 「虚而无象」不是绝对虚无——道虽无象，却「通生无匮」，具有无穷生化作用。
  3. 「不知所以然而然」不是拒绝理性——它说明大道的最终根据不能被普通因果概念完全穷尽，不表示日常事务无须理性分析。
  4. 「形神合一」属于道教神仙学——不能直接当作现代医学关于人体不死的结论。
  5. 「蹈水火而无害」不可进行现实模仿——现实人体会被水火严重伤害；任何修行体验都不能成为冒险试验的理由。
  6. 「慧而多辩致早终」不能机械化——过度劳心可能影响健康，但现实寿命由复杂因素共同决定，不能据此评判早逝者的修行。
  7. 尸解在不同道教传统中的地位并不一致——本篇将其置于形神俱化之下，但不能据此概括所有道教经典对尸解的看法。
  8. 「无知」不是无慧——得道者仍然「智照无边」；无知所破的是人为机心和自以为知。
  9. 「无体」不是不存在——它是无固定粗重形体之执，而非断灭。
  10. 「六根洞达」不应成为追求异能的借口——在原文中它是形神与道同的结果，不是修行起点；若以神通为目标，反而重新落入贪求。
  11. 「即身之妙」不是纵容肉身欲望——「即身」要求炼形、凝神、宝气，并非以当前习气和欲望为天然完满。
  12. 不可因宗教信仰否定医疗与安全——贵生、全生贯穿《坐忘论》；身体有病应当合理治疗，危险环境应当回避。

「得道」之「得」究竟是什么意思 ​

一、不是把道变成「我的东西」——大道虚而无象、通生万物，不可能成为个人私有物。若心中仍有「我已经得道」「我比他人高明」「我掌握了特殊能力」，便说明名心仍在，尚未真正做到无心、忘名。

二、「得道」首先是人与道相应：

text
人虚心 → 与道之虚相应；人无为 → 与道之自然相应
人不争 → 与道之无私相应；人通生 → 与道之生化相应

不是将道纳入自我，而是使自我不再成为道的阻隔。

三、「得」也可以理解为「不失」——普通人的道性并未彻底消失，只是受到贪爱、多事、名利、妄想、自是、生死恐惧层层遮蔽：

text
不再逐境 → 心不失其静；不再多事 → 神不失其凝
不再炫慧 → 气不失其全；形神皆不外散 → 道不失于身

四、最高的「得」反而无所得心——「学道无心」意味着修而不以修自居、得而不以得自满。

越想把道占为己有，越不能得；越能虚心忘我，道越能自然来集。

「神异」是不是得道的判断标准 ​

本篇描写了许多神异能力，但依全书次第，它们不能成为初学者判断得道的主要标准。

一、神异是结果，不是起点——原文的次序不是「追求神通→获得神通→因此得道」，而是敬信、断缘、收心、简事→真观、泰定→含光藏辉、凝神宝气→形神与道冥一→真应无方、六根洞达。

二、追求神异本身仍是一种贪爱——如果修行只是为了获得超常能力、延长寿命、显示不同、吸引崇拜，便仍没有离开【断缘】【收心】所批评的名利结构：

text
世俗贪求：我要拥有名利；宗教贪求：我要拥有神通
共同点：都以所得强化自我

三、真正的征验仍在心行——较可靠的修行征验是：贪爱是否减少？毁誉是否仍能夺心？事务是否更加清简？有慧以后是否更少争辩？面对生死是否较少恐惧？能否行善而不居功？若这些基础没有变化，仅有奇异体验，不能据此认定得道。

四、神异描述必须保留安全边界——现实中不应尝试以身体验证水火不害、不食不饮、肉身不死等。经典中的宗教描述不能替代物理规律、医学常识和安全判断。

实践启示 ​

一、不要把少许明白当作全部完成——能理解经典、观察念头，只表示道力开始「及心」，不等于已经形神俱化。应继续观察：生活是否真正改变？智慧是否减少而非增加烦恼？是否从「知道」进入「做到」？

二、智慧越增长，越应减少自我表现——刚明白某些道理时，最容易急于言说。可以先问：这句话现在有必要说吗？是为了帮助事情，还是为了证明自己？说完以后能停止吗？是否会由此引出更多非必要关系？这就是现实中的「含光藏辉」。

三、修心不能长期以损害身体为代价——既然本篇主张道力最终「兼被于形」，修行就不应表现为长期损害身体（过度绝食、严重睡眠剥夺、强忍疾病而不就医、以痛苦程度证明境界、进行危险试验）。真正的形神相养，应使生活整体趋向有序、节制和稳定。

四、减少泄漏神气的无益活动——按本篇语言，常见的「神气漏泄」包括无止境争论、反复证明自己、过量社交、长期沉浸毁誉、事务触类增长。现代不必把「神气」机械物质化，也能理解其经验意义：注意力、情绪与体力若长期向外耗散，身心便难以稳定。

五、让身体也参与修道——「即身之妙」可以先落实为较基础的形神协调：饮食适量、作息稳定、动静有节、情绪出现时能够觉察、必要时接受医疗与专业帮助、不把身体当作欲望工具也不当作敌人。

完整路线图 ​

text
总色空而为用：不滞于有形，也不沉于空无
        ↓ 含造化以成功：不以个人机心强作，而使大道生化之用自然显现
真应无方：因境而应，随物而化，没有固定不变的作用形式
        ↓ 与天同心而无知：不以人为智巧经营万物
与道同身而无体：不再受固定、粗重的形质限制
        ↓ 无知而智照无边，无体而隐显自在
神不出身：形神不再分离
        ↓ 身与道同，则无时而不存；心与道同，则无法而不通
耳目乃至六根与道同，则洞达无碍
        ↓ 六根洞达并非独立追求异能所得，而是整个形神与道相应的结果
由舍形之道，进一步通达即身之妙
        ↓ 不是抛弃此身以后才求成真，而是使现有形神共同接受道力薰习
不只神有所成，形体也由粗入微、由滞入通
        ↓ 不只心中知道大道，整个生命都与大道冥合
形神俱妙，即身成真 → 由凡入圣，成就神人 → 与道同久，是谓得道

压缩成四个核心阶段：

text
第一阶段：道集于心——虚心谷神，克己勤行，使心神先与大道相应
第二阶段：慧而不泄——虽得慧觉，却含光藏辉，不因多知好辩而耗散神气
第三阶段：道力被形——凝神宝气，资薰日久，使形质逐渐由粗重转为精微
第四阶段：形神俱化——身神并一，形随道通，最终与道冥一，成就真身

其中最关键的转折点是：得慧以后，能否含光藏辉。

text
若不能：定极生慧 → 得少慧而自悦 → 多言好辩 → 兴心徇事 → 神气漏泄
      → 道力只及于心 → 形体未能受道薰化 → 身不免谢

若能：  定极生慧 → 慧而不用 → 含光藏辉 → 凝神宝气 → 神气内全
      → 道力兼被于形 → 变质同神 → 炼形入微 → 身神并一 → 成就真身

由此可见，【得道】并不是突然出现的第七步，而是前六篇所有功夫的最终结果：

text
没有敬信 → 不能长期勤行；没有断缘 → 神气耗于人事
没有收心 → 心神逐境外驰；没有简事 → 形神疲于事务
没有真观 → 爱恶妄想不能解除；没有泰定 → 定慧不能彼此涵养
前六阶不能成熟 → 道力便难以由心及形

小结 ​

【得道】把《坐忘论》的修行由心理层面推向整个生命的转化。它从大道的性质开始（「灵而有性，虚而无象，通生无匮」），继而说明修道者如何与道相应（「上士纯信，克己勤行，虚心谷神，唯道来集」）。

道力初步作用于心，使人得到慧觉；但司马承祯认为这还不是最高成就。若修行者因少许智慧而喜悦多辩，便会：

text
慧向外驰 → 心神劳损 → 神气漏泄 → 形体不得道力润养 → 道果难以全备

因此必须「含光藏辉，凝神宝气，学道无心」。长期如此，道力才由心及形：

text
资薰日久 → 徐易形神 → 变质同神 → 炼形入微 → 形随道通 → 身神并一 → 与道冥一

本篇最关键的五句话是：

道有深力，徐易形神。深则兼被于形，浅则唯及于心。慧是心用，用多则心劳。含光藏辉，以期全备；凝神宝气，学道无心。资薰日久，变质同神，炼形入微，与道冥一。

它们共同构成【得道】的核心论证：道能改变生命，但改变有深浅；只有心明尚未全备；智慧若向外炫用，便会阻断形神继续转化；智慧若含藏，神气便能润养形体；最终不是舍形求道，而是形神俱化、即身成真。

附：《坐忘论》七篇总纲 ​

至此，《坐忘论》七篇全部贯通。全书可以概括为一条由外而内、由心及形的路线：

text
敬信 解决「是否相信大道」的问题
断缘 解决「外界关系不断牵心」的问题
收心 解决「内在念头随境流浪」的问题
简事 解决「事务过多耗散形神」的问题
真观 解决「为何会爱、会恶、会怕、会怨」的问题
泰定 解决「定极生慧后，智慧是否反伤清静」的问题
得道 解决「道力能否由心及形，使整个生命成真」的问题

若再压缩，全书只有三个大阶段：

text
第一阶段 为道清障：敬信 → 断缘 → 收心 → 简事
（使外缘减少、内心安定，为真观创造条件）

第二阶段 由定发慧：真观 → 泰定
（看清爱恶妄执，并使定慧彼此涵养）

第三阶段 形神俱化：得道
（使大道之力由心及形，最终形神合同、与道冥一）

全书最简洁的逻辑则是：

text
外不逐缘，内不逐念，事不过分，观不带欲，定不灭照，慧不外驰，形神俱化

这便是《坐忘论》从凡俗心行通向得道的完整道路。

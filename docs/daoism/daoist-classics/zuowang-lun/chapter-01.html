坐忘论·敬信

坐忘论第一篇精读：信为道根、敬为德蒂；有形之物尚且难信，何况无形之道；信敬必须落实为勤行。

导读坐忘论司马承祯

坐忘论·敬信 ​

入读提示

信是道之根，敬是德之蒂

第一篇解决的不是技巧，而是方向：若不信坐忘是修道要门，一遇困难便会退转。但「敬信」不是盲信——它要求认可其价值、尊重其方法、亲自实行，再由实践验证。它同时提前给出了全书的终极境界：内不觉其身，外不知宇宙，与道冥一。

立根蒂 根深则道可长，蒂固则德可茂。破反例 卞和以玉致刖、伍子以言从诛——形器已著而心绪反迷。归勤行 信、敬之外，还要「加之勤行」，得道方必。

此篇可与《天隐子·神仙一》对读：一篇说人本有灵气，一篇说信敬是修道之根，同是「先正见地」。

【原典层】原文 ​

一、信敬是道德的根蒂

夫信者道之根敬者德之蒂根深则道可长蒂固则德可茂

二、有形之物尚且不被相信

然则璧耀连城之彩卞和致刖

言开保国之效伍子从诛

斯乃形器著而心绪迷理事萌而情思忽

况至道超于色味真性隔于可欲

而能闻希微以悬信听罔象而不惑者哉

三、敬信坐忘，勤行得道

如人闻坐忘之言信是修道之要敬仰尊重

决定无疑者加之勤行得道必矣

故庄云隳支体黜聪明离形去智同于大通是谓坐忘

四、坐忘所忘与信不足之患

夫坐忘者何所不忘哉

内不觉其一身外不知乎宇宙与道冥一万虑皆遗

庄云同于大通此则言浅而意深

惑者闻而不信怀宝求宝其如之何

经云信不足焉有不信

谓信道之心不足乃有不信之祸及之何道之可望乎

【原典层】字词释义 ​

dì蒂

花蒂。根深蒂固，喻根基牢固——道以信为根，德以敬为蒂。信解决方向，敬解决态度。

biàn卞hé和zhì致yuè刖

事见《韩非子·和氏》：卞和献玉璞，两代楚王听玉工之言以为石，先后刖其双足。喻真实之宝因识见昏昧而不被承认。

wǔ伍zǐ子cóng从zhū诛

伍子胥谏吴王夫差警惕越国，不被采纳，反受赐死，后越果灭吴。与卞和并列，皆谓才器显著而心绪反迷。

xíng形qì器zhù著

形器，有具体形态之物；著，显著。谓对象明明可见可验，心却仍然迷惑。

lǐ理shì事méng萌

理事，事物中的道理与征验；萌，开始显露。谓事理与征兆已经显现，人却因情感成见而轻忽。

xī希wēi微

语本《道德经》第十四章：「听之不闻名曰希，搏之不得名曰微」。指大道无声无形、幽隐难见。

xuán悬xìn信

悬，悬远、尚未亲见。谓虽未直接证得，仍对幽微之道建立坚定信心——这是初学的起步方式，不是终点。

wǎng罔xiàng象

无形无象、恍惚幽隐、不能以具体形象限定。可与《庄子·天地》「象罔得玄珠」参看。

huī隳zhī支tǐ体

隳，消解、放下；支体，四肢身体。谓放下以身体感受、欲望与边界为中心的执著，非伤害身体。今本《庄子》多作「堕肢体」。

chù黜cōng聪míng明

黜，退去其主导地位。谓不把感官分辨与智力计算视为通向大道的最高能力，非教人愚昧。

lí离xíng形qù去zhì智

不再执身形为真实固定的自我，不再执分别判断为认识大道的唯一方式。所去者是「执」，不是正常功能。

tóng同yú于dà大tōng通

大通，无所阻隔、与道贯通。「我与万物绝对对立」的执著暂时消融，非谓事实差别消失。

míng冥yī一

冥，幽深无形，亦有暗合默契之义；一，合而不分。谓在幽深无迹中与道合一，不留外在痕迹，也无「我成功进入合一」的宣告。

wàn万lǜ虑jiē皆yí遗

种种思虑都被放下，不再留藏于心。遗，非暴力消灭，而是放下、不再承载。

huái怀bǎo宝qiú求bǎo宝

怀中本有宝，却向外求宝。宝指人与生俱来的真性、灵明与道性——道不在外，真性原本是自身之宝。

【解读层】精读 ​

一、信是道之根，敬是德之蒂 ​

「信」是信受、确认，不再反复犹疑；「敬」是尊重、慎重，不轻慢、不怠惰。二者各有侧重：

text
信如根：使修道有立足之处，不因怀疑而轻易动摇
敬如蒂：使道不只停留在观念中，而能落实、结成果实
  • 「信」解决方向问题：我是否真正认定坐忘值得实行？
  • 「敬」解决态度问题：我是否认真、持续地对待已经认定的道路？

有信而无敬，容易变成口头认同（觉得道理很好，却不肯调整生活）；有敬而无信，则可能只剩形式（恭敬仪式、尊崇权威，却不明白自己为什么修）。信使方向确定，敬使行动郑重，二者相合，才算开始真正修道。

「根深则道可长，蒂固则德可茂」——「可长」「可茂」说明敬信只是起点：种子有根不等于已是大树，相信坐忘不等于已经达到坐忘。它也解释了为什么【敬信】之后紧接【断缘】：真正的信敬必须表现为现实生活中的取舍；若一切外缘照旧经营，只说自己信道，根仍没有扎进土里。

二、有形之物尚且不被相信 ​

卞和献玉（《韩非子·和氏》）：楚人卞和得玉璞，先后献给厉王、武王，玉工却说是石头，卞和因此两遭刖足。后楚文王命人剖开，果得美玉，即和氏璧。玉是「形器著」的——有具体形体、可以剖开检验、最终能证明价值；即使如此，人仍可能因成见与判断错误而拒绝相信。

伍子胥进谏：他多次劝夫差警惕越国、不可因眼前胜利而放过后患，夫差不听谗言反赐其死，后越果灭吴。这是「理事萌」——越国的威胁并非无从预见（勾践忍辱求存、越国暗复国力、吴国连年用兵而疲弊），事情已显端倪，却因骄傲、好胜与个人爱恶而被忽略。

卞和伍子胥
献上真玉献上忠言
玉有实际价值忠言有实际效用
世人不能识玉吴王不能识忠
卞和遭刖伍子胥遭诛
text
形器已著，却不能识物
理事已萌，却不能识机

二者共同说明：有形可验、事理可察的真相，人尚且会因迷惑而拒绝；无形无象的大道，自然更难得到信受。

人不能认识真实，不一定因为真实过于遥远，也可能是因为心已被成见、利害、好恶、对权威的依从、对忠言的排斥所干扰。所以认识问题首先是心的问题——这已预告了【真观】的主题：真正的观照，必须建立在欲望减弱、心绪清静的基础上。

不过本篇并非要求盲目相信他人，也不意味着「无法验证的说法就更该相信」；它诊断的是认识障碍：我是否只相信符合自身欲望的东西？是否把不合己意的忠言当成错误？是否把暂时看不到效果，等同于方法没有价值？

三、至道为何更难相信 ​

「至道超于色味」——美玉能被眼睛看见，食物能被口舌尝到；大道却不是可以摆在眼前、供感官占有的东西。「超于色味」不是说大道在遥远的另一个世界，而是说：道不是一个与其他物品并列的感官对象。人可以看见某种合道的行为，却不能像看见器物一样看见「道自身」。

这与《道德经》第十四章相应：「视之不见，名曰夷；听之不闻，名曰希；搏之不得，名曰微。」

「真性隔于可欲」——不是说真性远离人，而是说真性与通常的欲望机制不在同一方向：

text
可欲之物：通过追逐、占有而得
真实本性：通过减少遮蔽、停止外驰而显

欲望的基本结构是「感到缺少 → 把某物当成满足对象 → 努力占有 → 短暂满足后又追下一个」。但真性不是外在物品，不能被「我」占有；修行要做的不是获得一个新对象，而是使不断占有对象的心安静下来。这与总论「将生灭质，求无为道」的批评相连：若仍以追逐可欲之物的心态追逐真性，就把修道变成了另一种占有。

「闻希微以悬信」——「希微」语出《道德经》第十四章，成为大道无声无形的代称；「悬信」谓虽未亲证，仍建立坚定信心。初学者尚未亲证，须暂时依据经典的指引、前人的经验、自己对生活困境的反省与初步实践的身心验证：

text
最初：闻道而信 → 继而：依信而行 → 再后：由行而知 → 最终：亲自契入

所以敬信是「根」，不是最后的「果」。

「听罔象而不惑」——罔象指无形无象、不能用具体形象限定（可与《庄子·天地》「象罔得玄珠」参看）。世俗事物看得见、尝得到、可以交易，所以容易相信；坐忘之道要求减少欲望、放下占有，初期又难以直接看见成果，所以容易怀疑。敬信不是多余的宗教装饰，而是帮助人跨过**「尚未亲证」的阶段**。

四、信敬必须落实为勤行 ​

「信是修道之要」中的「信」有明确对象：不是泛泛相信神秘事物，而是相信坐忘是修道之要。因为修道的主要障碍正是心神不断向外驰逐（逐声色、名利、毁誉、知识、修行境界、乃至「我将成为怎样的人」）；坐忘不是额外增加一个对象，而是从根本上松开这种逐取活动，所以它触及修道的枢要。

「敬仰尊重，决定无疑者」——「决定无疑」不等于禁止提问。可以区分两种「疑」：

  • 有益的审察：这句话究竟怎样理解？我现在的做法是否过紧？这是清醒安定还是昏沉？——帮助辨别正误。
  • 使修行无法开始的摇摆：今天试这个明天换那个；因暂时没有特殊感受便否定方法；一遇杂念便认为自己不能修；永远研究方法却不实际开始。

「加之勤行，得道必矣」——关键不只是「必矣」，而是「加之勤行」：

text
闻道 ≠ 得道    信道 ≠ 得道    敬仰 ≠ 得道
敬信 + 勤行，才构成实际修道

这与总论「重道德之名，轻道德之行」直接相接。「勤行」不是追求高强度，而是长期持续、不随情绪中断：从断缘、收心等基础做起，念起时觉察并收回，在日常行住坐卧中安养其心。

五、《庄子》所说的坐忘 ​

书中引「隳支体，黜聪明，离形去智，同于大通，是谓坐忘」，出自《庄子·大宗师》颜回与孔子的对话（今本常见作「堕肢体，黜聪明，离形去知，同于大通，此谓坐忘」，底本作「隳」「智」）。

语所去者注意
隳支体以身体感受、欲望与边界为中心的执著非伤害身体——那反而与道教保养性命相冲突；是身体不再占据全部意识中心
黜聪明把感官分辨与智力计算视为通向大道的最高能力非教人愚昧；是把智巧从主人位置退下来
离形去智不再执身形为固定自我，不再执分别为唯一认识方式所去者是「执」，不是正常功能
同于大通「我与万物绝对对立」的执著不是说事实差别消失，而是主体与对象的分立暂时消融

「黜聪明」所退去的，正是总论批评的「自云智巧」：聪明可以帮助处理事务，也可能不断强化计较、分别、自我证明与名声竞争。而「离形去智」所去的是执，这为《枢翼》的「唯灭动心，不灭照心」预留了空间——坐忘要去除攀缘智巧，却不消灭清醒觉照。

六、坐忘究竟忘什么 ​

「夫坐忘者，何所不忘哉」——这个反问表示坐忘之「忘」是彻底的，可分几层：

text
忘外缘：不再反复经营名利、人情和毁誉
忘所欲：不再让声色财货占据心神
忘形：  身体不再成为自我执著的中心
忘智：  不再依赖分别、辩论和机巧把握道
忘我：  不再突出一个修道、得道的主体
忘忘：  连「我已经忘了什么」的意识也不保留

最后一层本篇未明说，却与《天隐子》「因存想而得也，因存想而忘也」完全相通。

「内不觉其一身」——不是昏迷、麻木、失去身体知觉，也不是故意压制呼吸或感官；而是说在深度安定中，平常异常突出的身体中心感逐渐淡化。静坐时人通常不断觉察（腿是否舒服、姿势是否正确、有没有进步），这些自我监控一旦不断占据注意力，「一身」就仍然鲜明。

「外不知乎宇宙」——不是知识丧失，而是外界不再成为攀缘分别的对象：外界仍然存在，但心不再不断把它组织成与「我」有关的欲望与利害网络。

text
内不执我，外不逐物 → 我与物的对立暂息 → 与道冥一

「与道冥一」——不同于通过概念得出「万物是一」的结论。若只不断告诉自己「我与道合一」，仍有一个「我」、一个「道」、一个「合一」的观念。真正的「冥一」不留外在痕迹：不一定出现奇异景象，不需要向人展示境界，甚至不应执著自己达到某种状态。

「万虑皆遗」——放下过去的追悔、未来的筹划、对毁誉的反应、对得失的计算、对修行进度的评判。「遗」不是暴力消灭，而是放下、不再承载。可与《庄子·应帝王》「至人之用心若镜，不将不迎，应而不藏」互相说明：念未起时不主动招引，念已起时不继续追随，事情过去不留藏于心。

七、言浅而意深 · 怀宝求宝 ​

「同于大通」只有四个字，却至少包含：身体中心感的淡化、感官攀缘的止息、智巧分别的退位、自我意识的松开、内外二分的超越、心神与道的相应。言浅而意深——若把「同于大通」变成哲学口号，却不经历断缘、收心、简事、真观、泰定，就仍是总论所批评的「重道德之名，轻道德之行」。

「惑者闻而不信，怀宝求宝」——「宝」指人与生俱来的真性、灵明与道性：

text
人本来禀道而生，真性并未真正失去，只是被欲望与思虑遮蔽
      ↓ 若不知道自己有宝，便不断向外求取
      ↓ 所得越多，外驰越甚，反而离本有之宝更远

这与《天隐子·神仙一》「修我灵气，勿为世俗所沦污；遂我自然，勿为邪见所凝滞」高度一致——两书都把修行理解为返与复，而不是外在占有。

但「怀宝求宝」并不意味着不需要老师与经典：本篇本身就在引《庄子》并要求「闻坐忘之言」。老师和经典的作用不是把道性从外面塞进人心，而是指出人本有的根本、揭示遮蔽所在、提供修习次第、帮助辨别偏差。可以比喻为：经典不是替你制造宝物，而是提醒你不要继续背着宝物向外乞求。

八、信不足焉，有不信 ​

「信不足焉，有不信」出自《道德经》第十七章（通行本多作「信不足焉，有不信焉」），原章讨论统治者与百姓的关系，本篇转用于个人修道。「不信之祸」不必理解成大道降罚，更适合从修习因果理解：

text
信心不足 → 不能决定实行 → 今日修、明日废 → 一遇杂念便退
        → 不断更换方法 → 修习始终不能深入
        → 最后以「没有效果」证明自己原先的不信

这是一种自我实现的循环。而且信心不足时，人会不断退回原来的价值尺度：以外在成就衡量修行、期待迅速获得特殊体验、以是否受人认可判断自己、仍用智巧和欲望追逐无为。

「何道之可望乎」是全篇结尾的反问：道无形无象，修习又必须长期调心；若连第一步的方向都不能确定，后面的七阶便无从谈起。敬信不是七阶中的一项普通内容，而是贯穿其余六阶的动力。

容易误解的地方 ​

  1. 敬信不是盲信——盲信不许提问、拒绝验证、只凭权威；本篇的敬信有明确对象与实践路径：闻坐忘之言 → 信其为修道之要 → 敬重不轻忽 → 加之勤行 → 在身心变化中逐步体认。
  2. 「决定无疑」不是不能辨别真伪——《枢翼》明说「虽知诵读其文，仍须辨识真伪」。它指修道方向不再反复动摇，不是取消思考能力。
  3. 「黜聪明」不是反智——所黜的是以聪明建立优越感、以智巧追逐名利、以辩论代替实行。真正的慧并未被取消，【真观】【泰定】正要讨论智慧的生起。
  4. 「内不觉身，外不知宇宙」不是昏迷——《枢翼》后来说得明白：「唯灭动心，不灭照心。」坐忘是清醒而不攀缘。
  5. 「万虑皆遗」不是压抑所有思考——《收心》说「如有时事或法要有疑者，且任思量，令事得济……悟已则止」。问题不在思考本身，而在它是否无休止地盘旋、是否由欲望与毁誉驱动、是否长期占据内心。
  6. 「得道必矣」不是只要相信即可——完整条件是：信受 + 敬重 + 决定 + 勤行。没有「勤行」，敬信仍只是道德之名。

现实启示 ​

  1. 我信的是「道」，还是修道带来的身份？ ——我是想减少执著，还是想成为一个「懂修行的人」？若修道成了新的身份资本，仍然是在向外求宝。
  2. 我是否因看不到即时效果而轻易放弃？ ——坐忘的变化往往并不戏剧化：对毁誉的反应稍微减弱、杂念起来后更快察觉、不再主动增加无谓事务、能在事情结束后放下。这些不如感官刺激强烈，却更接近真正的「根深蒂固」。
  3. 我所相信的，是否已经变成行动？ ——检验不是口头赞同，而是：是否开始减少不必要的外缘？是否给收心留出稳定时间？是否愿意放下反复证明自己的冲动？

        ↓

小结 ​

修道必须有根，成德必须有蒂；信是其根，敬是其蒂。

但人心容易被情欲与成见蒙蔽：真玉在前而不识，忠言有效而不听，何况大道希微罔象、不能由感官直接占有。因此初学必须经过：闻道 → 信受 → 敬重 → 决定 → 勤行。

本篇又提前给出全书的终极境界：内不觉其一身，外不知乎宇宙，与道冥一，万虑皆遗。 这不是昏沉，也不是失去正常能力，而是不执内身、不逐外境、不以智巧建立自我、不以欲望占有真性。

而「怀宝求宝」点明了坐忘的返归性质：大道并非完全在外，真性原本是自身之宝；修行不是向外获得一个新对象，而是停止外求，使本有的灵明不再受到遮蔽。

下一篇《断缘》将把敬信落实到现实生活：如果信道是真，便必须观察究竟有哪些关系、事务和机心正在持续牵引自己。

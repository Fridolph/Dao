坐忘论·引经据典 ​

《坐忘论》大量引经，但它不是现代论文式的原句引用——许多引文经过节取、改写，甚至把原典的应用范围整个转换了。本篇集中收这些引文的出处与原典语境。

出处标记分三级：

标记含义
明确出处可以确定对应经典及篇章
相近出处思想或语句接近，但并非逐字引用
暂待考目前不能可靠确定，不强作结论

二、逐条说明 ​

1. 《庄子·大宗师》：坐忘的根本出处（敬信） ​

书中引：「隳肢体，黜聪明，离形去智，同于大通，是谓坐忘。」今本《庄子·大宗师》常见文字为「堕肢体，黜聪明，离形去知，同于大通，此谓坐忘」。

这是全书题目的直接来源。《坐忘论》把它解释为「内不觉其一身，外不知其宇宙，与道冥一，万虑皆遗」——共同指向遗形忘我，但不是昏迷，而是主体与外物的对立不再成为意识中心。「隳／堕」「智／知」的差异，属传抄异文。

2. 《道德经》第十七章：信不足（敬信） ​

书中引：「信不足焉，有不信。」《老子》原文讨论统治者诚信不足、人民便不相信；《坐忘论》把它转化为修道心理——对道的信心不足，便会不断怀疑、退转，因而无从实践。典型的「引经转义」。

3. 《道德经》第五十二章：塞兑闭门（断缘） ​

书中引：「塞其兑，闭其门，终身不勤」，又引「开其兑，济其事，终身不救」。「兑」指感官、孔窍或心神与外界交通的门户；「塞兑闭门」不是毁掉感官，而是不让心神不停向外泄露。《坐忘论》直接用它来说明断缘。

4. 《庄子·应帝王》：不将不迎，与「无为名尸」（断缘） ​

书中引：「不将不迎」「无为谋府，无为事任，无为知主」。《庄子·应帝王》有「至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤」——事物未到不预先追逐，离去不继续挽留。这正是《坐忘论》处理外缘的原则：不是失去应对能力，而是不提前攀附、事后留滞。后一条反对的是显能、干进与机心交际。

5. 《道德经》第十六章：归根、复命、知常（收心） ​

书中引：「夫物芸芸，各归其根，归根曰静，静曰复命，复命曰常，知常曰明。」这是《收心》一篇最重要的经典根据：

text
收心离境 → 不再流浪 → 归根 → 静定 → 复命 → 知常 → 明

《天隐子·存想》中的「归根复命」也以此为来源。

6. 《道德经》第六十二章：坐进此道（收心） ​

书中引：「虽有拱璧，以先驷马，不如坐进此道。」即使有人手捧大玉、驾着驷马前来，也不如安坐而进献此道。《坐忘论》借它说明：外在珍宝远不如修心之道，而修法的关键又在实际安坐修习、不只在言说。「坐进此道」也在字面上加强了「坐忘」的修习意象。

7. 《道德经》第七十章：易知易行（收心） ​

书中引：「吾言甚易知，甚易行，天下莫能知，莫能行。夫惟无知，是以不我知。」《坐忘论》借此批评一种倾向：人们崇拜艰深晦涩的理论，对简单直接、可以实行的方法反而轻视；误把不可理解当高深，误把切实可行当浅近。这与《天隐子·易简》几乎完全一致。

8. 名家辩题「火不热」（收心） ​

书中批评：「又有言火不热，灯不照暗，称为妙义。」「火不热」属先秦名家辩题，《庄子·天下》记录过一系列类似命题（火不热、目不见、白马非马等）。《坐忘论》认为，若只以语言破坏常识，实践中却仍依赖火的热、灯的照明，就是言行相违。它反对的不是哲学辨析，而是把语言奇论本身当作修道成就。

9. 《道德经》第六十四章：起于毫末（收心） ​

书中说：「蔽日之干，起于毫末。」化用「合抱之木，生于毫末」。其义是：巨木自细小萌芽长成，圣人的自然无为也从初步练习积累而来——不能只模仿圣人「处事不染」的外表，却跳过收心、断缘的基础。

10. 《道德经》第六十五章：玄德与物反（收心） ​

书中引：「玄德深矣，远矣，与物反矣，然后乃至大顺。」这里的「反」是返归，也是与世俗逐物方向相反：

text
世俗方向：向外求取、不断增加
玄德方向：向内返归、日损有为

经过这种「与物反」，最后才能达到真正的大顺，而不是初学便自称无碍。

11. 《庄子·达生》：不务生命所不需要之物（简事） ​

书中引：「达生之情者，不务生之所无以为。」出自《庄子·达生》「达生之情者，不务生之所无以为；达命之情者，不务知之所无奈何」。真正通达生命实情的人，不追求生命根本不需要的东西。《坐忘论》据此区分性命所需、欲望余好、分内之事、分外之物——这是「简事」最重要的理论依据。

12. 随珠弹雀（简事） ​

书中说：「以隋珠而弹千仞之雀，人犹笑之。」隋珠即随侯珠，极贵重的宝物；用作弹丸射高空小鸟，是以至贵换至贱。《坐忘论》以此比喻：性命、道德至贵，名位、财货、欲望相对轻贱；为名利损害性命，就是以珍珠弹雀。

13. 《西升经》：抱元守一（简事） ​

书中引：「抱元守一，过度神仙，子未能守，但坐荣官。」《西升经》是早期道教重要经典之一，常以老子西出函谷、传道尹喜为叙事背景。这段话把两个方向相对：抱元守一，超越俗世；不能守一，只是安坐荣官、沉迷名位。它支持《简事》「不以位易志」的思想。

14. 《道德经》第一章：常无欲以观其妙（真观） ​

书中引：「常无欲，以观其妙。」《坐忘论》认为，只有经过收心、简事、减少欲望之后，才可能进行真观——因为欲望会预先规定我们看见什么：

text
有欲而观 → 只看见对象能否满足自己
无欲而观 → 才可能看见事物的根本和变化

15. 《庄子·齐物论》：鱼鸟不以美色为美（真观） ​

书中说：「又观色若定是美，何故鱼见深入，鸟见高飞……」这是对《庄子·齐物论》一段的化用——毛嫱、丽姬为人所美，鱼见之深入、鸟见之高飞、麋鹿见之决骤。「美」并非所有生命共同认可的绝对属性，而与观察者的感知与分别有关。《坐忘论》把这一相对性论证转化为戒除色欲的观法。

16. 《道德经》第十三章：无身何患（真观） ​

书中引：「及吾无身，吾有何患。」《坐忘论》借此观察疾病：病痛依托于身体，对身体的执著又增加心理忧患；若能松开「身体就是绝对自我」的观念，便可减少第二层烦恼。它并非说身体不重要，而是区分 身体的实际痛苦 与 心对身体的恐惧和执著——修行先减轻后者。

17. 《庄子·庚桑楚》：宇泰定而发天光（泰定） ​

书中引：「宇泰定者，发乎天光。」《坐忘论》把「宇」解为心之器宇，「天光」则是本性中自然显发的智慧：

text
心宇虚静 → 遮蔽减少 → 本有智慧自然显露

智慧不是从外面加入，也不是通过更多概念堆积出来，而是恢复本有的清明。

18. 《庄子·知北游》一系：知道易，不言难（泰定） ​

书中引：「知道易，而弗言难。知而不言，所以之天；知而言之，所以之人。」重点不是绝对禁止说话，而是：知道以后，不急于以言辞建立自我，不用智慧追逐名声。《坐忘论》由此提出「忘名比忘形更难」。

19. 《庄子·缮性》：以恬养知（泰定） ​

书中引：「古之治道者，以恬养智。智生而无以智为也，谓之以智养恬。」这里的「恬」近于定，「智」近于慧：恬静生智慧，智慧又守护恬静，定慧交养，道德自然显发——这正是《泰定》一篇的核心结构。

20. 《庄子·达生》：用志不分，乃凝于神（泰定） ​

书中引：「用志不分，乃凝于神。」心志不分散，精神不向多处泄露，久而久之，神凝而不乱。司马承祯以此说明定力是积习而成，并非突然获得。

21. 《道德经》第四十八章：日损有为（泰定） ​

书中说：「渐之以日损有为。」化用「为学日益，为道日损。损之又损，以至于无为」。七阶渐修表面上似乎不断增加方法，实际方向却是不断减少：

text
断缘：减少关系牵累    收心：减少外驰
简事：减少非必要事务  真观：减少爱恶妄执
泰定：减少智用与自我表现

所以它的「渐修」是一条逐渐做减法的道路。

22. 《道德经》第五十六章：挫锐解纷（泰定） ​

书中说：「法则挫锐解纷。」来自「挫其锐，解其纷，和其光，同其尘」。「挫锐」是减弱心智的锋芒，「解纷」是解除复杂缠结——不是消灭能力，而是不让能力转化为争胜与自我炫耀。

23. 《生神经》：身神合一（得道） ​

书中引：「身神并一，则为真身。」支持《坐忘论》的形神观：形不离神，神不弃形，身神合一才称「真身」。所以它的最高理想不是单纯抛弃肉身，而是使形神共同受到道的转化。

24. 《西升经》：形神合同（得道） ​

书中引：「形神合同，故能长久」，又引「与天同心而无知，与道同身而无体」「神不出身，与道同久」。这些共同支撑一种道教「即身成真」的方向：神不必通过厌弃身体才能得道；形与神可以共同转化。这也是《坐忘论》批评「唯闻舍形之道，未达即身之妙」的理论依据。

25. 《道德经》第二十三章：同于道者（得道） ​

书中引：「同于道者，道亦得之。」（通行本多作「同于道者，道亦乐得之」。）修道不是主体占有一个外在对象，而是人趋同于道，道也自然在其身心中呈现。

26. 《道德经》第六十二章：贵道之由（得道） ​

书中引：「古之所以贵此道者何？不日求以得，有罪以免邪？」道之所以可贵，在于求之可以得、有过可以由此返回，不会永远抛弃处于迷误中的人。《坐忘论》据此强调：修道是「复归」，而不是创造一个全新的自我。

三、「经云」而暂未定出处 ​

底本中还有几处只写「经云」、未标书名：

  • 「至道之中，寂无所有，神用无方，心体亦然。」
  • 「人能虚心无为，非欲于道，道自归之。」
  • 「色者，想尔，想悉是空，何有色也？」
  • 「今代发心为夫妻，死后不得俱生人道。」
  • 「天地不能改其操，阴阳不能回其业。」
  • 「吾本弃俗，厌离世间。」
  • 「耳目声色，为子留愆；鼻口所喜，香味是怨。」

其中一些很可能出自《西升经》或其他早期道教经典，也有些带着明显的佛教观念与语言。在未逐一核对可靠版本之前，不宜只凭语感强行指定出处。

四、《坐忘论》如何使用经典 ​

  1. 直接引文：基本保留原典文字，如「吾言甚易知，甚易行」。
  2. 节引：从较长段落中抽出最需要的一句，如「用志不分，乃凝于神」。
  3. 改写或异文：如《庄子》常见「堕肢体」，底本作「隳肢体」；「离形去知」又可能作「离形去智」。可能来自当时所见版本，也可能是传抄异文。
  4. 转换应用范围：如「信不足焉，有不信焉」原与政治治理有关，被转为修道信心；「塞兑闭门」在《老子》中含义广泛，被具体应用于断绝俗缘。

因此，读每一处引文时可以同时问两个问题：原典在自己的上下文里说什么？司马承祯把它转化成了什么修炼方法？

五、佛教思想的位置 ​

《坐忘论》主要使用道家、道教名词，却明显处在唐代三教交涉的思想环境中。其中带有佛教色彩的内容包括：心受境染、断缘、收心离境、不著一物、真观、妄想本空、色由想生、业报与诸趣、地狱、定慧关系、不灭觉照、烦恼与旧业、新业不造、出离尘网。

尤其是「息乱而不灭照，守静而不著空」，与佛教止观对以下偏差的防范很接近：只有止而没有观容易昏沉；执著空境仍是执著；灭除一切觉知会落入无记或盲定；定中异象不可执取。

但《坐忘论》的最终归宿仍是道教性的：归根复命、神与道合、形神合同、炼形入微、长生、真人、神人、至人。因此它不是一部佛教禅定论，而是吸收佛教观心方法后重新道教化的坐忘论。

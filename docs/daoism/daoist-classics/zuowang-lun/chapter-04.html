坐忘论第四篇精读：知生有分、识事有当；权衡轻重而保全形神，不为外物耗损性命。

导读坐忘论司马承祯

坐忘论·简事 ​

入读提示

知生有分，识事有当

【收心】处理心与念头的关系；【简事】进一步调整生活的外在结构。它不是把所有事清空，而是根据生命所需、能力限度与修道目标重新决定去取——哪些必要、哪些只是欲望附加、哪些属于分内、哪些已经足够。

知分 生命、时间与能力都有现实限度——不务分之所无。识当 事情各有合适的承担者与处理方式——不任事之非当。知足 有用者取其足，多余者亦须舍；非要非重者皆应绝之。

此篇可与《天隐子·斋戒》对读：一个节的是食，一个简的是事，同是「去其多余、取其足用」。

【原典层】原文 ​

一、人离不开事物，却不必承担万事

夫人之生也必尝于事物事物称万不独委于一人

巢林一枝鸟见遗于丛泊

饮河满腹兽不吝于洪波

外求诸物内明诸己知生之有分

不务分之所无识事之有当不任事之非当

任非当则伤于智力

务过分则弊于形神

身且不安何能及道

二、取舍：知闲要、量轻重、识去取

是以修道之人莫若断简事物知其闲要

较量轻重识其去取非要非重皆应绝之

犹人食有酒肉衣有罗绮身有名位财有金玉

此并情欲之余好非益生之良药

众皆徇之自致亡败

静而思之何迷之甚

三、达生：不求生命所不需要之物

庄云达生之情者不务生之所无以为

生之所无以为者分外物也

蔬食弊衣足养性命岂待酒肉罗绮然后生全哉

是故于生无所要用者并须去之

于生之用有余者亦须舍之

四、以性命为重，以外物为轻

财有害气积则伤人虽少犹累而况多乎

以隋珠而弹千仞之雀人犹笑之况背道德

忽性命而从非要以自促伐者乎

夫以名位比道德则名位假而贱道德真而贵

能知贵贱应须去取不以名害身不以位易志

五、初学不可冒充「处事无累」

庄云行名失己非士也

西升经云抱元守一过度神仙子未能守但坐荣官

若不简择触事皆为心劳智昏修道事阙

若处事安闲在物无累者自属证成之人

若实未成而言无累者诚自诳耳

【原典层】字词释义 ​

bì必cháng尝yú于shì事wù物

依底本作「尝」，文字略显不畅，或涉版本异文。按上下文理解为：人要维持生命，必然要接触、取用和处理一定的事物。

chēng称wàn万

称，举其数；万，极言其多。谓世间事物多至万端。

bù不dú独wěi委yú于yī一rén人

委，委任、交付、归于承担。谓天下万事不可能也不应全部交给一个人。

cháo巢lín林yī一zhī枝

化用《庄子·逍遥游》「鹪鹩巢于深林，不过一枝」。鸟栖只需一枝，喻生命真正的需要有限。

yǐn饮hé河mǎn满fù腹

化用《庄子·逍遥游》「偃鼠饮河，不过满腹」。与「巢林一枝」并喻知足有度的尺度。

shēng生zhī之yǒu有fèn分

分，非宿命意义上的注定，而是生命的限度、能够承担的范围、与实际条件相称的尺度。

shí识shì事zhī之yǒu有dàng当

当，合宜、应当，与时机、身份、责任相称。谓辨明事情各有其合适的承担者与处理方式。

xián闲yào要

闲，次要、非急需、可以放下；要，必要、紧要。知其闲要，即分清轻重缓急。

jiào较liàng量qīng轻zhòng重

衡量价值轻重。不能只看眼前收益，也要看它消耗什么——本篇章的价值序是性命道德重于名位财货。

yú余hào好

超过实际需要以后、由情欲继续追加的部分。非由物品名称机械决定，而看实际用途、数量与内心动机。

xùn徇

曲从、追随，甚至不惜牺牲自身。众皆徇之，谓世人普遍追逐余好而自致损伤。

dá达shēng生

通达生命实情。不是知道很多养生理论，而是明白什么真正养生、什么看似享受实则伤生。语本《庄子·达生》。

bì弊yī衣

朴素甚至破旧的衣服。此处表达足用原则，非要求营养不足、衣不蔽体——损害健康同样违背贵生。

suí隋zhū珠tán弹què雀

隋珠（亦作随珠、随侯之珠）为至贵之宝，用作弹丸射高空小鸟，是以至贵换至贱。喻为外物损伤性命。

cù促fá伐

促，促短、加速耗损；伐，伤害、戕害。自促伐，谓自己以错误取舍用性命换取外物。

hài害qì气

财物具有牵动、耗损心气的可能。非神秘性质，而指财富引出的保管、恐惧、比较、争夺等一系列心理与事务。

xíng行míng名shī失jǐ己

行名，以成名为行动目的；失己，失去自己。语出《庄子》。以名声为中心者，会不断根据他人目光塑造自己。

bào抱yuán元shǒu守yī一

《西升经》语。抱元，保守生命根元；守一，使心神不散、安守道一。与「但坐荣官」相对。

chù触shì事jiē皆wéi为

遇到任何事情都去承担。看见问题便认为自己必须解决，任何意见都想回应，任何机会都怕错过。

xiū修dào道shì事quē阙

阙，缺失。谓修道之事被耽误缺失——事情不会自然结束，因为每件事都引出下一件，修道永远停在「以后」。

zhèng证chéng成

修证已经成熟。「处事安闲，在物无累」属证成境界，是长期积习成熟后的结果，非初学口号。

【解读层】精读 ​

全篇结构与四层读法 ​

上一章【收心】处理心与念头的关系；本篇进一步调整生活的外在结构：

text
断缘：停止以机心经营关系、谋求时利
收心：不让见闻、念头与毁誉占据内心
简事：辨别事务的必要与非必要、分内与分外

全篇的核心原则是八个字：知生有分，识事有当。

层范围（首句 → 末句）核心问题
一 · 事物不必一人承担「夫人之生也」→「何能及道」人离不开事物，为何还要简事？「分」与「当」何意？过分任事为何损伤形神？
二 · 分辨必要、重要与余好「是以修道之人」→「何迷之甚」怎样判断去取？酒肉罗绮名位金玉为何是「余好」？
三 · 以性命为重，外物为轻「庄云：达生之情者」→「不以位易志」「生之所无以为」是什么？为何有余也要舍？隋珠弹雀说明什么？
四 · 初学不可冒充处事无累「庄云：行名失己」→「诚自诳耳」「行名失己」何意？「抱元守一」与「坐荣官」如何对立？
text
人必须接触事物，但天下万事不必一人承担
        ↓ 生命有其限度，事务有其合宜
任非当之事伤智力，求分外之物弊形神
        ↓
因此必须辨别：闲与要、轻与重、去与取
        ↓ 非要非重者减
外物只应服务性命，不可反以性命追逐外物
        ↓
名位假而贱，道德真而贵：不以名害身，不以位改志
        ↓
初学若不简事，必然心劳智昏
处事无累属于证成境界，不可预先自称已经做到

一、人离不开事物，却不必承担万事 ​

「夫人之生也，必尝于事物」——依底本作「尝」，文字略显不畅，可能涉及版本异文；按上下文理解为：人要维持生命，必然要接触、取用和处理一定的事物。 修道不能完全脱离现实条件（饮食、衣服、居处、基本身体问题，也可能包括一定的家庭与社会责任）。所以本篇不是认为「事情本身都是错误」，而是承认：

生命必然有所用，只是所用应当有限、有度。

这与【断缘】篇末「若事有不可废者，不得已而行之」相承。

「事物称万，不独委于一人」——这是非常重要的现实判断。人之所以事务过多，有时不是因为事情确实非做不可，而是因为：觉得只有自己能做好、害怕拒绝别人、想证明自己有能力、享受被需要的感觉、害怕错过机会、把一切问题都视为自己的责任。

text
世间事务无穷，个人生命有限
若以有限之身承担无穷之事 → 必然形劳、心乱、智昏

这并非鼓励推卸责任，而是反对把「不属于自己的万事」都揽到身上。

二、「巢林一枝，饮河满腹」：生命真正需要的很有限 ​

两句化用《庄子·逍遥游》「鹪鹩巢于深林，不过一枝；偃鼠饮河，不过满腹」。鸟在广大森林中筑巢，只需一根树枝；兽面对浩荡河水饮水，也只需装满自己的肚腹。

text
世界可以很丰富，生命所需却有自然限度

问题不在外界事物众多，而在心是否因此产生「全部都要」的欲望：食物种类很多，不等于都要尝遍；职位机会很多，不等于都要争取；信息无限，不等于都要了解；可做之事很多，不等于都有必要承担。

真正使人劳苦的，往往不是生命实际所需，而是想象中的不足：

text
身体已经足够，心却认为还不够
生活已经可以维持，比较又制造新的匮乏
一件事已经完成，好胜又要求做到更多

所以，简事首先不是外在贫乏，而是内心知道：什么程度已经足够。

三、外求诸物，内明诸己 ​

「外求诸物，内明诸己」——向外取得维持生命所需，同时向内明白自己的限度、能力与真正需要。这一句同时保留「外求」与「内明」：

text
若只有外求 → 不断被事物牵引
若只有内明而忽视饮食安全与责任 → 也可能损害生命

故简事不是绝对拒物，而是：以对自身生命的明察，指导对外物的取舍。「诸己」至少需要明白四件事——自己的生命所需、能力限度、责任边界、心理动机（是在尽责，还是借任事求名）。这便引出「分」与「当」。

知生之有分——「分」不能简单理解为宿命论意义的「命里注定」，而主要指生命的限度、个人能够承担的范围、实际需要的分量。「生之有分」首先是一种有限性意识：时间有限、体力有限、注意力有限、能力有边界。若不承认有限，就会用有限生命追逐无限对象，最终必然耗损。「不务分之所无」的「务」比普通接触更强，指全力经营、刻意求取；所谓「分外物」，还包括超过生命实际需要的占有、超过自身能力的事务、不属于自己责任的控制、仅因别人拥有而想要的追问。

识事之有当——「当」指合宜、应当、与时机身份责任相称。「知分」主要从人的承受限度说，「识当」则主要从事情本身的合理归属说：

原则所问的问题
知生有分我能承担多少？我真正需要多少？
识事有当这件事应不应该由我做？现在是否应该做？

一件事即使有价值，也未必此时必须做、必须由自己做、必须做到最大规模。可以形成三类：

事务类型处理方式
分内且必要应当完成
有益但可由他人承担不必独揽
非时、非事、超出分限应当舍弃

四、「任非当」与「务过分」的不同损害 ​

任非当，则伤于智力——非当之事为什么首先伤「智力」？因为要不断处理本不属于自己的问题，心便被迫进行大量额外计算（协调、判断、解释、预测、防备、维持、收拾后果）：

text
任事过多 → 心神不断切换 → 注意力耗散 → 判断能力下降 → 应做之事反而不能做好

这与【收心】「小事关心，心必动乱」相应。

务过分，则弊于形神——「务过分」比「任非当」更深一步：不只是事务太多，而是欲望没有限度（已有足够财富仍不断积累、已经完成责任仍追求完美控制、身体已经疲惫仍不肯停止）。结果是：

text
外物增加 → 维护成本增加 → 忧虑与劳作增加 → 形体疲惫 → 精神耗散

所以，简事不是为了提高效率后承担更多，而是为了真正减少不必要的消耗。

身且不安，何能及道——《坐忘论》并不把修心与现实身心状态完全分开。若睡眠严重不足、事务始终过量、每日处于急迫状态，就很难稳定地收心、真观与入定。简事不是修道之外的生活管理，而是进入定慧的必要条件。

五、怎样进行取舍 ​

莫若断简事物——「断简」是两个动作：

text
断：对于明显妨道、毫无必要之事，停止它
简：对于不能完全废除之事，减少其数量与复杂程度

有些应立即停止，有些应逐渐减少，有些需保留，有些可转交他人——这比简单说「什么都不要」更有层次。

知其闲要——「闲」不等于完全没有价值，而是相对于当前生命与修道而言不必优先处理。一件事可能有趣却不必要、有益却不紧要、可以做却不必现在做。能够承认「可做而不必做」，是简事的重要能力。

较量轻重——比较轻重时，不能只看眼前收益，也要看它消耗什么：

text
获得一项名利，是否要以长期心神不安为代价？
增加一项事务，是否会挤压休息与修道时间？
追求更高成就，是否会损害身体与基本责任？

识其去取——仅仅知道一件事不重要，还不等于真正能舍；简事最终必须落实到选择：不接受某些邀请、不承担额外任务、降低对某些目标的投入、给事务设定完成边界。「去取」正是敬信落实到行动的地方。

非要非重，皆应绝之——第一重筛选：「是否必要？是否重要？二者皆否→应当舍弃。」但「重要」不能由社会热度、他人评价或个人虚荣决定，而应从性命与道德判断。

六、酒肉、罗绮、名位、金玉为何都是「余好」 ​

类别例子
饮食酒肉
衣服罗绮
社会身份名位
财物金玉

这些并非生命完全不能接触之物，而是相对于基本需要而言的附加享受，故称「情欲之余好，非益生之良药」。「余好」不是一切正常喜好，而是超过实际需要以后由情欲继续追加的部分：

text
因饥饿而进食 → 性命所需
在营养健康范围内有所选择 → 正常生活
明知身体已足，仍为刺激不断追求 → 情欲余好

衣能御寒蔽体 → 必需
衣求华美以证明身份 → 余好
职位用于履行责任 → 有当
职位用于满足优越与控制 → 余好

所以余好与必要并非由物品名称机械决定，而要看实际用途、数量和内心动机。「非益生之良药」是比喻：生命真正需要的是饮食适度、衣服适宜、居处安全、身心调和、事务不过量；酒肉华服名位金玉或许带来暂时满足，却不能解决生命根本问题——若反过来为它们劳神伤身，就成了「以养生之物害生」。

「众皆徇之，自致亡败」——揭示从众的力量：许多欲望不是生命自然需要，而是比较产生（别人拥有所以我也需要、社会认为名位重要所以我不能舍）。这与总论「喜色味为得志，鄙恬素为穷辱」相应。

「静而思之，何迷之甚」——说明简事并非反对一切思考，而是要求用清明思考重新检查生活：这真是生命所需吗？收益是否值得相应消耗？我是在使用外物，还是已被外物役使？【收心】使心静下来，【简事】则运用这种清静重新判断轻重。

七、「达生」就是不求生命所不需要之物 ​

《庄子·达生》通行本有「达生之情者，不务生之所无以为；达命之情者，不务知之所无奈何」，「情」指实情。真正通达生命实情的人，不会追求生命本来不需要的东西。「达生」不是知道很多养生理论，而是明白什么真正养生、什么看似享受实则伤生。

「生之所无以为者，分外物也」——不是说它绝对不能用，而是：没有它，生命仍能成立。 既然生命不依赖它，就不应为了它反过来伤害生命。

「蔬食弊衣，足养性命」表达的是古代出家修道者的简素标准。现代阅读不必机械模仿「衣服越破越好」，重点在于：

text
衣食的基本功能 重于 借衣食展示身份

衣服若已不能保暖、饮食若营养不足，反而损害生命——本篇提倡的是「足用」，不是自我虐待。 「岂待酒肉罗绮，然后生全哉」切断的正是这个错误等式：

text
生活奢华 ≠ 生命完整；感官满足 ≠ 性命得到保全

八、不仅「无用」要去，「有余」也要舍 ​

text
于生无所要用者，并须去之：去掉无用、非必要之物
于生之用有余者，亦须舍之：确实有用但已超过所需，也应舍去多余部分

有些东西不是完全无用（金钱有生活用途、工具有工作用途），问题在于「有余」：

text
有用 ≠ 越多越好
足够以后继续增加 → 产生新的保管、维护、比较和焦虑

所以本篇不是简单的「有用主义」，而是足用原则：

有用者取其足，无用者去之，多余者舍之。

情况原则
对生命、责任皆无必要去除
有一定用途，但已过量舍去多余
确属必要、数量适度保留使用

这正是「简事」，而不是「灭事」。

九、「财有害气，积则伤人」 ​

这不是说财物具有某种必然伤人的神秘性质，而是说财富积聚会引出一系列心理和事务：

text
获得财物 → 需要保管 → 财物增加 → 害怕失去 → 加强防备和经营 → 心气越受扰动

还可能引出比较、争夺、猜疑、身份依赖、对未来损失的恐惧。故「害气」的关键仍在财物与心的关系。「虽少犹累，而况多乎」语气较严格，符合出家修道者的语境；现代阅读需区分：为基本生活保留必要资源（必要储备可以减少不安）与因恐惧贪欲而无限积累（越怕失去越要积累）。本篇真正反对的不是数字意义上的财富，而是「财物由生活工具变成心神主人」。

十、「隋珠弹雀」：不要用至贵追逐轻贱 ​

底本作「隋珠」，通常亦写作「随珠」，指珍贵无比的宝珠。此典常以「所用者重，所要者轻」说明价值失衡：

譬喻所指
隋珠性命与道德
千仞之雀名位、财货与欲望余好
以珠弹雀为轻贱外物损伤宝贵性命

人不是被外物单方面伤害，而是因为错误取舍，主动用性命换取外物——这就是现代形式的「随珠弹雀」：

text
以睡眠换名利 / 以健康换地位 / 以心安换财货 / 以道德换机会 / 以自由换无穷占有

十一、名位与道德：何者真，何者假 ​

「名位假而贱，道德真而贵」——「假」不是说名位根本不存在，而是说它「假借众缘」才成立（需要制度承认、他人评价、特定环境，且会随时代与关系变化；人离开职位，名位可能随即消失）。道德则主要表现为心是否清静、行为是否合宜、是否不以机心伤人、是否不因得失改变志向。所以「真假」主要是依存方式和稳定程度的区别：

text
名位依外而立 → 条件一变便会改变
道德由内而成 → 不完全取决于别人承认

「能知贵贱，应须去取」——知道道德比名位重要，却每逢冲突都牺牲道德保全名位，这种「知」尚未成为真实知见。真正的知贵贱应表现为：名位不伤道，可以因事承担；名位与道相冲突，宁守道而舍位。

「不以名害身，不以位易志」——分别指出名位的两种危险：

  • 名害身：为名声过度任事、耗损身体、不能承认自己的限度、明知疲惫仍要维持形象；
  • 位易志：为地位改变原有原则、曲意迎合、不敢说真实判断、把角色利益置于道德之上。

简事不是否定一切名位，而是不允许名位成为损身易志的力量。

十二、「行名失己」与「抱元守一」 ​

「行名失己，非士也」——「行名」不是正常行动获得名声，而是以成名为行动目的。当名声成为中心，人会不断根据他人目光塑造自己（别人称赞什么便表现什么、害怕失去形象便掩饰过错、为了维护名声逐渐失去本志），这就是「失己」。

与【敬信】「怀宝求宝」相比，二者共同揭示向外追逐的悖论：

text
本来有心性之宝，却向外求评价
越向外经营名声，越远离自身本根

《西升经》「抱元守一，过度神仙，子未能守，但坐荣官」——

text
抱元守一：心神内敛，不为万事耗散，趋向道与神仙
但坐荣官：心系名位，事务繁兴，被外在身份固定

「坐荣官」并不是说做官必然不能修道，而是说若心安住于官位荣耀、把它当作生命归宿，便无法守一。心为什么不能守一？原因之一就是事务过多：

text
事多 → 心分 → 神散 → 不能守一

所以简事的目的不是单纯获得空闲，而是保护心神的统一性。

十三、若不简择，为什么「心劳智昏」 ​

「触事皆为」是本篇批评的典型状态：看见问题便认为自己必须解决、收到邀请便觉得不能拒绝、遇到机会便害怕错过、任何意见都想回应、任何知识都想了解。

text
事务数量增加 → 注意力不断切换 → 心神长期疲劳
        → 判断力下降 → 应做之事也做不好 → 修道永远被排到最后

「修道事阙」尤其值得注意。人可能总说：

等这些事情结束，我再安坐收心。

但如果没有简择，事情不会自然结束，因为每件事情都会引出下一件事情。修道于是永远停留在「以后」。

十四、「处事安闲」属于证成，不是初学口号 ​

「若处事安闲，在物无累者，自属证成之人」——司马承祯并不否认存在这种境界（这正是【收心】篇末所承认的「在物而不染，处事而不乱」）。证成之人的状态是：事情来时清楚处理、事情去后不留于心、身在名位而不以名位为己、能承担事务而不显德露能、能使用智慧而不以智害恬。但这是长期积习成熟后的结果。

「若实未成，而言无累者，诚自诳耳」——怎样判断自己是否「实未成」？可以观察：

  • 遇到毁誉是否立刻动心？
  • 事情结束后是否反复回想？
  • 失去名位时是否强烈不安？
  • 是否以「我不执著」为由不断增加事务？
  • 是否表面无累，实际身心已经疲惫？

若这些现象仍然明显，就应承认自己尚在训练阶段，而不是借最高境界取消基础练习。

两者的关系是：

text
处事不乱：最终能力
简事收心：形成这种能力的过程

十五、简事不是「效率管理」 ​

现代人容易把【简事】理解成提高生产效率——这只理解了一半。《坐忘论》的目标不是通过简化让人承担更多、获得更多，而是：

减少外事对形神的占用，为归根、静定与真观保存生命条件。

效率式简化《坐忘论》的简事
省时以做更多省事以保养形神
追求更大产出追求合宜与足够
仍以成就为中心以性命与道德为重
淘汰低效事项舍弃非要、非重之事
可能继续扩大目标有意识地承认限度

简事的终点不是「高效繁忙」，而是「事称其分，心有余闲」。

十六、简事的三重判断法 ​

第一层：要不要做？ 它是否关系基本生活？是否属于不可废的责任？是否真正有益于性命和道德？若不做会有什么实际后果？——若非要非重，可以舍弃。

第二层：应不应该由我做？ 是否属于我的分内？是否可以由更合适的人承担？我是否因害怕拒绝而揽事？是否借承担事务证明自己的重要？——若属「事之非当」，不应独任。

第三层：做到多少才足够？ 完成基本责任以后，是否还在不断追加？更多投入是否仍有真实收益？是否已经开始损害身体与心神？——即使有用，超过所需也应减少。

text
非必要 → 去之
非我所当 → 不任
虽有用而过量 → 舍其有余
确属必要且适量 → 如理完成，事毕即止

容易误解的地方 ​

  1. 简事不是完全不做事——本篇说「不任事之非当」，反过来也承认「当做之事」应当承担；重点是有选择、有边界。
  2. 「知分」不是宿命主义——不是要求人永远停留在某种社会位置，而是承认时间、体力、注意力和责任都有现实限度。
  3. 朴素不等于自我虐待——「蔬食弊衣」表达足用原则，不是要求故意营养不足、衣不蔽体；损害健康同样违背贵生。
  4. 财物并非绝对邪恶——财物是生活工具；当它引发无穷积聚、恐惧和争夺时，才成为「害气」之累。
  5. 名位也不是绝对不可承担——问题在于是否以名害身、以位易志、是否把名位当作固定自我。
  6. 「有余则舍」不能成为对他人的强制——每个人的实际责任、身体条件与生活处境不同；简事首先是反观自身，而不是用自己的简朴标准评判所有人。
  7. 不能以「在物无累」为由无限加事——判断是否无累，不看口头自称，而看身体是否安稳、心是否仍受毁誉得失扰动、事情结束后是否能放下、定慧是否因事务而中断。

现实修养练习 ​

把当前事务分为四栏：

类别特征原则
必要且分内关系生活、责任与承诺如理完成
重要但可分担有价值，但不必独自承担合理分工
有用但过量已超过实际需要减少余量
非要非重由虚荣、比较或惯性维持停止或渐退

对每件长期占据心神的事，可以问：

  1. 如果没有他人的目光，我还会做它吗？
  2. 它属于生命所需，还是情欲余好？
  3. 它真的必须由我承担吗？
  4. 做到什么程度就已经足够？
  5. 它带来的利益，是否值得形神上的消耗？
  6. 我是在使用名位财物，还是已经被它们役使？
  7. 舍弃它损失的是生命根本，还是仅仅损失某种形象？

这些问题，就是「知其闲要，较量轻重，识其去取」的现代实行。

小结 ​

【简事】并不是否定现实生活，而是为现实事务建立尺度：

生命有所需，却不需要万物；个人有所当，却不应承担万事。

四项判断：

text
知分：承认生命、时间与能力有限
识当：辨别事情是否应由自己承担
量重：以性命、道德重于名位财货
知足：有用者取其足，多余者亦须舍

最尖锐的警告是「隋珠弹雀」：

性命与道德是至贵之珠，名位财货只是相对轻微之外物；若为了轻物耗损形神，就是以重求轻、以贵换贱。

而全篇最后又回到修道次第：证成之人可以处事安闲、在物无累；初学者若尚受事务扰动，却借此境界拒绝简事，只是自欺。

所以本篇可以浓缩为一句话：

简事不是把人生缩减成空白，而是舍去非要、非重、非当与过量之事，使有限的形神回到真正重要的性命与大道。

经过【断缘】，不再以机心结交；经过【收心】，不再随见闻流浪；经过【简事】，又从现实结构上减少了形神负担。下一篇《真观》便要进一步追问：即使外缘已断、事务已简，内心为什么仍会对色欲、贫病、毁誉、生死产生执著？又应怎样从根本上观察它们？

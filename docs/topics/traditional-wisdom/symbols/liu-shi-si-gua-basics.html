08 · 六十四卦基础：从八卦到六十四卦 ​

版本与引用说明 ​

本篇承担"易经入门详细科普"的职责，因此特别说明：

人更三圣，世历三古的“三圣说”出自班固的《汉书·艺文志》。

而四圣说实际上是将中古时期的“文王演易”这一项工作，具体分拆为了“文王作卦辞”和“周公作爻辞”，让成书的脉络更加清晰。

《周易》的成书，历史上有一个著名的"四圣"说：

伏羲画卦 → 文王演卦 → 周公作爻辞 → 孔子作十翼

这个说法，流传极广，但每一环节都有争议。
本篇将如实呈现：哪些有文献依据，哪些是后世建构，哪些至今存疑。

一、先说位置：六十四卦在体系中的哪里？ ​

plain
道
 └─ 阴阳
      └─ 四象
           └─ 八卦（三爻·8种）
                ├─ 先天八卦（体）
                ├─ 后天八卦（用）
                └─ 六十四卦（8×8·64种）← 我们在这里
                     = 八卦两两相叠
                     = 宇宙所有基本情境的完整枚举
                     = 《周易》的符号系统基础

六十四卦解决的问题：

八卦描述了八种基本状态。
但现实世界的情境，远比八种复杂。
两个基本状态叠加，产生 8×8=64 种组合——
这64种，被认为足以覆盖人世间所有基本情境。

二、从八卦到六十四卦：数学逻辑 ​

2.1 重卦的生成 ​

【原典】《周易·系辞下传》第二章
【原文】八卦成列，象在其中矣；因而重之，爻在其中矣。

plain
"因而重之"= 将八卦两两叠加

  上卦（外卦）
  ─────────── ← 上面三爻
  下卦（内卦）
  ─────────── ← 下面三爻

  8（上卦）× 8（下卦）= 64卦
  每卦 6 爻
  64 × 6 = 384 爻

2.2 三爻到六爻：信息量的跃升 ​

plain
三爻八卦：2³ = 8 种状态
六爻六十四卦：2⁶ = 64 种状态

每增加一爻，信息量翻倍：
  3爻 → 8
  4爻 → 16
  5爻 → 32
  6爻 → 64

= 六爻，是在三爻基础上，
  信息量精确扩展8倍的结果。

2.3 "重卦"是谁发明的？——考据现状 ​

这是《周易》研究中争议最大的问题之一。

历史上主要有三种说法：

plain
说法一：伏羲重卦说
  代表人物：郑玄（东汉）
  依据：《周礼注》"伏羲制六十四卦"
  问题：郑玄之前无此说，先秦文献无据。

说法二：神农重卦说
  代表人物：孙盛（东晋）
  依据：《三国志注》引《魏氏春秋》
  问题：孤证，无其他文献佐证。

说法三：文王重卦说
  代表人物：王弼（魏晋）
  依据：《周易略例》
  问题：同样无先秦文献直接支撑。

梁韦弦《关于数字卦与六十四卦符号体系之形成问题》（《周易研究》，2007年）指出：

从考古材料看，商代甲骨文中已出现六爻数字卦，
说明六十四卦的符号体系早于文王已经存在。
"文王重卦"之说，在考古证据面前难以成立。

史宁中《从八卦到六十四卦：试论〈周易〉的思维逻辑》（《哲学研究》，2011年）指出：

八卦到六十四卦的演化，是一个逻辑必然——
只要掌握了三爻叠加的方法，重卦就是自然的推论，
不需要归功于某一个具体的历史人物。

本篇的处理原则：

六十四卦符号体系的起源，早于文王，具体发明者不可考。
文王的贡献，在于卦辞的撰写，而非符号的发明。

三、《周易》的成书：文王、周公与孔子 ​

3.1 文王与卦辞 ​

【原典】《史记·太史公自序》，西汉·司马迁
【原文】昔西伯拘羑里，演《周易》。

plain
西伯 = 周文王姬昌
羑（yǒu）里 = 今河南汤阴，商纣王的囚禁之地
演《周易》= 推演、整理《周易》

= 司马迁的记载：文王被囚期间，整理推演了《周易》。

【原典】《汉书·艺文志》，东汉·班固
【原文】文王以诸侯顺命而行道，天人之占可得而效，于是重《易》六爻，作上下篇。"

考据说明：

"文王作卦辞"这一说法，最早见于东汉马融、郑玄。先秦文献（包括《左传》《国语》中大量引《易》之处）均未明确说"卦辞为文王所作"。

廖名春《周易经传与易学史新论》（齐鲁书社，2001年），写到：

现代学者普遍认为，卦辞的写定，大约在西周初期（约公元前1046年前后），作者可能是周初史官群体，文王参与其中的可能性存在，但无法确证。

3.2 周公与爻辞 ​

传统说法：爻辞为周公所作。

依据：东汉马融《周易注》

考据现状：

爻辞中有若干内容涉及文王之后的史事，如"帝乙归妹"（归妹卦）等，说明爻辞的写定，可能跨越文王、周公两个时代，甚至延续到西周中期。

    ——黄寿祺、张善文《周易译注》（上海古籍出版社，1989年）

3.3 孔子与十翼 ​

【原典】《史记·孔子世家》，西汉·司马迁
【原文】**孔子晚而喜《易》，序《彖》《系》《象》《说卦》《文言》。
**读《易》，韦编三绝。

十翼为《周易》的十篇解说文字：

  • 彖传上·彖传下（解释卦辞）
  • 象传上·象传下（解释卦象与爻辞）
  • 系辞上·系辞下（哲学总论）
  • 文言传（专解乾坤两卦）
  • 说卦传（解说八卦属性）
  • 序卦传（解说六十四卦排列顺序）
  • 杂卦传（对卦关系总结）

考据说明：

"孔子作十翼"的说法，同样存在争议。现代学者多认为：十翼并非孔子一人所作，而是孔门弟子及后学在战国至秦汉间陆续整理完成的文献集合。

司马迁的记载，反映的是汉代的通行说法，不能直接等同于历史事实。

——谢金良《本世纪〈易经〉来源问题研究的若干考辨》（《福建论坛》，1998年）

3.4 《周易》成书时间线（学界基本共识） ​

约商代晚期（公元前13—11世纪）

六爻数字卦符号已存在（甲骨文·考古证据）

约西周初期（公元前11世纪）

卦辞写定（周初史官群体，文王参与可能性存在）

爻辞写定（西周初至中期）

约战国至秦汉（公元前5—前2世纪）

十翼陆续写定（孔门后学）

西汉（公元前2世纪）

《周易》经传合编，成为今日通行本面貌

四、六十四卦的结构：一卦解剖 ​

在进入六十四卦之前，必须先搞清楚一卦的内部结构。

4.1 一卦的解剖图 ​

以乾卦（☰☰）为例：

plain
      ──────   上爻（第六爻）·上九
      ──  ──   五爻（第五爻）·六五
      ──────   四爻（第四爻）·九四
             ↖︎ 上卦（外卦）与下卦（内卦）的分界
      ──  ──   三爻（第三爻）·六三
      ──────   二爻（第二爻）·九二
      ──────   初爻（第一爻）·初九

读卦方向：从下往上读（初爻在下，上爻在上）

4.2 爻的命名规则 ​

plain
阳爻（——）= 九
阴爻（--）= 六

命名格式：位置 + 阴阳
  初九 = 第一爻·阳
  九二 = 第二爻·阳
  六三 = 第三爻·阴
  九四 = 第四爻·阳
  六五 = 第五爻·阴
  上九 = 第六爻·阳

为什么阳爻叫"九"，阴爻叫"六"？
  九 = 老阳之数（最大的阳数）
  六 = 老阴之数（最大的阴数）
  来源：大衍筮法的数字系统
  ——《周易·系辞上传》第九章

4.3 卦的三个层次 ​

plain
每一卦，包含三个层次的信息：

① 卦象（符号）
  六爻的阴阳排列 = 视觉符号
  = 最直观的信息层

② 卦辞（文字）
  对整卦情境的总体描述
  = 文王（或周初史官）所写

③ 爻辞（文字）
  对每一爻具体变化节点的描述
  = 周公（或西周史官）所写
  = 六十四卦 × 六爻 = 384条爻辞
    （加上乾坤两卦各有"用九""用六"，共386条）

五、六十四卦总览：序卦的逻辑 ​

六十四卦不是随机排列的。它们的顺序，有内在逻辑。

【原典】《周易·序卦传》
【原文（节选）】有天地，然后万物生焉……有万物，然后有男女；有男女，然后有夫妇，有夫妇，然后有父子……

《序卦传》解释了六十四卦的排列逻辑：
从宇宙起源，到人伦社会，是一部完整的"宇宙演化史"。

5.1 六十四卦排列结构 ​

plain
上经（第1—30卦）：以乾坤为首，讲天地宇宙与自然规律
下经（第31—64卦）：以咸恒为首，讲人伦社会与人生百态

上经首卦：乾（☰☰）= 天·纯阳·创始
上经末卦：离（☲☲）= 火·日·文明

下经首卦：咸（☱☶）= 泽山·感应·男女相感
下经末卦：未济（☲☵）= 火水未济·未完成·永恒的开放

六十四卦以未济（未完成）结尾，不是以"既济"（完成）结尾——这是《周易》最深刻的哲学态度之一。

宇宙永远处于未完成状态，变化永无终止。

六、六十四卦的核心关系：八种卦变全解 ​

六十四卦不是孤立存在的。
每一卦，都可以通过多种方式，衍生出与之相关的卦——
这些关系，构成了《周易》及后世六爻占卜的完整工具箱。

plain
一卦在手，多卦可得：

  本卦 → 互卦（取中间四爻重组）
       → 变卦（某爻阴阳互换）
       → 错卦（全部爻阴阳互换）
       → 综卦（整卦上下翻转）
       → 伏卦（宫主卦为参照）
       → 游魂卦 / 归魂卦（八宫流变中的特殊位置）
       → 世爻 / 应爻（六爻体系的主客定位）

6.1 本卦 ​

plain
定义：
  占得的原始卦，即当下情境的直接呈现。
  是所有关系的起点与基础。

功能：
  描述"此刻是什么情境"。
  是判断的第一层信息。

本篇以**屯卦（水雷屯 ☵☳）**贯穿全节示例。

plain
屯卦结构：
  上卦：坎（☵）= 阴·阳·阴（从下到上）
  下卦：震（☳）= 阳·阴·阴（从下到上）

六爻（从下到上）：

  上爻 ── ──  上六（阴）
  五爻 ─────  九五（阳）
  四爻 ── ──  六四（阴）
             上卦／下卦分界
  三爻 ── ──  六三（阴）
  二爻 ── ──  六二（阴）
  初爻 ─────  初九（阳）

屯：元亨，利贞，勿用有攸往，利建侯。 ——《周易·屯卦·卦辞》

虽然亨通，但不宜轻举妄动，适合建立根基、寻求支持。

6.2 互卦（互体卦） ​

plain
定义：
  取本卦第二、三、四爻组成下互卦，
  取本卦第三、四、五爻组成上互卦，
  两者合成一个新的六爻卦。

取法：
  下互卦234    
  上互卦345

功能：
  揭示情境内部隐藏的结构与潜在动力。
  事物表面之下，暗中运作的力量。

屯卦互卦示例：

plain
屯卦六爻（从下到上）：阳·阴·阴·阴·阳·阴

下互卦 = 取二三四爻：阴·阴·阴 = 坤（☷）
上互卦 = 取三四五爻：阴·阴·阳 = 艮（☶）

互卦 = 山地剥（☶☷）

解读：
  屯卦表面是"艰难起步"，
  互卦剥卦（剥落、削减）暗示：
  内部正在经历消耗与剥蚀，
  需特别警惕内部损耗与人心涣散。

【原典依据】《左传·成公十六年》筮例中已有互体用法的实际记录，是互卦见于文献的最早证据之一。 ——高亨《周易古经今注》（中华书局，1984年）

6.3 变卦（之卦） ​

plain
定义：
  将本卦中某一爻（或数爻）阴阳互换，
  得到新的卦，称为变卦，又称"之卦"。

  "本卦之变卦"写法示例：
  "屯之比" = 屯卦初爻变动，变成比卦。

取法：
  占筮时，通过蓍草或铜钱演算，
  出现"老阳"（9）或"老阴"（6）的爻，即为变爻。
  老阳变阴，老阴变阳。（少阳·少阴不变）

功能：
  描述"情境将如何发展"。
  本卦 = 现在，变卦 = 未来趋势。
  = 动态推演的核心工具。

屯卦变卦示例（以初爻变为例）：

plain
屯卦初爻（初九·阳爻）为变爻：
  初爻：阳（─────）→ 变为 阴（── ──）

变后六爻（从下到上）：阴·阴·阴·阴·阳·阴

  下卦（初二三爻）= 阴·阴·阴 = 坤（☷）
  上卦（四五六爻）= 阴·阳·阴 = 坎（☵）

变卦 = 水地比（☵☷）

解读：
  屯（艰难起步）→ 比（亲比团结）：
  艰难之中，寻求联合与支持，化解孤立、建立支持网络，是当前情境的发展方向。

变爻的读法规则：

plain
无变爻：  读卦辞，看整体情境。
一个变爻：读该变爻的爻辞，最为准确。
两个变爻：读上位变爻的爻辞为主。
三个变爻：读本卦卦辞与变卦卦辞，各取一半。
四个变爻：读变卦中不变的两爻，以下爻为主。
五个变爻：读变卦卦辞。
六个变爻：乾坤两卦读"用九""用六"；
           其余卦读变卦卦辞。

——《卜筮正宗》（清·王洪绪）

6.4 错卦（旁通卦） ​

plain
定义：
  将本卦所有爻阴阳互换（全部取反），
  得到错卦，又称"旁通卦"。

取法：
  本卦每一爻：阳→阴，阴→阳，全部互换。

功能：
  揭示情境的"对立面"与"互补面"。
  = 当前情境的镜像，完全相反的状态。
  提示：此刻缺少的是什么？对立面在说什么？

屯卦错卦示例：

plain
屯卦六爻(从下到上)：阳·阴·阴·阴·阳·阴
全部互换后：       阴·阳·阳·阳·阴·阳

  下卦（初二三爻）= 阴·阳·阳 = 巽（☴）
  上卦（四五六爻）= 阳·阴·阳 = 离（☲）

错卦 = 火风鼎（☲☴）

解读：
  屯（艰难起步·水雷）的错卦是鼎（稳定成就·火风）。
  错卦提示对立面：此刻艰难，
  目标方向是走向鼎的稳定与成熟状态。

六十四卦错卦对照（部分）：

plain
乾（☰☰）↔ 坤（☷☷）
坎（☵☵）↔ 离（☲☲）
屯（☵☳）↔ 鼎（☲☴）
蒙（☶☵）↔ 革（☱☲）
需（☵☰）↔ 晋（☲☷）
讼（☰☵）↔ 明夷（☷☲）

【原典依据】"旁通"一词由东汉虞翻在《周易注》中系统提出，是错卦理论的最早系统表述。

6.5 综卦（覆卦） ​

plain
定义：
  将本卦整体上下翻转180°，
  得到综卦，又称"覆卦"。

取法：
  本卦上爻 → 新卦初爻
  本卦五爻 → 新卦二爻
  本卦四爻 → 新卦三爻
  本卦三爻 → 新卦四爻
  本卦二爻 → 新卦五爻
  本卦初爻 → 新卦上爻
  = 整卦倒过来读。

功能：
  揭示"换个角度看同一情境"。
  = 你看到的是屯，对方看到的是蒙。
  = 同一件事，立场不同，卦象不同。
  提示：不要只站在自己的角度判断。

屯卦综卦示例：

plain
屯卦六爻(从下到上) 阳·阴·阴·阴·阳·阴
上下翻转(从下到上) 阴·阳·阴·阴·阴·阳

上卦（四五六爻）= 阴·阴·阳 = 艮（☶）
下卦（初二三爻）= 阴·阳·阴 = 坎（☵）
综卦 = 山水蒙（☶☵）

解读：
  你正在艰难起步（屯），
  对方眼中你是蒙昧未开（蒙）——
  同一个情境，两种视角，互为镜像。
  提示：此刻需要启蒙与引导，不要急于求成。

特殊情况：综卦等于本卦（非覆卦）

plain
有8个卦，翻转后等于自身，称为"非覆卦"：
  乾（☰☰）  坤（☷☷）
  坎（☵☵）  离（☲☲）
  颐（☶☳）  大过（☱☴）
  中孚（☴☱）小过（☳☶）

这8个卦，上下翻转后卦象不变，
说明它们描述的情境具有"方向无关性"——
无论从哪个角度看，都是同一个状态。

【原典依据】《周易·杂卦传》：对六十四卦两两对比关系的系统总结。
——向世陵《"重""错"之义与六十四卦的生成》（《周易研究》，2001年）

6.6 伏卦（飞伏卦） ​

plain
定义：
  每一卦，都有一个对应的"伏卦"。
  伏卦 = 该卦所属八宫的宫主卦（八纯卦）。

  飞爻 = 本卦各爻（显现于外的）
  伏爻 = 宫主卦对应位置的爻（隐藏于内的）
  飞与伏，一显一隐，互为表里。

功能：
  揭示卦中隐藏的、未显现的信息。
  在六爻占卜中，若某五行在本卦飞爻中找不到，
  则去伏爻中寻找，称为"取用神于伏爻"。
  = 伏卦是六爻占卜中寻找"隐藏用神"的工具。

屯卦伏卦示例：

plain
屯卦属于坎宫，宫主卦为"坎为水（☵☵）"。

坎卦六爻（从下到上）：阴·阳·阴·阴·阳·阴
屯卦六爻（从下到上）：阳·阴·阴·阴·阳·阴

飞爻（屯卦）vs 伏爻（坎为水）：

  初爻：飞=阳（初九）  伏=阴（初六）  → 不同，伏爻藏阴
  二爻：飞=阴（六二）  伏=阳（九二）  → 不同，伏爻藏阳
  三爻：飞=阴（六三）  伏=阴（六三）  → 相同，伏爻不显
  四爻：飞=阴（六四）  伏=阴（六四）  → 相同，伏爻不显
  五爻：飞=阳（九五）  伏=阳（九五）  → 相同，伏爻不显
  上爻：飞=阴（上六）  伏=阴（上六）  → 相同，伏爻不显

解读：
  屯卦初爻、二爻的飞伏不同，
  说明这两个位置有隐藏信息——
  初爻之下藏着阴的力量，
  二爻之下藏着阳的力量，
  是占断时需要特别留意的隐伏之处。

【原典依据】
——《增删卜易》（清·野鹤老人）
——《卜筮正宗》（清·王洪绪）

伏卦理论源于京房《京氏易传》（西汉），是汉代象数易学的重要组成部分。

6.7 八宫与八纯卦 ​

来源： ​

西汉·京房（前77—前37年）在《京氏易传》中创立"八宫卦"体系，将六十四卦按八纯卦归宫，每宫8卦，共64卦，是后世六爻占卜的基础框架。

八纯卦（宫主卦），即八卦自身相叠的卦，上下卦相同。例：

  • 乾为天（☰☰）坎为水（☵☵）艮为山（☶☶）震为雷（☳☳）
  • 巽为风（☴☴）离为火（☲☲）坤为地（☷☷）兑为泽（☱☱）

八纯卦的特点： ​

① 是本宫的"宗主"，代表该宫的纯粹能量

② 是本宫所有卦的"伏卦"参照基准

③ 在六爻占卜中，八纯卦的上爻为世爻

6.8 世爻与应爻（六爻体系基础） ​

说明：世爻与应爻是六爻占卜（纳甲筮法）的核心概念，本节仅作基础科普，不展开六爻占断的完整体系。

世爻：

plain
定义：
  每一卦中，代表"占卜者自身"或"所问之事主体"的爻，
  称为世爻。

  世爻的位置，由该卦在八宫中的"世数"决定：

  八纯卦（宫主）：上爻（第六爻）为世爻
  一世卦：        初爻为世爻
  二世卦：        二爻为世爻
  三世卦：        三爻为世爻
  四世卦：        四爻为世爻
  五世卦：        五爻为世爻
  游魂卦：        四爻为世爻（退回四爻）
  归魂卦：        三爻为世爻（内卦归宗）

功能：
  世爻 = 主体、自己、所问之事的核心。
  世爻的旺衰，直接反映主体的强弱与事情的走向。

应爻：

plain
定义：
  与世爻相对应的爻，称为应爻。
  = 对方、他人、事情的客体、外部环境。

对应规律（世应相距三爻）：
  世爻在初爻 → 应爻在四爻
  世爻在二爻 → 应爻在五爻
  世爻在三爻 → 应爻在六爻（上爻）
  世爻在四爻 → 应爻在初爻
  世爻在五爻 → 应爻在二爻
  世爻在六爻 → 应爻在三爻

功能：
  应爻 = 客体、对方、外部条件。
  世应关系，反映主客双方的互动状态。

世应关系的基本判断：

  • 世应相生：主客互利，事情顺遂。
  • 世应相克：主客对立，存在阻力。
  • 世克应：我能控制对方，主动有力。
  • 应克世：对方压制我方，被动受制。
  • 世应比和：阴阳相同，关系平淡，无明显助力或阻力。
  • 世应相冲：主客矛盾激烈，事情多变。

屯卦世应示例：

plain
屯卦属坎宫二世卦，世爻在二爻。

  上爻 ── ──  上六
  五爻 ─────  九五  ← 应爻（与二爻相距三位）
  四爻 ── ──  六四
  三爻 ── ──  六三
  二爻 ── ──  六二  ← 世爻（二世卦，世在二爻）
  初爻 ─────  初九

世爻 = 六二（阴）
应爻 = 九五（阳）
世应关系：阴阳相应，有呼应之象，
          但世爻为阴、力弱，应爻为阳、力强，
          = 主体力量不足，需借助外力（应爻）支持。
          与屯卦"利建侯"（寻求支持）的卦辞完全吻合。

【原典依据】京房《京氏易传》（西汉）：世应爻理论的源头。
《火珠林》（五代·麻衣道者，托名）：世应判断规则的系统整理，是六爻占卜的奠基文献。

6.9 游魂卦与归魂卦 ​

游魂卦背景 ​

在八宫卦体系中，每宫八卦按"世爻"位置，从初爻依次上升至五爻（一世→五世），之后不再继续上升，而是发生两次特殊变化，从而产生游魂卦与归魂卦。

游魂卦定义 ​

plain
定义：
  五世卦的上卦（外卦）三爻全部变回本宫八纯卦的上卦，
  世爻退回第四爻，称为游魂卦。

  "游魂"= 魂魄离体游荡，有去无归之象。

特点：
  ① 世爻在四爻
  ② 外卦（上卦）已变回本宫纯卦的上卦
  ③ 内卦（下卦）与五世卦相同，尚未归宗

象意：
  游离、漂泊、变动不居、根基不稳。
  事情处于游移状态，尚未有定论。

示例：
  乾宫游魂卦 = 火地晋（☲☷）
  乾宫五世卦"山地剥"的上卦变回乾宫上卦乾→离，世爻退至四爻

归魂卦：

plain
定义：
  游魂卦的内卦（下卦）三爻全部变回本宫八纯卦的下卦，
  世爻在第三爻，称为归魂卦。

  "归魂"= 游魂归位，落叶归根之象。

特点：
  ① 世爻在三爻
  ② 内卦（下卦）恢复为本宫八纯卦的下卦
  ③ 外卦（上卦）与游魂卦相同

象意：
  回归、收束、落定、事情有了结果。
  适合收尾、回归本源，不宜再大幅变动。

示例：
  乾宫归魂卦 = 火天大有（☲☰）
  （游魂卦"火地晋"的下卦变回乾宫下卦坤→乾，世爻在三爻）

游魂归魂的哲学含义：

plain
一世→五世：阳气（或阴气）逐步上升，事物由弱到强。
游魂：      到达极点后，开始游离，无所归依。
归魂：      游离之后，最终回归本源，落叶归根。

= 任何事物的发展，都遵循"生长→极盛→游离→归根"的轨迹。
= 归魂卦，是一个周期的终点，也是下一个周期的起点。

【原典依据】
京房《京氏易传》（西汉）
郭璞《葬书》中亦有游魂归魂的引申应用（东晋）

6.10 八种关系综合对比 ​

名称操作方式揭示内容所属体系
本卦原始卦象当下情境是什么通用
互卦取二三四爻与三四五爻重组内部隐藏的结构通用
变卦变爻阴阳互换情境的发展趋势通用
错卦全部爻阴阳互换对立面与互补面通用
综卦整卦上下翻转换角度看同一情境通用
伏卦以宫主卦为参照隐藏未显的信息六爻占卜
游魂／归魂八宫流变的特殊位置事物游离与归根的状态六爻占卜
世爻／应爻八宫世数定位主客关系与强弱对比六爻占卜

一句话记忆法：

plain
本卦 = 我是谁（当下）
互卦 = 我内部在发生什么（隐藏）
变卦 = 我将去哪里（趋势）
错卦 = 我的对立面是什么（镜像）
综卦 = 别人眼中的我是什么（视角）
伏卦 = 我身上还藏着什么（隐伏）
游魂 = 我是否已经游离失根（漂泊）
归魂 = 我是否正在回归本源（落定）
世应 = 我与对方的关系如何（主客）

6.11 实战示例：屯卦多卦联读 ​

以**屯卦（☵☳）**为例，综合运用：

plain
本卦：水雷屯（☵☳）
  = 艰难起步，万物初生，困难重重，但生机勃勃。

互卦：山地剥（☶☷）
  = 内部正在经历剥落与消耗，
    警惕内部损耗与人心涣散。

变卦（初爻变）：水地比（☵☷）
  = 发展方向是寻求联合、亲比团结，
    化解孤立，建立支持网络。

错卦：火风鼎（☲☴）
  = 对立面是稳定成熟的鼎盛状态，
    目标：走向稳定，建立制度。

综卦：山水蒙（☶☵）
  = 换个角度：在外人眼中，
    此刻的艰难起步是蒙昧未开——
    需要启蒙与引导，不急于表现。

伏卦：坎为水（☵☵）
  = 初爻、二爻有隐伏信息，
    初爻之下藏阴，二爻之下藏阳，
    需留意隐而未发的变数。

八宫归属：坎宫二世卦
  世爻 = 六二（阴）  应爻 = 九五（阳）
  = 主体力弱，需借外力，
    与"利建侯"的卦辞完全吻合。

综合解读：
  此刻艰难（本），内有暗耗（互），
  方向是联合（变），目标是稳定（错），
  外人看你尚未成熟（综），
  身上还有隐藏变数（伏），
  主体力量不足，需积极寻求支持（世应）。

  = 踏实积累，广结善缘，
    不急于表现，内外兼顾，
    静待时机，方能化屯为比。

七、卦辞与爻辞：如何读一卦 ​

7.1 读卦的基本框架 ​

plain
第一步：看卦名
  卦名往往直接点明情境。
  如"屯"= 艰难，"蒙"= 蒙昧，"需"= 等待。

第二步：读卦辞
  卦辞描述这个情境的总体性质与建议。
  格式通常是：情境描述 + 吉凶判断 + 行动建议

第三步：定爻位
  根据具体问题，定位到相关爻。
  初爻 = 事情开始阶段
  二爻 = 内部核心位置（臣位·内卦中）
  三爻 = 内外交界，危险位置
  四爻 = 外卦开始，近君之位
  五爻 = 君位，最重要的爻（九五之尊）
  上爻 = 事情终结，物极必反

7.2 以乾卦为例：完整读法 ​

【原典】《周易·乾卦》
【卦辞】乾：元，亨，利，贞。

plain
元 = 始，万物之始，大善之德
亨 = 通，亨通顺畅
利 = 宜，有利于行动
贞 = 正，坚守正道

= 乾卦的总体判断：
  这是一个充满创造力与生命力的情境，
  亨通顺畅，有利于行动，但必须坚守正道。

【六爻爻辞节选】

plain
初九："潜龙，勿用。"
  = 龙潜于水，时机未到，不要轻举妄动。
  = 事情刚刚开始，积蓄能量，等待时机。

九二："见龙在田，利见大人。"
  = 龙出现在田野，适合拜见贵人。
  = 开始展现实力，寻求贵人支持。

九三："君子终日乾乾，夕惕若厉，无咎。"
  = 君子整日勤勉，夜晚仍保持警惕，虽危险但无过失。
  = 内外交界的危险位置，必须加倍谨慎。

九四："或跃在渊，无咎。"
  = 或跃起，或潜渊，随机应变，无过失。
  = 进入外卦，面临选择，保持灵活。

九五："飞龙在天，利见大人。"
  = 龙飞于天，适合拜见大人（或成为大人）。
  = 最佳状态，位正当中，是整卦最吉之爻。
  = "九五之尊"的来源。

上九："亢龙有悔。"
  = 龙飞得太高，必有悔恨。
  = 物极必反，盛极而衰，知退为上。

这六爻，描述的是一个完整的生命周期：
潜伏→出现→勤勉→选择→飞翔→过极。
从"潜龙勿用"到"亢龙有悔"，
是任何事物从起步到极盛到衰退的完整轨迹。

八、《周易》的三个基础层次：象·数·理 ​

这是读《周易》必须建立的基本框架。

plain
象（Xiang）= 符号与图像
  六十四卦的卦象、爻象
  = 宇宙现象的符号化表达
  = 最直观，最古老的层次

数（Shu）= 数字与推算
  大衍之数、爻变、纳甲……
  = 用数字系统推演变化
  = 汉代象数易学的核心

理（Li）= 义理与哲学
  卦辞爻辞的哲学解读
  = 从符号中提炼人生智慧
  = 宋代义理易学（程颐·朱熹）的核心

【原典】《周易·系辞上传》第十二章
【原文】是故，易有太极，是生两仪，两仪生四象，四象生八卦，八卦定吉凶，吉凶生大业。

plain
太极 → 两仪 → 四象 → 八卦 → 吉凶 → 大业

= 从宇宙本体（太极）
  到符号系统（八卦）
  到人事判断（吉凶）
  到人生成就（大业）

= 《周易》的完整逻辑链：
  宇宙规律 → 符号表达 → 人事应用

九、《周易》不是止算命说明书——必要的澄清 ​

【原典】《周易·系辞上传》第一章
【原文】**天尊地卑，乾坤定矣。卑高以陈，贵贱位矣。
**动静有常，刚柔断矣……

plain
《周易》原本的功能，至少包含三个层次：

① 占筮工具（最早的功能）
  西周时期，《周易》首先是一部占卜用书。
  通过蓍草演算，得到卦象，参照卦辞爻辞判断吉凶。
  这是它最原始、最直接的用途。

② 哲学文本（孔子之后）
  孔子及其后学，将《周易》提升为哲学经典。
  "一阴一阳之谓道"——
  《周易》从占卜工具，变成了宇宙哲学的载体。

③ 变化之学（最深层的理解）
  《周易》的核心，不是"算出结果"，
  而是"理解变化的规律"。
  
  "易"字，本义即"变化"。
  《周易》告诉你的，不是命运是什么，
  而是变化如何发生，以及如何在变化中做出正确的选择。

朱伯崑《易学哲学史》（北京大学出版社，1986年）：
《周易》经历了从卜筮之书到哲学经典的历史转变，这一转变的关键节点，是孔子及其后学对《易》的哲学化诠释。

十、形·意·神·象·数·理：东方思维的六层模型 ​

1、从"象数理"到"形意神"：为什么要多走这一步？ ​

前两章讲了《周易》的三个层次：

plain
象（Xiàng）= 符号与图像
数（Shù）  = 数字与推算
理（Lǐ）   = 义理与哲学

这三个层次，是《周易》从外到内的读法——
从看得见的符号（象），
到可以推算的规律（数），
到可以言说的道理（理）。

但东方思维，尤其是古人撰写经典时所用的思维方式，
并不止步于此。

象数理，是工具层——用来观察、推演、表达。
形意神，是本质层——用来归纳、表意、洞见根源。

古人的思维路径，是一条从表象到本质的俯瞰之路：

plain
现象世界（可见）
    ↓ 归纳
  形（Form）    ← 万象的外在轮廓与分类
    ↓ 提炼
  意（Meaning） ← 形背后承载的意象与含义
    ↓ 洞见
  神（Essence） ← 意背后不可言说的本质与规律

= 从"看见"到"理解"到"洞见"
= 从"现象"到"规律"到"本质"
= 天人合一的俯瞰观

2、六层模型的完整结构 ​

将"形意神"与"象数理"合并，
得到东方思维的六层完整模型：

plain
┌─────────────────────────────────────────┐
│              神（Shén）                  │  ← 本质层·不可言说的终极规律
│         天人合一·道·太极                │
├─────────────────────────────────────────┤
│              意（Yì）                    │  ← 意象层·承载含义的符号与隐喻
│         意象思维·卦象表意·文字意象      │
├─────────────────────────────────────────┤
│              形（Xíng）                  │  ← 归纳层·对现象的抽象分类
│         归纳·分类·建立基本范畴          │
├─────────────────────────────────────────┤
│              理（Lǐ）                    │  ← 义理层·可言说的道理与哲学
│         义理·逻辑·推论                  │
├─────────────────────────────────────────┤
│              数（Shù）                   │  ← 推算层·数字化的规律表达
│         大衍之数·爻变·纳甲              │
├─────────────────────────────────────────┤
│              象（Xiàng）                 │  ← 符号层·最直观的图像表达
│         卦象·爻象·八卦符号              │
└─────────────────────────────────────────┘

↑ 从下往上：由表及里，由具体到抽象，由现象到本质
↓ 从上往下：由本质落地，由道到器，由神到象

3、形——归纳的艺术 ​

3.1 什么是"形"？ ​

plain
形，不是指事物的外形长相，
而是指：对现象进行归纳后，
         得到的"基本类型"。

= 抽象分类的结果。
= 把无限的现象，归纳为有限的范畴。

3.2 三角形的例子 ​

plain
现实中的三角形：
  等边三角形、等腰三角形、
  直角三角形、钝角三角形、锐角三角形……
  形态无穷无尽。

"形"的归纳：
  按角度本质分类 →
    直角三角形（含一个90°角）
    非直角三角形（锐角·钝角）

  按边长本质分类 →
    等边、等腰、不等边

= 无论多少种三角形，
  都可以用少数几个"形"的范畴来覆盖。
= 这就是"形"的思维：化繁为简，归纳本质类型。

3.3 《周易》中的"形" ​

plain
《周易》对宇宙万象的"形"的归纳：

第一层归纳：阴·阳（两仪）
  = 所有现象，归纳为两种基本属性。

第二层归纳：四象
  = 老阳·少阳·少阴·老阴
  = 两种属性的动态组合，归纳为四种状态。

第三层归纳：八卦
  = 八种基本自然力量
  = 天·地·水·火·雷·风·山·泽

第四层归纳：六十四卦
  = 六十四种基本情境
  = 宇宙所有基本情境的完整"形"的分类。

= 《周易》本身，就是一部
  用"形"的思维对宇宙进行归纳的伟大工程。

【原典】《周易·系辞上传》第二章
"圣人设卦观象，系辞焉而明吉凶，
**** 刚柔相推而生变化。"
= 圣人设立卦象，是为了对现象进行归纳（形），
并在归纳的基础上，揭示吉凶变化。

4、意——表意的艺术 ​

4.1 什么是"意"？ ​

plain
意，是"形"背后承载的含义与意象。
= 不是直接说出来的，而是"寓于象中"的。
= 意象思维：用具体的形象，承载抽象的含义。

中文"意象"二字，本身就是这个思维的体现：
  意 = 含义（抽象）
  象 = 图像（具体）
  意象 = 用具体图像承载抽象含义。

4.2 意象思维的特点 ​

plain
西方思维路径：
  抽象概念 → 定义 → 逻辑推论
  （直接说出来）

东方意象思维路径：
  具体形象 → 意象 → 感悟含义
  （让你自己悟出来）

例：
  "亢龙有悔"（乾卦上九爻辞）
  不说"物极必反，盛极而衰"，
  而是用"龙飞得太高，必有悔恨"这个意象，
  让读者自己感受到那个道理。

  "潜龙勿用"（乾卦初九爻辞）
  不说"时机未到，不宜行动"，
  而是用"龙潜于水"这个意象，
  让读者感受到那种蓄势待发的状态。

4.3 《周易》中的"意" ​

plain
《周易》的卦名，几乎全部是意象：
  屯 = 草木破土而出，艰难初生之象
  蒙 = 山下有泉，蒙昧待启之象
  需 = 云在天上，等待时机之象
  讼 = 水与天相背，争讼对立之象

每一个卦名，都是一个意象，
每一个意象，都承载着一套含义。
读懂意象，才能读懂卦。

【原典】《周易·系辞下传》第二章
"古者包牺氏之王天下也，
**** 仰则观象于天，俯则观法于地……
**** 近取诸身，远取诸物，
**** 于是始作八卦，以通神明之德，
**** 以类万物之情。"
= 八卦的创立，本身就是意象思维的产物：
观天地万物之象（形），
提炼其意（意），
以通神明（神）。

5、神——洞见的艺术 ​

5.1 什么是"神"？ ​

plain
神，不是神灵，不是神秘，
而是：透过形与意，洞见的那个
       "不可言说的终极规律"。

= 老子所说的"道"。
= 《周易》所说的"太极"。
= 不能被完全定义，只能被感悟。

"神"的特点：
  ① 不可被完全言说（"道可道，非常道"）
  ② 可以被感悟与体验
  ③ 是形与意的最终归宿
  ④ 是天人合一的那个"合一点"

5.2 "神"与天人合一 ​

plain
天人合一，不是一句空话，
它是"神"这个层次的具体体现：

  天（宇宙规律）
  ↕ 合一
  人（人的认知与行为）

= 当人的认知（形·意）
  深入到宇宙的本质规律（神）时，
  天与人之间的隔阂消失——
  这就是天人合一。

《周易》的终极目标，不是算卦，
而是让人通过象·数·理·形·意，
最终洞见那个"神"——
即宇宙变化的终极规律，
并与之合一，做出顺应规律的选择。

5.3 "神"在《周易》中的体现 ​

【原典】《周易·系辞上传》第五章
一阴一阳之谓道，继之者善也，成之者性也。

plain
"一阴一阳之谓道"——
  这句话，是《周易》对"神"的最接近的表达：
  阴阳的交替变化，就是道，就是神，
  就是宇宙的终极规律。

  但注意：这句话说的是"之谓道"，
  = 阴阳只是道的"表达方式"，
    不是道本身。
  道（神）本身，依然不可被完全言说。

【原典】《周易·系辞上传》第十章
**《易》无思也，无为也，寂然不动，感而遂通天下之故，
**非天下之至神，其孰能与于此？"

plain
"寂然不动，感而遂通"——
  这正是"神"的状态：
  不是主动推算，而是静默感应，
  与宇宙规律直接相通。
  = 象数理是路径，神是目的地。

6、六层模型在《周易》中的完整对应 ​

plain
神  ←→  太极·道·一阴一阳之谓道
         = 不可言说的终极规律

意  ←→  卦名·卦象·意象表达
         = 用具体形象承载抽象含义

形  ←→  阴阳·四象·八卦·六十四卦
         = 对宇宙现象的归纳分类

理  ←→  卦辞·爻辞·十翼的哲学阐释
         = 可言说的道理与义理

数  ←→  大衍之数·爻变·纳甲·八宫
         = 数字化的规律推演

象  ←→  六十四卦符号·爻象·卦图
         = 最直观的视觉符号

七、这个模型如何用于读书与写作？ ​

这个六层模型，不只是读《周易》的工具，
它是古人撰写一切经典时所用的思维框架。

7.1 古人写作的思维路径（从上到下） ​

plain
神（洞见本质）
  ↓ 转化为
意（选择意象）
  ↓ 落实为
形（建立分类）
  ↓ 表达为
理（阐述道理）
  ↓ 辅助以
数（数字佐证）
  ↓ 呈现为
象（符号图像）

= 古人先洞见本质（神），
  再选择意象（意），
  再建立分类（形），
  最后才落笔成文（理·数·象）。

= 我们看到的经典文字，
  是"从上往下"落地的结果；
  我们读经典，
  则是"从下往上"溯源的过程。

7.2 读者阅读的思维路径（从下到上） ​

plain
象（看到符号与文字）
  ↓ 理解
数（感受数字规律）
  ↓ 推论
理（领会道理）
  ↓ 归纳
形（建立分类认知）
  ↓ 感悟
意（体会意象含义）
  ↓ 洞见
神（触及本质规律）

= 读书，是一个从象到神的溯源之旅。
= 读懂了"神"，才算真正读懂了一本书。

7.3 实例：用六层模型读乾卦 ​

plain
象：☰☰ 六条阳爻，纯阳之卦。

数：六爻全阳，2⁶最大值，阳能量的极致表达。

理：元亨利贞，创始·亨通·有利·守正，
    是最完整的生命周期描述。

形：乾代表"纯阳"这一基本类型，
    是六十四卦中阳能量的极致归纳。

意：六条龙的意象——
    潜龙·见龙·乾乾·跃渊·飞龙·亢龙，
    是一切生命从潜伏到极盛到衰退的意象表达。

神：乾卦的"神"，是"刚健自强"的宇宙本质——
    《象传》曰："天行健，君子以自强不息。"
    这不是一条建议，而是宇宙规律的洞见：
    天道永远运行不息，这是神；
    君子效法天道，这是天人合一。

8、本章小结 ​

plain
象数理，是《周易》给我们的工具：
  用来观察（象）、推演（数）、理解（理）。

形意神，是东方思维给我们的方向：
  用来归纳（形）、表意（意）、洞见（神）。

六层合一，是古人撰写经典时的完整思维框架：
  从神到象，是写作（由本质落地为符号）；
  从象到神，是阅读（由符号溯源到本质）。

十、本章小结 ​

六十四卦，说了一件事，但这件事很具体：

**宇宙的64种基本情境，每一种都有其内在逻辑、
**发展轨迹与应对之道。

plain
① 不是神秘，是分类
   64卦 = 用二分法对宇宙情境的穷举分类。
   不神秘，是逻辑。

② 不是宿命，是变化
   每一卦都有六爻，每一爻都在变化。
   《周易》的核心字，就是"易"——变化。
   它告诉你的，永远是"此刻如何"，不是"永远如此"。

③ 不是答案，是框架
   卦辞爻辞给的，不是"你会怎样"，
   而是"这种情境下，通常的规律是什么"。
   用框架思考，不用框架代替思考。

象数理，是《周易》给我们的工具：

用来观察（象）、推演（数）、理解（理）。

形意神，是东方思维给我们的方向：

用来归纳（形）、表意（意）、洞见（神）。

六层合一，是古人撰写经典时的完整思维框架：

从神到象，是写作（由本质落地为符号）；

从象到神，是阅读（由符号溯源到本质）。

《周易》六十四卦，可能是人类历史上最早的、最系统的情境分类学（个人观点）。

这也是为什么，《周易》读了三千年，每个时代的人都能从中读出新的东西——

因为它的"象"是固定的，但它指向的"神"是开放的。

每一个读者，都在用自己时代的"形"与"意"，去触碰那个永恒的"神"。

这，就是经典的生命力所在。

12 · 十二地支：时间坐标系的第二维 ​

版本与引用说明 ​

本篇主要依据：

  • 《史记·律书》（司马迁，约前91年）
  • 《淮南子·天文训》（刘安等，约前139年）
  • 《礼记·月令》（先秦至汉，礼制文献）
  • 《说文解字》（许慎，约公元100年）——字源考据
  • 《三命通会》（万民英，明代）——藏干体系
  • 《渊海子平》（徐升，宋代）——地支五行应用
  • 《周礼》——十二时辰制度依据
  • 考古参照：睡虎地秦简《日书》（约前217年），现存最早十二生肖与地支对应实物

一、体系定位：在知识树中的坐标 ​

plain
十天干（太阳周期·10段·能量状态）
         +
十二地支（月亮轨道·12段·时空容器）  ←── 本篇
         ↓
      六十甲子（10×12，完整时间编码）
         ↓
  四柱·奇门·六爻·六壬·紫微·择日

天干与地支的根本区别：

plain
天干 = 天上的能量（阳·主动·状态描述）
地支 = 地上的容器（阴·被动·时空承载）

天干问：此刻的能量是什么性质？
地支问：此刻的时空容器装着什么？

一句话定位：
十二地支是古人对月亮轨道与地球季节的十二段编码——
它不只是"第几月"的标签，
而是每个时空容器里，藏着什么五行能量、处于什么生命状态的完整描述。

二、原典依据（四条核心文献） ​

文献一：《史记·律书》——地支的天文本义 ​

【原典】《史记》卷二十五·律书第三（司马迁，约前91年）

【原文节选】

子者，滋也；滋者，言万物滋于下也。
丑者，纽也；言阳气在上未降，万物厄纽未敢出也。
寅者，言万物始生螾然也。
卯者，言万物茂也。
辰者，言万物之蜄也。
巳者，言阳气之已尽也。
午者，阴阳交，故曰午。
未者，言万物皆成，有滋味也。
申者，言阴用事，申贼万物，故曰申。
酉者，万物之老也，故曰酉。
戌者，言万物尽灭，故曰戌。
亥者，该也，言阳气藏于下，故该也。

这是现存最早对十二地支逐一训释的系统文献，揭示了每个地支对应的自然物候与阴阳消长状态。

文献二：《淮南子·天文训》——地支与历法的完整对应 ​

【原典】《淮南子》卷三·天文训（刘安等，约前139年）

【原文节选】

寅，木也；卯，木也；辰，土也；巳，火也；午，火也；未，土也；申，金也；酉，金也；戌，土也；亥，水也；子，水也；丑，土也。

这是地支五行归属的最早系统记载，同时《天文训》还详细记载了地支与月建（每月对应地支）的对应关系，是地支"时间坐标"功能的第一手文献。

文献三：《礼记·月令》——地支与月份的制度化 ​

【原典】《礼记》第六篇·月令（先秦至汉）

《月令》以十二个月为框架，详细规定每月的天象、物候、政令与禁忌，是地支月建制度的礼制依据。其中"孟春之月，日在营室，昏参中，旦尾中"等记载，将地支月份与二十八星宿精确对应，是天文与历法融合的重要文献。

文献四：考古实物——睡虎地秦简《日书》（约前217年） ​

1975年湖北云梦睡虎地出土，其中《日书》甲种记载了十二地支与动物的对应关系，是现存最早的十二生肖与地支对应实物，证明这一体系在秦代已完全成型并广泛应用于日常择日。

3.2 象意详解：每个地支的"状态描述" ​

与天干一样，理解地支最重要的是建立画面感，而不是死记属性。
依据《史记·律书》逐一解读：

🌊 子（zǐ）· 阳水 · 十一月 · 仲冬 ​

【字形】象婴儿在襁褓中，头大身小
【原文】"子者，滋也；言万物滋于下也。"（《史记·律书》）
【状态】一阳初生，万物在地下悄然滋生，外表寂静，内部涌动

plain
子 = 冬至时节
  = 最黑暗的夜晚，但一阳已生
  = 表面是极寒，内部是新生命的起点
  = 深夜子时，万籁俱寂，但生机已在暗中萌动

关键：子是水，但是阳水——不是静止的水，是地下涌动的泉源。

🌱 丑（chǒu）· 阴土 · 十二月 · 季冬 ​

【字形】象手指弯曲，有纽结之形
【原文】"丑者，纽也；言阳气在上未降，万物厄纽未敢出也。"（《史记·律书》）
【状态】阳气已生但尚未下降，万物被束缚，蓄势待发

plain
丑 = 严冬腊月
  = 种子在土里，已经感受到阳气，但还不敢破土
  = 被压制的力量，内部张力极大
  = 丑土 = 冻土，藏而不发

丑是四库之一（辰戌丑未），是金的墓库——冬末的冻土，封存着金的能量。

🐯 寅（yín）· 阳木 · 正月 · 孟春 ​

【字形】象两手捧物，有生发之意
【原文】"寅者，言万物始生螾然也。"（《史记·律书》）——螾然，蠕动生发之状
【状态】万物开始蠕动萌发，生命力破土而出

plain
寅 = 立春时节，正月建寅
  = 第一声春雷，万物惊蛰前的蠕动
  = 生命力最旺盛的起点
  = 寅时（凌晨3–5点）= 黎明前最后的黑暗，但生机已无法遏制

寅是奇门遁甲的重要方位，也是四柱中"长生"的关键地支之一。

🌿 卯（mǎo）· 阴木 · 二月 · 仲春 ​

【字形】象门开两扇，有开放之意
【原文】"卯者，言万物茂也。"（《史记·律书》）
【状态】万物茂盛生长，门户大开，欣欣向荣

plain
卯 = 春分时节
  = 昼夜等长，阴阳平衡的节点
  = 万物全面生长，生机最旺
  = 卯时（5–7点）= 日出，一天的开始

卯是木的旺地——木在卯月达到最旺状态（帝旺）。

🐉 辰（chén）· 阳土 · 三月 · 季春 ​

【字形】象蛟龙之形，有震动之意
【原文】"辰者，言万物之蜄也。"（《史记·律书》）——蜄，震动生长
【状态】春末，万物震动生长到极致，即将转入夏季

plain
辰 = 清明谷雨时节
  = 春雨充沛，万物疯长的最后阶段
  = 辰土 = 湿土，含水量最高的土
  = 龙行雨施，生机勃发

辰是四库之一，是水的墓库——春末的湿土，储藏着水的能量。

🐍 巳（sì）· 阴火 · 四月 · 孟夏 ​

【字形】象蛇盘曲，有收藏之意
【原文】"巳者，言阳气之已尽也。"（《史记·律书》）
【状态】阳气上升到极致，阴气开始萌生，转折点

plain
巳 = 立夏时节
  = 阳气最盛的起点，但一阴已生
  = 表面是热烈，内部已有收敛之机
  = 巳时（9–11点）= 上午最热烈的时段

巳是火的长生地——火在巳月开始进入旺盛期。

🔥 午（wǔ）· 阳火 · 五月 · 仲夏 ​

【字形】象杵臼，有冲击之意；又象阴阳交叉
【原文】"午者，阴阳交，故曰午。"（《史记·律书》）
【状态】阴阳在此正式交接——阳气极盛，阴气开始上升

plain
午 = 夏至时节
  = 一年中阳气最盛的顶点，同时一阴生
  = 正午烈日，但已过顶点
  = 午时（11–13点）= 一天中最热的时段，也是阳气开始下降的转折

午是火的旺地（帝旺），也是水的绝地——水火对冲，是地支中阴阳转换最剧烈的节点。

🌾 未（wèi）· 阴土 · 六月 · 季夏 ​

【字形】象木有枝叶繁茂，果实已成
【原文】"未者，言万物皆成，有滋味也。"（《史记·律书》）
【状态】万物成熟有味，夏末丰收前的饱满状态

plain
未 = 小暑大暑时节
  = 果实饱满，滋味最浓
  = 未土 = 燥土，夏末的干热之土
  = 成熟但尚未收割，最丰盛的等待

未是四库之一，是木的墓库——夏末的燥土，封存着木的能量。

🐒 申（shēn）· 阳金 · 七月 · 孟秋 ​

【字形】象闪电之形，有伸展贯通之意
【原文】"申者，言阴用事，申贼万物，故曰申。"（《史记·律书》）
【状态】阴气开始主事，肃杀之气开始侵蚀万物

plain
申 = 立秋时节
  = 秋风初起，肃杀之气开始
  = 申时（15–17点）= 下午阳光开始西斜，暑气渐退
  = 变革·决断·开始收割

申是水的长生地——金生水，申月水开始萌生。

🐔 酉（yǒu）· 阴金 · 八月 · 仲秋 ​

【字形】象酒坛，有收藏精华之意
【原文】"酉者，万物之老也，故曰酉。"（《史记·律书》）
【状态】万物老熟收藏，精华内敛，秋收完成

plain
酉 = 秋分时节
  = 昼夜再次等长，万物收藏
  = 酉时（17–19点）= 日落，一天的收尾
  = 精炼·收敛·成熟之极

酉是金的旺地（帝旺）——金在酉月达到最旺状态。

🐕 戌（xū）· 阳土 · 九月 · 季秋 ​

【字形】从"戊"从"一"，有戍守之意
【原文】"戌者，言万物尽灭，故曰戌。"（《史记·律书》）
【状态】万物趋于消灭，秋末肃杀，归于沉寂

plain
戌 = 寒露霜降时节
  = 草木凋零，万物归藏
  = 戌时（19–21点）= 夜幕降临，活动收束
  = 守护·终结·为下一个循环清场

戌是四库之一，是火的墓库——秋末的燥土，封存着火的能量。

🐗 亥（hài）· 阴水 · 十月 · 孟冬 ​

【字形】象猪之形，有藏纳之意
【原文】"亥者，该也，言阳气藏于下，故该也。"（《史记·律书》）
【状态】阳气完全潜藏于地下，外表是极寒，内部是下一个循环的种子

plain
亥 = 立冬时节
  = 万物入冬，阳气深藏
  = 亥时（21–23点）= 深夜，万籁俱寂
  = 终结即是开始，亥之后就是子（新的循环）

亥是木的长生地——水生木，亥月木开始萌生，为来年寅月的破土做准备。

3.3 十二生肖：地支的文化面孔 ​

生肖是什么？ ​

十二生肖，是十二地支的"民间面孔"。

plain
地支 = 学术符号（子丑寅卯……）
生肖 = 文化符号（鼠牛虎兔……）

两者一一对应，是同一套系统的两种表达方式：
  学者用地支，民间用生肖。

生肖的作用，是让抽象的地支符号，变成普通人可以直觉感知的具体形象——
不识字的农民不懂"子水阳支"，但他知道自己属鼠，知道鼠年是什么年。

考古依据：生肖何时成型？ ​

【文献】睡虎地秦简《日书》（约前217年，湖北云梦出土，1975年）

这是现存最早记载十二生肖与地支对应的实物文献，证明该体系在秦代已完全成型。

值得注意的是：秦简中的生肖对应，与今日略有差异（如"午"对应"鹿"而非"马"），说明生肖与地支的配对，经历了一个历史演化过程，在汉代前后才基本固定为今日版本。

生肖动物的选择逻辑 ​

这是一个至今没有完全定论的问题，诚实说明：

可解释的部分（天文与物候对应）：

plain
子鼠 · 午马 = 昼夜活动的极端代表
              鼠活跃于深夜子时，马奔腾于正午午时
              两者是一天中阴阳极点的象征

卯兔 · 酉鸡 = 日出日落的报时者
              兔在卯时（日出5–7点）出没
              鸡在酉时（日落17–19点）归巢报时

辰龙         = 龙为行云布雨之神，辰为湿土、春雨之月
              龙与辰月的农业意象高度吻合

寅虎         = 虎为百兽之王，寅时（凌晨3–5点）是虎出没的时段
              古代猎人的实际观察记录

尚无定论的部分：

plain
丑牛·未羊·申猴·巳蛇·亥猪
这几个生肖与地支的对应，
目前学界主流倾向于"图腾崇拜融合说"：
上古不同部落以不同动物为图腾，
各部落融合后，图腾动物被分配到对应的地支位置。

生肖与地支的对应，象征意义大于天文逻辑，是“文化积累”的结果。
文化本身反映某种“真实”。
更多的考证与发现，留待后人探索。

3.4 十二时辰：一天的十二段编码 ​

什么是十二时辰？ ​

十二时辰，是古人将一天（24小时）划分为十二段的时间系统，每段对应一个地支，每段时长两小时。

plain
1个时辰 = 2小时
12个时辰 = 24小时 = 1天

这是地支"纪时"功能的直接体现：
同一套地支符号，既用于纪年、纪月，也用于纪时。

【文献依据】《周礼》已有十二时辰制度的雏形；

《淮南子·天文训》有完整的十二时辰与地支对应记载；汉代以后成为官方标准时间制度，沿用至清末。

重要概念：夜子时与早子时 ​

这是初学者最容易混淆的问题，也是术数实战中的重要细节。

plain
子时横跨两个自然日：
  23:00–24:00 = 当日的"夜子时"（属当日）
  00:00–01:00 = 次日的"早子时"（属次日）

问题：23:30出生，算当天的子时，还是次日的子时？

两种流派：
  ① 以23:00为界（子时起即换日）
     → 23:30出生 = 次日子时
     → 此为多数命理师采用的标准

  ② 以00:00为界（自然日换日）
     → 23:30出生 = 当日亥时之后、次日子时之前
     → 此为部分流派的做法

【实战建议】以所用体系为准，保持内部一致即可。
若无特别说明，本知识库采用"子时起即换日"标准。

时辰与现代时间的换算 ​

plain
标准换算（以北京时间为基准，东经116°）：

北京标准时间 - 地方经度修正 = 地方真太阳时

修正公式：
  每偏离东经120°一度，修正4分钟
  偏西则减，偏东则加

举例：
  出生地：成都（东经104°）
  偏西16°，修正 = 16 × 4 = 64分钟
  北京时间14:30 → 地方真太阳时 = 13:26
  → 实际时辰为未时（13:00–15:00），无误

  出生地：上海（东经121°）
  偏东1°，修正 = 1 × 4 = 4分钟
  北京时间14:30 → 地方真太阳时 = 14:34
  → 仍为未时，无影响

时辰换算在四柱八字中影响时柱，进而影响整个命盘。
出生地偏差较大时（如新疆、云南），换算尤为重要。

四、地支的核心结构：四组三元 ​

十二地支不是随机排列，有严密的内部结构。

4.1 四季三元（最重要的分组） ​

plain
春（木）：寅 → 卯 → 辰
         孟春  仲春  季春
         生    旺    墓

夏（火）：巳 → 午 → 未
         孟夏  仲夏  季夏
         生    旺    墓

秋（金）：申 → 酉 → 戌
         孟秋  仲秋  季秋
         生    旺    墓

冬（水）：亥 → 子 → 丑
         孟冬  仲冬  季冬
         生    旺    墓

每一季的三个地支，对应该五行的"生·旺·墓"三个阶段：

阶段含义类比
生（孟月）该五行开始萌生种子入土
旺（仲月）该五行达到极盛花开正艳
墓（季月）该五行收藏入库果实入仓

这就是四库（辰戌丑未）的来源——每季最后一个月，是该季主气的墓库。

4.2 四正（子午卯酉） ​

plain
子（正北·水旺）
午（正南·火旺）
卯（正东·木旺）
酉（正西·金旺）

四正地支对应四个方位的极点，也是各五行的帝旺之地（能量最强处）。
在奇门遁甲中，四正对应四门（休·生·伤·杜·景·死·惊·开中的正方位门）。

4.3 四库（辰戌丑未） ​

plain
辰（东南·水库）
未（西南·木库）
戌（西北·火库）
丑（东北·金库）

四库是四个过渡方位，每个都是某种五行能量的"仓库"。

【重要】四库的五行归属，初学者常混淆：

plain
● 辰是水库（不是木库，虽然辰在春季）
● 未是木库（不是火库，虽然未在夏季）
● 戌是火库（不是金库，虽然戌在秋季）
● 丑是金库（不是水库，虽然丑在冬季）

规律：每季末月，收藏的是上一季的主气，而非本季主气。

五、藏干：地支内部藏着什么？ ​

这是十二地支中最复杂、也最有价值的部分。

5.1 什么是藏干？ ​

每个地支内部，都"藏"着一到三个天干。
这些天干代表该地支内部包含的五行能量。

plain
类比：
地支 = 一个房间
藏干 = 房间里住着的人（天干）

有的房间只住一个人（单纯）
有的房间住三个人（复杂）

5.2 十二地支藏干完整表 ​

依据《三命通会》（万民英，明代）标准版本：

地支本气（主）中气（次）余气（辅）
子癸（水）——
丑己（土）癸（水）辛（金）
寅甲（木）丙（火）戊（土）
卯乙（木）——
辰戊（土）乙（木）癸（水）
巳丙（火）庚（金）戊（土）
午丁（火）己（土）—
未己（土）丁（火）乙（木）
申庚（金）壬（水）戊（土）
酉辛（金）——
戌戊（土）辛（金）丁（火）
亥壬（水）甲（木）—

【版本说明】藏干体系历代略有差异，以《三命通会》为主流标准。
《渊海子平》与《滴天髓》个别地支藏干有出入，实战以所用体系为准。

5.3 藏干的三个层次 ​

plain
本气（司令之气）= 该地支最主要的五行，力量最强
中气（中间之气）= 次要五行，力量居中
余气（初气）    = 最弱的五行，但仍有影响

力量比例参考（以寅为例）：
寅藏：甲（本气·约70%）· 丙（中气·约20%）· 戊（余气·约10%）

5.4 为什么要有藏干？ ​

如果地支只有一个五行，世界就太简单了。
现实中，每个时间段、每个空间，都同时包含多种能量，只是主次不同。

藏干，就是对这种"复合能量状态"的精确描述。

举例： ​

寅月（正月）= 表面是木（甲木当令）

但内部还藏着：

  • 丙火（春天的阳光，温暖已在积累）
  • 戊土（大地的承载，根系在扎深）

所以寅月不只是"木旺"，而是"木主导，火在孕育，土在承载"的复合状态。

这就是为什么同样是"木旺"的寅月和卯月，在术数应用中会有细微差别——卯只藏乙木，单纯；寅藏甲丙戊，复杂。

六、地支六冲：为什么正对面的地支会"冲"？ ​

6.1 六冲列表 ​

plain
子 ↔ 午（水火相冲）
丑 ↔ 未（土土相冲）
寅 ↔ 申（木金相冲）
卯 ↔ 酉（木金相冲）
辰 ↔ 戌（土土相冲）
巳 ↔ 亥（火水相冲）

6.2 冲的本质 ​

plain
十二地支排成一圈（以时钟12点为午，6点为子）
相隔六位 = 正对面 = 方位相反 = 五行相克或同性相斥

子午：正北↔正南，水↔火，阴阳极点相冲
卯酉：正东↔正西，木↔金，春秋相冲
寅申：东北↔西南，木↔金，生克相冲
巳亥：东南↔西北，火↔水，生克相冲
辰戌：东南↔西北，土↔土，同性相斥
丑未：东北↔西南，土↔土，同性相斥

冲的作用：

  • 冲动（激活）：沉寂的地支被冲，会激发其藏干的能量
  • 冲破（破坏）：稳定的结构被冲，会造成动荡
  • 冲开库：四库（辰戌丑未）被冲，藏干中的能量得以释放

七、地支六合：日月相会的天文配对 ​

7.1 六合列表 ​

plain
子 + 丑 = 合化土
寅 + 亥 = 合化木
卯 + 戌 = 合化火
辰 + 酉 = 合化金
巳 + 申 = 合化水
午 + 未 = 合化火土

7.2 六合的真实来源：日月相会 ​

古人观测发现：太阳每月运行到某个地支方位（月建），月亮会在与之对应的另一个地支方位与太阳相会（即朔，农历初一）。这个固定的配对关系，就是六合的天文来源。

以月建（太阳所在位置）为基准，日月相会的配对：

plain
正月 （寅月）= 太阳在寅，月亮在亥与之相会 → 寅亥合
二月 （卯月）= 太阳在卯，月亮在戌与之相会 → 卯戌合
三月 （辰月）= 太阳在辰，月亮在酉与之相会 → 辰酉合
四月 （巳月）= 太阳在巳，月亮在申与之相会 → 巳申合
五月 （午月）= 太阳在午，月亮在未与之相会 → 午未合
十一月（子月）= 太阳在子，月亮在丑与之相会 → 子丑合

六合的本质，是日月相会的天文记录，是日月交会的固定配对。
依据《淮南子·天文训》的月将体系，六合是日月交会在十二地支上的投影。

子丑、午未 = 相邻两位

寅亥、卯戌、辰酉、巳申 = 跨越多位

记忆六合，最可靠的方法是记住天文来源（日月相会的月份配对）

7.3 合化五行的来源 ​

每对六合，合化的五行来自两者共同激发的旺气：

六合合化原因
子 + 丑土子丑同处冬末，丑土当令，土气最旺
寅 + 亥木亥为木长生，寅为木旺地，木气汇聚
卯 + 戌火卯为木旺（木生火），戌为火墓（火归藏），火气流转
辰 + 酉金酉为金旺，辰为水库（金生水），金气主导
巳 + 申水申为水长生，巳中藏庚（金生水），水气汇聚
午 + 未火土午为火旺，未为火墓兼土旺，火土同气

八、地支三合：最重要的组合关系 ​

8.1 三合列表 ​

plain
申 + 子 + 辰 = 三合水局
亥 + 卯 + 未 = 三合木局
寅 + 午 + 戌 = 三合火局
巳 + 酉 + 丑 = 三合金局

简化记忆：子水，丑金，寅火，卯木记这 4 个，每一组，依次找 + 3，如：

水：子，（+3 丑寅卯）辰、（+3 巳午未）申，这样水局三合可推出，其他同理。

8.2 三合的结构逻辑 ​

每个三合局，由生·旺·墓三个地支组成：

plain
水局：申（水长生）+ 子（水帝旺）+ 辰（水墓库）= 水的完整生命周期
木局：亥（木长生）+ 卯（木帝旺）+ 未（木墓库）= 木的完整生命周期
火局：寅（火长生）+ 午（火帝旺）+ 戌（火墓库）= 火的完整生命周期
金局：巳（金长生）+ 酉（金帝旺）+ 丑（金墓库）= 金的完整生命周期

三合的力量远大于六合：
三合是一个五行从出生到极盛到收藏的完整闭环，
三个地支聚在一起，等于把这个五行的全部生命力量汇聚一处。

九、地支三会：方位的极致聚合 ​

9.1 三会列表 ​

plain
寅 + 卯 + 辰 = 三会东方木局（春季三月）
巳 + 午 + 未 = 三会南方火局（夏季三月）
申 + 酉 + 戌 = 三会西方金局（秋季三月）
亥 + 子 + 丑 = 三会北方水局（冬季三月）

9.2 三会与三合的区别 ​

plain
三合 = 同一五行的生旺墓聚合（跨季节，力量完整）
三会 = 同一季节的三个月聚合（同方位，力量纯粹）

三会的力量 > 三合的力量
（因为三会是同方位、同季节、同五行的三重叠加）

plain

    → 年支·月支·日支·时支

十一、现代解读：地支本质上是什么？ ​

11.1 时空容器的十二种状态 ​

plain
如果天干是"能量的性质"
那地支就是"能量所在的容器"

容器不同，同样的能量，表现出来的效果也不同：
  同样是"木"的能量
  在寅（阳木·初生）= 破土而出，锐不可当
  在卯（阴木·极旺）= 枝繁叶茂，生机盎然
  在辰（木入库）   = 收敛入土，准备转化

11.2 为什么是12，不是10？ ​

plain
天干是10（对应十月太阳历）
地支是12（对应十二月阴历）

12 的来源：
  木星公转周期 ≈ 11.86年 ≈ 12年
  → 每年木星移动约一个"宫位"
  → 12个宫位 = 12地支

同时：
  一年12个月（阴历）
  一天12个时辰
  → 12是月亮周期与木星周期的共同因子

这解释了为什么十二地支能同时用于纪年·纪月·纪日·纪时——
因为它本身就来自多个天文周期的最大公约数。

十三、本章小结 ​

十二地支，是古人对月亮轨道与地球季节周期的十二段精确编码。

五重价值：

  1. 📅 历法价值：纪年·纪月·纪日·纪时，四维时间坐标
  2. 🌱 物候价值：每个地支对应真实的自然状态，是古代农业文明的时间智慧
  3. 🐯 文化价值：十二生肖是地支的民间面孔，是中华文化最广泛的符号系统之一
  4. 🔮 术数价值：藏干·冲合·三合·三会，构成所有术数体系的时间操作基础
  5. 🧠 思维价值：复合能量模型（藏干），是理解"表象与内在"关系的思维工具

学地支，有两个层次：

第一层：记住每个地支的五行·方位·时辰·月份·生肖。这是工具层，必须熟练。

第二层：理解每个地支描述的那个自然状态。

plain
子是冬至地下的涌动，午是夏至正午的转折，
寅是破土而出的第一声，酉是秋收入仓的满足，
丑是冻土中蓄势待发的种子，亥是深冬里潜藏的新生……

第二层才是根。有了根，第一层自然记得住，切勿本末倒置。

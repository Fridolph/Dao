二、原典依据 ​

文献一：《尚书·尧典》——最早的授时记载 ​

【原典】《尚书》·虞书·尧典（先秦，今文尚书）

【原文节选】

乃命羲和，钦若昊天，历象日月星辰，敬授人时。
……期三百有六旬有六日，以闰月定四时成岁。

【解读】
这是中国文献中最早明确记载历法制度的文字。
"历象日月星辰，敬授人时"——观测天象，向人民颁布时间，
这是历法最原始的政治功能：授时，是天子的权力与责任。
"以闰月定四时成岁"——用置闰月来协调年与月的关系，
说明至迟在《尚书》成书时，置闰法已经是历法的核心机制。

文献二：《史记·历书》——历法沿革的系统记载 ​

【原典】《史记》卷二十六·历书（司马迁，约前91年）

【原文节选】

王者易姓受命，必慎始初，改正朔，易服色，推本天元，顺承厥意。

【解读】
司马迁揭示了中国历法的一个重要政治逻辑：改朝换代，必须改历法。
"改正朔"——改变一年的起点（正月）和每月的起点（朔日），是新王朝宣示天命的核心仪式之一。
这解释了为什么中国历史上有那么多套历法——每个朝代都需要"自己的"历法来确立合法性。

文献三：《汉书·律历志》——历法制度化的权威文献 ​

【原典】《汉书》卷二十一·律历志（班固，约公元80年）

【原文节选】

历数之起上矣。传述颛顼命南正重司天以属神，
北正黎司地以属民……
太极元气，函三为一。极，中也。元，始也。
行于十二辰，始动而建子……

【解读】
《律历志》是汉代历法理论的集大成文献，记载了从上古到汉代的历法演变，并系统阐述了干支纪时、朔望月、回归年的理论基础。
"行于十二辰，始动而建子"——十二地支与历法月建的对应关系，在此有明确记载。

文献四：《淮南子·天文训》——历法原理的综合阐述 ​

【原典】《淮南子》卷三·天文训（刘安等，约前139年）

【原文节选】

日行一度，以周于天。
日冬至，日出东南维，入西南维…… 十九岁为一章。

【解读】
"十九岁为一章"—— 19个太阳年 ≈ 235个朔望月，这是阴阳合历置闰的天文基础。

值得注意的是，【存疑】古希腊天文学家默冬（Meton）约于前432年发现此周期，而中国文献的记载时间与之相近。

天文需要大量实际观察数据，需要时间来验证，这是几代人、几百年积累的结果，不可能由个人发现，后面单独写了一篇提出假设与质疑，感兴趣可移步。

三、三种历法的本质区别 ​

理解中国历法，必须先厘清三个概念：

3.1 纯阴历（太阴历）——以月亮为基准 ​

定义： 完全以月亮的朔望周期为基础制定的历法。

核心参数：

  • 朔望月 = 29.53059天（月亮从新月到下一个新月）
  • 一年 = 12个朔望月 = 354.367天

特点：

  • 月份与月相严格对应（初一必是新月，十五前后必是满月）
  • 与太阳年不同步，每年比太阳年少约11天
  • 季节在历法中漂移，33年后完全错位

代表： 伊斯兰历（回历）——现今世界上仍在使用的纯阴历

⚠️ 关键纠正：中国农历不是纯阴历。
这是最常见的误解。中国农历是阴阳合历（见3.3节）。

3.2 纯阳历（太阳历）——以太阳为基准 ​

定义： 完全以地球绕太阳公转周期（回归年）为基础制定的历法。

核心参数：

  • 回归年 = 365.2422天
  • 现行公历（格里历）：平年365天，闰年366天

特点：

  • 与季节严格同步（春分永远在3月20-21日前后）
  • 月份是人为规定，与月相无关
  • 节气在公历中日期几乎固定（误差1-2天）

代表： 格里历（公历）——现今世界通用

中国的太阳历传统：
二十四节气，本质上就是一套纯太阳历，它是中国古代独立发展的太阳历坐标系，与格里历的天文基础完全相同，只是分段方式不同。

3.3 阴阳合历——中国农历的真相 ​

定义： 同时以月亮周期和太阳周期为基础，用置闰法协调两者的历法。

中国农历的双轨结构：

plain
中国农历（阴阳合历）
    ├── 阴历轨道：朔望月（月份 = 月亮周期）
    │       初一 = 朔日（新月）
    │       十五/十六 = 望日（满月）
    │       每月29或30天
    │
    └── 阳历轨道：节气（年 = 太阳周期）
            二十四节气嵌入农历
            节气日期在农历中每年漂移
            但在公历中几乎固定

协调机制：置闰法

  • 问题：12个朔望月（354天）比回归年（365天）少约11天
  • 解决：每隔2-3年插入一个闰月，补足差额
  • 规则：19年插入7个闰月（默冬周期）
  • 判断：无中气月为闰月（详见6.3节）

农历的精妙之处：
它同时满足了两个需求——

  • 月相可见（农业灌溉、潮汐、渔业需要月相）
  • 季节准确（农耕播种需要节气/太阳位置）

3.4 三种历法对比总览 ​

维度纯阴历（伊斯兰历）纯阳历（公历）阴阳合历（中国农历）
月份基准朔望月人为规定朔望月

四、中国历法的演变史 ​

4.1 上古：物候历与观象授时（前有文字记载之前） ​

最早的"历法"，不是数字，而是自然现象的观察：

  • 候鸟迁徙（大雁北归 = 春天来了）
  • 植物物候（桃花开 = 可以播种了）
  • 星象观测（昴星团晨见 = 秋收时节）

这就是《夏小正》记载的物候历传统——用动植物的季节性变化来标记时间，是一切历法的原始形态。

观象授时的政治化：
《尚书·尧典》记载，尧命羲和"历象日月星辰，敬授人时"，说明至迟在传说中的尧舜时代，天文观测已经是国家行为，授时权力掌握在天子手中。

4.2 商代：甲骨文中的干支纪日（约前14-前11世纪） ​

考古证据：
殷墟出土的甲骨文中，有大量干支纪日记录，
这是目前可考的最早的系统性历法实物。

商代历法特征：

  • 已使用干支纪日（六十甲子循环）
  • 已有朔望月的概念（"月"字的甲骨文象形即为月牙）
  • 已有置闰的实践（甲骨文中有"十三月"的记载）
  • 岁首建丑（以丑月为正月）——后世"夏历建寅、殷历建丑、周历建子"之说的来源

意义：
商代甲骨文证明，中国历法的核心要素（干支纪日、朔望月、置闰）在距今3000年以上已经完备。

4.3 周代：四分历的形成（约前8-前3世纪） ​

四分历的核心参数：

  • 回归年 = 365又1/4天（即365.25天）
  • 朔望月 = 29又499/940天（≈29.53085天）
  • 19年7闰

"四分历"得名于将回归年定为365又四分之一天。

先秦各国历法：
战国时期，各诸侯国使用不同的历法，岁首各异（有建子、建丑、建寅之别），这是"战国七雄"时代历法混乱的历史背景。

《左传》《国语》中的历法记载：
先秦文献中大量出现"某年某月某日"的干支纪日，证明四分历在春秋战国时期已广泛使用。

4.4 秦汉：颛顼历→太初历（历法史的里程碑） ​

秦·颛顼历（前221年-前104年）：

  • 秦始皇统一六国后，颁布颛顼历
  • 岁首建亥（以亥月/十月为正月）
  • 这是"秦以十月为岁首"的来源
  • 颛顼历是四分历的一种，精度有限

汉武帝·太初历（前104年）：
这是中国历法史上最重要的改革节点。

改革内容颛顼历（旧）太初历（新）
岁首建亥（十月）建寅（正月）
节气未正式入历二十四节气正式入历
置闰规则粗略无中气置闰（精确化）
历法基准纯四分历阴阳合历完整体系

太初历的历史意义：

  1. 将岁首定为建寅（正月/寅月），沿用至今
  2. 将二十四节气正式纳入国家历法
  3. 确立"无中气置闰"规则，解决了置闰的精确判断问题
  4. 奠定了此后2000年中国历法的基本框架

司马迁参与了太初历的制定工作，《史记·历书》是这次历法改革的第一手文献记录。

五、农历的核心机制 ​

5.1 朔望月：月份的物理基础 ​

朔望月 = 29.53059天

月亮的四个关键相位：

plain
朔（新月）→ 上弦月 → 望（满月）→ 下弦月 → 朔（新月）
  初一        初七/八    十五/十六    二十二/三    下月初一

农历月份的规则：

  • 每月以朔日（新月）为初一
  • 大月 = 30天，小月 = 29天
  • 大小月的安排由精确天文计算决定（不是固定交替）
  • 现行农历：用现代天文方法精确计算每月朔日时刻

为什么初一不一定能看到月亮？
朔日是月亮与太阳同方向的时刻（合朔），
月亮完全被太阳光淹没，肉眼不可见。
初二初三才能看到细细的月牙。

5.2 回归年：年的天文基础 ​

回归年 = 365.2422天

这是地球绕太阳公转一周（从春分点到下一个春分点）的时间。

农历年的长度：

  • 平年 = 12个朔望月 = 354或355天
  • 闰年 = 13个朔望月 = 383或384天
  • 平均年长 ≈ 365.25天（通过19年7闰实现）

与公历年的比较：

农历平年农历闰年公历平年公历闰年
天数354/355天383/384天365天366天
月数12个月13个月12个月12个月

5.3 置闰法：协调阴阳的核心机制 ​

问题的本质：

plain
12个朔望月 = 354.367天
1个回归年  = 365.2422天
差值       = 10.875天/年

如果不置闰，每年农历比太阳年少约11天，
3年后少33天（超过一个月），
17年后，农历的"正月"会出现在夏天——
历法与季节完全脱节。

解决方案：19年7闰

plain
19个回归年 = 19 × 365.2422 = 6939.6018天
235个朔望月 = 235 × 29.53059 = 6939.6887天
误差 = 0.0869天（约2小时）

19个太阳年与235个朔望月几乎完全相等，
因此每19年插入7个闰月，可以使阴阳历保持同步。

无中气置闰：判断哪个月是闰月

这是太初历确立的精确置闰规则：

在一个含有13个月的农历年中，第一个没有"中气"的月份，定为闰月。

什么是"中气"？
二十四节气分为12个"节"和12个"气"（中气）：

  • 节：立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒
  • 气（中气）：雨水、春分、谷雨、小满、夏至、大暑、处暑、秋分、霜降、小雪、冬至、大寒

为什么用"无中气"判断闰月？

plain
中气间隔 = 回归年 ÷ 12 ≈ 30.44天
朔望月   = 29.53天

中气间隔（30.44天）> 朔望月（29.53天），
因此偶尔会出现某个农历月内没有中气的情况——
这个月就是"多出来"的月份，定为闰月。

实例：2020年闰四月

plain
2020年农历：
正月（含雨水）→ 二月（含春分）→ 三月（含谷雨）→ 四月（含小满）
→ 闰四月（无中气！）→ 五月（含夏至）→ ……

闰四月内没有任何中气（小满在四月，夏至在五月），
因此这个月被定为"闰四月"。

5.4 月建：地支月与农历月的关系 ​

月建，是地支月（干支历的月份）与历法的接口。

核心规则：

plain
月建 = 以节气为换月基准的地支月
     ≠ 农历朔望月

十二月建对照表：

地支月月建对应节气（节）公历约日期
寅月建寅立春约2月4日
卯月建卯惊蛰约3月6日
辰月建辰清明约4月5日
巳月建巳立夏约5月6日
午月建午芒种约6月6日
未月建未小暑约7月7日
申月建申立秋约8月7日
酉月建酉白露约9月8日

子月建子大雪约12月7日

月建 vs 农历月：两套系统并行

plain
月建（地支月）：以节气交节为换月时刻，纯太阳历
农历月：       以朔日（新月）为初一，朔望月

两者不同步：
例：2026年2月
  农历：正月（从2月17日朔日开始）
  月建：丑月（1月6日小寒→2月4日立春）
       寅月（2月4日立春→3月6日惊蛰）
  
  2月4日立春之前出生 → 月建丑月
  2月4日立春之后出生 → 月建寅月
  无论农历是几月，月建以节气为准。

5.5 岁首之争：建寅 vs 建子 vs 建亥 ​

岁首，即一年的起点，是历法的政治核心。

中国历史上有三种主要的岁首：

岁首正月使用朝代依据
建寅寅月（立春后）夏·汉（太初历后）·至今"人统"，以人事为中心
建丑丑月（小寒后）商"地统"，以大地为中心
建子子月（大雪后）周·秦（颛顼历前）"天统"，以天道为中心
建亥亥月（立冬后）秦（颛顼历）秦以水德，亥为水旺

"三正论"：
《史记·历书》记载，夏用建寅、商用建丑、周用建子，称为"三正"，历代改朝换代往往在三者之间选择，以示"承天命、继正统"。

现行农历的岁首：建寅
汉武帝太初历确立建寅为岁首，此后除少数例外，中国历法一直以寅月（立春后的第一个朔日）为正月初一。

注意：术数体系的"年"以立春换年，不以正月初一换年。
农历正月初一是"春节"（民俗年），
立春才是干支历的"年"的换年节点（术数年）。
两者可能相差数天，在四柱排盘时必须区分。

六、节气在历法中的位置 ​

6.1 节气是农历的"阳骨架" ​

一个最精准的比喻：

农历 = 骨架 + 肉身

骨架 = 二十四节气（太阳历，固定不动）

肉身 = 朔望月（阴历，随月亮浮动）

节气是农历的太阳坐标，
朔望月是农历的月亮坐标，
两者叠加，构成阴阳合历。

为什么节气在公历中日期几乎固定？ ​

plain
节气 = 太阳到达某黄经度数的时刻
公历 = 也是太阳历（回归年为基准）

→ 两者天文基础相同
→ 节气在公历中日期误差仅1-2天

为什么节气在农历中日期每年不同？ ​

plain
农历月 = 朔望月（月亮周期）
节气   = 太阳周期

→ 两者基准不同
→ 节气在农历中每年漂移，无规律可循

实例对比：冬至

年份公历日期农历日期
2023年12月22日农历十一月初十
2024年12月21日农历十一月廿一
2025年12月22日农历十一月初三
2026年12月22日农历十一月十四

公历日期：极度稳定（12月21-23日）
农历日期：每年不同，毫无规律

这就是节气"属于太阳历"的最直观证明。

6.2 无中气置闰：节气决定闰月 ​

（已在5.3节详述，此处补充逻辑链）

完整逻辑链：

plain
步骤一：确定当年是否需要置闰
  → 判断：本农历年是否包含13个朔望月？
  → 依据：19年7闰的周期

步骤二：确定哪个月是闰月
  → 规则：找到第一个没有中气的农历月
  → 该月即为前一个月的闰月

步骤三：命名闰月
  → 闰月以前一个月命名
  → 例：闰四月 = 四月之后、没有中气的那个月

为什么是"无中气"而非"无节"？

中气（12个）间隔约30.44天，
节（12个）间隔同样约30.44天，
但中气是每个地支月的"核心标志"——
每个地支月必须包含对应的中气：

plain
寅月必含雨水，卯月必含春分，辰月必含谷雨 ……

若某农历月不含中气，说明这个月"没有归属"，是多出来的，因此定为闰月。

这个规则的精妙之处在于：
它用节气（太阳历）来规范朔望月（阴历）的置闰，正是阴阳合历"以阳统阴"的核心体现。

6.3 为什么说农历是"世界上最复杂的历法" ​

复杂性来源：

plain
① 每月天数不固定（29或30天，由精确天文计算决定）
② 每年月数不固定（12或13个月）
③ 闰月位置不固定（可以是任何月份的闰月）
④ 同一年可能出现两个同名月（如两个"四月"）
⑤ 节气日期在农历中每年不同
⑥ 年的长度在354-384天之间浮动

精妙性来源：

plain
① 月相可见：初一必是新月，十五前后必是满月
② 季节准确：通过节气，与太阳年严格同步
③ 19年自我修正：19年后，月相与节气几乎回到原位
④ 农业适用：既能看月相（潮汐·渔业），又能看节气（播种·收割）

一句话总结：
农历的复杂，是为了同时服务两个主人——太阳和月亮。
它的精妙，在于用一套规则，让两个不同步的天文周期，在19年的尺度上实现近乎完美的和谐。

七、术数体系与历法的接口 ​

对术数不感兴趣可直接跳过。 该章为本篇对于术数应用的实战验证章节。

核心问题：不同术数体系，用的是哪种历？

答案出乎很多人意料：不同术数用不同的历法基准。

7.1 四柱八字：用节气历（纯太阳历） ​

月柱的历法基准：节气

plain
换月标准：十二节（立春·惊蛰·清明·立夏·芒种·小暑
                   立秋·白露·寒露·立冬·大雪·小寒）
换年标准：立春

与农历月的关系：无关
与公历月的关系：无关
唯一基准：太阳到达对应黄经度数的精确时刻

为什么四柱不用农历月？

四柱的月柱，本质上是太阳在黄道上的位置，代表出生时刻的"季节能量"。
季节能量由太阳决定，与月亮无关。
农历月是月亮周期，用农历月排月柱，等于用月亮的位置来代表太阳的能量——逻辑上根本不通。

实战规则：

plain
排月柱三步法：

第一步：查出生日期对应的节气区间
  → 该日期在哪两个"节"之间？

第二步：确认是否已过节
  → 必须查精确交节时刻（精确到分钟）

第三步：确定月柱
  → 过了节 = 新月柱
  → 未过节 = 上一个月柱

例：2026年2月10日 08:30出生
  立春：2026年2月4日 05:02
  惊蛰：2026年3月6日 03:07
  → 已过立春，未到惊蛰
  → 月柱 = 寅月 ✓

年柱的历法基准：立春

plain
立春前出生 → 用上一年的年干支
立春后出生 → 用本年的年干支

例：2026年2月3日出生（立春前）
  → 年柱用乙巳年（2025年干支）
  
  2026年2月5日出生（立春后）
  → 年柱用丙午年（2026年干支）

⚠️ 这与春节（农历正月初一）完全无关。
2026年春节是2月17日，但干支历的换年是2月4日立春。两者相差13天，不可混淆。

7.2 奇门遁甲：用节气历（最精细的太阳历应用） ​

奇门的时间基准：节气 × 三元

plain
一年 = 24个节气
每个节气 = 上元·中元·下元（三元）
每元 = 对应一个奇门局

局的种类：
  阳遁 9局（局1-9）  ← 冬至→夏至，阳气渐长
  阴遁 9局（局1-9）  ← 夏至→冬至，阴气渐长
  共 18局，循环使用

24节气 × 3元 = 72元/年
72元对应的局，从9局中循环取用

⚠️ 注意：局只有9个（阳遁9+阴遁9=18种），
不是72个。72是元的数量，局是循环使用的。

三元的天数：补拆法 vs 置闰法

三元的天数划分，历史上有两种主要算法：

算法三元天数特点
补拆法强制每元5天，用补、拆凑整整齐，便于排盘，民间常用
置闰法（超神接气）每元天数不固定，以实际节气时刻为准精确，但处理复杂，传统正宗

两种算法各有传承，实践中需按所学门派规范操作。

换局的精确性

plain
奇门换局 = 节气交节的精确时刻
         ≠ 当天零点
         ≠ 农历初一

交节前一秒 → 旧局
交节后一秒 → 新局

超神与接气

超神接气要精通，移步换形在其中。 —— 《烟波钓叟歌》

这是奇门时间推算的核心难点：

plain
理想状态：
  节气交节时刻 与 元的起点 完全对齐

现实情况：
  两者往往错位，产生两种情况：

  超神：
    按周期该换元了，但节气还未到
    → 提前启用下一节气的局
    → "超前于节气"

  接气：
    节气已过，但按周期元尚未换
    → 继续沿用，等待新气接入
    → "衔接新节气"

超神接气的处理，是区分奇门遁甲入门排盘与精深推算的重要分水岭，本篇仅作概念说明，详细推算规则见奇门专篇。

奇门与农历的关系 ​

奇门遁甲完全不使用农历月，它的时间坐标系是纯粹的节气太阳历，是二十四节气在术数中应用最精细的体系。

7.3 六爻：月建用节气，但有争议 ​

六爻的月建：

六爻中，月建（当月地支）影响爻的旺衰，这是六爻断卦的重要参数。

主流观点：月建以节气为准

plain
与四柱相同：
过了节 → 换月建
未过节 → 用上月月建

争议观点：月建以农历朔日为准

部分六爻传统认为，月建应以农历初一（朔日）为换月时刻，而非节气交节时刻。

如实呈现：
这个争议在六爻传统中确实存在，不同门派有不同实践。

本文采用主流观点（节气换月），但学习者应了解争议的存在，在实践中根据所学门派的规范操作。

7.4 择日：阴阳合历并用 ​

择日是历法应用最综合的术数体系，同时使用农历（阴历轨道）和节气（阳历轨道）：

plain
阴历轨道（朔望月）：
  → 农历日期（初一·十五·月相）
  → 建除十二神（以月建为基准起算）
  → 月破日（月建对冲之日）

阳历轨道（节气）：
  → 月建（换月以节气为准）
  → 节气日本身（某些节气日有特定宜忌）
  → 三伏·三九（以节气计算）

干支轨道（两者叠加）：
  → 年·月·日·时的干支
  → 神煞（太岁·岁破·天德·月德等）

择日的历法复杂性：
正因为择日同时使用三套轨道，它是对历法知识要求最高的术数应用，也是最能体现阴阳合历精妙之处的实践领域。

7.5 大六壬：月将以节气换将 ​

大六壬的月将：

大六壬用"月将"（太阳所在的黄道宫位）作为起课的时间参数。

plain
月将换将时间：以节气中的"气"（中气）为准

具体对应：
雨水后  → 亥将（登明）
春分后  → 戌将（河魁）
谷雨后  → 酉将（从魁）
小满后  → 申将（传送）
夏至后  → 未将（小吉）
大暑后  → 午将（胜光）
处暑后  → 巳将（太乙）
秋分后  → 辰将（天罡）
霜降后  → 卯将（太冲）
小雪后  → 寅将（功曹）
冬至后  → 丑将（大吉）
大寒后  → 子将（神后）

注意：大六壬以"气"换将，四柱以"节"换月
这是两套体系在节气应用上的重要区别，不可混淆。

7.6 各术数历法基准总览 ​

术数体系换月/换年基准使用的历法轨道备注
四柱八字十二节（节气）纯太阳历年以立春换年
奇门遁甲节气（节+气）纯太阳历精细到三元五天
六爻节气（主流）太阳历为主存在朔日换月的争议
大六壬十二气（中气）太阳历以气换将，非以节
择日节气+朔日阴阳合历并用最综合
紫微斗数农历月阴历为主与四柱不同
风水节气+方位太阳历为主三元九运以甲子计

一个值得深思的规律：
越是以"天（太阳）"为核心的术数，越用节气历；
越是以"人事·流年"为核心的术数，越用农历月。
这不是偶然，而是各体系对"时间本质"理解的不同侧重。

八、历法的文化层：从制度到生活 ​

8.1 授时：天子的权力 ​

在古代中国，颁布历法是天子的专属权力，称为"颁朔"或"授时"。

历象日月星辰，敬授人时。 ——《尚书·尧典》

《礼记·月令》记载：每月天子要"告朔"，即在太庙祭祀，宣布本月朔日，颁布本月的政令与禁忌。

历法与政治合法性：

  • 改朝换代必须"改正朔"（改变历法岁首）
  • 藩属国使用宗主国历法，是臣服的象征
  • 私自制历、私藏历书，在某些朝代是重罪

这解释了为什么中国历史上有那么多套历法——每个朝代都需要通过改历来宣示"奉天承运"。

8.2 年节：历法活在节日里 ​

中国传统节日，几乎全部建立在历法基础上：

节日历法基准日期
春节农历正月初一（朔日）朔望月
元宵节农历正月十五（望日）朔望月
清明节清明节气节气（太阳历）
端午节农历五月初五朔望月
七夕农历七月初七朔望月
中秋节农历八月十五（望日）朔望月
重阳节农历九月初九朔望月
冬至冬至节气节气（太阳历）
除夕农历十二月最后一天朔望月

有趣的规律：

  • 以"月相"为核心的节日（元宵·中秋），用农历（朔望月）
  • 以"季节"为核心的节日（清明·冬至），用节气（太阳历）
  • 这正是阴阳合历"双轨并行"在节日文化中的体现

8.3 三伏与三九：节气的延伸计算 ​

三伏（最热）：

入伏规则：

  • 夏至后第三个"庚日" = 初伏（10天）
  • 夏至后第四个"庚日" = 中伏（10或20天）
  • 立秋后第一个"庚日" = 末伏（10天）

为什么用"庚日"？

庚属金，金畏火克，夏季火旺，庚金最受克制，故以庚日标记最热时段。这是干支五行与节气历法的交叉应用

三九（最冷）：

入九规则：

  • 冬至后每9天为一"九"
  • 一九·二九·三九·……·九九
  • 三九 = 冬至后第19-27天，是一年中最冷的时段

"九九消寒图"：从冬至开始，每天填一笔，填满81笔（九九八十一天），春天就到了。

三伏三九，是节气历法与干支五行结合的典型应用，也是历法"活在日常生活"的最生动例证。

8.4 历法与中医：时间即治疗 ​

《黄帝内经·素问·四气调神大论》：

春三月，此谓发陈，天地俱生，万物以荣……
夏三月，此谓蕃秀，天地气交，万物华实……
秋三月，此谓容平，天气以急，地气以明……
冬三月，此谓闭藏，水冰地坼，无扰乎阳……

中医以历法（节气+月建）为时间坐标，指导养生、用药、针灸的时机：

  • 节气灸：在特定节气施灸，预防性治疗
  • 冬至灸 → 补阳气，防寒症
  • 夏至灸 → 清热，防暑症
  • 三伏灸 → "冬病夏治"的核心时机
  • 三九灸 → "夏病冬治"的核心时机

子午流注 ​

以十二时辰对应十二经络，按时辰选穴针灸。这是时辰历法与人体经络的对应

五运六气 ​

以干支纪年推算每年的气候特征，指导当年的疾病预防与治疗。这是历法与医学的最深层结合

九、万年历——历法的载体与工具 ​

9.1 万年历不是一种历法 ​

先说结论：

**万年历不是独立的历法，
**而是把现有历法预先推算汇编的工具。

plain
阴历（朔望月）  ┐
阳历（回归年）  ├─→ 预先计算 → 汇编 → 万年历
干支历（节气）  ┘

历法  = 数学规则（公式）
万年历 = 用规则提前算好的答案表

打个比方：
万年历之于历法，
就像九九乘法表之于乘法——
规则没变，只是把常用结果提前列出，不用每次现算。

9.2 "万年"是什么意思？ ​

不是真的推算了一万年。

  • 古代版：通常推算 60年（一个甲子）或 100
  • 现代纸质版：通常推算 100-200年
  • 数字App版：理论上可以无限推算（用现代天文算法）

"万年"是夸张修辞，与"万寿无疆""万古长青"用法相同，意思是"长久可用、永久有效"，不是字面意义上的一万年。

9.3 万年历的历史来源 ​

起源于历代官方颁历的实际需要：

plain
古代运作逻辑：

钦天监（国家天文机构）
    ↓ 每年推算来年历书
颁布给全国使用（"颁朔"）

问题：
皇帝·官员需要提前规划数年，
希望能查到未来多年的日期·节气·吉凶

→ 出现了提前推算多年的"长历"
→ 民间需求扩大
→ 明清：民间历书（皇历/通书）大量流行
→ "万年历"名称逐渐固定

历史沿革简表：

时期形态内容
汉代以前官方颁历每年颁布，仅含当年
唐宋长历·具注历含多年日期+节气+宜忌
明清皇历·通书民间广泛流通，含干支·神煞·宜忌
近现代印刷万年历通常含100年，案头工具书
当代万年历App实时计算，理论上无限年

9.4 万年历包含什么？——三套历法的叠加显示 ​

现代万年历（无论纸质还是App），
本质上是一个多历法对照查询工具，
同一天同时显示三套历法的信息：

plain
同一天，万年历显示：

┌───────────────────────────────┐
│  公历：2026年7月23日（星期四）    │  ← 格里历（纯太阳历）
│  农历：六月初九                  │  ← 阴阳合历（朔望月）
│  干支：丙午年·壬午月·庚午日       │  ← 干支历（节气历）
│  节气：大暑（7月23日）           │  ← 太阳黄经120°
│  宜：祭祀·出行                  │  ← 择日术数系统
│  忌：动土·嫁娶                  │  ← 择日术数系统
└───────────────────────────────┘

**它把三套历法的计算结果叠加在同一天上显示，
**本身不是第四种历法。

9.5 一个常见误解的澄清 ​

❌ 很多人以为："农历 = 阴历 = 万年历上的那套"

实际上，万年历上同时有三套：

plain
公历   → 太阳历（与月相无关）
农历   → 阴阳合历（不是纯阴历）
干支历 → 纯太阳历（节气换月，与农历月无关）

三套并列显示，万年历只是容器，
不代表它们是同一种历法。

这也是为什么：
同一天，农历是"六月初九"，
干支月却可能已经是"壬午月"（芒种后）——
两套历法的月份换月基准根本不同，
万年历把它们同时显示出来，
反而容易造成混淆。

使用万年历时，必须清楚自己在看哪一套。
四柱排盘看干支栏，不看农历栏

9.6 万年历与术数实战 ​

万年历在术数实践中的核心用途：

用途看哪一栏注意事项
四柱排盘（年月日时柱）干支栏年以立春换年，月以节换月
奇门起局节气时刻需精确到分钟的交节时刻
六爻月建干支月以节气换月（主流）
择日农历+干支+节气 三栏并用最综合，三套都要看
大六壬月将中气时刻以气换将，非以节

万年历的局限：

plain
纸质万年历：
  → 节气时刻通常只精确到"日"，
    不标注具体时分
  → 四柱排盘时，节气当天出生者，
    必须另查精确交节时刻，不可只看万年历日期

App万年历：
  → 大多数App已提供精确交节时刻
  → 但宜忌·神煞的计算逻辑各家不同，
    仅供参考，不可盲从

9.7 小结 ​

万年历的本质： ​

  • 工具，不是历法
  • 容器，不是内容
  • 答案表，不是公式

万年历的价值： ​

把公历·农历·干支历三套历法的计算结果，汇聚在同一个界面，方便日常查阅。

一句话：
万年历是历法知识的"显示屏"，但读懂显示屏上的内容，
需要先理解屏幕背后三套历法各自的逻辑。

十、现代解读 ​

10.1 农历的现代科学地位 ​

农历不是"封建迷信"，而是精确的天文历法系统：

plain
现代天文学验证：
  朔日计算：现行农历用现代天文方法精确计算合朔时刻，
            误差在秒级以内
  节气计算：用现代天文软件计算节气时刻，
            与古代历法的误差在分钟级别
  19年7闰：现代天文学完全验证了默冬周期的精确性

农历在现代的实用价值：

领域农历的现代应用
农业节气指导播种收割，沿用至今
渔业朔望月指导潮汐预测，渔民仍用农历
中医节气灸·子午流注·五运六气
民俗传统节日·婚丧嫁娶择日
天文月食·日食预测（朔望月）

10.2 公历 vs 农历：不是替代，是互补 ​

常见误解：公历是"科学的"，农历是"落后的"

正确理解：

  • 公历（格里历）= 纯太阳历，适合国际通用、工业计时
  • 农历（阴阳合历）= 阴阳合历，适合农业、渔业、中医、民俗

两者不是竞争关系，而是服务于不同需求的两套系统。

中国现代社会同时使用两套历法，这本身就是一种文化智慧：

用公历处理国际事务，用农历传承文化传统。

10.3 历法思维：时间是有质地的 ​

公历思维：时间是均匀的刻度，1月1日和7月1日没有本质区别。

历法思维（节气+月建）：时间是有质地的——

plain
寅月的时间，是木气初生、万物萌动的时间；
午月的时间，是火气帝旺、阳极将转的时间；
子月的时间，是水气最旺、一阳初生的时间。

同样是"一个月"，
寅月和子月的能量质地完全不同，
适合做的事、需要注意的方向，也完全不同。

这不是迷信，而是一种与自然节律同频的时间感知方式。
它建立在真实的天文观测基础上，
经过数千年的农业实践验证，
是中华文明对时间本质的独特洞察。

十二、本章小结 ​

历法，是人类把天文周期转化为社会时间坐标的系统工程。
中国农历，是这项工程中最复杂、也最精妙的成就之一。

五个核心认知：

① 农历不是阴历
农历是阴阳合历，同时追踪太阳（节气）和月亮（朔望月），
用置闰法协调两者。把农历叫做"阴历"，是一个根本性的误解。

② 节气是农历的太阳骨架
节气属于太阳历，嵌入农历，构成农历的"阳"的部分。
节气在公历中日期稳定，在农历中日期漂移，
根本原因是两者的天文基准不同。

③ 置闰法是阴阳合历的核心机制
19年7闰，无中气置闰——
这套规则用太阳历（节气）来规范阴历（朔望月）的置闰，
是"以阳统阴"的历法智慧。

④ 不同术数用不同历法基准
四柱·奇门用节气历（纯太阳历），
六爻月建以节气为主，
择日阴阳合历并用，
大六壬以中气换将。
理解这个差异，是避免术数实战错误的基础。

⑤ 历法思维：时间是有质地的
节气历法不只是计时工具，
它是一种与自然节律同频的时间感知方式。
每个月建都有其独特的能量质地，
这是中华文明对时间本质的独特洞察，
也是术数体系得以成立的时间哲学基础。

学历法，有两个层次：

第一层：记住三种历法的区别，
记住农历的核心机制（朔望月·置闰·月建），
记住各术数体系用哪种历法基准。
这是工具层，必须熟练。

第二层：理解为什么古人要建立这套系统——
他们面对的问题是：太阳和月亮，各有自己的节律，
两者不同步，但人的生活需要同时跟随两者。
农历，是古人给出的答案：
不放弃任何一个，用智慧让两者和谐共存。

这种"和而不同、阴阳并行"的思维方式，
不只是历法的逻辑，更是中华文化底层世界观的体现。

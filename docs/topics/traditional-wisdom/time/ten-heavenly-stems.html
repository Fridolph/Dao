11 · 十天干：时间坐标系的第一维 ​

版本与引用说明 ​

本篇主要依据：

  • 《史记·律书》（司马迁，约前91年）
  • 《汉书·律历志》（班固，约公元80年）
  • 《淮南子·天文训》（刘安等，约前139年）
  • 《说文解字》（许慎，约公元100年）——字源考据
  • 《尔雅·释天》（先秦至汉，字义训诂）
  • 参考：彝族十月太阳历研究（刘尧汉等，20世纪民族学田野调查）

一、体系定位：在知识树中的坐标 ​

plain
九宫方位（空间坐标）
       +
十天干（时间坐标·第一维）  ←── 本篇
十二地支（时间坐标·第二维）
       ↓
    六十甲子（完整时间编码）
       ↓
  四柱·奇门·六爻·六壬·择日

一句话定位：

十天干是古人对太阳运行周期的十段编码——
记录的不只是"第几天"，
而是每个时间段里，天地能量处于什么状态。

二、原典依据 ​

文献一：《史记·律书》——天干的天文本义 ​

【原典】《史记》卷二十五·律书第三（司马迁，约前91年）

【原文节选】

"甲者，言万物剖符甲而出也。
乙者，言万物生轧轧也。
丙者，言阳道著明，故曰丙。
丁者，言万物之丁壮也，故曰丁。
戊者，言万物尽冒土而出也，故曰戊。
己者，言阴气既起，万物而止，故曰己。
庚者，言阴气庚万物，故曰庚。
辛者，言万物之辛生，故曰辛。
壬者，言阳气任养万物之下也，故曰壬。
癸者，言万物可揆度，故曰癸。"

这是现存最早对十天干逐一训释的系统文献，揭示了每个天干对应的自然物候状态，是天干"象意"的第一手来源。

文献二：《淮南子·天文训》——天干与历法的对应 ​

【原典】《淮南子》卷三·天文训（刘安等，约前139年）

【原文节选】

甲乙寅卯，木也；

丙丁巳午，火也；

戊己四季，土也；

庚辛申酉，金也；

壬癸亥子，水也。

这是天干五行归属的最早系统记载，将十天干明确分配给五行，奠定了后世所有术数体系的基础框架。

文献三：《说文解字》——字形溯源 ​

【原典】《说文解字》（许慎，约公元100年）

许慎对十天干的字形解释，是从汉字本义角度理解天干的权威来源。以"甲"为例：

甲，东方之孟，阳气萌动，从木戴孚甲之象。

字形本身就是象意的载体——这是中华文字体系独有的"图像编码"传统。

文献四：《汉书·律历志》——官方历法确认 ​

【原典】《汉书》卷二十一·律历志（班固，约公元80年）

【原文节选】

出甲于甲，奋轧于乙，明炳于丙，大盛于丁，丰楙于戊，理纪于己，敛更于庚，悉新于辛，怀任于壬，陈揆于癸。

《汉书》在《史记》基础上进一步系统化，将天干与生命成长周期完整对应，是天干"生命模型"解读的官方文本依据。

3.2 象意详解：每个天干的"状态描述" ​

理解天干，最重要的不是死记属性，而是理解它描述的那个状态。

依据《史记·律书》与《汉书·律历志》逐一解读：

🌱 甲（jiǎ）· 阳木 ​

【字形】种子破壳而出，外有硬壳（甲）包裹
【原文】"万物剖符甲而出"（《史记·律书》）
【状态】破土而出的第一股力量——冲破束缚，强势萌发
【象意】开创·突破·领头·硬壳保护下的新生

plain
甲 = 参天大树的主干
  = 森林里最高的那棵
  = 领导力·方向感·开拓性

🌿 乙（yǐ）· 阴木 ​

【字形】弯曲柔韧的草木之形
【原文】"万物生轧轧"（《史记·律书》）——轧轧，柔韧弯曲之声
【状态】已经出土，但还在柔韧生长中，遇障则绕
【象意】柔韧·适应·缠绕·生命力的韧性

plain
乙 = 藤蔓、花草
  = 遇石头绕过去，遇缝隙钻进去
  = 柔软但生命力极强

🔥 丙（bǐng）· 阳火 ​

【字形】从"一"从"内"，阳气充盛于内
【原文】"阳道著明"（《史记·律书》）
【状态】阳光普照，光明显赫，无所遮蔽
【象意】光明·热烈·外向·照耀四方

plain
丙 = 太阳本身
  = 正午的阳光，直射无遮
  = 热情·开朗·透明·不藏私

🕯️ 丁（dīng）· 阴火 ​

【字形】象钉子，有形有质
【原文】"万物之丁壮"（《史记·律书》）
【状态】火已成形，精炼而聚焦，有方向的热
【象意】精准·内敛·文明之火·人工之光

plain
丁 = 烛火、炉火、星光
  = 有边界的光，照亮特定范围
  = 精细·专注·有温度但不张扬

🏔️ 戊（wù）· 阳土 ​

【字形】从"戈"，有武力守护之意
【原文】"万物尽冒土而出"（《史记·律书》）
【状态】大地厚重，承载万物，阳刚之土
【象意】厚重·稳固·城墙·高山·边界

plain
戊 = 高山、城墙、旷野
  = 大地的阳刚面：边界感、防御性、稳重
  = 可依靠，但不易亲近

🌾 己（jǐ）· 阴土 ​

【字形】象纪录之形，有条理
【原文】"阴气既起，万物而止"（《史记·律书》）
【状态】土地内敛，滋养收纳，阴柔之土
【象意】包容·滋养·田园·内化·消化吸收

plain
己 = 田地、湿土、花园
  = 大地的阴柔面：包容、滋养、转化
  = 能消化万物，将异物变为己用

⚔️ 庚（gēng）· 阳金 ​

【字形】象更新、收割之形
【原文】"阴气庚万物"（《史记·律书》）——庚，更也，更新
【状态】秋风肃杀，刚硬决断，收割更新
【象意】刚硬·决断·变革·肃杀·斧钺

plain
庚 = 刀剑、斧头、铁矿
  = 秋天的肃杀之气
  = 果断·不拖泥带水·有时显得冷酷

💎 辛（xīn）· 阴金 ​

【字形】象刑具、针刺之形，有刺痛感
【原文】"万物之辛生"（《史记·律书》）——辛，新也，辛苦中新生
【状态】金已精炼，细腻锋利，珠宝首饰之金
【象意】精致·敏锐·洁净·有时带刺

plain
辛 = 珠宝、针、精炼金属
  = 经过锻炼后的精华
  = 审美感强，对细节敏感，完美主义

🌊 壬（rén）· 阳水 ​

【字形】象水中有物孕育之形
【原文】"阳气任养万物之下"（《史记·律书》）——任，承担
【状态】大水奔涌，包容万物，深不可测
【象意】智慧·流动·包容·深邃·承载

plain
壬 = 大海、大江、深渊
  = 水的阳刚面：奔涌、宽广、深不可测
  = 智慧型，善于运筹，有大局观

🌧️ 癸（guǐ）· 阴水 ​

【字形】象水流细密、可测度之形
【原文】"万物可揆度"（《史记·律书》）——揆度，测量推算
【状态】细水渗透，滋润万物，冬藏之水
【象意】渗透·滋润·隐秘·直觉·孕育

plain
癸 = 雨露、地下水、冬雪
  = 水的阴柔面：无声渗透，滋养根系
  = 直觉敏锐，善于感知，内敛深沉

四、十天干的来源之谜：十月太阳历 ​

这是整个天干体系中，最少被现代人知道、却最重要的一个来源问题。

4.1 主流说法：商代纪日 ​

通常的说法是：天干起源于商代，用于纪日（甲日、乙日……），商王以天干命名（如"武丁"、"盘庚"）。 这是有甲骨文实证的，鲜有争议。

4.2 更深的来源：十月太阳历 ​

【依据】彝族十月太阳历研究（刘尧汉《中国文明源头新探》，1985年）及后续民族学研究。

上古中国存在一种以10为基数的太阳历：

plain
一年 = 10个月
每月 = 36天
10×36 = 360天
余下5-6天 = 过年日（不计入月份）

10个月 → 用10个符号标记 → 甲乙丙丁戊己庚辛壬癸

这解释了一个长期悬而未决的问题：

为什么天干是10个，而不是12个？

plain
如果天干只是纪日工具，用12（配合地支）更方便。
但天干偏偏是10——
因为它最初对应的，是十月太阳历的10个月份，
而不是后来的十二月历。

彝族至今保留十月太阳历的活态传统，每年火把节即是这套历法的遗存。

4.3 两套历法的融合 ​

plain
上古十月太阳历（10天干）
         +
上古十二月阴历（12地支）
         ↓
    六十甲子（10×12=60的最小公倍数）
         ↓
    融合为现行干支纪年体系

这不是偶然的数字游戏，是两套独立历法系统在漫长历史中融合的结果。

五、阴阳配对：为什么每个五行都有一阴一阳？ ​

5.1 阴阳干的本质区别 ​

plain
同一五行，阴阳干的区别不是"强弱"，而是"形态"：

甲（阳木）= 参天大树  → 主干·方向·不易弯折
乙（阴木）= 花草藤蔓  → 柔韧·适应·善于缠绕

丙（阳火）= 太阳烈火  → 外放·照耀·无所遮蔽
丁（阴火）= 烛火星光  → 内敛·精准·有边界的温暖

戊（阳土）= 高山旷野  → 厚重·边界·防御
己（阴土）= 田园湿土  → 包容·滋养·消化转化

庚（阳金）= 刀剑斧钺  → 刚硬·决断·肃杀
辛（阴金）= 珠宝首饰  → 精致·敏锐·有时带刺

壬（阳水）= 大海江河  → 奔涌·宽广·深不可测
癸（阴水）= 雨露地下水 → 渗透·滋润·隐秘孕育

5.2 阴阳干的运动方向 ​

plain
阳干（甲丙戊庚壬）：
  → 向外扩张，主动出击，显性力量

阴干（乙丁己辛癸）：
  → 向内收敛，柔性渗透，隐性力量

这与阴阳的基本属性完全一致：

阳主动、外、显；阴主静、内、隐。

六、十天干的生命周期模型 ​

《史记·律书》与《汉书·律历志》共同揭示了一个关键视角：

十天干不只是10个标签，而是一个完整生命周期的10个阶段。

plain
甲 → 破壳萌发（出生·冲破）
乙 → 柔韧生长（成长·适应）
丙 → 光明显赫（盛放·外显）
丁 → 丁壮成熟（壮年·精炼）
戊 → 茂盛极致（极盛·守护）
己 → 收敛内化（转折·内省）
庚 → 肃杀更新（收割·变革）
辛 → 辛苦新生（精炼·蜕变）
壬 → 深藏孕育（潜伏·承载）
癸 → 揆度待发（休眠·准备）
   → 回到甲，新一轮开始

这是一个完整的能量循环：
从萌发→成长→极盛→收敛→肃杀→孕育→再萌发。

这个模型，与十二长生（第18篇）高度对应，
是同一套生命哲学在不同维度上的表达。

七、与各术数体系的接口 ​

7.1 四柱八字 ​

plain
天干 = 八字中"天"的层面
  → 年干·月干·日干·时干
  → 日干 = "我"（命主本人）
  → 其余天干 = 与"我"的关系（生·克·比·泄）

7.2 奇门遁甲 ​

plain
天干 = 奇门三奇六仪的基础
  → 三奇：乙·丙·丁（三个阴干中的精华）
  → 六仪：戊·己·庚·辛·壬·癸
  → 甲统领六仪，隐而不现（甲为尊，藏于六仪之下）

7.3 大六壬 ​

plain
天干 = 月将与贵神的五行来源
  → 天干五行决定各神的旺衰
  → 日干定贵人方位（天乙贵人查日干）

7.4 中医（五运六气） ​

plain
天干 = 五运的来源
  → 甲己合化土运
  → 乙庚合化金运
  → 丙辛合化水运
  → 丁壬合化木运
  → 戊癸合化火运
  （天干五合 → 五运，是中医运气学的基础）

八、天干五合：为什么相隔五位的天干会"合"？ ​

这是初学者常见的疑问，值得单独解释。

8.1 五合列表 ​

plain
甲（1）+ 己（6）= 合化土
乙（2）+ 庚（7）= 合化金
丙（3）+ 辛（8）= 合化水
丁（4）+ 壬（9）= 合化木
戊（5）+ 癸（10）= 合化火

8.2 为什么相隔五位？ ​

plain
十天干排成一圈（1-10）
相隔五位 = 正好对冲的两个位置

1 ←→ 6（甲己）
2 ←→ 7（乙庚）
3 ←→ 8（丙辛）
4 ←→ 9（丁壬）
5 ←→ 10（戊癸）

阴阳互根原则：相对的两极，因为互补而相吸。
这与九宫中坤（2）与艮（8）相对，（奇门遁甲中）阳遁寄坤阴遁寄艮，是同一个逻辑。

8.3 合化的五行来源 ​

合化结果的五行，来自河图的生成数关系：

天一生水，地六成之（1·6 → 水，但甲己合土，另有说法）

【说明】天干五合的合化五行，历代有不同解释，主流以《三命通会》为准。

合化是否成立，还需看"得令"（当月是否为该五行旺月），不是无条件合化，这是实战中的重要细节。

九、现代解读：天干本质上是什么？ ​

9.1 能量状态的十段编码 ​

天干不是"第一天、第二天"的序号，
而是"能量处于什么状态"的质性描述。

如果把一年的能量变化比作一首交响乐：

plain
  甲 = 序曲，第一个音符破空而出
  乙 = 主题展开，旋律开始流动
  丙 = 高潮，全乐队齐奏，光芒万丈
  丁 = 精彩华章，精炼而有力
  戊 = 乐曲顶点，所有声部汇聚
  己 = 开始收束，进入尾声准备
  庚 = 强力终止，干净利落
  辛 = 余音绕梁，精华留存
  壬 = 深沉的低音，在黑暗中孕育
  癸 = 最后的静默，等待下一个甲

好的，我们回到状态本身，

吾十有五而志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。 —— 《论语·为政》

天干描述的是：能量在一个完整周期内的十种状态；孔子描述的是：一个人在一生中经历的十种境界，两者的底层结构完全相同：

萌发 → 生长 → 显赫 → 精炼 → 立身 → 内化 → 决断 → 精华 → 包容 → 孕育 → 再萌发（下一代·下一个甲）

9.2 为什么需要"状态描述"而不只是序号？ ​

plain
现代日历：1月2日、1月3日……（序号，只告诉你"第几天"）

天干系统：甲日、乙日……（状态，告诉你"这天的能量是什么性质"）

区别：
  序号系统 → 适合精确计时
  状态系统 → 适合判断"此刻适合做什么"

这正是术数与现代历法的根本差异：

现代历法问"什么时候"，
天干系统问"什么状态"。

十一、本章小结 ​

十天干，是古人对太阳能量在一个完整周期内十种状态的精确编码。

  1. 📅 历法价值：十月太阳历的遗存，记录了上古最早的时间体系
  2. 🌱 哲学价值：完整的生命周期模型，从萌发到孕育，循环不息

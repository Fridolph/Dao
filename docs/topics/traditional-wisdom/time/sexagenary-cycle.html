13 六十甲子

理解十天干与十二地支如何组合为完整的六十甲子时间编码。

导读

13 · 六十甲子：天地合轨的完整时间编码 ​

版本与引用说明 ​

本篇主要依据：

  • 《史记·历书》（司马迁，约前91年）
  • 《汉书·律历志》（班固，约公元80年）
  • 《淮南子·天文训》（刘安等，约前139年）
  • 《世本》（先秦至汉，已佚，辑本存）——"黄帝命大挠作甲子"来源
  • 《尔雅·释天》（先秦至汉）——甲子训诂
  • 考古参照：殷墟甲骨文（约前1300年），现存最早干支纪日实物

一、体系定位：在知识树中的坐标 ​

plain
十天干（10）× 十二地支（12）
         ↓
    最小公倍数 = 60
         ↓
      六十甲子
         ↓
  纪年 · 纪月 · 纪日 · 纪时
  四柱八字 · 奇门 · 六爻 · 六壬 · 择日

一句话定位：

六十甲子是天干与地支两套系统咬合运转的完整周期——
不是简单的10×12=120，而是10与12的最小公倍数60，
是两套不同节律的天文周期，在数学上找到的最短公共轨道。

二、原典依据（四条核心文献） ​

文献一：《史记·历书》——甲子纪年的官方确认 ​

【原典】《史记》卷二十六·历书第四（司马迁，约公元前91年）

【原文节选】

黄帝考定星历，建立五行，起消息，正闰余，于是有天地神祇物类之官，是谓五官。各司其序，不相乱也。

《历书》确认了干支历法在黄帝时代的建立，并记载了从黄帝元年起的干支纪年序列。虽然"黄帝建历"的具体年代存在争议，但《史记》将其作为中华历法的起点，具有重要的文化史意义。

文献二：《世本》——"大挠作甲子"的来源 ​

【原典】《世本》（先秦至汉，已佚，清人辑本）

【原文】

大挠作甲子。（《世本·作篇》）

【注疏】唐代司马贞《史记索隐》引《世本》注：

大挠，黄帝史官也。采五行之情，占斗机所建，始作甲乙以名日，谓之干；作子丑以名月，谓之支。有事于天则用日，有事于地则用辰，阴阳之别，故有支干名也。

这是关于干支起源最详细的古代文献记载：

  • 作者：大挠（黄帝史官）
  • 方法：观察北斗斗柄所指方位（斗建）
  • 功能：天干纪日，地支纪月，天地分用

文献三：考古实物——殷墟甲骨文（约公元前1300年） ​

1899年起陆续出土的殷墟甲骨文，包含大量干支纪日记录。其中完整的六十甲子表已被发现，证明六十甲子体系在商代中期已完全成型并用于日常纪日。

这将六十甲子的实证历史推至距今约3300年，远早于任何传世文献的记载。

文献四：《汉书·律历志》——数理逻辑的官方阐释 ​

【原典】《汉书》卷二十一·律历志（班固，约公元80年）

【原文节选】

天六地五，数之常也。天以六制，地以五制。五六相乘，是为三十；三十相乘，是为六十。

这是六十甲子数学来源的官方解释：

  • 天数以六为基（六律）
  • 地数以五为基（五行）
  • 5×6=30，30×2=60

【说明】《汉书》的这个解释是从音律角度切入的，与"10×12最小公倍数=60"是不同角度的解释

三、六十甲子完整表 ​

3.1 生成规则 ​

plain
天干（10）：甲乙丙丁戊己庚辛壬癸    → 循环
地支（12）：子丑寅卯辰巳午未申酉戌亥 → 循环

配对规则：
  阳干（甲丙戊庚壬）只配阳支（子寅辰午申戌）
  阴干（乙丁己辛癸）只配阴支（丑卯巳未酉亥）

所以不是10×12=120，而是：
  10与12的最小公倍数 = 60
  （阴阳同性配对，自动过滤掉另外60个组合）

四、空亡：六十甲子自带的"缺位" ​

4.1 什么是空亡？ ​

每旬十个干支，天干用完了10个，地支却只走了10个（还剩2个没被配到）。这剩下的2个地支，就是这一旬的空亡（又称"旬空"）。

plain
甲子旬（甲子→癸酉）：
  走过的地支：子丑寅卯辰巳午未申酉（10个）
  没走到的：戌·亥
  → 甲子旬，戌亥空亡

六旬的空亡：
  甲子旬 → 戌亥空
  甲戌旬 → 申酉空
  甲申旬 → 午未空
  甲午旬 → 辰巳空
  甲辰旬 → 寅卯空
  甲寅旬 → 子丑空

4.2 空亡的哲学意涵 ​

空亡者，虚而不实，有名无实之地。 ——《三命通会》

plain
天干走完了，地支还没走完——
这两个"没被天干照到"的地支，
就像没有阳光照射的角落：
  有形，但无力
  存在，但虚化
  在场，但不发挥作用

这不是神秘主义，是一个非常实用的状态标记：

plain
空亡 = 该地支所代表的事物，
       在这个时间段内"虚而不实"

应用：
  六爻中：某爻地支空亡 → 该爻代表的事不成立
  四柱中：某柱地支空亡 → 该柱代表的领域有缺失
  奇门中：某宫地支空亡 → 该宫方位不宜行动

【重要补充】"冲空则实"——空亡的地支，若被另一个地支冲，反而会被激活，从"虚"变"实"。
这个规则将在第22篇《空亡旬空》中完整展开。

五、纳音五行：六十甲子的第三层编码 ​

5.1 什么是纳音？ ​

每对干支（两个一组，如甲子·乙丑），除了各自的天干五行和地支五行之外，还有一个纳音五行——这是两者合并后，在音律层面产生的第三种五行属性。

plain
甲子 + 乙丑 = 海中金（纳音）
丙寅 + 丁卯 = 炉中火（纳音）
……

5.2 纳音的来源 ​

【原典】《汉书·律历志》

纳音来源于五音十二律的对应关系：

plain
古代音律：宫·商·角·徵·羽（五音）
对应五行：土·金·木·火·水

十二律管（十二律）与十二地支对应，
五音与五行对应，两者交叉产生六十甲子的纳音五行。

这是古代声学与历法的交叉学科——古人认为，每个时间段都有其对应的"音"，音与五行相通，因此每对干支都有其纳音五行。

5.3 纳音的应用场景 ​

plain
纳音五行主要用于：
  → 四柱命理（民间"五行缺什么"的判断，有时用纳音）
  → 择日（某些流派以纳音判断日子吉凶）
  → 起名（以纳音补充五行）

在奇门遁甲和六爻中，纳音使用较少。
主流四柱命理（子平法）以天干地支本身的五行为主，纳音为辅助参考。

【说明】纳音五行是六十甲子体系中争议较多的部分。
不同流派对纳音的重视程度差异很大。
本篇如实呈现，不强推某一立场。
初学者优先掌握天干地支本身的五行，纳音可后续深入。

六、六十甲子的四维应用：年·月·日·时 ​

6.1 纪年 ​

plain
六十年一轮回：
  2024年 = 甲辰年
  2025年 = 乙巳年
  2026年 = 丙午年
  ……
  2084年 = 甲辰年（下一轮）

计算方法：

$ \text{干支序号} = (\text{公历年份} - 3) \mod 60 $

以2026年为例：$$ (2026 - 3) \mod 60 = 2023 \mod 60 = 43 $$

查表第43位 = 丙午年 ✓

6.2 纪月 ​

plain
每年12个月，每月对应固定地支（月建）：
  正月（寅月）→ 天干随年干推算
  二月（卯月）→ 天干随年干推算
  ……

月干推算口诀（五虎遁年起月法）：
  甲己之年丙作首，
  乙庚之岁戊为头，
  丙辛必定寻庚起，
  丁壬壬位顺行流，
  若问戊癸何方发，
  甲寅之上好追求

以丙午年（2026）为例：
丙辛之年寻庚上 → 正月（寅月）从庚寅起，
二月 = 辛卯，三月 = 壬辰……

6.3 纪日 ​

plain
六十天一轮回（约两个月）
这是干支纪日最原始的用途
甲骨文中大量的干支记录，主要就是纪日

6.4 纪时 ​

补充：五鼠遁（日上起时法）

  • 用途：根据给定的“日干”推算“子时的干支”，进而顺推全天的时干。
  • 为何叫“鼠”：一天十二个时辰，排时干时固定从地支“子”时开始，因子对应生肖鼠，故称“五鼠遁”。

一天十二时辰，对应十二地支（固定）：

子时（23-01）· 丑时（01-03）· 寅时（03-05）……

时干随日干推算（五鼠遁日起时法）：

甲己还加甲，乙庚丙作初，丙辛从戊起，

丁壬庚子居，戊癸何方发，壬子是真途。

七、"黄帝命大挠作甲子"——历史真相辨析 ​

这是一个需要如实呈现、不回避的考据问题。

7.1 传说记载 ​

【原典】《世本·作篇》（辑本）：

大挠作甲子。

【注疏】《史记索隐》引：

大挠，黄帝史官也。

传说中，黄帝命史官大挠，观察北斗斗柄的指向，创制了干支体系，用于纪日纪月。

7.2 考古证据的修正 ​

plain
殷墟甲骨文（约前1300年）：
  → 已有完整六十甲子表
  → 大量干支纪日记录
  → 证明商代中期已完全成型

黄帝传说时代（约前2600年）：
  → 无直接考古证据支持干支体系已存在
  → 但也无证据证明不存在

7.3 如实结论 ​

"大挠作甲子"的文化意义： ​

将干支体系的创制归于黄帝时代，是中华文明"追溯圣王"传统的体现。

考古可确认的： ​

六十甲子在商代（约前1300年）已完全成型，这本身已是极为古老的成就

【诚实的边界】

  • 干支体系的最初创制时间，目前无法精确考证
  • "黄帝时代"是文化叙事，不是考古结论
  • 当前"环境"下不可以一言蔽之

八、六十年一甲子：周期的哲学意涵 ​

8.1 "一甲子"为什么是六十年？ ​

现代人说"活了一甲子"为活了六十岁。为什么六十是一个完整周期？

  • 天干周期：10年一轮（五行各主两年）
  • 地支周期：12年一轮（木星公转周期）

两个周期同时回到起点： 10和12的最小公倍数 = 60

天干走了6轮，地支走了5轮；

天地同时回到"甲子"这个起点。

8.2 更大的周期 ​

六十甲子可以叠加：

  • 一元 = 60年（基础周期）
  • 三元 = 180年（上元·中元·下元）

这是风水玄空飞星"三元九运"的来源

更大周期：

邵雍《皇极经世》：元·会·运·世

一元 = 129600年 = 60甲子的更大嵌套

补充一下不同体系的三元 ​

第一套：干支纪时体系的"三元" ​

plain
一甲子 = 60年（天干10 × 地支12 ÷ 最大公约数2）
一元   = 60年（= 1个甲子）
三元   = 上元 + 中元 + 下元 = 180年

这里的"元"是干支周期的计数单位，
60年走完一轮甲子，叫"一元"。
三元 = 三个甲子 = 180年。

用途：干支纪年、四柱、奇门遁甲的大周期框架。

第二套：玄空飞星风水体系的"三元九运" ​

  • 1 运 = 20年（九宫飞星轮换一次）
  • 1 元 = 3 运 = 60年（上元·中元·下元各含三运）
  • 三元 = 上元 + 中元 + 下元 = 180年
  • 九运 = 9 × 20年 = 180年（一个完整大周期）

具体分布：

元运年份当令星
上元一运1864–1883一白水星
上元二运1884–1903二黑土星
上元三运1904–1923三碧木星
中元四运1924–1943四绿木星
中元五运1944–1963五黄土星
中元六运1964–1983六白金星
下元七运1984–2003七赤金星
下元八运2004–2023八白土星
下元九运2024–2043九紫离火

用途：玄空飞星风水、紫白飞星择日。

两套体系的关系图 ​

plain
                  ┌─────────────────────────────────┐
                  │        180年 大周期               │
                  └─────────────────────────────────┘
                           ↙              ↘
        ┌──────────────────┐    ┌──────────────────────┐
        │  干支体系的三元   │    │  飞星体系的三元九运   │
        ├──────────────────┤    ├──────────────────────┤
        │ 1元 = 60年甲子   │    │ 1元 = 60年（3×20）   │
        │ 三元 = 180年     │    │ 1运 = 20年           │
        │                  │    │ 九运 = 180年         │
        │ 用于：干支纪年   │    │ 用于：风水·飞星      │
        │       奇门大周期 │    │       择日·布局      │
        └──────────────────┘    └──────────────────────┘
                  ↑                        ↑
            "元"= 甲子周期           "元"= 飞星换届周期

为什么会混淆？ ​

因为两套体系的大周期恰好都是180年，
"上元·中元·下元"的叫法也完全相同，
但内部的最小单位不一样：

plain
干支体系：180年 ÷ 3元 = 60年/元（不再细分"运"）
飞星体系：180年 ÷ 9运 = 20年/运，3运 = 1元 = 60年

两套体系共用了同一个180年框架，
这不是巧合——古人认为180年是天地能量的一个完整轮回，
干支与飞星都以此为基准，只是切分方式不同。

一句话总结 ​

"20年一运"是飞星风水体系的小周期；
"60年一元"是两套体系共用的中周期；
"180年三元"是两套体系共用的大周期。

2025年处于下元九运（2024–2043），
是180年大周期的最后一运，
2044年起将重启新一轮上元一运。

8.3 周期思维的现代意义 ​

六十甲子揭示的核心思维：

世界不是线性的（不是一直向前），世界是周期性的（螺旋上升）

每个甲子年，不是简单的"重复"，而是在更高层次上的"回归"——

同样的天地能量组合，遇到不同的历史积累，产生不同的结果。

这就是为什么：历史会"押韵"，但不会"重复"。

参考马克·吐温的说法，与甲子周期思维高度吻合

九、现代解读：六十甲子本质上是什么？ ​

9.1 两个齿轮的咬合 ​

plain
想象两个齿轮：
  小齿轮：10个齿（天干）
  大齿轮：12个齿（地支）

两个齿轮同时转动：
  每转一格 = 一个干支组合
  转到两个齿轮同时回到起点 = 60格

六十甲子，就是这两个齿轮
咬合运转一圈的完整轨迹。

这个模型解释了为什么六十甲子如此稳定：

它不是人为规定的，是两套独立的天文周期，在数学上自然产生的最短公共轨道。

9.2 四维时间坐标系的完成 ​

plain
有了六十甲子，古人建立了一套
完整的四维时间坐标系：

年柱（干支）= 大背景，60年周期
月柱（干支）= 季节背景，12月周期
日柱（干支）= 当日能量，60天周期
时柱（干支）= 当时能量，12时辰周期

四柱叠加 = 任意一个时间点的完整能量描述

这就是"四柱八字"名称的来源：
  四柱 = 年·月·日·时
  八字 = 每柱一干一支，共八个字

9.3 与现代坐标系的对比：两种时间观 ​

甲子坐标不是"给时间贴标签"，而是"把时间纳入能量周期"——让不同世纪的同类时间节点，产生可比较、可参照的意义。

第一层：坐标形式的差异 ​

现代时间坐标——线性定位系统：

$ T_{现代} = \text{年} + \text{月} + \text{日} + \text{时} $

$ \text{例：} 2026年7月15日14时30分 $

回答的问题只有一个：你在时间轴上的哪个点？

六十甲子坐标——周期能量系统：

$ T_{甲子} = \text{年柱} \otimes \text{月柱} \otimes \text{日柱} \otimes \text{时柱} $

$ \text{例：丙午年} \cdot \text{壬午月} \cdot \text{庚申日} \cdot \text{甲申时} $

回答的问题有四个：

  • 这个时间点处于哪个能量周期？
  • 当下的天地气场是什么性质？
  • 与历史上哪些时间节点同频共振？
  • 这个时间容器里，藏着什么？

第二层：线性时间 vs 周期时间 ​

这是两种根本不同的时间哲学：

plain
线性时间观（现代）：

公元元年 ──────────────────────────────▶ 无限未来
         过去不可回，未来不可知
         每个时间点都是孤立的、一次性的

         公元1000年5月6日
         公元2000年5月6日
         ↑ 这两个日期，除了"都是5月6日"，
           没有任何内在联系可以挖掘。
plain
周期时间观（甲子）：

    ┌──────60年──────┐
    ↓                ↓
甲子年 → 乙丑年 → … → 癸亥年 → 甲子年（重启）
    ↑                           ↑
  相同的能量坐标，跨越世纪重现

  历史上所有的"丙午年"，
  共享同一个能量坐标，
  可以横向比较、相互参照。

第三层：丙午年——同一坐标的历史回响 ​

丙午，天干丙（阳火·太阳之火·文明之光），
地支午（阳火·帝旺·极盛转折）。

$ \text{丙午} = \text{阳火} \times \text{阳火} = \text{火势极盛，盛极必变} $

午为火之帝旺，丙为火之本气。
两火叠加，是能量最烈、张力最大、最容易出现剧烈转折的年份坐标。

历史上的丙午年，发生了什么？

历史上的丙午年参考事件
1966年文化大革命
1906年清廷宣布"预备立宪"，旧秩序开始松动；孙中山等人在广西发动镇南关起义
1126 年靖康之变前夕：金兵南下首次包围北宋都城开封。该年被宋代学者列为“赤马红羊劫”的开端，直接导致次年北宋的灭亡
公元 286 年**五胡乱华，**南北朝分裂
公元前195年**汉高祖刘邦驾崩，**次年（丁未年）爆发吕后之乱及诸吕掌权

这不是"算命"，也不是说丙午年"注定出大事"。
而是说：当天地能量处于"火势极盛"的坐标时，
**人类社会中积累的张力，更容易在这个节点释放。
就像干燥的夏天，一粒火星更容易引发大火——
不是火星"命中注定"，而是环境的能量状态提供了条件**。

第四层：甲子坐标的真正价值 ​

现代时间系统解决的是导航问题：

我在哪里？现在是几点？

甲子时间系统解决的是意义问题：

此刻的时间容器，装着什么性质的能量？
历史上与此同频的时刻，发生过什么？
我该如何在这个能量场中做出判断？

plain
公元2026年7月15日
→ 只告诉你：你在时间轴的第738,000+天

丙午年·壬午月·庚申日
→ 告诉你：
  · 年柱：丙午（火极盛，盛极转折）
  · 月柱：壬午（水火对冲，张力激烈）
  · 日柱：庚申（金气肃杀，决断之日）
  · 这个时间容器的能量性质是什么
  · 与哪些历史节点共享同一坐标
  · 适合什么，不适合什么

公元纪年是一把尺子，精确测量你在时间轴上的位置。
六十甲子是一张地图，告诉你此刻的地形、气候与历史上走过同一条路的人。

尺子告诉你"在哪里"，地图告诉你"这里是什么"。
两者不是竞争关系——现代人需要的，是同时持有两种工具。

十一、本章小结 ​

六十甲子，是天干与地支两套系统咬合运转的完整周期，是中华时间体系的最终形态。

三重价值：

  1. 📐 数学价值：10与12的最小公倍数，是两套天文周期自然产生的最短公共轨道，不是人为规定
  2. 📅 历法价值：同时承担纪年·纪月·纪日·纪时四个维度，是人类历史上最精简的多维时间编码系统
  3. 🔮 术数价值：四柱八字·奇门遁甲·六爻·大六壬，所有体系的时间操作，都建立在六十甲子之上

学六十甲子，有三个层次：

第一层：记住六十个干支的顺序和对应属性。
这是工具层，熟练即可。

第二层：理解空亡的逻辑——
天干走完，地支还剩两个，
这两个"被遗忘的地支"，就是这一旬的虚位。

第三层：理解周期思维——
六十年一甲子，不是重复，是螺旋。
同样的天地能量，遇到不同的人，不同的时代，
产生的，永远是新的故事。

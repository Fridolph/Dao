17 · 五行旺相休囚死：季节维度的能量坐标系 ​

文档版本： v1.0
建立时间： 2026年7月
所属体系： 通识基础知识库 · 第四阶段 · 能量状态系统
上承： 五行论（04）· 十二地支（12）· 二十四节气（14）· 十二长生（16）
下启： 四库辰戌丑未（后续）· 四害（后续）· 干支互动综合规则（后续）

一、体系定位 ​

1.1 它在知识树中的位置 ​

plain
五行论（04）
  └─ 五行能量是动态的
       ├─ 十二长生（16）← 精细版·以地支宫位为坐标·12个状态
       └─ 五行旺相休囚死（17）← 粗粒度版·以季节为坐标·5个状态

两者描述的是同一件事，只是分辨率不同：

plain
十二长生  = 高分辨率·逐月追踪·12个坐标点
旺相休囚死 = 低分辨率·按季归纳·5个状态词

先学十二长生，再看旺相休囚死，
会发现五个状态词不过是十二个状态的归并与提炼。
这不是两套系统，是同一套系统的两个观察尺度。

1.2 它解决什么问题 ​

十二长生精确，但使用成本高——
每次都要查表，确认具体天干在具体地支上的状态。

旺相休囚死，是一套快速判断工具：

plain
问题：现在是春天，木的能量状态怎么样？
答案：木旺。

问题：现在是春天，火的能量状态怎么样？
答案：火相。

问题：现在是春天，金的能量状态怎么样？
答案：金囚。

不需要查表，直接由季节推出五行状态。
这是古人在实际应用中最高频使用的能量判断工具。

1.3 根本认知前提 ​

⚠️ 与十二长生相同：旺相休囚死描述的是能量状态，不是吉凶评分。

旺，不等于好。死，不等于坏。
依然是：处境描述，不是价值判断。

上一篇（十六·十二长生）已经把这个认知前提讲透，本篇不再重复铺垫，直接进入。

二、原典依据 ​

2.1 核心文献 ​

【原典】《黄帝内经·素问·藏气法时论》
【原文】（节选）

肝主春……旺于春，春者木也；
心主夏……旺于夏，夏者火也；
脾主长夏……旺于长夏，长夏者土也；
肺主秋……旺于秋，秋者金也；
肾主冬……旺于冬，冬者水也。

【版本】通行本（唐·王冰注本为主要流传版本）
【特别说明】
《素问·藏气法时论》（王冰注本） 明确区分了"夏"（心主夏）与"长夏"（脾主长夏），长夏特指农历六月。但这是王冰的注释立场。更早的全元起本则主张"脾王四季"（寄旺四季末各18天），两说在《内经》传本内部并存，并非铁板一块。

术数体系（四柱、六爻等）实际沿用的是全元起本的"寄旺四季末"逻辑，而非王冰的"长夏=六月"说。

【原典】《淮南子·时则训》
【原文】（节选）

春，木也……木壮，火相，水休，金囚，土死。
夏，火也……火壮，土相，木休，水囚，金死。

【版本】西汉·刘安撰，约公元前139年
【说明】
《淮南子·时则训》是现存最早完整列出五行旺相休囚死对应关系的文献之一。
注意原文用"壮"而非"旺"——"壮"与"旺"在此语境下同义，均指当令最盛。后世统一称"旺"。

【原典】《礼记·月令》
【原文】（节选）

孟春之月……其日甲乙，其帝太皞，其神句芒，
其虫鳞，其音角，律中太簇，其数八，其味酸，其臭膻……

【版本】郑玄注本（东汉·郑玄，127-200年）
【说明】
《礼记·月令》以月为单位，详细记录了每月对应的五行、方位、颜色、声音、味道，
是五行与时间对应体系的重要文献基础。
旺相休囚死的季节对应，与《月令》的框架高度一致。

2.2 文献层级说明 ​

  • 《礼记·月令》（先秦-秦汉）五行与月令对应的原始框架
  • 《淮南子·时则训》（西汉·约前139年） 最早完整列出旺相休囚死对应关系
  • 《黄帝内经·素问》（成书约西汉，唐代定型）
    • 五行旺季的医学权威依据
    • 引入"长夏"概念，处理土的旺季问题
  • 《三命通会》（明·16世纪）术数体系中旺相休囚死的集大成应用

三、底层逻辑 ​

3.1 为什么是五个状态？ ​

五行有五种，季节有四个（春夏秋冬）。
每个季节，五种能量各处于不同的状态。
古人用五个词，精准描述这五种状态：

  • 旺 = 当令·本气正当其时·能量最充沛
  • 相 = 即将当令·受当令之气滋生·能量上升
  • 休 = 刚刚退令·生了当令之气·能量平稳退位
  • 囚 = 被当令之气所克·能量受制
  • 死 = 当令之气是我所克·能量泄散最重

五个词，对应五行相生克关系在季节上的五种处境。

3.2 五行相生克是推导的钥匙 ​

理解旺相休囚死，只需要记住两条链：

plain
相生链（顺时针）：木 → 火 → 土 → 金 → 水 → 木
相克链（隔位）：  木 → 土 → 水 → 火 → 金 → 木

以**春季（木当令）**为例，推导五行状态：

plain
木 = 旺（我当令）
火 = 相（木生火，我生者，即将得势）
水 = 休（水生木，生我者，已经退位）
土 = 囚（木克土，克我者？）

⚠️ 这里需要注意：
囚 = 被当令之气所克 → 木克土，土被克 → 土囚 ✓
死 = 当令之气是我所克 → 木克土，不是木克金
    → 金克木，木克土……

重新整理：
木旺（当令）
  → 木生火 → 火相
  → 水生木 → 水休（母气退位）
  → 木克土 → 土囚（被克）
  → 金克木 → 金死（克当令者，反被耗）

⚠️ 死的逻辑：
金在春季，金克木，
但木当令，金反而要消耗大量能量去"克"旺木，
克而不胜，能量大量耗散——故称"死"。

推导口诀（以当令之行为基准）：

plain
当令者    → 旺
当令所生  → 相（子气得势）
生当令者  → 休（母气退位）
当令所克  → 囚（被克受制）
克当令者  → 死（克而不胜，耗散最重）

记住这五条推导规则，
任何季节、任何五行的状态，
都可以当场推导，无需死记。

3.3 土的特殊性 ​

土居五行中央，不专属于任何一个季节。
这是整个旺相休囚死体系中唯一的特殊处理。

主流处理方式：土寄旺于四季末各十八天

plain
每个季节的最后18天，土气当令。
具体对应：
  春末（辰月末）→ 土旺
  夏末（未月末）→ 土旺
  秋末（戌月末）→ 土旺
  冬末（丑月末）→ 土旺

文献依据：
【原典】《黄帝内经·素问·太阴阳明论》
【原文】"脾者土也，治中央，
         常以四时长四藏，各十八日寄治，
         不得独主于时也。"
【版本】通行本

补充说明：长夏说

plain
《黄帝内经·素问·藏气法时论》另有"脾主长夏"之说，
将农历六月（未月）单独列为"长夏"，
作为土的专属旺季，使五行对应五季：
  春→木  夏→火  长夏→土  秋→金  冬→水

两种说法在《内经》内部并存，
前者（寄旺四季末）更符合术数体系的实际使用，
后者（长夏说）更多见于中医理论框架。
本文以前者为主线。

3.4 与十二长生的对应关系 ​

旺相休囚死，是十二长生的季节归并版本。
两套系统内在一致，可以相互印证：

plain
旺 ≈ 临官 + 帝旺
     （能量成熟输出·达到顶峰）

相 ≈ 长生 + 冠带
     （能量启动·成形·上升中）

休 ≈ 衰
     （能量平稳回落·仍有余力）

囚 ≈ 病 + 死
     （能量受制·停止输出）

死 ≈ 墓 + 绝
     （能量归藏·形态消散）

注：胎与养（孕育·蓄势阶段）在旺相休囚死中
通常归入"死"的范畴，或视为"死"向"相"过渡的内部状态。
这正是粗粒度模型的特点：
把十二个细节状态，归并为五个大类。

四、五个状态详解 ​

说明：以**春季（木当令）**为例贯穿说明，
其余季节以此类推，当令之行不同，逻辑结构相同。

① 旺 ​

plain
定义：
  当令之行。本气正当其时，能量最为充沛。

物候（春·木旺）：
  春风吹来，草木萌发，生机勃勃。
  木气当令，天地之间木的能量最为充沛。

能量特征：
  能量处于当季最高点。
  对外输出能力最强，影响力最大。
  是整个季节中该五行能量的主导状态。

处境本质：
  当令主导之象。
  旺，不是永恒的强，而是"此时此地的当令"。
  当令则旺，过季则退——
  旺的背后，已经埋下了"相→休→囚→死"的转化种子。

对应十二长生：临官·帝旺

② 相 ​

plain
定义：
  当令之行所生者。子气得当令之气滋养，能量上升。

物候（春·火相）：
  春天木旺，木生火，
  火气得木气滋养，正在积蓄，即将迎来夏季的当令。
  如同太子——尚未登基，但已在蓄势。

能量特征：
  能量处于上升通道，受当令之气滋生。
  不是最强，但是最有"势"——
  方向向上，后劲充足。

处境本质：
  蓄势待发之象。
  相，是下一个"旺"的准备阶段。
  此时做事，顺势而为，后劲足。

对应十二长生：长生·冠带

③ 休 ​

plain
定义：
  生当令之行者。母气已将能量传递给子气，功成身退。

物候（春·水休）：
  冬天水旺，水生木，木气得水气滋养而萌发。
  春天来临，木已当令，水的使命已经完成，
  进入平稳退位的状态。
  如同功成身退的母亲——能量仍在，但不再主导。

能量特征：
  能量平稳，不升不降，处于"退而不衰"的状态。
  仍有余力，但不再是主角。

处境本质：
  功成退位之象。
  休，不是衰竭，是有序的退场。
  《道德经》第九章：
  "功遂身退，天之道也。"
  水在春季的"休"，正是这句话的能量模型版本。

对应十二长生：衰

④ 囚 ​

plain
定义：
  当令之行所克者。被当令之气压制，能量受制。

物候（春·土囚）：
  春天木旺，木克土，
  土气被旺木压制，能量受到明显约束。
  如同被关押——不是消失，而是被限制了自由。

能量特征：
  能量受制，对外输出受阻。
  不是没有能量，而是能量被压住了，
  难以自由发挥。

处境本质：
  受制待时之象。
  囚，是暂时的受制，不是永久的消亡。
  当令之行退去，囚者自然解脱。
  此时最忌强行突破，宜守待时。

对应十二长生：病·死

⑤ 死 ​

plain
定义：
  克当令之行者。以弱克强，能量大量耗散。

物候（春·金死）：
  春天木旺，金克木，
  金气试图克制旺木，但木气正盛，
  金克而不胜，反而大量消耗自身能量。
  如同以卵击石——不是不战，而是战而大损。

能量特征：
  能量处于最低点，大量耗散。
  不是静止（那是"囚"），
  而是在消耗中不断流失。

处境本质：
  耗散归零之象。
  "死"在此不是终结，而是能量耗散至极、
  即将进入归藏与孕育阶段的前奏。
  与十二长生中的"死"一样：
  归零，是为了重新出发。

⚠️ 注：
  旺相休囚死中的"死"，
  与十二长生中的"死"含义略有不同：
  十二长生的"死" = 能量静止归零
  旺相休囚死的"死" = 能量耗散至极（包含墓·绝的归藏状态）
  是粗粒度归并的结果，不必强行对齐。

对应十二长生：墓·绝（含胎·养的孕育状态）

五、完整对应表 ​

5.1 四季五行旺相休囚死表 ​

plain
季节  当令   木    火    土    金    水
──────────────────────────────────────
春    木    旺    相    囚    死    休
夏    火    休    旺    相    囚    死
秋    金    囚    死    休    旺    相
冬    水    相    囚    死    休    旺
──────────────────────────────────────
四季末 土   休    囚    旺    死    相
（辰戌丑未各18天）
──────────────────────────────────────

⚠️ 土行单独列出"四季末"一行，体现"土寄旺四季末"的处理方式。
在不涉及土的判断时，通常只用上面四行。

5.2 如何读这张表 ​

读法一：已知季节，判断五行状态

plain
现在是夏季 → 查"夏"行
→ 火旺·土相·木休·水囚·金死

含义：
夏季做事，火行能量最强（旺），
土行能量上升（相），
木行能量平稳退位（休），
水行能量受制（囚），
金行能量耗散（死）。

读法二：已知五行，判断最佳时机

plain
我想在金行能量最强的时候行事
→ 查"金=旺"对应的季节 → 秋季

金行能量最弱（死）的季节 → 夏季

读法三：推导口诀验证

plain
任意季节，当场推导，无需查表：

确定当令之行
  ↓
当令 = 旺
当令所生 = 相
生当令者 = 休
当令所克 = 囚
克当令者 = 死

5.3 月份精细版（十二地支对应） ​

旺相休囚死以季节为单位，
若需精细到月份，对应关系如下：

plain
寅卯辰月（春）= 木旺·火相·水休·土囚·金死
巳午未月（夏）= 火旺·土相·木休·水囚·金死
申酉戌月（秋）= 金旺·水相·土休·木囚·火死
亥子丑月（冬）= 水旺·木相·金休·火囚·土死

辰戌丑未月末各18天 = 土旺（寄旺）

注：月份精细版中，辰月（春末）、未月（夏末）、戌月（秋末）、丑月（冬末）的后18天，土气当令，其余四行状态随之调整。
这是"土寄旺四季末"在月份层面的落地。

六、核心争议如实呈现 ​

6.1 争议：囚与死的顺序 ​

这是旺相休囚死体系中最主要的文献分歧。

《淮南子·时则训》顺序：旺→相→休→死→囚

plain
原文（春季）：
"木壮，火相，水休，金囚，土死。"

⚠️ 注意：《淮南子》原文中，
土在春季为"死"，金为"囚"——
与后世主流顺序（土囚·金死）相反。

《淮南子》的逻辑：
金克木，金在春季克旺木，耗散最重 → 金死
木克土，土被旺木所克，受制 → 土囚

这与后世主流逻辑一致，
但"囚"与"死"的标签贴反了。

后世主流顺序：旺→相→休→囚→死

plain
《三命通会》及后世命理主流：
春季：木旺·火相·水休·土囚·金死

逻辑：
木克土 → 土被克 → 土囚
金克木 → 金克旺木，耗散最重 → 金死

两者的五行对应完全一致，
只是"囚"与"死"两个词的定义略有不同：
主流定义：囚=被克，死=克当令者耗散
淮南子：囚=克当令者，死=被克

本文立场：

采用后世主流顺序（旺相休囚死），以《三命通会》为准。
《淮南子》的差异属于术语定义层面的分歧，五行状态的实质内容两者完全一致。理解逻辑比记住顺序更重要。

6.2 争议：土的旺季 ​

详见第三章3.3节，此处简要总结：

plain
主流（术数体系）：土寄旺四季末各18天
  → 依据：《黄帝内经·素问·太阴阳明论》
  → 土无专属旺季，分布于四季交接处

补充（中医理论）：土旺于长夏（农历六月）
  → 依据：《黄帝内经·素问·藏气法时论》
  → 给土一个独立的旺季，使五行对应五季

两说在《内经》内部并存，
术数应用以前者为主，中医理论以后者为框架。

七、跨体系接口（通识层） ​

旺相休囚死是各体系共用的能量判断底层工具。
以下为各体系的调用方式，通识层说明，不展开细节。

四柱八字

plain
调用方式：
  以日主五行为基准，
  判断日主在出生月份（月令）的旺相休囚死状态，
  是判断"身强身弱"的第一步。

举例：
  日主甲木，生于寅月（春）→ 木旺 → 身强
  日主甲木，生于午月（夏）→ 木休 → 身中
  日主甲木，生于申月（秋）→ 木囚 → 身弱

奇门遁甲

plain
调用方式：
  判断宫位五行在当前节气下的旺相休囚死，
  辅助判断该宫位能量的强弱与行事的时机。

举例：
  震宫（木）在春季 → 木旺 → 震宫能量最强
  震宫（木）在秋季 → 木囚 → 震宫能量受制

六爻

plain
调用方式：
  爻所代表的五行，在月建（当月地支）下的旺相休囚死，
  判断该爻的能量强弱，影响爻的动静与应期。

举例：
  木爻在寅卯月 → 木旺 → 爻有力，应事较快
  木爻在申酉月 → 木囚 → 爻无力，需冲动方显

中医（五运六气）

plain
调用方式：
  五脏对应五行，五行随季节旺相休囚死，
  对应五脏在不同季节的能量盛衰，
  是中医"因时制宜"的理论基础。

举例：
  春季木旺 → 肝气旺盛 → 春季养肝为要
  秋季金旺 → 肺气旺盛 → 秋季养肺为要
  （五运六气专篇将详细展开）

通识层核心结论：

无论哪个体系，调用旺相休囚死的逻辑一致：
确定主体五行 → 确定当前季节/月令 → 查表或推导状态 → 判断能量处境
五个状态词，是各体系共用的能量语言。

八、现代解读 ​

8.1 它本质上是一套"时机判断框架" ​

旺相休囚死，用现代语言来说，
是一套关于**"什么时候做什么事最顺势"**的判断框架。

plain
旺 → 全力输出·主动进攻·扩张
     此时能量最充沛，做当令之事事半功倍

相 → 积极布局·蓄势·准备
     能量上升中，此时投入，后劲足

休 → 平稳守成·总结·传承
     能量退位，不宜大动，适合整理与交棒

囚 → 减少暴露·守待·不强出头
     能量受制，强行突破只会加大消耗

死 → 深度休整·归零·等待转机
     能量耗散至极，此时最需要的是停下来

这个框架，与现代商业中的"顺势而为"思维高度一致：

plain
风口期（旺）= 全力冲刺，能量最充沛
上升期（相）= 积极布局，顺势积累
平台期（休）= 守成优化，不盲目扩张
逆风期（囚）= 降低损耗，等待时机
低谷期（死）= 深度调整，蓄力重启

8.2 "顺势"不是"躺平" ​

一个常见的误读：

"囚死阶段，什么都不能做。"

这是错误的。旺相休囚死描述的是能量处境，不是行动指令。

plain
囚死阶段，不是什么都不做，
而是：做符合这个处境的事。

囚 → 受制·守·减少消耗 → 适合：内部整理·深度学习·保存核心
死 → 耗散·归零 → 适合：彻底放下·重新审视·孕育新方向

就像冬天的树：
地面上枯萎了（死），但根系在地下悄然积蓄（胎·养）。
冬天的树不是"什么都没做"，它在做冬天该做的事。

8.3 与经典的哲学呼应 ​

旺相休囚死，表面上是一张能量状态表，
骨子里是一套循环宇宙观。
这套宇宙观，在先秦经典中有两处最精准的表达。

【原典】《道德经》第四十章
【原文】

反者道之动。弱者道之用。
天下万物生于有，有生于无。

【版本】王弼注本（魏·王弼，226–249年）
【王弼注】"反者道之动——高以下为基，贵以贱为本，有以无为用，此其反也。"

"反者道之动"，是说：道的运动方式，是循环往复、返回本源。

对照旺相休囚死：

plain
旺 → 相 → 休 → 囚 → 死 → （返回旺）

这不是一条直线，而是一个圆。
死，不是终点，是返回的起点。
"反者道之动"——死而复旺，正是"反"的运动。

旺相休囚死的五个状态，本来就是一个循环结构，
而道德经四十章说的，正是这种循环往复就是道的运动方式。

【原典】《周易·系辞上》
【原文】

一阴一阳之谓道。
继之者善也，成之者性也。

"一阴一阳之谓道"，说的是：阴与阳的交替消长，就是道的本质。

生生之谓易。

"生生之谓易"，说的是：不断地生发、不断地更新，就是易的本质。

对照旺相休囚死：

plain
春木旺 → 夏火旺 → 秋金旺 → 冬水旺 → 春木旺……

这正是"一阴一阳"的消长节律在五行上的展开：
没有哪个五行永远当令，
没有哪个五行永远受制，
旺与死，只是同一个循环里的不同位置。

"生生之谓易"——
死而复旺，就是"生生"，
旺相休囚死的循环，就是易的运动。

两处引用的共同指向

plain
《道德经》第四十章：反者道之动
  → 循环往复是道的运动方式
  → 旺相休囚死是一个圆，不是一条线

《易经·系辞上》：一阴一阳之谓道 / 生生之谓易
  → 消长交替是道的本质
  → 五行轮流当令，生生不息

两者共同指向同一个认知：
  旺，不是永恒的强；
  死，不是最终的终结。
  它们只是循环中的两个坐标点。
  理解了这个循环，才真正理解了旺相休囚死。

九、全文总结与承前启后 ​

9.1 一句话定义 ​

**五行旺相休囚死，是以季节为坐标，用五个状态词描述五行能量盛衰处境的粗粒度判断工具。
**它是十二长生的季节归并版，是各术数体系最高频使用的能量语言。

9.2 三个核心认知 ​

认知一：五个状态可以当场推导，无需死记

plain
记住推导口诀：
当令 = 旺 / 当令所生 = 相 / 生当令者 = 休
当令所克 = 囚 / 克当令者 = 死
任何季节·任何五行，当场推出，不需要查表。

认知二：旺相休囚死与十二长生是同一件事的两个尺度

plain
十二长生 = 高分辨率·逐月追踪
旺相休囚死 = 低分辨率·按季归纳
两者不矛盾，互为补充。
精细判断用十二长生，快速判断用旺相休囚死。

认知三：状态描述处境，不是行动禁令

plain
旺 ≠ 必须冲刺
死 ≠ 什么都不能做
每个状态，都有它适合做的事。
顺势而为，不是躺平，是选择与当下处境最匹配的行动。

9.3 学完这篇，你应该能回答 ​

plain
① 旺相休囚死怎么推导？不用查表能推出来吗？
  → 能。记住五条推导规则，任何季节当场推导。

② 旺相休囚死和十二长生有什么关系？
  → 同一件事的不同分辨率。
    旺≈临官帝旺，相≈长生冠带，休≈衰，
    囚≈病死，死≈墓绝。

③ 土的旺季在哪里？
  → 主流：寄旺于四季末各18天（辰戌丑未月末）。
    中医另有"长夏说"，两说并存，各有侧重。

④ 囚和死哪个更严重？
  → 不是"严重"的问题，是两种不同的受制方式：
    囚 = 被当令之气压制，能量受限但稳定；
    死 = 以弱克强，能量在消耗中耗散。
    两者都是能量不利的处境，处境不同，应对方式不同。

⑤ 《淮南子》和后世主流的顺序为什么不一样？
  → 术语定义层面的分歧，五行状态的实质内容完全一致。
    后世统一采用"旺相休囚死"顺序，以《三命通会》为准。

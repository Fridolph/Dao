07 · 后天八卦：宇宙的运行地图 ​

版本与引用说明 ​

"后天八卦"与"先天八卦"一样，命名本身不见于先秦文献。
"后天"之名，同样由北宋邵雍正式提出，图式亦经朱熹《周易本义》（1177年）定型。

但后天八卦所依据的核心原文，来自《周易·说卦传》第五章——
这是目前可考的最早、最直接的文献依据。

本篇同样严格区分：

  • 《说卦传》原文（先秦）
  • 邵雍的"后天学"命名（北宋）
  • 朱熹的图式定型（南宋）
  • 后世术数应用（风水、奇门、中医等）

一、先说位置：先天之后，后天接上 ​

plain
道
 └─ 阴阳
      └─ 四象
           └─ 八卦
                ├─ 先天八卦（体）← 上一篇
                │    = 本质关系，对称结构，静态
                └─ 后天八卦（用）← 我们在这里
                     = 时空流行，运动规律，动态

如果说先天八卦是宇宙的基因图谱（本质是什么），
那后天八卦就是宇宙的运行地图（如何在时空中展开）。

两者的关系，用邵雍的话说：

【原典】邵雍《观物外篇》，北宋，约1060年代
【原文】先天之学，心也；后天之学，迹也。

plain
先天 = 心 = 内在本质，不可见
后天 = 迹 = 外在轨迹，可以观察、可以应用

二、原典依据：《说卦传》第五章 ​

【原典】《周易·说卦传》第五章
【时代】西周至春秋，孔子《十翼》之一
【原文】帝出乎震，齐乎巽，相见乎离，致役乎坤，说言乎兑，战乎乾，劳乎坎，成言乎艮。

这是后天八卦最核心的原典。逐句拆解：

plain
"帝出乎震"
  帝（万物生机）从震（东方·春雷）出发。
  = 春天，雷声初动，万物萌发，生命开始。
  = 后天八卦的起点：震居正东。

"齐乎巽"
  万物在巽（东南·风）中整齐生长。
  = 春末夏初，万物蓬勃，欣欣向荣。
  = 巽居东南。

"相见乎离"
  万物在离（南方·火·日）中彼此显现。
  = 夏天，日照最强，万物盛极，光明灿烂。
  = 离居正南。

"致役乎坤"
  万物在坤（西南·地）中劳作服务。
  = 夏末秋初，大地承载万物，收获在即。
  = 坤居西南。

"说言乎兑"
  万物在兑（西方·泽·秋）中喜悦。
  = 秋天，收获丰盈，万物成熟，喜悦之时。
  = 兑居正西。

"战乎乾"
  阴阳在乾（西北）中交战。
  = 秋末冬初，阴气渐盛，阳气退守，
    阴阳在此激烈交替。
  = 乾居西北。

"劳乎坎"
  万物在坎（北方·水·冬）中劳苦潜藏。
  = 冬天，万物蛰伏，生命潜藏，
    是最艰难、最沉寂的时刻。
  = 坎居正北。

"成言乎艮"
  万物在艮（东北·山）中终结与开始。
  = 冬末春初，旧的一年终结，新的一年孕育。
  = 艮居东北。艮，终也，始也。

⚠️ 重要说明：《说卦传》第五章描述的是时间流行的过程，
是一个完整的年度循环。将其对应为空间方位图，
是后世易学家（尤其是邵雍）的诠释工作。
原文本身，首先是一个时间叙事，其次才是方位对应。

三、"文王八卦"之名的考辨 ​

后天八卦又常被称为"文王八卦"。这个名称，需要辨析。

plain
通行说法：后天八卦为周文王所作。

考据现状：
  此说最早见于宋代文献，先秦及汉代文献
  均无"文王作后天八卦"的明确记载。
  
  《说卦传》第五章本身，也没有说"此为文王所作"。
  
  朱伯崑《易学哲学史》（北京大学出版社，1986年）指出：
  "文王八卦"之名，是宋代易学家为区分先后天
  而追加的命名，其历史归属尚无确凿文献支撑。

本篇的处理原则：

使用"后天八卦"这一中性名称，不采用"文王八卦"的表述，以免引入未经证实的历史归属。

四、后天八卦图：方位与结构 ​

📌 【后天八卦方位图预留位置】
圆形排布：上离（南）下坎（北），左震（东）右兑（西）

标准方位（上南下北，面南而立） ​

plain
              离（☲）南·上
    巽（☴）东南          坤（☷）西南
    震（☳）东                      兑（☱）西
    艮（☶）东北          乾（☰）西北
              坎（☵）北·下

⚠️ 同样是上南下北的面南视角，与先天八卦一致。
但方位排布完全不同——这是最容易混淆的地方。

先天 vs 后天：方位对比 ​

plain
卦名    先天方位    后天方位
─────────────────────────
乾      南          西北
坤      北          西南
离      东          南
坎      西          北
震      东北        东
巽      西南        东南
兑      东南        西
艮      西北        东北

除了震（东北→东）、艮（西北→东北）、巽（西南→东南）、兑（东南→西）之外，乾坤坎离四正卦的方位全部改变。
先天乾南，后天乾西北；先天坎西，后天坎北——这不是笔误，是两套体系本来就不同。

五、后天八卦与五行、四时的完整对应 ​

这是后天八卦最重要的应用基础。

卦名符号方位五行四时节气区间九宫数
震☳正东木春春分前后3
巽☴东南木春末立夏前后4
离☲正南火夏夏至前后9
坤☷西南土长夏立秋前后2
兑☱正西金秋秋分前后7
乾☰西北金秋末立冬前后6
坎☵正北水冬冬至前后1
艮☶东北土冬末立春前后8
（中）—中央土——5

【原典依据】

  • 方位与四时：《周易·说卦传》第五章
  • 五行对应：《礼记·月令》、《黄帝内经·素问·阴阳应象大论》
  • 九宫数：《黄帝内经·灵枢·九宫八风》（战国至西汉）

六、九宫数：洛书与后天八卦的叠合 ​

后天八卦的方位，与洛书九宫数完全对应：

plain
        4  9  2
        3  5  7
        8  1  6

对应方位（上南下北）：

        巽4  离9  坤2
        震3  中5  兑7
        艮8  坎1  乾6

【原典】《黄帝内经·灵枢·九宫八风》
【原文】"太一常以冬至之日，居叶蛰之宫四十六日……"
（九宫方位与八卦、八风的对应，此篇有完整描述）

洛书幻方验证：

plain
任意一行、一列、对角线之和 = 15

  4+9+2 = 15  ✓
  3+5+7 = 15  ✓
  8+1+6 = 15  ✓
  4+3+8 = 15  ✓
  9+5+1 = 15  ✓
  2+7+6 = 15  ✓
  4+5+6 = 15  ✓（对角）
  2+5+8 = 15  ✓（对角）

后天八卦 + 洛书九宫 = 一套完整的时空坐标系。
这个叠合，是后世风水、奇门遁甲、紫微斗数等术数体系的共同数理基础。

七、后天八卦的运动规律：顺时针流行 ​

先天八卦是对称的、静态的；
后天八卦是流动的、循环的。

plain
后天八卦的运行方向：顺时针

震（东·春）
  → 巽（东南·春末）
    → 离（南·夏）
      → 坤（西南·长夏）
        → 兑（西·秋）
          → 乾（西北·秋末）
            → 坎（北·冬）
              → 艮（东北·冬末）
                → 震（东·春）……

= 一个完整的年度循环，周而复始。

这个循环，对应的是：

plain
阳气：冬至（坎·北）开始生发
      → 春分（震·东）阳气旺盛
      → 夏至（离·南）阳气极盛
      → 秋分（兑·西）阳气收敛
      → 冬至（坎·北）阳气潜藏

= 一年四季，阴阳消长的完整轨迹。

八、先天与后天的核心差异 ​

这是理解两套体系最关键的一步。

plain
先天八卦                    后天八卦
────────────────────────────────────────────
体                          用
本质关系                    时空流行
对称结构                    循环运动
静态                        动态
乾南·坤北（天地定位）       离南·坎北（日月运行）
《说卦传》第三章            《说卦传》第五章
宇宙"是什么"               宇宙"怎么动"

一个关键的哲学转换：

plain
先天：乾（天）在南，坤（地）在北
      = 天在上，地在下，这是本体的位置

后天：离（火·日）在南，坎（水·月）在北
      = 太阳在南方最高处，水在北方潜藏
      = 这是现象界的实际运行

先天讲的是"天地"，后天讲的是"日月"。
天地是本体，日月是现象。体用之别，在此最为清晰。

朱伯崑《易学哲学史》（北京大学出版社，1986年）指出：
先天后天之分，是宋代易学最重要的理论建构之一，
其核心是将《易》的体用关系系统化，
为后世象数易学提供了完整的理论框架。

九、后天八卦的三大应用领域 ​

后天八卦之所以比先天八卦更常见于日常应用，
原因很简单：它是动态的，可以对应时间和空间的变化。

① 中医：脏腑与方位

【原典】《黄帝内经·素问·阴阳应象大论》

  • 东方·木·肝
  • 南方·火·心
  • 中央·土·脾
  • 西方·金·肺
  • 北方·水·肾
plain
后天八卦方位 + 五行 = 中医五脏定位的空间依据

  震·巽（东·东南）= 木 = 肝·胆
  离（南）         = 火 = 心·小肠
  坤·艮（西南·东北）= 土 = 脾·胃
  兑·乾（西·西北） = 金 = 肺·大肠
  坎（北）         = 水 = 肾·膀胱

② 风水：九宫飞星的起点

plain
后天八卦九宫方位，是玄空风水"飞星盘"的静盘基础。
一白坎·二黑坤·三碧震·四绿巽·
五黄中·六白乾·七赤兑·八白艮·九紫离

（九星颜色为星宿本命色，非五行本色——
 详见上一篇"九星颜色体系"的辨析）

③ 奇门遁甲：时空推演的坐标

plain
奇门遁甲以后天八卦九宫为基础坐标，
将时间（时辰·日·月·年）与空间（九宫方位）
叠合推演，是古代最复杂的时空推算体系之一。

十、一个常见误区的澄清 ​

误区：先天八卦和后天八卦，哪个"更正确"？

plain
这个问题，本身就问错了。

先天八卦 = 描述本质关系的工具
后天八卦 = 描述时空运行的工具

就像问"地图和地球仪，哪个更正确？"——
两者描述的是不同维度的信息，
不存在谁取代谁的问题。

正确的用法：
  谈宇宙的本质结构 → 用先天八卦
  谈时间、方位、运动 → 用后天八卦
  谈中医、风水、奇门 → 用后天八卦
  两者混用 → 错误

十一、本章小结 ​

后天八卦，说了一件事：

宇宙在时空中，是一个周而复始的循环。

plain
① 有起点，有终点，终点即起点
   震（春·东）出发，艮（冬末·东北）终结，
   终结之后，又回到震——
   这不是直线，是圆。

② 每个位置，都有其时间含义
   不只是空间方位，更是时间节点。
   后天八卦，是把时间画在了空间里。

③ 阴阳消长，有迹可循
   从坎（冬·水·阳气最弱）到离（夏·火·阳气最盛），
   再从离回到坎——
   这个循环，是可以观察、可以推算、可以应用的。

最后说一句实在话：

先天八卦告诉你宇宙的结构，后天八卦告诉你宇宙的节奏。

结构是不变的，节奏是流动的。两张图合在一起，才是完整的宇宙观。

帝出乎震——每一年的春天，雷声第一次响起的那一刻，都是这个循环重新开始的证明。

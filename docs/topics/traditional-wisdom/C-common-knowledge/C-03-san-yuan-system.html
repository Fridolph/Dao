C-03 · 三垣体系：古代星空的中枢坐标 ​

系列： 中华传统智慧体系 · 通识基础知识库 · 文化通识篇（C系列）· 天文宇宙组
版本： v1.0（2026年8月）
前置篇目（必读）： 09·二十八星宿 / C-02·北斗七星与斗建
后续篇目： C-04·十二建除 / Shu·紫微斗数

写在前面：为什么要学三垣？ ​

中国古代的星空，不是一片混沌。

先人将整个可见天空，划分为一套极其精密的坐标体系：
三垣 + 二十八宿，合称"三垣二十八宿体系"，
是中国古代天文学的核心架构，
也是读懂古籍星象记载、理解术数体系的基础地图。

不懂三垣：

  • 读《史记·天官书》《晋书·天文志》，遇到"紫微""太微""天市"一头雾水
  • 学紫微斗数，不知道"紫微"二字从何而来
  • 读古典小说，"天庭""帝座""朝廷星官"等意象无从理解

本篇目标：
还原三垣体系的完整结构，厘清三垣各自的天文位置、所含星官、文化象征，以及三垣与北斗、二十八宿、术数体系的接口关系。

一、俯瞰：三垣在整个体系里的位置 ​

plain
古代天文坐标体系
  ├─ 三垣（中央天区）← 本篇核心
  │    ├─ 紫微垣（北天极周围·天帝居所）
  │    ├─ 太微垣（黄道北·天子朝廷）
  │    └─ 天市垣（黄道南·天下市集）
  │
  └─ 二十八宿（黄道带·四象各七宿）← 主干09
       ├─ 东方青龙七宿
       ├─ 南方朱雀七宿
       ├─ 西方白虎七宿
       └─ 北方玄武七宿

三垣 + 二十八宿 = 古代全天星空坐标系

"垣"字的本义：
垣，城墙也。三垣，即天空中三座"有围墙的城池"——每座垣由两列星官构成"左右垣墙"，围合出一片天区，如同天上的宫城。

二、三垣体系的历史沿革 ​

【原典】《晋书·天文志》
【原文】"紫宫垣十五星，西藩七，东藩八……太微，天子庭也……天市垣二十二星，东藩十一，西藩十一……"
【版本】唐·房玄龄等撰，二十四史标准本

三垣体系的定型，以《晋书·天文志》为标志。但其思想渊源，可上溯至先秦：

时代发展阶段代表文献
先秦北极星区"紫宫"概念萌芽《楚辞》《诗经》零散记载
西汉五宫体系（中官+四方）初步建立《史记·天官书》
魏晋三垣概念基本成型，星官系统化《晋书·天文志》
隋唐三垣二十八宿体系完全定型《步天歌》（丹元子）
宋代全面整理，星数精确统计《宋史·天文志》

【原典】《步天歌》
【原文】紫微垣内细分明，太微垣中帝座清，天市垣里星官聚，三垣分列布天庭。
【版本】唐·丹元子撰（约7世纪），中国古代最重要的认星口诀

《步天歌》是古代天文学的入门教材，以七言诗的形式，将全天星官逐一记录，三垣二十八宿体系由此得到最广泛的普及与传播。

三、紫微垣 · 天帝居所 ​

3.1 天文位置 ​

紫微垣，位于北天极周围，是三垣中最核心、最尊贵的天区。

plain
位置：北天极（北极星）周围
特点：拱极星区，常年可见，永不落于地平线以下
范围：大致对应现代星座中的小熊座、大熊座、天龙座、仙王座、仙后座等

【原典】《史记·天官书》
【原文】"中宫天极星，其一明者，太一常居也；旁三星三公，或曰子属。后句四星，末大星正妃，余三星后宫之属也。环之匡卫十二星，藩臣，皆曰紫宫。"
【版本】西汉·司马迁撰

司马迁在《天官书》中以"紫宫"描述北极星周围的天区，
这是紫微垣最早的系统性文字记载。
"太一常居"——北极星是天帝（太一）的居所，
周围的星官，是天帝的宫廷与臣属。

3.2 垣墙结构 ​

紫微垣由左垣（东藩）和右垣（西藩）两列星官构成围墙：

垣墙星数主要星官
右垣（西藩）7星右枢·上宰·少宰·上弼·少弼·上卫·少卫
左垣（东藩）8星左枢·上丞·少丞·上辅·少辅·上卫·少卫·天乙

垣墙之内，核心星官包括：

星官名含义说明
北极五星天帝与皇室含太子、帝、庶子、后宫、天枢
勾陈六星天子护卫勾陈一即北极星（现代）
北斗七星帝车北斗属紫微垣，是垣内最重要的星官
天一·太一天帝本座最尊贵的星位
华盖七星天子仪仗华盖·杠九星，帝王出行之象

⚠️ 北斗与紫微垣的关系：
北斗七星隶属紫微垣，是垣内地位最高的星官之一。
《史记》称北斗为"帝车"——天帝乘坐北斗巡行天下，北斗居于紫微垣内，正是"帝车停于宫中"的天文象征。

3.3 文化象征 ​

紫微垣的核心象征：天帝的宫城，宇宙的中心。

plain
紫微垣 → 天帝居所
  ↓ 人间对应
皇宫（紫禁城）← "紫"字来源于紫微垣
             ← "禁"字意为禁地，对应天帝宫城不可侵犯

北京故宫之所以称"紫禁城"，正是取"紫微垣"之"紫"与"禁地"之意——人间皇宫，是天上紫微垣的对应与投影。
这是中国古代"天人合一"宇宙观最直观的建筑体现。

四、太微垣 · 天子朝廷 ​

4.1 天文位置 ​

太微垣，位于紫微垣之南，黄道以北，是三垣中象征"朝廷政务"的天区。

plain
位置：室女座、狮子座、后发座一带
特点：黄道北侧，季节性可见
范围：大致对应现代星座中的室女座、狮子座、后发座等

【原典】《晋书·天文志》
【原文】太微，天子庭也，五帝之坐也，十二诸侯府也。其外藩，九卿也。
【版本】唐·房玄龄等撰，二十四史标准本

这段话极为精炼地道出了太微垣的政治象征：
天子朝廷、五帝之座、诸侯府邸、九卿官署——太微垣，是天上的"中央政府"。

4.2 垣墙结构 ​

太微垣同样由左右垣墙围合：

垣墙星数主要星官
右垣（西藩）5星右执法·西上将·西次将·西次相·西上相
左垣（东藩）5星左执法·东上将·东次将·东次相·东上相

垣内核心星官：

星官名含义说明
五帝座五方天帝之位太微垣最核心的星官
太子·从官储君与侍从皇室成员对应
三公·九卿朝廷百官人间官制的天上对应
郎位·常陈宫廷侍卫护卫天子之星
谒者·三台礼官·台阁朝廷礼制星官

4.3 文化象征 ​

太微垣的核心象征：天子的朝廷，政令的发布中心。

古代占星中，太微垣的星象变化，直接对应人间朝廷的政治动向——
某星明亮，对应某官位兴旺；某星暗淡或有异常，则预示对应官位的变动。

这是古代"星占政治学"的核心运作区域。

五、天市垣 · 天下市集 ​

5.1 天文位置 ​

天市垣，位于黄道东南方向，是三垣中象征"民间经济"的天区。

plain
位置：武仙座、巨蛇座、蛇夫座、天鹰座一带
特点：夏秋季节最为显著
范围：大致对应现代星座中的武仙座、蛇夫座、巨蛇座等

【原典】《晋书·天文志》
【原文】天市垣二十二星，东藩十一星，西藩十一星……天市，天子率诸侯幸都市也。
【版本】唐·房玄龄等撰，二十四史标准本

"天子率诸侯幸都市"——天市垣象征天子巡视市场，是天上的"经济中心"。

5.2 垣墙结构 ​

天市垣的垣墙最为特殊：
左右垣墙各11星，共22星，且每颗垣星均以诸侯国名命名：

垣墙星名（部分）
东藩（左垣）11星宋·南海·燕·东海·徐·吴越·齐·中山·九河·赵·魏
西藩（右垣）11星韩·楚·梁·巴·蜀·秦·周·郑·晋·河间·河中

这是三垣中最具政治地理意味的设计——
天上的市场，由天下诸侯共同围合而成。

垣内核心星官：

星官名含义说明
帝座天帝临市之座天市垣中心最亮星
候·宦者市场监察官管理市场秩序
市楼市场管理机构六星，主市场度量
车肆·列肆商铺摊位天上的商业区
斗·斛度量衡器具主公平交易

5.3 文化象征 ​

天市垣的核心象征：天下的经济命脉，民间的生产与贸易。

三垣的政治结构，构成了一个完整的天上社会：

plain
紫微垣 → 天帝宫城（皇权核心）
太微垣 → 天子朝廷（政务中枢）
天市垣 → 天下市集（经济民生）

三垣合一 → 完整的天上"国家结构"

六、三垣与二十八宿的关系 ​

三垣与二十八宿，是古代天文坐标系的两套互补系统：

维度三垣二十八宿
位置中央天区（以北极为核心）黄道带（环绕黄道一周）
功能定星官等级·政治象征定日月五星位置·历法基准
结构三个有围墙的天区四象各七宿，共28宿
核心用途星占·政治预兆历法·节气·方位
与太岁关系太岁方位参照三垣方位体系岁星（木星）以二十八宿定位

【原典】《隋书·天文志》
【原文】垣、宿、星官者，星之集也。为辨诸星，全天分为东南西北中五宫，中宫下分三垣，余者各分七宿，垣、宿又分星官若干。
【版本】唐·魏征等撰，二十四史标准本

这段话是对三垣二十八宿体系最简洁的官方定义：
全天分五宫，中宫含三垣，四方各含七宿，垣与宿之下，再细分为具体的星官。

七、三垣在术数体系中的应用 ​

7.1 紫微斗数 ​

紫微斗数的命名，直接来源于紫微垣：

"紫微"二字，取自紫微垣——天帝居所，宇宙中心。
紫微斗数以"紫微星"为命盘主星，象征命主在人生格局中的核心地位，如同紫微垣之于整个天空。

紫微斗数中的星曜命名，大量来自三垣星官：

  • 紫微星（紫微垣·帝座）
  • 太微星系（太微垣·五帝座）
  • 天府星（天市垣·帝座）

7.2 奇门遁甲 ​

奇门遁甲的九宫布局，以紫微垣为"中宫"的象征来源：
中宫居中不动（如天禽星），对应紫微垣"居中央，临制四方"的宇宙结构。

7.3 风水与方位 ​

风水中"坐北朝南"的核心原则，
与紫微垣居北天极、面向南方的天文格局直接对应——
天帝居北，朝向南方，
人间皇宫（紫禁城）亦坐北朝南，
是天文格局在地理空间上的投影。

7.4 古典文学中的三垣意象 ​

意象来源常见场景
"紫微""紫宫"紫微垣指代天帝居所、皇权核心
"太微""天庭"太微垣指代天上朝廷、神仙议政之所
"天市"天市垣指代天上的市集、民间繁荣
"紫禁城"紫微垣人间皇宫以天上宫城命名
"魁星"紫微垣·斗魁科举文化中的文运之星

九、现代视角：三垣是什么？ ​

用现代天文学语言重新理解三垣：

三垣，是古人对北天极周围及黄道带两侧天区的系统性划分。

plain
紫微垣 ≈ 北天极拱极星区（北纬35°以上常年可见）
太微垣 ≈ 黄道北侧天区（春夏可见）
天市垣 ≈ 黄道东南天区（夏秋可见）

与西方星座体系的核心区别：

维度中国三垣体系西方星座体系
划分逻辑政治社会结构（宫城·朝廷·市集）神话故事与几何形状
核心功能星占·政治预兆·历法辅助航海导航·历法·神话记录
中心参照北极星（天帝居所）黄道带（太阳运行轨迹）
文化内涵天人合一·天上对应人间秩序神话人格化·英雄叙事

两套体系，代表了东西方文明对同一片星空的不同理解方式：
中国先人看到的是天上的朝廷与秩序，西方先人看到的是神话中的英雄与故事。
这正是文明多样性最美丽的体现。

   三垣 = 紫微垣（北天极）+ 太微垣（黄道北）+ 天市垣（黄道东南）
   每垣由左右垣墙围合，内含若干星官
   与二十八宿合称"三垣二十八宿"，是古代全天坐标系

2. 象征体系：
   紫微垣 = 天帝宫城（宇宙中心·皇权象征）
   太微垣 = 天子朝廷（政务中枢·百官之位）
   天市垣 = 天下市集（经济民生·诸侯围合）
   三垣合一，构成完整的天上"国家结构"

3. 定型历史：
   思想渊源先秦，《史记·天官书》初步建立
   《晋书·天文志》定型，《步天歌》普及
   宋代完成精确星数统计

4. 术数接口：
   紫微斗数命名直接来源于紫微垣
   奇门中宫象征源于紫微垣居中临制的结构
   风水坐北朝南原则，与紫微垣天文格局同构

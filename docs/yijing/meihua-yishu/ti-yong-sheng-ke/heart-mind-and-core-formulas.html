体用生克篇之一：心易·体用·总诀

进入体用、生克与变通的核心判断框架。

学习计划 · 第二阶段

【体用生克篇之一】心易·体用·总诀 ​

本篇是全书灵魂所在。前三篇是工具箱，这里才是真正的用法。

📜 原文 ​

心易占卜玄机 ​

天下之事有吉凶，托占以明其机。天下之理无形迹，假像以显其义。故干有健之理，于马之类见之。故占卜寓吉凶之理，于卦象内见之。然卦象一定不易之理，而无变通之道，不可也。易者，变易而已矣。至如今日观梅复得革兆，有女子折花，异日果有女子折花，可乎。今日算牡丹得姤兆，为马所践，异日果为马所践毁，可乎。且兑之属，非止女子。干之属，非止马。谓他人折花有毁，皆可切验之真，是必有属矣。嗟乎！占卜之道，要变通。得变通之道者，在乎心易之妙耳！

占卜总诀 ​

大抵占卜之法，成卦之后先看《周易》爻辞，以断吉凶。如乾初九「潜龙勿用」，则诸事未可为，宜隐伏之类；九二「见龙在田，利见大人」，则宜谒见贵人之类。余皆仿此。

次看卦之体用，以论五行生克。体用即动静之说。体为主，用为事。应用生及比和，则吉；体生用及克体，则不吉。

又次看克应。如闻吉说见吉兆，则吉；闻凶说见凶兆，则凶。见圆物，事易成；见缺物，事终毁之类。

复验己身之动静。坐则事应迟，行则事应速，走则愈速，卧则愈迟之类。数者既备，可尽占卜之道，必须以易卦为主，克应次之。俱吉则大吉；俱凶则大凶；有凶有吉，则详审卦辞，及克用体应之类，以断吉凶也。要在圆机，不可执。

占卜论理诀 ​

数说当也，必以理论之而后备。苟论数而不论理，则拘其一见而不验矣。且如饮食得震，则震为龙。以理论之，龙非可取，当取鲤鱼之类代之。又以天时之得震，当有雷声，若冬月占得震，以理论之，冬月岂有雷声，当有风撼震动之类。既知以上数条之诀，复明乎理，则占卜之道无余蕴矣。

先天后天论 ​

先天卦断吉凶，止以卦论，不甚用《易》之爻辞。后天则用爻辞，兼用卦辞，何也？盖先天者未得卦、先得数，是未有《易》书，先有《易》理，辞前之《易》也。故不必用《易》书之辞，专以卦断。后天则以先得卦，必用卦画，辞后之《易》也。故用爻之辞，兼《易》卦辞以断之也。又后天起卦，与先天不同，其数不一。今人多以坎一、坤二、震三、巽四、中五、干（乾）六、兑七、艮八、离九之数为用。盖圣人作《易》画卦，始以太极、两仪、四象、八卦加一倍，数自成干一、兑二、离三、震四、巽五、坎六、艮七、坤八。故占卜起卦，合以此数为用。又今人起后天卦，多不加时，得此一卦，止此一爻动，更无移易变通之道。故后天起卦定爻必加时而后可。又先天之卦，定事应之期，则取之卦气，如干、兑则应如庚、辛及申金之日，或坤为戌、亥之日时，兑为酉日时。如震、巽当应于甲、乙及支木之日，或震取卯，巽取辰之类。后天则以卦数加时数，总之而分行卧坐立之迟速，以为事应之期。卦数时类，应近而不能决诸远者，必合先后之卦数取诀可也。又凡占卦中决断吉凶，其理洞见，止于全卦体用生克之理，及参《易》辞，斯可矣。今日以后天卦，却于六十甲子之日取其对方之魁，破败亡灭迹等以助断决。盖历象选时，并于《周易》不相干涉，不可用也。

卦断遗论 ​

凡占卜决断，固以体用为主，然有不拘体用者。如起例中西林寺额得山地剥，体用互变，俱比和，则为吉，而乃不吉，何也？盖寺者，纯阳人居之地，而纯阴爻象，则群阴剥阳之义显然也。此理甚明，不必拘体用也。又若有人问：「今日动静如何？」得地风升，初爻动，用克体卦，俱无饮食矣，而亦有人相请，虽饮食不丰而终有请，何也？此人当时必有当日之应，又有「如何」二字带口，为重兑之义。又有用不生体，互变生之而吉者，若少年有喜色，占得山火贲是也。又有用不生体，互变俱克之而凶者，如牛哀鸣占得地水师是也。盖少年有喜色，占则略知其有喜，而《易辞》又有「束帛戋戋」之吉，是二者俱吉，互变俱生，愈见其吉矣。虽用不生体不吉，不为其害也。牛鸣之哀，则略知其有凶，而易爻复有「舆尸」之凶，互变俱克，愈见其凶。虽用爻不克，不能掩其凶也。盖用《易》断卦，当用理胜处验之，不可拘执于一也。

八卦心易体用诀 ​

心易之数，得之者众，体用之诀，有之者罕。余幼读《易》书，长参数学，始得心易卦数。初见起例，以知占其吉凶。如以蠡测海，茫然无涯。后得智人见授体用心易之诀，而后占事之诀，疑始有定。据验则验。如繇基射的，百发百中。其要在于分体用之卦，察其五行生克、比和之理，而明乎吉凶悔吝之机也。于是易数之妙始见，而《易》道之卦义备矣。乃世有真实，人罕遇之耳。得此者，幸甚秘之！

体用总诀 ​

体用云者，如易卦具卜筮之道，则易卦为体，以卜筮用之，此所谓体用者，借体用二字以寓动静之卦，以分主客之兆，以为占例之准则也。大抵体用之说，体卦为主，用卦为事，互卦为事之中间，刻应变卦为事之终。应体之卦气宜盛不宜衰。盛者如春震、巽、秋干、兑，夏离，冬坎，四季之月坤、艮是也。衰者，春坤、艮，秋震、巽，夏干兑，冬离，四季之月坎是也。

宜受他卦之生，不宜他卦之克。他卦者，谓用互变也。生者，如干、兑金体，坤、艮生之，坤、艮土体，离火生之。离，火体，震巽木生之。余皆仿此。克者，如金体火克，火体水克之类。体用之说，动静之机，八卦主宾。五行生克，体为己身之兆，用为应事之端。体宜受用卦之生，用宜见卦体之克。体盛则吉，体衰则凶。用克体固不宜，体生用亦非利。体党多而体势盛，用党多则体势衰。如卦体是金，而互变皆金，则是体之党多。如用卦是金，而互变皆金，则是用之党多。体生用，为之泄气，如夏火逢土，亦泄气。

体用之间，比和则吉，互乃中间之应，变乃末后之期。故用吉变凶者，先吉后凶；用凶变吉者，先凶后吉。体克用，诸事吉；用克体，诸事凶。体生用，有耗失之患；用生体，有进益之喜。体用比和，则百事顺遂。又卦中有生体之卦，看是何卦。

干卦生体，则主公门中有喜益，或功名上有喜，或因官有财，或问讼得理，或有金宝之利，或有老人进财，或尊长惠送，或有官贵之喜。
坤卦生体，主有田土之喜，或有田土进财，或得乡人之益，或得阴人之利，或有果谷之利，或有布帛之喜。
震卦生体，则主山林之益，或因山林得财，或进东方之财，或因动中有喜，或有木货交易之利，或因草木姓氏人称心。
巽卦生体，亦主山林之益，或因山林得财，或于东南得财，或因草木姓人而进利，或以茶果得利，或有茶果菜蔬之喜。
坎卦生体，有北方之喜，或受北方之财，或水边人进利，或因点水人称心，或有因鱼盐酒货文书交易之利，或有馈送鱼盐酒之喜。
离卦生体，主有南方之财，或有文书之喜，或有炉冶场之利，或因火姓人而得财。
艮卦生体，有东北方之财，或山田之喜，或因山林田土获财，或得宫音带土人之财。物当安稳，事有终始。
兑卦生体，有西方之财，或喜悦事，或有食物金玉货利之源，或商音之人，或带口之人欣逢，或主宾之乐，或朋友讲习之事。

又看卦中有克体之卦者，看是何卦。如干卦克体，主有公事之忧，或门户之忧，或有财宝之失，或于金谷有损，或有怒于尊长，或得罪于贵人。
坤卦克体，主有田土之忧，或于田土有损，或有阴人之侵，或有小人之害，或失布帛之财，或丧谷粟之利。
震卦克体，主有虚惊，常多恐惧，或身心不能安静，或家宅见妖灾，或草木姓氏之人相侵，或于山林有所失。
巽卦克体，亦有草木姓人相害，或于山林上生忧。谋事，乃东南方之人；处家，忌阴人小口之厄。
坎卦克体，主有险陷之事，或寇盗之忧，或失意于水边人，或生灾于酒后，或点水人相害，或北方人见殃。
离卦克体，主文书之忧，或失火之惊，或有南方之忧，或火人相害。
艮卦克体，诸事多违，百谋中阻。或有山林田土之失，或带土人相侵，防东北方之祸害，或忧坟墓不当。
兑卦克体，不利西方，主口舌事之纷争。或带口人侵欺，或有毁折之患，或因饮食而生忧。生克不逢，则止以本卦而论之。

📖 白话译文 ​

心易占卜玄机 ​

天下的事情有吉有凶，借助占卜来揭示其中的机理。天下的道理没有固定形迹，借助象来显现其义。所以乾卦有刚健之理，在马这类事物上可以看见。所以占卜将吉凶之理，寄托在卦象之中来显现。

然而，如果卦象只有一成不变的道理，而没有变通之道，那是不行的。易，就是变易而已。

比如今天观梅得到革卦之兆，有女子折花；难道以后每次得到革卦，都必然是女子折花吗？今天算牡丹得到姤卦之兆，为马所践毁；难道以后每次得到姤卦，都必然是马踩毁花吗？

况且兑卦所属，不止是女子；乾卦所属，不止是马。说他人折花有毁损，都可以切实验证，是因为必然有其所属的象在。

唉！占卜之道，贵在变通。得到变通之道的，在于心易的妙处！

占卜总诀 ​

大体上，占卜的方法是：成卦之后，第一步先看《周易》爻辞，以断吉凶。如乾卦初九「潜龙勿用」，则诸事不可为，宜隐伏等待；九二「见龙在田，利见大人」，则宜谒见贵人。其余仿此。

第二步看卦的体用，以论五行生克。体用就是动静之说。体为主（己方），用为事（所问之事）。用生体及比和，则吉；体生用及用克体，则不吉。

第三步看克应。听到吉语、见到吉兆，则吉；听到凶语、见到凶兆，则凶。见圆物，事易成；见缺物，事终毁。

第四步验己身动静。坐则事应迟，行则事应速，走则愈速，卧则愈迟。

以上四者俱备，可尽占卜之道。必须以易卦为主，克应次之。俱吉则大吉，俱凶则大凶；有凶有吉，则详审卦辞及克应体用，以断吉凶。要在圆机，不可执。

占卜论理诀 ​

数说得对，还必须用理来补充才算完备。只论数不论理，就会拘于一端而不灵验。

比如饮食占得震卦，震为龙——以理论之，龙不可取食，当取鲤鱼之类代替。又如天时占得震卦，当有雷声——若是冬月占得震，以理论之，冬月哪有雷声？当有风撼震动之类。

知道以上诸诀，再明白理，则占卜之道无有遗漏。

先天后天论 ​

先天卦断吉凶，只以卦论，不怎么用《易》的爻辞。后天则用爻辞，兼用卦辞，为什么？

先天是未得卦先得数，是未有《易》书先有《易》理，是爻辞之前的《易》，所以不必用《易》书之辞，专以卦断。后天是先得卦，必用卦画，是爻辞之后的《易》，所以用爻辞兼卦辞来断。

后天起卦与先天不同，其数不一。今人多用坎一·坤二·震三·巽四·中五·乾六·兑七·艮八·离九。但圣人作《易》画卦，从太极·两仪·四象·八卦加一倍而来，数自成乾一·兑二·离三·震四·巽五·坎六·艮七·坤八。故占卜起卦，应以此数为用。

后天起卦定爻，必须加时才可，不加时则无变通之道。

先天卦定事应之期，取卦气：乾兑应庚辛及申酉金日，震巽应甲乙及卯辰木日，余仿此。后天则以卦数加时数，按行卧坐立之迟速定期。

断卦吉凶，止于全卦体用生克之理，及参《易》辞即可。今人用六十甲子取对方魁罡破败等来助断，此乃历象选时之法，与《周易》不相干，不可用。

卦断遗论 ​

占卜决断，固然以体用为主，但有不拘体用者。

如西林寺额得山地剥，体用互变俱比和，按体用应为吉，但实为不吉——因为寺是纯阳人居之地，而卦得纯阴爻象，群阴剥阳之义显然，此理甚明，不必拘体用。

又如「今日动静如何」得地风升，初爻动，用克体，按体用无饮食之象，但终有人相请——因为当时必有当日之应，且「如何」二字带口，为重兑之义（兑为口，为饮食）。

又有用不生体，互变生之而吉者：少年有喜色占得山火贲。
又有用不生体，互变俱克之而凶者：牛哀鸣占得地水师。

少年有喜色，已略知有喜，爻辞又有「束帛戋戋，终吉」，互变俱生，愈见其吉——虽用不生体，不为其害。
牛鸣之哀，已略知有凶，爻辞又有「舆尸，凶」，互变俱克，愈见其凶——虽用爻不克，不能掩其凶。

用《易》断卦，当用理胜处验之，不可拘执于一。

八卦心易体用诀 ​

心易之数，得之者多，体用之诀，得之者少。我幼时读《易》，长大后研习数学，才得到心易卦数。初见起例，能知吉凶，但如同用瓢量海，茫然无边。后来得智者传授体用心易之诀，占事才有定准，据验则验，如养由基射靶，百发百中。

其要在于：分体用之卦，察五行生克比和之理，而明吉凶悔吝之机。

于是易数之妙始见，《易》道之卦义备矣。世间有此真实之法，人罕能遇。得此者，幸甚秘之！

体用总诀 ​

所谓体用：借体用二字寓动静之卦，分主客之兆，为占例之准则。

  • 体卦：主（己方·所占之人）
  • 用卦：事（所问之事·对方）
  • 互卦：事之中间过程
  • 变卦：事之终结

体卦之气，宜盛不宜衰。
体卦宜受他卦（用·互·变）之生，不宜受克。

五行生克判断口诀：

  • 用生体 → 有进益之喜（吉）
  • 体用比和 → 百事顺遂（吉）
  • 体克用 → 诸事吉
  • 体生用 → 有耗失之患（不利）
  • 用克体 → 诸事凶（凶）

党势判断：

  • 体党多（互变皆同体五行）→ 体势盛 → 吉
  • 用党多（互变皆同用五行）→ 体势衰 → 凶

时间线：

  • 用卦 → 当下·事之起
  • 互卦 → 中间过程
  • 变卦 → 最终结果
  • 用吉变凶 → 先吉后凶
  • 用凶变吉 → 先凶后吉

🧭 义理解析 ​

一、心易：变通是核心 ​

「心易占卜玄机」这一节，是邵雍在说一件事：

卦象是象，不是判决书。

观梅得革，不是说「以后每次革卦都有女子折花」。
牡丹得姤，不是说「以后每次姤卦都有马踩花」。

卦象给出的是一类象，不是一个固定答案。兑不止是女子，乾不止是马——它们是一类象的集合。占卜者的任务，是在当下的情境里，感受这类象对应的是什么。

这就是「心易」——用心去感受象，而不是用脑去查表。

二、占卜总诀：四步判断框架 ​

这是全书最重要的操作框架，四步有明确的优先级：

plain
第一步：《周易》爻辞  ← 最优先，定基调
    ↓
第二步：体用五行生克  ← 核心判断
    ↓
第三步：克应         ← 外部印证
    ↓
第四步：己身动静     ← 定时间快慢

俱吉则大吉，俱凶则大凶，有吉有凶则详审。

最后一句「要在圆机，不可执」——这是整个占卜总诀的总结，也是心易的精神。

三、先天后天论的关键补充 ​

这一节解决了一个重要问题：为什么不用坊间流传的先天数（坎一坤二……）？

邵雍明确说：

「圣人作《易》画卦，始以太极·两仪·四象·八卦加一倍，数自成乾一·兑二·离三·震四·巽五·坎六·艮七·坤八。故占卜起卦，合以此数为用。」

坊间的「坎一坤二」是先天八卦方位数（洛书数），用于风水方位，不是梅花易数的起卦数。梅花易数用的是后天卦序数：乾一兑二离三震四巽五坎六艮七坤八。

同时，他明确反对用六十甲子的魁罡破败来断卦——那是择日学的东西，与《周易》无关。

四、体用总诀：核心模型 ​

体用关系是全书的核心逻辑，可以用一张图来理解：

plain
┌─────────────────────────────────┐
│          一卦六爻                  │
│                                   │
│  体卦（静爻所在卦）= 己·主·我方   │
│  用卦（动爻所在卦）= 事·客·对方   │
│  互卦              = 事之过程      │
│  变卦              = 事之结局      │
└─────────────────────────────────┘

判断吉凶：
用生体 ✅ 吉    用克体 ❌ 凶
体克用 ✅ 吉    体生用 ⚠️ 耗
比和   ✅ 顺

党势是一个容易忽略但很重要的概念：

  • 不只看体用两卦的关系，还要看互卦和变卦站哪边
  • 互变帮体 → 体党多 → 体势盛 → 吉
  • 互变帮用 → 用党多 → 体势衰 → 凶

这与篇之二案例完全对应：

  • 观梅占：互见乾巽，乾金克巽木，巽木助离火克兑金（体）→ 用党多 → 凶
  • 少年喜色：互变俱生离（体）→ 体党多 → 吉

五、卦断遗论：体用之外的判断 ​

这一节非常重要，它说的是：体用是主要框架，但不是唯一框架。

三种超越体用的情况：

情况案例判断依据
卦名·卦义胜过体用西林寺额得剥卦，体用比和本应吉，但剥卦群阴剥阳，寺为纯阳之地，故凶卦义·情境
外应·字象补充体用今日动静得升卦，体用无饮食象，但「如何」带口为兑，终有宴请克应·字象
互变反转用卦判断贲卦用不生体，但互变俱生体，终吉；师卦用不克体，但互变俱克体，终凶互变综合

核心原则：用理胜处验之，不可拘执于一。

🌀 象的感悟 ​

「心易」是什么 ​

邵雍说「得变通之道者，在乎心易之妙」，但他没有直接解释什么是心易。

读完这一篇，我的感受是：

心易，是让象在心里活起来。

不是「乾=马」，而是感受到乾的那种刚健运行的气息——这种气息，可以是马，可以是老人，可以是圆形的金属，可以是一个果决的决定。当你感受到了这种气息，你就知道在当下的情境里，它对应的是什么。

这就是为什么同一个卦，在不同的情境下，应验的事情不同。不是卦变了，是象在当下的显现不同。

体用：主客之间的博弈 ​

体用的关系，本质上是一场主客之间的力量对比。

体是我，用是事。
用来滋养我（用生体）→ 事情对我有利。
我去滋养事（体生用）→ 我在付出，有耗损。
用来压制我（用克体）→ 事情对我不利。
我去压制事（体克用）→ 我能掌控局面。

这不只是占卜的逻辑，是任何关系中都成立的动态——
谁在滋养谁，谁在消耗谁，谁在压制谁。

感受到了这个，体用就不只是占卜工具，而是观察世界的一种方式。

「要在圆机，不可执」 ​

这句话，是邵雍在整篇总诀里说的最后一句话，也是最重要的一句。

前面给了四步框架，给了体用生克，给了克应动静——然后他说：不可执。

这不是自相矛盾。规则是脚手架，不是房子本身。学规则是为了最终放下规则，用心去感受当下的象。

就像养由基射箭——他不是在射箭时还在想「拉弓角度多少度·风速几级」，那些都已经化进身体里了。他只是看见靶，然后射。

心易的终点，是不需要查表，只需要感受。

📌 小结 ​

本节关键词

  • 心易：变通之道，象在心中活，不执于一
  • 占卜四步：爻辞→体用生克→克应→动静
  • 体用：体=己·主，用=事·客，互=过程，变=结局
  • 五行判断：用生体吉·比和顺·体克用吉·体生用耗·用克体凶
  • 党势：互变帮体则体盛，互变帮用则体衰
  • 时间线：用→互→变，先吉后凶或先凶后吉
  • 先天数：乾一兑二离三震四巽五坎六艮七坤八（坊间坎一坤二为误）
  • 圆机：不可执，理胜处验之

规律提炼

  1. 体用是主框架，但卦义·情境·克应·互变都可以修正判断
  2. 党势比单纯的体用关系更全面——互变站哪边，决定力量对比
  3. 先天后天的区别不只在起卦方式，在断卦时用不用爻辞也不同
  4. 「不可执」是最高原则，所有规则都服从于「理」

与前文呼应

  • 篇之二「推数又须明理」→ 此篇「数说当也，必以理论之」：同一原则的深化
  • 篇之二各案例的断卦逻辑，在此篇体用总诀中得到了系统化的理论支撑
  • ❓-001（先天后天定义）→ 此篇「先天后天论」完整解答，先天专以卦断，后天兼用爻辞

❓ 存疑 ​

❓****-009：体用总诀中「体卦」的判断方式——原文说「体用即动静之说」，动爻所在卦为用，静爻所在卦为体。但一卦六爻，若动爻在上卦，则上卦为用，下卦为体；若动爻在下卦，则下卦为用，上卦为体。这个判断方式是否正确？待卷三「体用互变之诀」章节印证。

❓****-010：「生克不逢，则止以本卦而论之」——体用既不生也不克（比如体为金，用为木，金克木，但若体为木，用为金呢？）此句的「生克不逢」具体指什么情况？是指体用五行无生克关系（如同五行比和），还是指互变中无生克？待后续章节印证。

断占总诀篇之三：观物占

以卦象观察器物的形、色、数与成败，深化以象断物的训练。

学习计划 · 第三阶段

【断占总诀篇之三】诸卦反对性情·占物类例·物数为体诀·观物诸诀·万物戏验 ​

本篇专论「观物占」——通过卦象断定手中或笼中之物的性质、形色、数目、成败。是梅花易数「以象断物」最完整的专论。

📜 原文 ​

诸卦反对性情 ​

干刚坤柔反其义，比卦欢欣困忧虑。
临逢百物观求之，蒙卦难明屯不失。
大畜其卦福之生，无妄若遇祸之始。
升者去而不复回，萃者聚而终不去。
谦卦自尊豫怠人，震则动而艮则止。
兑主外遇祸之藏，随前坎后偷安矣。
剥体消烂复自生，蛊改前非而已矣。
明夷内朗又逢伤，晋主外明并通理。
益拟茂盛损象衰，咸速恒迟涣远遁。
同人内亲睽外疏，解卦从容蹇难启。
离文美丽艮光明，遁退回身姤相遇。
大有曰众丰曰多，坎卦履险震卦起。
需不进兮讼不宁，既济一定无后虑。
未济之卦男之终，归妹之辞归之始。
否遭大往而小来，泰卦大来而小去。
革去旧故鼎从新，小畜曰寡噬嗑食。
旅羁其外大过颠，夬卦分明曰快利。
要将字字考精详，杂卦性情反对是。

占物类例 ​

凡看物数，看其成卦，观其爻辞。如得干，曰「潜龙勿用」，乃曰不可用之物；「见龙在田」，乃曰田中之物；「或跃在渊」，乃曰水中之物；「亢龙有悔」，乃废物也。如得坤之「直、方、大」，乃曰直而方大之器物；「括囊无咎」，乃曰包裹之物；「黄裳元吉」，乃曰黄色衣服之物；「其血玄黄」，乃石物或逢石而破；「困于株林」，乃曰木物。又言爻辞，不言物类，而不能决者，须以八卦所属之象察之。

又诀，体用断物之妙，生克制化之妙，于诸诀中此极为美验。其所以生体者，为可食之物；克体者，为可近人之秽物。体生者，为不成之器；体克者，为破碎损折之物；比和者，乃有用成器之物，又生体象者为贵物，克体象者为贱物，所泄为废物也。

又诀，凡算此数，以体卦为主，看其刚柔。用卦看其有用无用。体生方圆曲直，可作可用，如用生体，乃可食。用变互卦，看其色与数目。此互卦决其物之数目也。如互见干、兑，决为一二之数。互见艮、坤，为七八之数也。但互卦重干、重艮、重坤、重坎、重离之属，皆是两件。物乘旺，物数多，衰而物少。离为中虚之物，或空手无物。又决物之数者，如互艮卦，先天七数，后天亦不出八数之外。

物数为体诀 ​

凡算物数者，不但以体卦为体，凡卦之多者，皆可为体。如干金多，以金为体，则多刚；坤多以土为体，多柔。干卦体卦干而互又是干。固曰：金为体而刚矣，便是圆健刚硬之物。非金非石，此为体矣。观物有体互变卦，并无生旺之气者，为不入五行物。观物观爻，如八卦中阳爻多，乃多刚之物；阴爻多，乃多柔之物。

又诀，观物变在五六爻，多是能飞动之物。

观物看变爻为主 ​

凡观物，以变卦为主，应用之应验也。如得干，初爻变为巽，金刀削过之木物。二爻动，变为离，乃火中锻炼之金。三爻动，变为兑，乃毁折五金之器，虽圆而破处多也。

观物克应法 ​

凡算物之成败，又看体卦克应如何。成卦未决之际，有见圆物相遇，即断圆物。见有负土者过，即断为土中之物。见刚健之物，即言是刚健之物。见有柔腐之物，即言是柔腐之物。

观物趣时诀 ​

凡算物，趣时察理，无有不验。以春得震、离为花，夏得震为有声之物，秋得兑为毁折成器之物，冬得坤为无用土物也。

观物用易例 ​

有人以笼盛物者，算得地天泰之初变升，互见震、兑，曰此必是草木类而生土中也。色青根黄，当连根之草木也。盖爻辞曰：「拔茅茹，以其汇。」乃曰：此乃干根之草木也，视之乃草木连根，新采于土中也。互震为清色，兑为黄根也。

又有以锺覆物者，令占之，得火风鼎之雷风恒。乃曰：此有声价气势之物，虽圆而今毁缺矣。其色白而可用。盖其辞曰：「鼎玉铉，大吉。」互见干、兑，虽圆而毁也。开视之，乃玉绦环，果破矣。

万物戏验 ​

凡猜手中物，干金为圆白之物。其色白，其性刚，为宝货之物，有气为无价物。坎为黑色，性柔，近水之物。又艮为土中之物，瓦石之类，有气为成器之物，其色黄。逢兑克，无气，折伤之物。又巽、震为竹木，有气为有用之物，为可食之物；无气为竹木之属。遇兑之属可食，当时之果物，色青。有气柔，无气刚。震、巽遇坎为污湿物，或有气；如无气，为烂朽之木。离色亦，性柔，有水有木，而火焚之，必炭之类。有气，为价值可货之物。坤为土中之物，色黄而性温。兑为毁折之物，带口。凡占物，以春震巽、夏离、秋干兑、冬坎皆当以为可用之物，成器之物。否则为无用之物。值六虚冲破，则必无物而空手矣。

占物类例（译） ​

第一法：爻辞取象

看所得之卦的爻辞，直接从爻辞文字中取物象：

卦爻爻辞断物
乾初爻潜龙勿用不可用之物
乾二爻见龙在田田中之物
乾四爻或跃在渊水中之物
乾上爻亢龙有悔废物
坤二爻直·方·大直而方大之器物
坤四爻括囊无咎包裹之物
坤五爻黄裳元吉黄色衣服之物
坤上爻其血玄黄石物或逢石而破
坤（困卦）困于株林木物

爻辞不能决断时，退而用八卦所属之象察之。

第二法：体用生克断物性

plain
生体之卦 → 可食之物（滋养体者）
克体之卦 → 可近人之秽物（伤体者）
体生用   → 不成之器（体气外泄，物未成）
体克用   → 破碎损折之物（体强克外，物受损）
比和     → 有用成器之物（和谐，物完整有用）
生体象   → 贵物
克体象   → 贱物
体所泄   → 废物

第三法：互卦断物之数目与颜色

plain
互见乾·兑 → 一·二之数
互见艮·坤 → 七·八之数
互卦重复（重乾·重艮等）→ 两件
物乘旺 → 物数多；物衰 → 物数少
离为中虚之物，或空手无物

物数为体诀（译） ​

断物不只以体卦为体，卦中出现最多的五行，皆可为体：

plain
乾金多 → 以金为体 → 多刚
坤土多 → 以土为体 → 多柔
体卦乾 + 互卦又乾 → 金体极刚 → 圆健刚硬之物

阴阳爻断刚柔：

plain
阳爻多 → 多刚之物
阴爻多 → 多柔之物

特殊规则：

  • 体·互·变卦皆无生旺之气 → 不入五行之物（难以归类）
  • 变爻在五·六爻 → 多是能飞动之物（鸟·虫·飞禽）

观物看变爻为主（译） ​

观物以变卦为主，变爻位置决定物的性质：

以乾卦为例：

动爻变卦断物
初爻动变巽金刀削过之木物（乾金·巽木，金加工木）
二爻动变离火中锻炼之金（乾金经离火锻炼）
三爻动变兑毁折五金之器，虽圆而破处多（兑为毁折）

观物克应法（译） ​

成卦未决之际，以当下所见的外应印证物象：

plain
见圆物 → 断圆物
见负土者过 → 断土中之物
见刚健之物 → 断刚健之物
见柔腐之物 → 断柔腐之物

观物趣时诀（译） ​

顺应时令取象，无有不验：

plain
春得震·离 → 花（春花，震为生发，离为文采）
夏得震   → 有声之物（震为雷声，夏季震动）
秋得兑   → 毁折成器之物（兑为收割·成器）
冬得坤   → 无用土物（冬藏，坤土闭藏）

观物用易例（案例译） ​

案例一：笼中之物

卦：地天泰，初爻动，变地泽升，互见震·兑

断：

  • 泰卦初爻辞「拔茅茹，以其汇」→ 连根之草木
  • 互震 → 青色（木色）
  • 互兑 → 黄根（兑为金黄）
  • 坤土（下卦变后仍有坤象）→ 生于土中

结论：连根带土的草木，色青根黄，新采于土中。

开笼验之：果然是连根新采的草木。✅

案例二：钟覆之物

卦：火风鼎，变雷风恒，互见乾·兑

断：

  • 鼎卦上爻辞「鼎玉铉，大吉」→ 玉质之物
  • 互见乾·兑 → 虽圆而毁（乾圆·兑毁折）
  • 恒卦 → 有声价气势之物
  • 色白（乾兑皆白）

结论：有声价的玉质圆形之物，但已破损。

开钟验之：果然是玉绦环，且已破裂。✅

万物戏验（各卦手中物速断表） ​

卦颜色性质有气（旺）无气（衰）特殊情况
乾白刚·圆无价宝货普通金属—
坎黑柔近水之物——
艮黄土·瓦石成器之物折伤之物（逢兑）—
震·巽青竹木可食之物竹木之属遇坎→污湿物或烂朽木
离赤柔·燥价值可货之物炭类有水有木而火焚→炭
坤黄温·土土中之物——
兑白毁折·带口—破损之物—

时令加持：

plain
春：震·巽当令 → 可用成器之物
夏：离当令   → 可用成器之物
秋：乾·兑当令 → 可用成器之物
冬：坎当令   → 可用成器之物
非当令之卦   → 无用之物
值六虚冲破   → 必无物，空手

🧭 义理解析 ​

一、诸卦反对性情：六十四卦的「性格」 ​

此歌出自《周易·杂卦传》，是孔子对六十四卦性情的精炼总结。梅花易数引用此歌，目的是：断卦时，卦名本身就是一个象。

几个最重要的对比：

剥·复：「剥体消烂复自生」

  • 剥（山地剥）：剥落·消烂，阴盛阳衰到极点
  • 复（地雷复）：一阳来复，自然复生
  • 这是易理中「物极必反」最典型的一对

升·萃：「升者去而不复回，萃者聚而终不去」

  • 升（地风升）→ 行人占：去而不回（❓-026 在此解答）
  • 萃（泽地萃）→ 聚集不散，事物凝聚

咸·恒：「咸速恒迟」

  • 咸（泽山咸）：感应迅速，少男少女之卦，感而遂通
  • 恒（雷风恒）：持久而迟，长男长女之卦，恒久不变

同人·睽：「同人内亲睽外疏」

  • 同人（天火同人）：内部亲和
  • 睽（火泽睽）：外部乖离疏远

二、占物三法：爻辞·体用·互卦，层层递进 ​

本篇给出了断物的三个层次，优先级依次递进：

plain
第一层：爻辞取象（最直接）
↓ 爻辞不能决断时
第二层：体用生克断物性（定性）
↓ 需要进一步细化时
第三层：互卦断颜色与数目（定量）

这三层是一个完整的断物框架：

  • 爻辞告诉你「这个物是什么」
  • 体用生克告诉你「这个物是好是坏·是贵是贱」
  • 互卦告诉你「这个物有几件·是什么颜色」

三、体用生克断物性：最精妙的对应 ​

这一段是全书「观物占」最精华的部分：

plain
生体 → 可食之物

生体 = 滋养我的，食物滋养人，逻辑完全对应。

plain
克体 → 可近人之秽物

克体 = 伤害我的，秽物（垃圾·污物）靠近人但有害，逻辑对应。

plain
体生 → 不成之器

体生用 = 体的气外泄，物的能量散出去了，所以「不成之器」——还没做完的东西。

plain
体克 → 破碎损折之物

体克用 = 体强力克外，物受到强力作用，所以是破损之物。

plain
比和 → 有用成器之物

比和 = 和谐平衡，物完整有用，是最理想的状态。

这五个对应，把体用生克的逻辑完美地映射到物的性质上，是梅花易数「以象断物」最精妙的理论。

四、变爻为主：物的「加工痕迹」 ​

「观物看变爻为主」这一节，揭示了一个重要的逻辑：

变爻 = 物经历过的「变化·加工」

以乾卦为例：

plain
乾（金）初爻变巽（木）→ 金刀削过的木物
（金加工了木，留下了金的痕迹）

乾（金）二爻变离（火）→ 火中锻炼的金
（金经过火的锻炼，是精炼金属）

乾（金）三爻变兑（毁折）→ 破损的金属器
（金遇毁折，是破损之物）

变爻不只是「结局」，在观物占中，它更像是「这个物的来历和状态」。

五、趣时诀：时令是象的背景色 ​

「趣时察理，无有不验」——时令是所有象的背景色，同一个卦在不同时令下，象意完全不同：

plain
春得震·离 → 花（生发·文采，春天的花）
夏得震   → 有声之物（震为雷，夏雷最盛）
秋得兑   → 成器之物（秋收·收割·成器）
冬得坤   → 无用土物（冬藏，土物闭藏无用）

这与体用衰旺之诀完全呼应：当令之卦，物有用；非当令之卦，物无用。

🔍 案例复盘 ​

案例一：地天泰初爻动 ​

plain
本卦：地天泰（坤上乾下）
初爻动（乾初爻）→ 变地泽临（坤上兑下）
互卦：震（下互二三四爻）·兑（上互三四五爻）

断物逻辑：

plain
1. 爻辞：泰卦初爻「拔茅茹，以其汇」
   → 茅草连根拔起，汇聚成束
   → 断：连根之草木

2. 互震（木·青色）→ 物色青
3. 互兑（金黄）→ 根色黄
4. 坤（土）→ 生于土中，新采

综合：连根带土的草木，色青根黄

验证：笼中果然是连根新采的草木 ✅

案例二：火风鼎变雷风恒 ​

plain
本卦：火风鼎（离上巽下）
变卦：雷风恒（震上巽下）
互卦：乾（上互三四五爻）·兑（下互二三四爻）

断物逻辑：

plain
1. 爻辞：鼎卦上爻「鼎玉铉，大吉」
   → 玉质之物

2. 互乾（圆·白·贵）→ 圆形，色白，有价值
3. 互兑（毁折）→ 虽圆而破
4. 变恒（有声价气势）→ 贵重之物

综合：白色圆形玉质贵重之物，但已破损

验证：钟中果然是玉绦环，且已破裂 ✅

🌀 象的感悟 ​

诸卦反对性情：卦名就是象 ​

「咸速恒迟」——咸卦感应迅速，恒卦持久而迟。

这让我感受到：卦名本身就是一个完整的象。不需要起卦，光是卦名这两个字，就已经在告诉你这件事的性情。

咸，是少男少女初相遇的感应，当然迅速。恒，是长男长女长久相守，当然持久而迟。

这不是规则，是象的自然流露。

体用断物：生克是一种关系，不只是规则 ​

「生体者，为可食之物」——这句话让我停下来感受了很久。

为什么生体的是可食之物？因为食物滋养你，让你的「体」得到补充。这不是规定，是生克关系在生活中最自然的映射。

克体的是秽物——因为秽物伤害你，靠近你但让你不舒服。

体生的是不成之器——因为你把能量给出去了，物还没做完。

这五个对应，每一个背后都有活生生的生活逻辑，不是死记硬背的规则，而是象的自然延伸。

两个案例：象的精准 ​

泰卦初爻「拔茅茹，以其汇」——连根拔起的茅草。

这句爻辞，两千年前写下来，是讲君子同心协力的道理。但在观物占里，它直接告诉你：笼里装的是连根的草木。

同一句话，在不同的语境里，说的是不同层次的真相。这就是「象」的深度——一个象，可以同时在多个层次上为真。

📌 小结 ​

本节关键词

  • 诸卦反对性情：六十四卦的性格总结，卦名即象（升→去不回·萃→聚不散·咸→速·恒→迟）
  • 占物三法：爻辞取象→体用生克断物性→互卦断颜色数目，层层递进
  • 体用断物：生体→可食；克体→秽物；体生→不成器；体克→破损；比和→成器有用
  • 互卦断数：乾兑→一二；艮坤→七八；重卦→两件；离→中虚或空手
  • 物数为体：卦中多者为体；阳爻多→刚；阴爻多→柔；变在五六爻→飞动之物
  • 变爻为主：变爻揭示物的「加工痕迹」和「经历状态」
  • 趣时诀：春震离→花；夏震→有声；秋兑→成器；冬坤→无用；当令→有用，非当令→无用
  • 六虚冲破→必无物空手

规律提炼

  1. 卦名本身就是象，诸卦反对性情是断卦时的「性格参考」
  2. 观物占有三个层次：爻辞（最直接）→体用生克（定性）→互卦（定量·定色）
  3. 体用生克在观物占中有完美的物性映射：生体=食物，克体=秽物，比和=成器
  4. 变爻在观物占中揭示的是「物的来历与加工状态」，不只是结局
  5. 时令是象的背景色，同一卦在不同时令下物性完全不同
  6. 外应（克应法）在成卦未决之际可直接印证物象

与前文呼应

  • 篇之一「动者为用·静者为体」→ 观物看变爻为主：变爻（动）为观物之主
  • 篇之一「体用衰旺之诀」→ 趣时诀：当令=旺=有用，非当令=衰=无用
  • 篇之一「体用生克之诀·真生真克」→ 占物类例「体用断物」：同一生克逻辑在物性判断上的应用
  • 篇之二「观物玄妙歌诀·象在关系中生成」→ 观物看变爻：乾遇巽·乾遇离·乾遇兑，象随关系变
  • ❓-026「成远恒迟升不回」→ 诸卦反对性情「升者去而不复回」：❓****-026 解答，升卦主去而不回，恒卦主迟

❓ 存疑 ​

❓****-026 已解答：「成远恒迟升不回」——升卦（地风升）主「去而不复回」，恒卦（雷风恒）主「持久而迟」。行人占中，得升卦则远行不归，得恒卦则归期迟缓。

❓****-027：占物类例「体用断物」中，「克体者，为可近人之秽物」——「可近人」三字费解。秽物本应远离，为何说「可近人」？推测：「可近人」指的是「会接触到人、靠近人的」，即秽物虽然有害，但它会出现在人的生活环境中（如垃圾·污物），是「会被人接触到的有害之物」，而非「应该远离的」。存疑待印证。

❓****-028：「观物变在五六爻，多是能飞动之物」——五六爻在上卦，上卦对应天·高处，故飞动之物（鸟·虫）多在上爻变动。这个逻辑是否与「上卦为外·下卦为内」的空间逻辑相关？即变在上爻=物在高处=飞动之物？待后续印证。

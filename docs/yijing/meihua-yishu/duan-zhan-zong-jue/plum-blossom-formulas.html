📜 原文 ​

观梅数诀 · 变卦式 · 诸诀

离南 巽东南 坤西南 震东 兑西 艮东北 乾西北 坎北

嗟呼易岂易言哉

盖易之为书至精微至玄妙

然数者不外乎易理也

有先后天之殊有叶音取音之辨

明忧虞得失之机取互变迟速之应

数有前定祸福难测

易理灼然可察予求得先天玄黄灵应诸篇

外采易辞曰观梅数诀

列图明五行生克衰旺之理分例指避凶趋吉之道

后学群子幸鉴焉

易辞曰易有太极是生两仪两仪生四象

四象生八卦八卦生万物

邵子曰一分为二二分为四四分为八也

说卦传曰易逆数也

邵子曰干一兑二离三震四巽五坎六

艮七坤八自干至坤皆得未生之卦

若逆推四时之比也

后天六十四卦仿此

干为父震长男坎中男艮少男

坤为母巽长女离中女兑少女

离卦初爻阳动变阴变艮卦兑金为少女离火克之

巽为股干金克之曰伤股

得艮土生入兑金断曰不至于死

体用于变爻作动静取之

动者为用静者为体

木是用爻断出软物文章之体也

此卦断出是铁器之物

此卦乃用金体火夏火得旺能出土必是土物也

用爻属木变火体卦属金

四爻变卦成艮土能生金断出是铁

此卦非金是石断是破磁盘也

本卦得泽火革为少女近物为口远取羊

内离为中女近日远取雉

初爻变艮卦为土土能生金则扶起兑金之妹

次除去初爻移上四爻又成巽木断得伤股之灾

得初爻变艮土生兑金是故有救而不至于死也

近取诸身干头坤腹震足巽股坎耳

离目兑口艮手人身

远取诸物干马坤牛震龙巽鸡坎豕

离雉艮狗兑羊畜道

盖卦是体生而乃泄已之气其财空望

次得离卦属火能克金

其日午时客来食去酒返自消耗也

又如占卦问吉事则看卦中有生体之卦则吉事应之必速

便看生体之卦于八卦时序类决其日时

如生体是用卦则事即成

生体是互卦则渐成

生体是变卦则稍迟耳

若有生体之卦又有克体之卦则事有阻节好中不足产

便看克体卦气阻于几日若干克体阻一日

兑克体阻二日之类推之

如占吉事无生体之卦有克体之卦则事不谐矣

无克体之卦则吉事必可成就矣

又如占不吉之事卦中有生体之卦则有救无害

如无生体之卦事必不吉矣

若以日期而论看卦中有生体之卦

则事应于生体卦气之日

有克体之卦则事败于克体卦气之日

要在活法取用也

大凡占卜以体为其主互用变皆为应

卦用最紧互次之变卦又次之

故曰用为占之即应互为中间之应变为事占之终应

然互卦则分其有体之互有用之互

如体在上则上互为体之互下互为用之互

体卦在下则下互为体之互上互为用之互

体互最紧用互次之

例如观梅恒卦互兑干兑为体互见女子折花

若干为体互则老人折花矣

盖兑干皆克体但取兑而不取干此体互用之分

大凡占卦变卦克体事于末后必有不吉

变生体及比和则事事临终有吉利

此用互变之诀也

占卦即以卦分体用互变即以五行之理断其吉凶

然生克之理于内卦体用互变一定之生克

若外卦则须明其真生真克之五行以分轻重则祸福立应

何也

假如干兑之金为体见火则克然有真火之体有火之形色

真火能克金形色则不能克

能克则不吉不能克则不顺而已

盖见炉中火窑灶之火真火也

烈焰巨炷真火也

干兑为体遇之不吉

若色之红紫形之中虚槁木之离日火之火

则灶之形色非真火也干兑之体不为深忌

又若一盏之灯一炬之烛虽曰真火微细而轻小不利耳

又若震巽之木体遇金则克然钗钏之金

金铂之金成锭之银杯盘之银与器之锡

琐屑之钢铁皆金也

此等之金岂能克木

木之所忌者快刀锐刃巨斧大锯

震巽之体值之必有不吉

又若离火为体见真水能克

然但见色之黑者见体之湿者与夫血之类

皆坎之属终忌而不深害也

余卦为体所值外应克者皆以轻重断之

若夫生体之卦亦当分辨

土与瓦器皆坤土金遇之土能生金瓦不能生也

树木柴薪皆木也

离火值之柴薪生火之捷树木之末伐者生炎之迟也

木为体真水生木之福重如豕如血虽坎之属生木之类轻也

其余五行生克并以类以推之

凡体卦宜乘旺克体之卦宜衰

盖体卦之气如春木夏火秋金冬水

四季之月土此得令之卦乘旺之气

虽有他卦克之亦无大害

用互变卦乘旺皆吉但不要克体之卦气旺

而体卦气衰是不吉之占

占者有此若问病必死问讼必败

若非问讼与病而常占则防有官病之事

末临其期在于克体卦气之月日也

若卦体旺而复有生体之卦吉事之来可刻期而至矣

若内卦外卦有生体者体卦虽衰亦无大害也

内外并也生体虽体之卦党多皆是衰卦终不吉也

故体用之卦必须详其盛衰也

占卦体用互变既分必以内外之卦察其动不动

不动不占亦不断

其吉凶悔吝生乎动也

夫体卦为静互卦为静用卦变卦则动也此内卦之动静也

以外卦言之方应之卦天地地理之卦应皆静

若人事之应器物之类则有动者矣

器物本静人持其器物而来则动矣

若干马坤牛皆动者矣

盖水之井沼土之山岩石皆静者矣

人汲水担水而前水之动也

又人持石负土而前土之动也

于外卦之应观其动静而审其吉凶动而吉者应吉之速

动而凶者应凶之速

不动而应者吉凶之末见也

此则外卦体用之动静也

若夫起卦之动静

亦以我之中静而观其动者而占之

如雀之争坠如牛鸡之衰鸣如枯木之坠

皆物之动者我以静而占之也

又若我坐则事应之迟

我行而事应之速

我立而半迟半速此皆动静之理也

坐端之诀以我之所坐为中八位列于八方占卦决断之

须虚心待应坐而端之察其八卦八方应兆

以为占卜事端之应

随其方卦有生克之应者以定所占之家吉凶也

如干上有土生之或干宫有诸吉兆

则尊长老人分上见吉庆大事

若干上有火克之或有凶兆则主长上老人有忧

坤有火生之或坤上有吉兆

则主母亲分上或主阴人有吉利之喜

坤宫见克或有凶兆则主老母阴人有灾厄

震宫有水生之及东方震宫有吉兆则喜在长子长孙

见克而或见凶则长子长孙不利

坎宫宜见五金及有吉利之谶则喜在中男之位

若土克若见凶则忧在中男矣

离宫喜木生之或有可喜之应则中女有喜

若遇克或见凶则中女有厄矣

艮为少男之位宜火生之见吉则少男之喜

若遇克或见凶则灾及少男

问产必不育矣

兑为少女土宜生之见吉则少女有喜或有欢悦之事

若问病如干卦受克病在头

坤宫见克病在腹推之震足巽股离目

坎耳及血艮手指兑口齿于其克者定见其病

至于八端之中有奇占巧卜者则在乎人

此引其端为之例也

克应者所谓克期应验也

占卜之道无此诀

则吉凶成败之事不知应于何时

故克应为卦之切要也

然克则最难有以数而克之者有以理而克之者皆要论也

以数而刻期必详其理如算屋宅之初创

男女之始婚坟之方葬器物之新置

俱以年月日时加事物之数而起卦

卦成则于体用互变之中视全卦之数

以为约定之期审其事端之迟速而刻之

如屋宅坟墓永久者也

屋宅则以全卦之数刻其期

如屋宅之终应盖屋宅有朽坏之期也

坟墓亦有损坏然占墓但占吉凶不计成败也

男女之婚远亦不过数年

年内之事全卦之数可决又不如屋宅之久也

然婚姻亦不过卜其吉凶不必刻其期也

若吉凶之期但以生体及比和之年月为吉期

克体之年月为不吉之期也

器物之占则金石之质终远草木之质终不久也

远者以全卦之数为年期

近者以全卦之数为月期

又近者以全卦为日期也

如置砚则全卦之数为岁

计笔墨亦可以全卦为岁计

笔墨之小者以日卦之数可也

此器物刻期之占也

如先天观梅与牡丹二花俱旦夕之事

故以卦理推则不必决其远日也

如后天老年少年鸡牛之占

以方卦物卦之数合而计之

老少鸡牛之占亦只可以日计也

若永远之占则以日为月以月为年矣

占者详吉必又寻常之占事刻期

则于全卦中细观生体之卦为吉

应决期克体之卦为凶

应之期远则以年近则以月又近则以日也

如问求名则干为体看卦中有坤艮则断其辰

戌丑未之土月日

盖干兑金体也

此为吉事生体之应

若问病而干卦为体则看卦中有离

又看卦中无坤艮及有凶犯

则其体死于巳午火日此克体为凶事之期也

又若问行人以生体之日为归期

无生体比和之日则归必迟

若此例者具难尽载学者审焉

📖 白话译文 ​

观梅数诀序 ​

唉，《易》哪里是容易说清楚的！《易》这部书，至精微，至玄妙。但数，不外乎易理。有先天后天之分，有谐音取象之辨，能明了忧患得失的机理，取互卦变卦迟速的应验。数有前定，祸福难测，但易理明显可察。我求得先天、玄黄、灵应诸篇，外采《易辞》，名为「观梅数诀」，列图说明五行生克衰旺之理，分例指出避凶趋吉之道，后学诸君幸加鉴察。

《易辞》说：「易有太极，是生两仪，两仪生四象，四象生八卦，八卦生万物。」邵子说：「一分为二，二分为四，四分为八。」《说卦传》说：「易逆数也。」邵子说：「乾一·兑二·离三·震四·巽五·坎六·艮七·坤八，自乾至坤，皆得未生之卦，如同逆推四时一样。后天六十四卦仿此。」

变卦式八则（译解） ​

第一则：泽火革，体为兑金。初爻（离卦初爻）阳动变阴，变为艮卦。兑为少女，离火克兑金（克体）。巽为股（大腿），乾金克巽（互卦有巽），故曰伤股。但初爻变艮，艮土生兑金（生体），故断：伤股但不至于死。

关键原则：动者为用，静者为体。

第二则：地雷复，体土用金。动爻属木，断出软物、文章之类。

第三则：天泽履，体金用金，互卦有木火，变乾卦。断出铁器之物。

第四则：泽火革，用金体火，夏月火旺，能生土，断出土物。

第五则：雷泽归妹，用木体金，互卦水火，变火泽睽。用爻木变火，四爻变卦成艮土，土生金（体），断出铁器。

第六则：泽天夬，体金用金，互卦金，变兑卦。虽皆金象，但断出的不是金而是石，是破磁盘（瓷器）。

第七则：泽火革详解。兑为少女，近取为口，远取为羊。离为中女，近取为日，远取为雉。初爻变艮土，土生兑金（体），扶起体卦。去初爻移上四爻，又成巽木（互卦），巽为股，故有伤股之灾。但艮土生兑金，故有救不至于死。

第八则：天水讼变兑，问求财。体生用（泄气），财空望。互见离火克金，加之午时（火旺），客来消耗，财反有损。

占卦诀（译） ​

占吉事：

  • 有生体之卦 → 吉事必速应
    • 生体在用卦 → 事即成
    • 生体在互卦 → 渐成
    • 生体在变卦 → 稍迟
  • 有生体又有克体 → 有阻节，好中不足
    • 乾克体 → 阻一日；兑克体 → 阻二日（类推）
  • 无生体，有克体 → 事不谐
  • 无克体 → 吉事必成

占不吉之事：

  • 有生体之卦 → 有救无害
  • 无生体之卦 → 事必不吉
  • 生体卦气之日 → 吉应之期
  • 克体卦气之日 → 凶败之期

体用互变之诀（译） ​

体为主，用·互·变皆为应。优先级：用卦最紧，互卦次之，变卦又次之。

  • 用卦 → 占之即应（当下）
  • 互卦 → 中间之应（过程）
  • 变卦 → 事之终应（结局）

互卦分体之互与用之互：

  • 体在上卦 → 上互为体之互（最紧），下互为用之互
  • 体在下卦 → 下互为体之互（最紧），上互为用之互

案例：观梅恒卦，互见兑·乾。兑为体，则互见女子折花（兑克体，取兑）；若乾为体，则互见老人折花（乾克体，取乾）。体互优先于用互。

变卦克体 → 末后必有不吉；变卦生体或比和 → 临终有吉利。

体用生克之诀（译） ​

内卦的生克是固定的五行生克。外卦（克应）则须辨真生真克，以分轻重。

体用衰旺之诀（译） ​

  • 体旺虽有克，亦无大害

体用动静之诀（译） ​

内卦动静：

  • 体卦·互卦 → 静
  • 用卦·变卦 → 动

外卦动静：

  • 天时·地理之卦 → 静
  • 人事·器物 → 有动有静（人持器物则动，器物本身则静）
  • 动而吉 → 应吉之速；动而凶 → 应凶之速；不动 → 吉凶未见

起卦动静：

  • 以我之静，观物之动而占
  • 我坐 → 事应迟；我行 → 事应速；我立 → 半迟半速

占卜克应之诀（译） ​

克应 = 克期应验，即在预定时间节点上应验。

不同事项的时间单位：

事项时间单位说明
屋宅·坟墓年（全卦之数为年）永久之物
婚姻年内（全卦之数可决）不必刻期，只卜吉凶
金石器物（砚台）年（全卦之数为岁）质地坚久
草木器物（笔墨）年或月视大小而定
笔墨之小者日短暂之物
观梅·牡丹旦夕（不必远日）先天起卦，即时之事
老少·鸡牛之占日后天起卦，以方卦物卦数合计
永远之占以日为月，以月为年换算放大

吉凶刻期原则：

  • 生体·比和之年月 → 吉期
  • 克体之年月 → 凶期
  • 期远 → 以年；期近 → 以月；又近 → 以日

案例：

  • 求名（乾为体，金体）→ 卦中有坤艮（土生金）→ 辰戌丑未土月日为吉期
  • 问病（乾为体，金体）→ 卦中有离（火克金），无坤艮，有凶犯 → 巳午火日为死期
  • 问行人 → 生体之日为归期；无生体比和之日 → 归必迟

🧭 义理解析 ​

一、变卦式八则：「动者为用，静者为体」 ​

变卦式八则是全书最重要的一句话的来源：

体用于变爻，作动静取之。动者为用，静者为体。

这句话解决了一个根本问题：如何确定体卦和用卦？

动爻所在卦 = 用卦（动）
无动爻所在卦 = 体卦（静）

八则案例展示了变卦式的实战应用，每则都有不同的侧重：

则次核心示范关键点
第一则体用·互变综合断克体有救（艮土生兑金）
第二则用爻断物性木爻→软物·文章
第三则互变断物性金体金用→铁器
第四则时令影响断物夏火旺→能出土物
第五则变爻断物性变艮土生金→铁
第六则形色辨真假金象但非金→磁盘（瓷器）
第七则互卦详解体互·用互的区分
第八则体生用→泄气求财反耗，时令加重

第六则特别值得注意：泽天夬，体金用金，互卦金，变兑金——全卦皆金象，但断出的是石（磁盘·瓷器），而非金属。这说明：象不等于物，要看象的组合与情境。全卦皆金，反而显示出「坚硬·圆·易碎」的综合象，指向瓷器而非金属。这是「心易」最精妙的地方。

二、体用互变之诀：优先级与体互的关键 ​

本诀最重要的补充是体互与用互的区分：

plain
体在上卦：
    上互 = 体之互（最紧）
    下互 = 用之互

体在下卦：
    下互 = 体之互（最紧）
    上互 = 用之互

以观梅恒卦为例：互见兑·乾，兑·乾皆克体。

  • 若兑为体 → 取体之互（兑的那一侧互卦）→ 见女子折花
  • 若乾为体 → 取体之互（乾的那一侧互卦）→ 见老人折花

体互决定了互卦中哪个象是主要的克应。这是之前各篇没有明确说明的细节，在此处首次系统化。

三、体用生克之诀：真生真克的精细化 ​

这是全书对「外卦生克」最精细的一次论述，核心原则是：

外卦须辨真生真克，以分轻重。

内卦的生克是固定的五行关系，但外卦（克应）是现实中的具体事物，同一五行属性的事物，克生的力量差异极大：

plain
真克（力量强）：炉火·窑灶·烈焰 → 真火克金
形色之克（力量弱）：红紫之色·日火 → 不深忌
微细之克：一灯一烛 → 小不利

真克（力量强）：快刀锐刃·巨斧大锯 → 真金克木
微细之金：钗钏·金箔·杯盘之银 → 不能克木

这个原则解决了一个实际问题：同样是「见火」，炉火和红色衣服，对金体的影响完全不同。

生的轻重同理：柴薪生火（快），未伐树木生火（慢）；真水生木（重），猪血生木（轻）。

四、占卦诀：生克位置决定时间快慢 ​

占卦诀里有一个重要的时间逻辑：

plain
生体在用卦 → 事即成（最快）
生体在互卦 → 渐成（中等）
生体在变卦 → 稍迟（最慢）

这与体用互变的优先级完全对应：用卦最紧（当下），互卦次之（过程），变卦又次之（终局）。越靠近当下的卦，应验越快。

五、克应之诀：时间单位的选择逻辑 ​

克应之诀解决了❓-020（全卦成数）的问题：

「视全卦之数，以为约定之期，审其事端之迟速而刻之。」
「远者，以全卦之数为年期；近者，以全卦之数为月期；又近者，以全卦为日期。」

关键在于：同一个「全卦之数」，用年·月·日哪个单位，取决于事物的性质（久暂）：

plain
屋宅（永久）→ 全卦数 = 年
草木器物（中等）→ 全卦数 = 月
旦夕之事（短暂）→ 全卦数 = 日
永远之占 → 以日为月，以月为年（换算放大）

这就解释了为什么田姓29年·王姓22年·韩姓31年——这些数字是各家卦的「全卦之数」，以「年」为单位，因为屋宅是永久之物。

🔍 案例复盘 ​

变卦式第一则·泽火革详解 ​

起卦：泽火革（兑上离下），初爻动

体用确定：

  • 初爻在下卦（离），动 → 离为用卦
  • 上卦兑，静 → 兑为体卦（金）

互卦：

  • 去初爻与上爻，中间四爻：二·三·四·五爻
  • 下互（二三四爻）：巽（木）
  • 上互（三四五爻）：乾（金）

体互：体在上卦（兑），上互为体之互 → 乾（金）
用互：下互为用之互 → 巽（木）

变卦：初爻阳变阴，离初爻变 → 艮，全卦变为泽山咸

断卦逻辑：

plain
体：兑（金）
用：离（火）→ 火克金（用克体）→ 凶
体互：乾（金）→ 比和，助体
用互：巽（木）→ 巽为股，乾金克巽（用互克用互？）
变卦：艮（土）→ 土生金（生体）→ 有救

近取诸身：兑为口，巽为股
→ 离火克兑金（体），伤在兑所主之处
→ 巽为股，乾金克巽，伤股

变卦艮土生兑金（体）→ 有救，不至于死

结论：伤股，但不至于死。

占卜克应之诀·求名案例 ​

乾为体（金体），问求名：

  • 卦中有坤·艮（土）→ 土生金（生体）
  • 土旺于辰·戌·丑·未月日
  • → 断：辰戌丑未土月日为得名之期

乾为体（金体），问病：

  • 卦中有离（火）→ 火克金（克体）
  • 卦中无坤·艮（无生体），有凶犯
  • 火旺于巳·午月日
  • → 断：巳午火日为死期

🌀 象的感悟 ​

「动者为用，静者为体」 ​

这句话是全书最简洁的一句断语，也是最深的一句。

体是静的——它是根，是主，是我。用是动的——它是事，是变，是来者。

静的东西不会主动改变，动的东西才是变化的源头。占卜的本质，是感受「动」对「静」的影响——动来生我，则吉；动来克我，则凶。

这让我想到：生活中也是如此。我们的「体」——内心的根基、价值观、核心能量——是相对静的。外部的事件·人·机遇，是动的。吉凶，取决于这些「动」与我们的「体」之间是生是克。

真生真克：力量是有重量的 ​

「炉中火是真火，红紫之色是火之形色」——这句话让我感受到：象是有重量的，不是所有同类的象力量都相同。

一把巨斧和一枚发钗，都是金，但对木体的影响天壤之别。

这提醒我们：在感受象的时候，不只要感受「是什么象」，还要感受「这个象有多重」。轻的象，轻轻带过；重的象，才需要认真对待。

克应之诀：时间是可以感知的 ​

「远者以年，近者以月，又近者以日」——时间的单位，取决于事物的性质。

屋宅是年的尺度，笔墨是日的尺度。不是随意选择，是因为屋宅的「体」厚重，笔墨的「体」轻薄。体的厚薄，决定了时间的尺度。

这让我感受到：一件事情能持续多久，取决于它的根基有多深。根基深厚的，以年计；根基轻薄的，以日计。

规律提炼

  1. 「动者为用，静者为体」是体用判断的根本原则，首次在此明确系统化
  2. 体互优先于用互——互卦中与体同侧的互卦，对体的影响最直接

❓ 存疑 ​

❓****-020 已解答：全卦之数以年·月·日为单位，视事物性质（久暂）而定。屋宅永久则以年，草木器物则以月，旦夕之事则以日。

❓****-022：变卦式第六则「泽天夬，体金用金，互卦金，变兑卦——断是破磁盘也」。全卦皆金象，为何断出的是瓷器（磁盘）而非金属？原文未作解释。推测可能的逻辑：兑为毁折（破），全卦皆金但无火（无烧炼之象），金象过盛反显「坚硬·圆·易碎」之象，指向瓷器。但此推测存疑，待后续章节或师传印证。

❓****-023：占卦诀「若干克体，阻一日，兑克体，阻二日之类推之」——乾克体阻一日，兑克体阻二日，这个「阻日数」的推算依据是什么？是先天卦序数（乾一·兑二）？还是另有规则？原文说「之类推之」，暗示有规律可循，但未明述。推测：乾一·兑二·离三·震四·巽五·坎六·艮七·坤八，克体之卦的先天序数即为阻日数。待后续章节印证。

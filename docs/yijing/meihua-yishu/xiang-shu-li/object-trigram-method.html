象数易理篇之二：物卦起例

从起卦方法到八卦万物属类，练习将所见之物读成卦象。

学习计划 · 第一阶段

占法·玩法 → 卦以八除·爻以六除·互卦 → 年月日时·物数·声音·字占 → 为人占·自己占·动静物占

象数易理篇之二·物卦起例与八卦万物属类 ​

📜 原文 ​

物卦起例（端法后天起卦）
后天端法：以物为上卦，方位为下卦，合物卦之数与方卦之数加时数以取动爻。

八卦万物属类（并为上卦）
干（乾）：天、父、老人、官贵、头、骨、马、金宝、珠玉、水果、圆物、冠、镜、刚物、大赤色、水寒。
坤：地、母、老妇、土、牛、金、布帛、文章、舆辇、方物、柄、黄色、瓦器、腹、裳、黑色、黍稷、书、米、谷。
震：雷、长男、足、发、龙、百虫、蹄、竹、萑苇、马鸣、馵足、的颡、稼、乐器之类、草木、青碧绿色、树、木核、柴、蛇。
巽：风、长女、僧尼、鸡、股、百禽、百草、臼、香气、臭、绳、眼、羽毛、帆、扇、枝叶之类、仙道工匠、直物、工巧之器。
坎：水、雨、雪、工、豕、中男、沟渎、弓轮、耳、血、月、盗、宫律、栋、丛棘、狐、蒺藜、桎梏、水族、鱼、盐、酒、醢、有核之物、黑色。
离：火、雉、日、目、电、霓霞、中女、甲胄、戈兵、文书、槁木、炉、兽、鳄龟蟹蚌、凡有壳之物、红赤紫色、花纹人、干燥物。
艮：山、土、少男、童子、狗、手指、径路、门阙、果、蓏、阍寺、鼠、虎、狐、黔喙之属、木生之物、藤生之物、爪、鼻。黄色。
兑：泽、少女、巫、舌、妾、肺、羊、毁折之物、带口之器、属金者、废缺之物、奴仆、婢。

八卦方位
离南坎北，震东兑西，人则介乎其中。

📖 白话译文 ​

物卦起例
后天端法的规则：以所见之物取上卦，以物所在的方位取下卦，将物卦之数与方位卦之数相加，再加上当时的时辰数，用来取动爻。

八卦方位
离卦在南，坎卦在北，震卦在东，兑卦在西，人居于中央。

🧭 义理解析 ​

一、端法：后天起卦的核心公式 ​

plain
上卦 = 所见之物（属何卦）
下卦 = 物所在方位（属何卦）
动爻 = （物卦数 + 方位卦数 + 时辰数）÷ 6，取余数

这是后天起卦最基本的公式，后面所有的「老人忧色」「牛鸣」「鸡鸣」「枯枝坠地」，都是这个公式的应用。

先天 vs 后天，再次对比：

先天后天（端法）
触发数字（年月日时·字画·物数）象（人·动物·外物·方位）
上卦来源数字除八取余所见之物属何卦
下卦来源总数加时除八取余物所在方位属何卦
动爻总数除六取余（物卦数+方位数+时数）除六取余

二、八卦万物属类：象的词典 ​

这张表是全书最重要的工具之一，但它不是用来「背」的，是用来「感受」的。

每一卦的象，都有一个内在的逻辑：

乾（天·金·圆·刚）
天是最高的，父是最尊的，头是最上的，圆是最完整的，金是最刚的——乾的象，是高、尊、刚、圆、完整。

坤（地·土·方·柔）
地是承载一切的，母是养育一切的，腹是容纳一切的，方物是稳定的，黍稷是养人的——坤的象，是承载、包容、滋养、稳定。

震（雷·木·动·发）
雷是震动的，长男是冲动的，足是行走的，发是生长的，龙是腾跃的——震的象，是动、发、冲、生。

巽（风·木·入·顺）
风是渗透的，长女是顺从的，鸡是报晓的，绳是绑缚的，扇是引导气流的——巽的象，是渗透、顺入、引导、延伸。

坎（水·险·陷·藏）
水是流动险陷的，盗是隐藏的，桎梏是束缚的，有核之物是外柔内藏的——坎的象，是险、陷、隐、藏。

离（火·日·明·文）
火是明亮的，日是照耀的，文书是有纹理的，甲胄是有纹饰的，有壳之物是外硬内空的——离的象，是明、文、纹、外刚内空。

艮（山·止·土·小）
山是静止的，少男是稚嫩的，门阙是阻隔的，径路是通道的，鼠是小而藏的——艮的象，是止、阻、小、藏于土中。

兑（泽·金·口·缺）
泽是有缺口的，少女是喜悦的，舌是说话的，毁折之物是有缺损的，带口之器是开口的——兑的象，是口、悦、缺、开。

三、方位图：八卦的空间坐标 ​

plain
      离（南·火）
        ↑
震（东·木）← 人 → 兑（西·金）
        ↓
      坎（北·水）

四正位：离南、坎北、震东、兑西
四隅位：巽东南、乾西北、坤西南、艮东北

「人则介乎其中」——这句话意味深长。八卦是宇宙的坐标系，人居中央，是观察者，也是被观察者。这与观卦的「观我生」是同一个意思。

🌀 象的感悟 ​

读这张万物属类表，有一个感受越来越清晰：

邵雍不是在分类，是在感受同频。

为什么老人属乾？因为老人和天一样——高远、历经、刚健、不可撼动。
为什么少女属兑？因为少女和泽一样——喜悦、开口、柔软、有缺口（未完成）。
为什么盗属坎？因为盗和水一样——隐藏、流动、险陷、从暗处渗入。

这不是规定，是感受到了同一种象。

学这张表，不是记「鸡=巽」，而是感受：鸡为什么像风？
鸡报晓——它是第一个感知到天光的，它把消息传出去，像风一样渗透进黑暗，唤醒沉睡的世界。鸡的鸣叫，是一种「入」，是一种「顺势而发」。这是巽的象。

感受到了，就再也不会忘。

📌 小结·物卦起例与万物属类 ​

  • 端法公式：物为上卦，方位为下卦，（物数+方位数+时数）÷6取余为动爻
  • 万物属类：不是分类表，是象的感受词典
  • 方位：离南坎北震东兑西，人居中央
  • 核心：每一卦的象，都有内在逻辑，感受比记忆更重要

▎观梅占（先天·年月日时起卦） ​

触发：辰年十二月十七日申时，见二雀争枝坠地

起卦过程：

plain
辰年  = 5（辰为地支第五位）
十二月 = 12
十七日 = 17
小计   = 34 ÷ 8 = 4余2 → 上卦：兑（二）

加申时 = 9（申为地支第九位）
总计   = 43 ÷ 8 = 5余3 → 下卦：离（三）

动爻   = 43 ÷ 6 = 7余1 → 初爻动

本卦：泽火革 ䷰
变卦：初爻动，兑初爻阳变阴 → 泽山咸（变）
互卦：二三四爻为离，三四五爻为乾 → 互见乾巽

⚠️ 原文说「初爻变咸，互见干巽」——互卦应为离与乾，原文写「干巽」，
此处存疑，标记 ❓-004，待卷三变卦式章节核对。

断卦逻辑：

plain
体卦：兑（金）
用卦：离（火）→ 火克金，用克体，凶

互卦：巽木 → 巽生离火，助克体之势更盛
互卦：乾金 → 乾克巽木（金克木）→ 巽被克

巽为股 → 巽被克 → 伤股之应
兑为少女 → 女子被伤

变卦：艮土 → 土生金（兑）→ 有救，不至于死

结果：次日傍晚，邻家女子折花，失惊坠地，伤股。

关键句：「不动不占，不因事不占。」——这是邵雍的占卜原则，不是随时随地都占，是有感而发，象动了才占。

▎牡丹占（先天·年月日时起卦） ​

触发：客问「花盛如此，亦有数乎？」——因问而占

起卦过程：

plain
巳年  = 6（巳为地支第六位）
三月  = 3
十六日 = 16
小计  = 25 ÷ 8 = 3余1 → 上卦：乾（一）

加卯时 = 4
总计  = 29 ÷ 8 = 3余5 → 下卦：巽（五）

动爻  = 29 ÷ 6 = 4余5 → 第五爻动

本卦：天风姤 ䷫
变卦：九五阳变阴 → 火风鼎
互卦：二三四爻为巽，三四五爻为乾 → 互见重乾

断卦逻辑：

plain
体卦：巽（木）
用卦：乾（金）→ 金克木，用克体，凶
互卦：重乾（金）→ 克体之势极盛，卦中无生意

乾为马 → 马所践毁
五爻动 → 午时（五爻对应午时，离明之象）

结果：次日午时，贵官二马相啮，践毁牡丹。

关键句：「莫不有数。且因问而可占矣。」——万物皆有数，有触动就可以占。

▎邻夜叩门借物占（后天·声音起卦） ​

触发：冬夕酉时，先扣一声，再扣五声，说借物

起卦过程：

plain
一声 = 乾（一）→ 上卦
五声 = 巽（五）→ 下卦

乾一 + 巽五 = 6
加酉时 = 10（酉为地支第十位）
总计 = 16 ÷ 6 = 2余4 → 第四爻动

本卦：天风姤 ䷫
变卦：九四阳变阴 → 天风巽（变）
互卦：重乾

断卦逻辑：

plain
卦中：乾金（三爻）+ 巽木（二爻）→ 金木之物
乾金短，巽木长 → 短金长木之器 → 斧

邵雍子断为「锄」（金短木长亦可）
邵雍校正：夕晚不用锄，必是斧（劈柴之用）

结果：果借斧。

关键句：「推数又须明理，为卜占之切要也。推数不推理，是不得也。」
——这是本节最重要的一句话。数给出范围，理缩小到唯一答案。

▎今日动静如何（先天·字音起卦） ​

触发：客问「今日动静如何」六字

起卦过程：

plain
上卦取「今日动」三字：
  今（平声）= 1，日（入声）= 4，动（去声）= 3
  合计 = 8 → 坤（八）→ 上卦

下卦取「静如何」三字：
  静（去声）= 3，如（平声）= 1，何（平声）= 1
  合计 = 5 → 巽（五）→ 下卦

动爻 = (8+5) ÷ 6 = 2余1 → 初爻动

本卦：地风升 ䷭
变卦：坤初爻阴变阳 → 地天泰
互卦：二三四爻为震，三四五爻为兑

断卦逻辑：

plain
升 → 有升阶宴请之义
互震、兑 → 东西席位之分（有宴席）
兑为口，坤为腹 → 口腹之事（饮食）
坤土独立，无同类 → 客不多
卦中无坎 → 无酒（坎为酒）
坤为黍稷 → 食物简单

结果：当晚果有人相请，客少，酒淡，菜简。

▎西林寺牌额占（先天·字画起卦） ​

触发：见「林」字少两勾，字形有缺

起卦过程：

plain
「西」字 = 7画 → 艮（七）→ 上卦
「林」字（缺两勾）= 8画 → 坤（八）→ 下卦

动爻 = (7+8) ÷ 6 = 2余3 → 第三爻动

本卦：山地剥 ䷖
变卦：第三爻动 → 艮（变）
互卦：重坤

断卦逻辑：

plain
剥 → 群阴剥阳之卦
寺 = 纯阳之所（僧侣）
纯阴之卦居纯阳之所 → 阴人之祸

若添「林」字两勾（10画）：
10 ÷ 8 = 1余2 → 兑（二）→ 下卦变兑
山泽损卦 → 第五爻动 → 中孚
互坤、震 → 用互俱生体 → 吉

结果：询之果有阴人之祸。添勾后，寺无事。

关键洞见：字形即象。「林」字缺两勾，是象的残缺，残缺的象对应残缺的事。改字形，即改象，象变则数变，数变则吉凶变。

▎老人有忧色占（后天·端法） ​

触发：见老人面有忧色，往巽方行

起卦过程：

plain
老人 → 乾（上卦）
巽方 → 巽（下卦）

乾一 + 巽五 = 6
加卯时 = 4（卯为地支第四位）
总计 = 10 ÷ 6 = 1余4 → 第四爻动

本卦：天风姤 ䷫
动爻：九四

断卦逻辑：

plain
爻辞：「包无鱼，起凶。」→ 易辞不吉
体卦：巽（木）
用卦：乾（金）→ 金克木，用克体
互卦：重乾 → 克体之势盛，无生气

时在途行 → 应速
成卦总数10，中分取半 = 5 → 五日内应验

结果：五日内，老人赴席，鱼骨鲠喉而终。

关键句：「行则应速，坐则应迟，立则半迟半速。」——动静决定克应时间。

▎少年有喜色占（后天·端法） ​

触发：见少年从离方来，喜形于色

起卦过程：

plain
少年 → 艮（上卦）
离方 → 离（下卦）

艮七 + 离三 = 10
加午时 = 7（午为地支第七位）
总计 = 17 ÷ 6 = 2余5 → 第五爻动

本卦：山火贲 ䷕
动爻：六五

断卦逻辑：

plain
爻辞：「贲于丘园，束帛戋戋，吝，终吉。」→ 终吉
变卦：贲变家人
互卦：震、坎 → 俱生离（体）
离为体，互变俱生 → 大吉

总数17 → 十七日内应验
束帛 → 聘币之象

结果：十七日内定亲。

▎牛哀鸣占（后天·端法） ​

触发：牛鸣于坎方，声极悲

起卦过程：

plain
牛 → 坤（上卦）
坎方 → 坎（下卦）

坤八 + 坎六 = 14
加午时 = 7
总计 = 21 ÷ 6 = 3余3 → 第三爻动

本卦：地水师 ䷆
动爻：六三

断卦逻辑：

plain
爻辞：「师或舆尸，凶。」→ 易辞凶
体卦：坤（土）
变卦：师变升 → 互坤、震 → 俱克体
无生气

总数21 → 二十一日内应验

结果：二十日后，牛被买去屠杀犒众。

▎鸡悲鸣占（后天·端法） ​

触发：鸡鸣于乾方，声极悲怆

起卦过程：

plain
鸡 → 巽（上卦）
乾方 → 乾（下卦）

巽五 + 乾一 = 6
加卯时 = 4
总计 = 10 ÷ 6 = 1余4 → 第四爻动

本卦：风天小畜 ䷈
动爻：六四

断卦逻辑：

plain
爻辞：「有孚，血去惕出，无咎。」→ 割鸡之义
体卦：乾（金）
互卦：离、兑 → 离火克乾金
巽木离火 → 烹饪之象

总数10 → 十日内应验

结果：十日后，客至，烹鸡。

▎枯枝坠地占（后天·端法） ​

触发：无风，枯枝自坠于兑方

起卦过程：

plain
槁木 → 离（上卦，干燥枯槁属离）
兑方 → 兑（下卦）

离三 + 兑二 = 5
加辰时 = 5（辰为地支第五位）
总计 = 10 ÷ 6 = 1余4 → 第四爻动

本卦：火泽睽 ䷥
动爻：九四
变卦：山泽损
互卦：坎、离

断卦逻辑：

plain
爻辞：「睽孤，遇元夫。」
体卦：兑（金）
用卦：离（火）→ 火克金，用克体
睽、损 → 卦名俱有伤残之义

总数10 → 十日内应验
匠者字「元夫」→ 爻辞克应

结果：十日后，伐树建公榭，工匠恰好字「元夫」。

▎先天后天小结 ​

原文在此处做了明确的分野标注：

「以上并是先得数，以数起卦，所谓先天之数也。」（观梅·牡丹·西林寺额）
「以上诸占例，并是先得卦，以卦起数，所谓后天之数也。」（老人·少年·牛·鸡·枯枝）

这里终于解开了序中的疑点 ❓-001：

触发方式起卦方式称谓
先天数字（年月日时·字画·物数）以数起卦先天之数
后天象（人·动物·方位·外物）以卦起数后天之数

序中两处「故曰后天」，第一处确为笔误，应为「故曰先天」。❓-001 已解。

▎风觉占·鸟占·听声音占·形物占·验色占 ​

这五节是「后天起卦」的延伸，讲的是更细腻的「象的读取方式」。

风觉占——风也是象：

维度内容
方位南风→家人卦，东风→益卦
时令春风发生，夏风长养，秋风肃杀，冬风凛冽
颜色黄祥·青半吉·白主刃·黑凶·赤灾·红紫吉
声势如阵马→斗争，如波涛→惊险，如悲咽→忧虑，如奏乐→喜事

鸟占——鸟的四个维度：

  • 数量（几只）→ 对应卦数
  • 方位（从哪来）→ 对应方位卦
  • 声音（几声·悲喜）→ 对应卦数与吉凶
  • 名义（鸦报灾·鹊报喜·鸾鹤祥瑞）→ 直接取象

听声音占——声音的五行归属：

声音类型属卦
口出之声（人语·动物鸣）兑
木器敲击（鼓·板·木）震
金器之声（钟·磬·铃）乾
火声（烈焰·爆竹）离
土声（筑基·山崩）坤

形物占——物的形状即象：

形状属卦
圆乾
刚·破缺兑
方坤
柔·长·直巽
仰震
覆艮
中刚外柔坎
内柔外刚·有文彩·干燥离

验色占——颜色即象：
青→震，红紫赤→离，黄→坤，白→兑，黑→坎

🌀 象的感悟 ​

「推数又须明理」 ​

这是邵雍借叫斧那个案例，亲口说出的最重要的话。

他儿子断出「金短木长之器」，答了「锄」，数上没错。邵雍说：不对，是斧。

为什么？夕晚不用锄，必借斧。

数给出了一个范围——金木之器。但范围里有很多东西：斧、锄、镰、锯……数到这里就停了。

然后理来了——此时此刻，冬夕，拥炉，邻人来借。冬夕能用什么？劈柴取暖，当然是斧。

数是地图，理是脚。 地图告诉你这片区域有什么，但你要用脚走进去，才能找到那个具体的东西。

这个原则，贯穿全书。后面每一个断卦，都是数和理的配合。

象无处不在 ​

这一节最让我震动的，是风觉占和鸟占。

风的颜色可以占，风的声势可以占，鸟的数量可以占，鸟的名字可以占……

邵雍的世界里，没有一样东西是「无意义的背景」。每一阵风，每一只鸟，每一声鸣叫，都是宇宙在说话。

这不是迷信，这是一种极度专注的感知状态——当你真的静下来，万物都在传递信息。

序里说「心致而目玩」，就是这种状态。心到了，眼睛才能看见那些平时被忽略的象。

📌 小结 ​

本节关键词

  • 端法：物为上卦，方位为下卦，合数取爻
  • 先天：数→卦；后天：卦→数（❓-001已解）
  • 「不动不占，不因事不占」：有感而发，象动才占
  • 「推数又须明理」：数定范围，理定唯一
  • 动静决定克应速度：行速·坐迟·立中
  • 万物皆象：风·鸟·声·色·形，无一不可起卦

规律提炼

  1. 所有案例的断卦，都遵循同一个框架：体用生克 → 爻辞 → 互变 → 克应时间
  2. 爻辞是重要参考，但不是唯一依据——卦象理气要综合判断
  3. 克应时间 = 成卦总数（行则减半，坐则加倍，立则原数）

❓ 存疑 ​

❓****-001：已解。序中第一处「故曰后天」确为笔误，应为「故曰先天」。

❓****-004：观梅占原文「初爻变咸，互见干巽」——泽火革互卦，二三四爻为离，三四五爻为乾，应为「互见乾离」，原文写「干巽」疑有误。待卷三变卦式章节核对。

❓****-005：老人忧色占，原文「谓老人虫」，「虫」字疑为「曰」字之误，传抄有误。

❓****-006：各案例中，克应时间的计算方式不完全统一——观梅用「次晚」（近乎即时），牛鸣用「二十一日」（成卦总数），老人用「五日」（总数中分取半，因在途行）。这三种处理方式的选择逻辑，待卷二「克应之诀」章节系统梳理。

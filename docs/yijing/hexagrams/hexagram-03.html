屯卦

第三卦·水雷屯——刚柔始交，动乎险中，万物初生，草昧未开。

hexagram《周易》
北
水
zhūn屯
卦象上坎下震，水雷屯

卦辞屯，元亨利贞。勿用有攸往，利建侯。

引读雷在水下，欲动未动；万物初生，草昧未开，险阻在前而生机在内。

象传 ​

云雷，屯。君子以经纶。

云雷交作、尚未成雨，正是屯聚未通之象；君子由此悟到，要在混乱中理出头绪、织出秩序。

「经纶」二字——经是整理丝线、理顺经络；纶是编织、系统化。经纶，就是把混乱的丝线一根一根理顺，织成有用之物。

分形结构：

  • 经纶（丝线）→ 微观：理顺思路，整理认知
  • 磐桓（磐石/桓柱）→ 宏观：稳固根基，建立体系

磐桓不过是大些的经纶。经纶理顺，思路清；磐桓理清，侯自然立。建侯不是冲出来的，是理出来的。

彖传 ​

屯，刚柔始交而难生，动乎险中，大亨贞。雷雨之动满盈，天造草昧，宜建侯而不宁。

逐句释义：

  • 刚柔始交而难生 —— 阴阳刚柔刚开始交合，困难由此而生。这是屯的本质：初生必遇难。
  • 动乎险中，大亨贞 —— 在险境中运动，正是屯的处境；但根本上是亨通的，只要守正。
  • 雷雨之动满盈，天造草昧 —— 雷雨交作、充盈天地，天地造化本就从混沌草昧开始。
  • 宜建侯而不宁 —— 应当建立根基，而不是急于安定。扎根，是屯卦给出的唯一正解。

草昧哲学：草昧不是障碍，是历练的场。被动承受屯，屯在磨你；主动迎接屯，你在用屯。

六爻 ​

初九
爻辞

，利，利。

今释

被大石压住、被柱子困住，看似动弹不得，却利于安居守正、建立根基。

象曰

虽，也。，大得民也。

今释

虽然受困于磐桓，但志向行为端正；以尊贵之身甘居卑下，所以大得民心。

六二
爻辞

屯如如，乘马。，女子不，十年乃。

今释

进退两难、原地打转，看似来犯其实求合；守正而不结果，十年后才开花。

象曰

六二之难，也。十年乃，也。

今释

六二的困难，是因为凌乘于阳刚之上；十年才结果，是反于常道的长久守正。

六三
爻辞

无，惟入于林中，君子不如，往。

今释

追逐猎物却没有向导，只会迷失林中；君子见机，不如放弃，贸然前往会有憾惜。

象曰

无，也。君子之，往穷也。

今释

没有向导就追鹿，是只凭欲望追逐禽兽；君子舍去，是因为前往必至困穷。

六四
爻辞

乘马，求，往吉，无不利。

今释

骑马原地踏步，但这次是主动寻求合道的连结；去，就吉祥，无不利。

象曰

求而往，明也。

今释

主动求合而前往，是明于时势的智慧。

九五
爻辞

屯其，小吉，大凶。

今释

把精华囤积起来发不出去；做小事守正吉，想做大而膏不通，凶。

象曰

屯其，也。

今释

膏泽囤积，是因为恩泽尚未能广泛施展。

上六
爻辞

乘马，。

今释

骑着马原地踏步，哭到流出血泪。

象曰

，也。

今释

哭到血泪涟涟，这样的处境怎么能长久呢。

六爻详解 ​

初九 · 磐桓，利居贞，利建侯 ​

  • 磐 → 大石，厚重，稳固
  • 桓 → 木 + 亘，连绵不断、永久竖立的木柱
  • 磐桓 → 被大石压住，被柱子困住，动弹不得

但「利居贞、利建侯」——利于安居守正，利于建立根基。

以贵下贱：初九是阳爻，居卦之初，本是贵的，却甘居低位，不急于冲出。道本是贵的，但它下贱——流到最低处，让普通人都能发现并运用。不是用价值换流量，是因为合道，所以自然聚人。

核心洞见：磐石与桓柱不是障碍，而是被迫扎根的定海神针。被压住的时候，正是扎根最深的时候。

六二 · 屯如邅如，乘马班如。匪寇婚媾，女子贞不字，十年乃字 ​

  • 屯如邅如 → 进退两难，原地打转
  • 乘马班如 → 骑着马，却原地踏步
  • 匪寇，婚媾 → 看似是敌人，其实是在等待合适的连结
  • 女子贞不字 → 守正而不开花结果
  • 十年乃字 → 十年之后，终于开花结果

乘刚三层结构：大势之刚（时代浪潮的压力）、家庭之刚（责任与现实的压力）、内心之刚（不甘被困的觉察与挣扎）。

「十年乃字」的意义：「反常也」——能长期守正本身就是非凡。那段停滞不是失败，是在等一个「合」的时机。

不悔观：没有革竹七日，就没有龙场悟道。人生不是审判，是体验。来路的每一步，都是现在的根基。

六三 · 即鹿无虞，惟入于林中。君子几不如舍，往吝 ​

  • 即鹿 → 追逐猎物（机会）
  • 无虞 → 没有向导（虞人）
  • 惟入于林中 → 只会迷失在树林里
  • 君子几，不如舍 → 君子看到苗头，不如放弃
  • 往吝 → 贸然前往，会有遗憾

核心逻辑：没有向导就贸然追逐，只会迷失。虞不是天生的，虞是屯出来的——屯的人不是在等，是在练。

六二教守，六三教辨。守住了，还要辨清哪头鹿值得追。

六四 · 乘马班如，求婚媾。往，吉；无不利 ​

第二次「乘马班如」，但这次是主动寻求合道的连结。「往吉，无不利」——去，就吉祥。

六二 vs 六四——同象异命：六二是被动、被压（乘刚），不知往哪走；六四是主动，知道方向，正在调头求合。

「婚媾」的四个维度：人（同道者、合伙人）、方向（对的赛道）、时机（对的入场时机）、确认（内心的准备）。

体用之辨：体不厚，用出去是散的；体厚了，用出去是聚的。临界点不是等到客观指标达到，而是等到内心自然生出「想求」的冲动。

九五 · 屯其膏，小贞吉，大贞凶 ​

  • 屯其膏 → 把最精华的东西（膏）囤积起来，发不出去
  • 小贞吉 → 做小范围的事，吉
  • 大贞凶 → 想做大事，但膏发不出去，凶

六五的处境：阴爻居君位（不得位），上无援、下无应，孤立的君，膏流不下去。

小贞吉的活法：边积累，边流通；不等完美，先发出去。文章博客是通道——写是整理地形，发是测试回响，回响是地图。

大贞凶的陷阱：膏还没流通成熟，就想一步到位。大的要等膏真正流通之后，自然而然地大。

上六 · 乘马班如，泣血涟如 ​

第三次「乘马班如」，哭到流血、泪如涟漪。

三次「乘马班如」对照：

爻位状态结局
六二等（乘刚被压）十年乃字，有出路
六四动（主动求合）往吉无不利，有出路
上六困（进退不能）泣血涟如，无出路

上六居卦之终，下无应，既不能前、又不能退，困在屯的最深处。它不是突然跌进去的，是一点一点滑进去的——每一天都是「乘马班如」，每一天都觉得还好，直到泣血涟如。

上六警示：不自知，才是上六真正的入口。度不是靠控，是靠觉。知道自己在哪，就是最好的度。

【解读层】三问解读 ​

象：这一卦在说什么 ​

屯卦讲的是万物初生之难。上坎（水、险）压着下震（雷、动），雷想冲出来，水压着它——生机在内，却处处受阻。

卦辞「元亨，利贞，勿用有攸往，利建侯」点明：根本上是亨通的，但要守正、不冒进、先扎根。

理：为什么这一卦重要 ​

屯不是叫你放弃，是叫你扎根；不是消极等待，是积极建立根基。能量不要消耗在冲动上，要转化为「根基」。

草昧不是障碍，是历练的场。被动承受屯，屯在磨你；主动迎接屯，你在用屯。

用：今天如何应用 ​

  1. 先守正：磐桓不是坏事，是扎根的定海神针
  2. 再辨清：没有向导（虞）时，不如舍，先练成有虞之人
  3. 养体待发：体不厚，用出去是散的
  4. 让膏流通：边积累边输出，细水长流

核心洞见：

  1. 草昧哲学——草昧不是障碍，是历练的场
  2. 经纶与磐桓的分形——磐桓不过是大些的经纶
  3. 以贵下贱——道下贱流到最低处，是因为合道所以自然聚人
  4. 不悔观——人生不是审判，是体验
  5. 虞是屯出来的——屯的人不是在等，是在练
  6. 体用之辨——体厚了，用出去是聚的
  7. 膏要流通——志越大而膏越堵，越凶
  8. 上六的警示——不自知，才是真正的入口

【解读层】我的理解 ​

屯卦对处境的自我定位，六个爻像一条成长的时间线：

  • 初九 → 已做到：磐桓扎根，以贵下贱，甘居低位
  • 六二 → 已经历：长期停滞，外力打破，走出来了
  • 六三 → 现在主体：即鹿无虞，在观察，没有深追
  • 六四 → 前夜：临界点还没到，体在养，用未发
  • 六五 → 部分到：膏在流通（文章博客），但求未发
  • 上六 → 警示已知：自知了，门已窄

两次「乘马班如」的本质区别：第一次是不自知，被外力打破；第二次是自知了，用内力觉察。上六的门，对自知的人，已经窄了很多。

关联 ​

  • 相关卦象：乾（第一卦）、坤（第二卦）、蒙（第四卦）
  • 屯与蒙的连结：屯而后蒙——草昧之后，是启蒙；根扎稳了，才能真正开始学。蒙卦卦辞「匪我求童蒙，童蒙求我」——不是我去找学生，是学生来找我。

礼记

儒家五经之一：礼制的义理与生活细节，四十九篇，《大学》《中庸》即出其中。

导读《礼记》

礼记 ​

《礼记》是「三礼」（《仪礼》《周礼》《礼记》）之一，由汉儒戴圣编定（故又称《小戴礼记》），四十九篇。它不是礼制的条文，而是对礼的解释、讨论与发挥——一部关于「为什么这样行礼」的文集。

是什么 ​

  • 性质：《仪礼》记「怎么做」，《礼记》说明「为什么」。所以它更近于礼学的义理与哲学。
  • 内容跨度极大：有制度（王制、月令）、有礼节（曲礼、少仪、内则）、有丧祭专论（檀弓、丧服小记、祭义）、有教育（学记）、有音乐（乐记）、有政治哲学（礼运）、有心性之学（大学、中庸）。
  • 四书中的两部出在这里：《大学》是第四十二篇，《中庸》是第三十一篇——朱熹把它们抽出来独立成书。

为什么重要 ​

  • 「礼」的义理在这一部里说透了：礼不是繁文缛节，而是「自卑而尊人」的社会语法；「礼也者，理之不可易者也」。
  • 《礼运》给了一个理想社会图景：「大道之行也，天下为公」——大同与小康之说，影响深远。
  • 《学记》是中国最早的教育学专论：「教学相长」「藏焉修焉，息焉游焉」皆出此。
  • 《乐记》是中国音乐美学的主干文献：「乐者，天地之和也」。
  • 《檀弓》记孔门丧礼与言行，是《论语》之外最重要的孔门材料。

怎么读 ​

  1. 先读《学记》《礼运》《乐记》三篇——一篇教育、一篇政治理想、一篇艺术论，最能见《礼记》的思想面貌；
  2. 再读《大学》《中庸》（本栏目已独立成篇），知道它们在《礼记》中的位置；
  3. 《曲礼》《少仪》《内则》 看日常生活的礼——饮食、应对、进退的细密规矩；
  4. 《檀弓》 读故事：孔门丧礼中的言行，文字极好；
  5. 注本：可参考孙希旦《礼记集解》、王梦鸥《礼记今注今译》。
